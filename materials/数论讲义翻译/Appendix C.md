## C.1 Vector Spaces

## Definition C.1.1 (Vector Space)

A vector space V over a field K, also called a K-vector space, is a set where you can add elements of V and also mutliply them by elements of K. More specifically, we have the following axioms. 

1. associativity of addition: $( u + v ) + w = u + ( v + w )$ for any $u , v , w \in V .$ 

2. commutativity of addition: $u + v = v + u$ for any $u , v \in V .$ 

3. identity of addition: there is a $0 _ { V } \in V$ such that $u + 0 _ { V } = 0 _ { V } + u$ for any $u \in V .$ 

4. compatibility of multiplication: $( a b ) v = a ( b v )$ for any $a , b \in K$ and $v \in V .$ 

5. identity of multiplication: $1 _ { K } v = v$ for any $v \in V \ ( 1 _ { K }$ is the identity of K). 

6. disitributy of multiplication: $a ( u + v ) = a u + a v$ and $u ( a + b ) = u a + u b$ for any $a , b \in K$ and $u , v \in V .$ 

The elements of the base field K are called scalars (and the elements of V vectors, although we won’t use this termniology much). 

These axioms are again all very obvious and you don’t need to try to remember them, they are exactly the properties which let us establish the next propositions (that’s why we defined it like that) so you just need to focus on what’s next. As an example of vector spaces one can take the K-vector space K, the K-vector space $K ^ { n }$ with componentwise addition and multiplication (these are regular vectors), $\mathbb { Z } / p ^ { n } \mathbb { Z }$ as a $\mathbb { F } _ { p } .$ -vector space, and as a final more elaborate example the R-vector space of functions $f : \mathbb { R } \to \mathbb { R }$ such that $f ( 0 ) = 0$ (it’s closed under addition). 

When the base field is obvious from context or does not matter, we will drop the K. 

## Definition C.1.2 (Linear Independence)

We say elements $u _ { 1 } , \ldots , u _ { n }$ of a K-vector space V are linearly independent if no non-trivial linear combination of them is zero, i.e. $\textstyle \sum _ { i } a _ { i } u _ { i } = 0$ for $a _ { i } \in K$ implies $a _ { i } = 0$ for all i. Otherwise, we say they are linearly dependent. 

For instance, the vectors $( 1 , 0 )$ and $( 0 , 1 )$ are linearly independent but the vectors (1, 0), (0, 1) and (1, 1) aren’t because $( 1 , 0 ) + ( 0 , 1 ) - ( 1 , 1 ) = 0$

## Definition C.1.3 (Bases)

A K-basis of a K-vector space V is a family of linearly independent elements $( e _ { i } ) _ { i \in I }$ such that they span all of V: any element of V is a unique linear combination $\sum _ { i } a _ { i } e _ { i }$ for some $a _ { i } \in K$ (all but finitely many zero so that the sum makes sense). 

The most common basis of $\mathbb { R } ^ { n }$ for instance is family set of unit vectors 

$$
(1, 0 \dots , 0), (0, 1, \dots , 0), \dots , (0, \dots , 0, 1).
$$

The next proposition says that the cardinality of a basis (if there is one) does not depend on the basis, but only on the vector space. But first, here is an application (even though we have only made definitions!). When the base field K is obvious, we will drop the K and simply say "basis" and "vector space". 

## Problem C.1.1

There are 2n + 1 cows such that, whenever one exludes one of them, the rest can be divided into two groups of size n such that the sum of the weights of the cows in each group is the same. Prove that all cows have the same weight. 

## Solution

Let $w _ { i }$ be the weight of the ith cow. First, we solve the problem by induction when the weights are in Z: if $\begin{array} { r } { \sum _ { i \in I _ { k } } w _ { i } = \sum _ { i \notin I _ { k } , i \neq k } w _ { i } } \end{array}$ then 

$$
\sum_ {i = 1} ^ {2 n + 1} w _ {i} = w _ {k} + \sum_ {i \in I _ {k}} w _ {i} + \sum_ {i \not \in I _ {k}, i \neq k} w _ {i} \equiv w _ {k} \pmod {2}
$$

so all weights have the same parity. If they are all even divide them by 2 and get a smaller solution (unless they are all equal to 0 in which case they are indeed equal), otherwise add 1 to all of them and divide them by 2; this yields another solution as the groups have the same size by assumption. 

Now solve the problem over Q: just multiply the weights by the lcm of the denominators to get weights in Z and we have already solved that case. 

Finally, let’s do the general case: $w _ { i } \in \mathbb { R }$ . Consider the Q-vector space generated by the weights: $V = w _ { 1 } \mathbb { Q } + \ldots + w _ { 2 n + 1 } \mathbb { Q } .$ . Find a basis of V like this: pick any maximal subset of weights which are linearly independent $( w _ { i } ) _ { i \in I } .$ . Indeed, any other weight $w _ { k }$ can be represented as a linear combination of $( w _ { i } ) _ { i \in I }$ since there is a linear combination 

$$
a w _ {k} + \sum_ {i \in I} a _ {i} w _ {i} = 0
$$

as $( w _ { k } ) \cup ( w _ { i } ) _ { i \in I }$ is linearly dependent by assumption, so 

$$
w _ {k} = \sum_ {i \in I} \frac {- a _ {i}}{a} w _ {i}
$$

as $a \neq 0$ (otherwise $( w _ { i } ) _ { i \in I }$ are linearly dependent). 

Thus, we have found a basis $e _ { 1 } , \ldots , e _ { m }$ of V. To finish, write each $w _ { i }$ as $\sum _ { j } a _ { j , i } e _ { j }$ . We shall prove that $a _ { j , 1 } , a _ { j , 2 } , \dotsc , a _ { j , 2 n + 1 }$ satisfy the same conditions as the $w _ { i }$ (you can partition them into two groups of same sum and same size when you remove any one of them) for any j. Since they are in $\mathbb { Q } ,$ by our prevous step this implies that they are all equal and thus the weights $w _ { i }$ are also all equal. This is however very easy: if $\begin{array} { r } { \sum _ { i \in I } w _ { i } = \sum _ { i \in I ^ { \prime } } w _ { i } } \end{array}$ then 

$$
\sum_ {j} e _ {j} \sum_ {i \in I} a _ {j, i} = \sum_ {j} e _ {j} \sum_ {i \in I ^ {\prime}} a _ {j, i}
$$

so $\textstyle \sum _ { i \in I } a _ { j , i } = \sum _ { i \in I ^ { \prime } } a _ { j , i }$ by definition of a basis. We are done. 

Now, we prove that any basis has the same cardinality if there exists a finite one. In that case we say the vector space is finite-dimensional. Unless otherwise stated, we will always work in the finite-dimensional case. 

## Proposition C.1.1 (Dimension)

Suppose $e _ { 1 } , \ldots , e _ { n }$ is a basis of a vector space $V .$ Then, any basis of $V$ has cardinality $n .$ This n is called the dimension of V and written dim $\mathfrak { l } _ { K } V .$ 

In fact we prove more. 

## Proposition C.1.2

Suppose $u _ { 1 } , \ldots , u _ { n }$ are linearly independent elements of $V$ and $v _ { 1 } , \ldots , v _ { m }$ span all of $V .$ Then $m \geq n$ 

Since bases satisfy both of these conditions, we get $n \geq m$ and $m \geq n { \mathrm { ~ s o ~ } } m = n$ for any bases of cardinality m and n. 

## Proof

We prove the contraposite: if $n > m$ then $u _ { 1 } , \ldots , u _ { n }$ are linearly dependent. Write $\textstyle u _ { j } = \sum _ { i } a _ { i , j } v _ { i }$ with $a _ { i , j } \in K .$ . We proceed by induction on m (when $m = 1$ it is obvious). 

Pick an $a _ { i , j } \neq 0$ , this is possible otherwise all $u _ { i }$ are zero so in particular linearly dependent; without loss of generality assume $i = j = 1$ . We will get rid of $u _ { i }$ and $v _ { j }$ for our induction. To do so, consider the family of vectors 

$$
u _ {1}, u _ {2} - \frac {a _ {1 , 2}}{a _ {1 , 1}} u _ {1}, u _ {3} - \frac {a _ {1 , 3}}{a _ {1 , 1}} u _ {1}, \dots , u _ {n} - \frac {a _ {1 , n}}{a _ {1 , 1}} u _ {1}.
$$

Clearly, these are linearly independent since you can recover $u _ { 1 } , \ldots , u _ { n }$ from them. Also, 

$$
u _ {j} - \frac {a _ {1 , j}}{a _ {1 , 1}} u _ {1} = \sum_ {j \geq 2} (a _ {i, j} - a _ {1, i} a _ {1, i} / a _ {1, 1}) v _ {i}
$$

has no coordinate in $v _ { 1 }$ . Thus by our induction hypothesis $( \mathrm { e . g . }$ on $V ^ { \prime }$ the space generated by $v _ { 2 } , \ldots , v _ { m } ) \ u _ { 2 } , \ldots , u _ { n }$ are linearly dependent and we are done. (This idea of getting rid of coordinates will be used again in the proof of Theorem C.3.1, which states that the determinant of linearly independent vectors is non-zero.) 

## Problem C.1.2

Let $f , g \in \mathbb { R } [ X ]$ be two non-constant polynomials. Prove that there is an $h \in \mathbb { R } [ X ]$ such that $f h$ is a polynomial in g. 

## Solution

This amounts to saying that some multiple of $f$ is a polynomial in g. Let $n = \deg f .$ We work in $\mathbb { R } [ X ] / f \mathbb { R } [ X ] .$ , i.e. $\mathbb { R } [ X ]$ modulo $f .$ This an R-vector space of dimension n as $( 1 , \bar { X } , \ldots , X ^ { n - 1 } )$ is a basis. 

Now consider the $n + 1$ elements $1 , g , g ^ { 2 } , \ldots , g ^ { n }$ , where $g ^ { k }$ denotes the kth iterate of $g .$ Since this family has more elements than the dimension of the vector space, they are linearly dependent: we get 

$$
\sum_ {i} a _ {i} g ^ {i} \equiv 0 \pmod {f}
$$

for some not all zero $a _ { i } \in \mathbb { R } .$ . This constitutes the wanted multiple of $f .$ 

## Remark C.1.1

As this solution shows, the problem is extremely flexible. For instance, for any infinite set of non-negative integers S (e.g. the set of primes), f has a multiple whose non-zero monomials have the form $X ^ { s }$ for some $s \in S$ 

A final important result on basis, that we already saw in the proof of Problem C.1.1, is that we can always complete a family of linearly independent vectors to get a basis. 

## Proposition C.1.3

Any family of linearly independent vectors of a finite-dimensional vector space V can be completed into a basis by adding elements to it, and from any generating family we can extract a basis.

## Proposition C.1.4

Suppose F is a field with q elements. Then there is some prime p and an integer n such that $q = p ^ { n }$ 

## Proof

The key is to consider F as a vector space over $\mathbb { F } _ { p } .$ where p is the characteristic of F. Indeed, the characteristic c is a prime, since if $0 = c = a b$ then either a or b must be zero too which means $a = c$ or $b = c$ by minimality of c. 

Now F is a $\mathbb { F } _ { p } .$ -vector space in the obvious way: just define $n x = \underbrace { x + \ldots + x } _ { n { \mathrm { ~ t i m e s } } }$ (technically that’s 

what we did before with the characteristic too) and this is compatible with $\mathbb { F } _ { p }$ as $p = 0$ in $F .$ 

Since F is finite, it is also finite-dimension as a vector space: let $e _ { 1 } , \ldots , e _ { n }$ be a basis (there exists one by Proposition C.1.3). Then, every element of $F$ can be written in a unique way as 

$$
\sum_ {i = 1} ^ {n} a _ {i} e _ {i}
$$

for some $a _ { i } \in \mathbb { F } _ { p }$ . There are exactly $p ^ { n }$ tuples $( a _ { 1 } , \ldots , a _ { n } ) \in \mathbb { F } _ { p } ,$ so $q = p ^ { n }$ as wanted. 

## C.2 Linear Maps and Matrices

In this section, we consider morphisms of vector spaces which are called linear maps, or linear transformations.<sup>1</sup> 

## Definition C.2.1 (Linear Maps)

Let U and V be two K-vector spaces. A linear map $\varphi : U \to V$ is a function which is additive and homogeneous, i.e. $\varphi ( x + y ) = \varphi ( x ) + \varphi ( y )$ and $\varphi ( \lambda x ) = \lambda \varphi ( x )$ for any x, $y \in U$ and $\lambda \in K$ 

For instance, the derivative map $f \mapsto f ^ { \prime }$ is a linear map from $K [ X ]$ to itself (as K-vector spaces). 

There is a very simple characterisation of linear maps $U \to V$ . Let $u _ { 1 } , \ldots , u _ { m }$ be a basis of U and $v _ { 1 } , \ldots , v _ { n }$ of $V .$ . Write 

$$
\varphi (u _ {j}) = \sum_ {i} a _ {i, j} v _ {i}
$$

for $j = 1 , \dots , m$ . Then $f$ is uniquely defined from these $a _ { i , j }$ , and any system of $a _ { i , j }$ gives rise to a linear map $U  V$ : if $\begin{array} { r } { x = \sum _ { j } b _ { j } u _ { j } } \end{array}$ then 

$$
\varphi (x) = \sum_ {i, j} b _ {j} a _ {i, j} v _ {i}.
$$

Note in particular that this shows that the structure of finite-dimensional vector spaces is more or less trivial: a vector space of dimension n is isomorphic to $K ^ { n }$ . However, the profoundness of linear algebra lies precisely in what these isomorphisms are. 

## Remark C.2.1

When $K = \mathbb { Q }$ , the Q-linear maps are precisely the additive maps. Indeed, it follows from additivity that $\varphi ( n x ) = n \varphi ( x )$ for $n \in \mathbb { Z } .$ which implies that 

$$
\varphi \left(\frac {m}{n} x\right) = \frac {\varphi (m x)}{n} = \frac {m}{n} \varphi (x).
$$

Additive functions are also called functions satisfying the "Cauchy equation" $\dot { { \mathbf { \varphi } } } ( \varphi ( x + y ) = \varphi ( x ) + { \mathbf { \varphi } }$ $\varphi ( y ) )$ . This explains why this equation is unsolvable over R: R is an infinite-dimensional Qvector space, so there are a lot of solutions: "just" pick a basis $( u _ { i } ) _ { i \in I }$ of R and send $u _ { i }$ wherever you want. (It is however impossible, in the general case, to prove the existence of a basis of an infinite-dimensional vector space without the axiom of choice.) 

Let us now comment a bit our proof of Lagrange’s interpolation theorem A.1.2. What we did was consider the canonical basis $e _ { 1 } , \ldots , e _ { n + 1 }$ where $e _ { i }$ has a 1 in the ith position and zeros everywhere else of the space $K ^ { n + 1 }$ consisting of vectors $\left( b _ { 1 } , \ldots , b _ { n + 1 } \right)$ . Then, for each element of this basis, we found polynomials $f _ { i }$ such that 

$$
(f _ {i} (a _ {1}), \dots , f _ {i} (a _ {n})) = e _ {i}.
$$

Finally, we get the wanted result by taking linear combinations of these $f _ { i }$ since $e _ { 1 } , \ldots , e _ { n + 1 }$ is a basis. 

We come back to more abstract considerations. Given the bases $\boldsymbol { B } \ : = \ : ( u _ { 1 } , \ldots , u _ { m } )$ and ${ \mathcal { C } } =$ $( v _ { 1 } , \ldots , v _ { n } )$ , we denote the linear map $\varphi$ in matrix form relative to the bases B and C by 

$$
M _ {\mathcal {B}} ^ {\mathcal {C}} (\varphi) = \left[ \begin{array}{c c c c} a _ {1, 1} & a _ {1, 2} & \dots & a _ {1, n} \\ a _ {2, 1} & a _ {2, 2} & \dots & a _ {2, n} \\ \vdots & \vdots & \ddots & \vdots \\ a _ {m, 1} & a _ {m, 2} & \dots & a _ {m, n} \end{array} \right].
$$

Note that we have used the index $j$ for elements of the domain, and the index i for the codomain. This means that, to get the matrix of $\varphi _ { \mathrm { i } }$ we represent $\varphi ( u _ { 1 } ) , \ldots , \varphi ( u _ { m } )$ by column vectors: 

$$
\left[ \begin{array}{c} a _ {1, 1} \\ a _ {2, 1} \\ \vdots \\ a _ {m, 1} \end{array} \right], \dots , \left[ \begin{array}{c} a _ {1, n} \\ a _ {2, n} \\ \vdots \\ a _ {m, n} \end{array} \right]
$$

and then piece them together. 

## Definition C.2.2 (Matrices)

An $m \times n$ matrix is a family $( a _ { i , j } ) _ { i , j \in [ m ] \times [ n ] }$ which is denoted by $\left[ \begin{array} { c c c } { a _ { 1 , 1 } } & { \cdot \cdot \cdot } & { a _ { 1 , n } } \\ { \vdots } & { \cdot } & { \vdots } \\ { a _ { m , 1 } } & { \cdot \cdot \cdot } & { a _ { m , n } } \end{array} \right]$ . The set of $m \times n$ matrices with coeficients in K is denoted by $K ^ { m \times n }$ ; when $n = 1$ we just write $K ^ { m }$ 

Note that this last notation clashes with the Cartesian product, and that an element of $K ^ { m }$ is a column vector not a row vector! To make things worse, we will even denote elements of $K ^ { m }$ by $( a _ { 1 } , \ldots , a _ { m } )$ as column vectors take too much place. 

Here is how we define the product of two matrices A and B: if $A = M _ { \mathcal { C } } ^ { B } ( \psi )$ and $S = M _ { \mathcal { D } } ^ { \mathcal { C } } ( \varphi )$ where $U \underset { \varphi } { \to } V \underset { \psi } { \to } W$ , we want $A B$ to correspond to $M _ { D } ^ { B } ( \psi \circ \varphi )$ where $D = ( w _ { 1 } , \dots , w _ { \ell } )$ is a basis of W. Thus we compute 

$$
\psi (\varphi (u _ {j})) = \psi \left(\sum_ {k} b _ {k, j} v _ {k}\right) = \sum_ {k} b _ {k, j} \psi (v _ {k}) = \sum_ {k} b _ {k, j} \sum_ {i} a _ {i, k} w _ {i} = \sum_ {i} w _ {i} \sum_ {k} a _ {i, k} b _ {k, j}.
$$

Hence we define $( a _ { i , j } ) ( b _ { i , j } ) = ( c _ { i , j } )$ where $\begin{array} { r } { c _ { i , j } = \sum _ { k } a _ { i , k } b _ { k , j } } \end{array}$ (scalar product of the ith row of A with jth column of B). (In particular, the product of two matrices is only defined when the coordinates agree: $m \times n$ and $n \times \ell . )$ 

## Definition C.2.3 (Matrix Multiplication)

The product of two matrices $( a _ { i , j } )$ and $( b _ { i , j } )$ of dimensions $m \times n$ and $n \times \ell$ is the matrix $( c _ { i , j } )$ of dimension $m \times \ell$ given by $\begin{array} { r } { c _ { i , j } = \sum _ { k } a _ { i , k } b _ { k , j } } \end{array}$ 

Matrix multiplication is clearly associative, since composition is. It is however not-commutative in general. Similarly, addition of matrices is defined componentwise because we want $M _ { \mathcal { C } } ^ { B } ( \varphi ) + M _ { \mathcal { C } } ^ { B } ( \psi )$ to correspond to $\varphi + \psi$ . (We do not define multiplication of matrices to correspond to multiplication of linear maps because this does not make sense: $x \mapsto x \cdot x$ is not linear.)

## Definition C.2.4 (Kernel and Image)

Let $\varphi : U \to V$ be a linear map. Its kernel ker $\varphi$ is the set of $u \in U$ such that $\varphi ( u ) = 0$ , and its image is the set of $v \in V$ such that $\varphi ( u ) = v$ for some $u \in U$ 

## Theorem C.2.1 (Rank-Nullity Theorem)

Suppose $\varphi : U \to V$ is a linear map (of finite-dimensional vector spaces). Then, dim ker $\varphi +$ dim im $\varphi =$ dim U. 

## Remark C.2.2

This is called the "rank-nullity theorem" because dim im is also called the rank, and nullity means dim ker. 

## Proof

Let $u _ { 1 } , \ldots , u _ { k }$ be a basis of ker ϕ and $\varphi ( u _ { 1 } ^ { \prime } ) , \ldots , \varphi ( u _ { m } ^ { \prime } )$ a basis of im $\varphi .$ . We prove that $u _ { 1 } , \ldots , u _ { k } , u _ { 1 } ^ { \prime } , \ldots , u _ { m } ^ { \prime }$ is a basis of $U .$ 

First we prove that these elements are linearly independent. Suppose that 

$$
\sum_ {i} a _ {i} u _ {i} + \sum_ {i} b _ {i} u _ {i} ^ {\prime} = 0.
$$

Then, $\begin{array} { r } { \sum _ { i } b _ { i } f ( u _ { i } ^ { \prime } ) = 0 } \end{array}$ by composing with $f .$ Since $f ( u _ { 1 } ^ { \prime } ) , \ldots , f ( u _ { m } ^ { \prime } )$ are linearly independent, this means $b _ { 1 } = \ldots = b _ { m } = 0$ . Then, from $\textstyle \sum _ { i } a _ { i } u _ { i } = 0$ , we deduce $a _ { i } = 0$ since $u _ { 1 } , \ldots , u _ { k }$ are also linearly independent. 

It remains to prove that they span all of U. Let $u \in U$ be an element. Write $\begin{array} { r } { f ( u ) = \sum _ { i } b _ { i } f ( u _ { i } ^ { \prime } ) } \end{array}$ Then, $\begin{array} { r } { f \left( { { u } - \sum _ { i } { b _ { i } { u _ { i } ^ { \prime } } } } \right) = 0 } \end{array}$ . This means $\begin{array} { r } { u - \sum _ { i } b _ { i } u _ { i } ^ { \prime } \in \dag , } \end{array}$ ker $f ,$ so 

$$
u - \sum_ {i} b _ {i} u _ {i} ^ {\prime} = \sum_ {i} a _ {i} u _ {i} \iff u = \sum_ {i} a _ {i} u _ {i} + \sum_ {i} b _ {i} u _ {i} ^ {\prime}

## Theorem C.3.2 (Vandermonde Determinant)

Let $x _ { 1 } , \cdots , x _ { n } \in K$ be elements. We have

## Proof

Let $p$ is a prime number and $a _ { 1 } , \ldots , a _ { m }$ integers which are not divisible by $p .$ Suppose $p$ $a _ { 1 } ^ { k } + \ldots + a _ { m } ^ { k }$ for $k = 1 , \ldots , m$ . Prove that $p \mid m$ 

## Solution

Collect the $a _ { i }$ which are equal modulo $p$ together to get 

$$
p \mid \sum_ {i = 1} ^ {n} c _ {i} b _ {i} ^ {n}
$$

for some positive integers $\textstyle \sum _ { i } c _ { i } = m$ and distinct $b _ { i } \in \mathbb { F } _ { p }$ . We have a system of equations 

$$
\left\{ \begin{array}{l} c _ {1} + \ldots + c _ {n} \equiv 0 \\ c _ {1} b _ {1} + \ldots + c _ {n} b _ {n} \equiv 0 \\ \dots\dots\\ c _ {1} b _ {1} ^ {n} + \ldots + c _ {n} b _ {n} ^ {n} \equiv 0. \end{array} \right.
$$

Since the $b _ { i }$ are distinct modulo $p ,$ the vectors $( 1 , \ldots , b _ { 1 } ^ { n } ) , \ldots , ( 1 , \ldots , b _ { n } ^ { n } )$ are linearly independent in $\mathbb { F } _ { p }$ by Vandermonde. Thus, we must have $c _ { 1 } \equiv \ldots \equiv c _ { n } \equiv 0 .$ . Since $m = \textstyle \sum _ { i } c _ { i }$ , we have $p \mid m$ as wanted.  

As we saw from the first example, matrices are deeply linked with system of linear equations. In hindsight, this is obvious: the system 

$$
\left\{ \begin{array}{l} a _ {1, 1} x _ {1} + a _ {1, 2} x _ {2} + \ldots + a _ {1, n} x _ {n} = b _ {2} \\ a _ {2, 1} x _ {1} + a _ {2, 2} x _ {2} + \ldots + a _ {1, n} x _ {n} = b _ {2} \\ \dots\dots\\ a _ {n, 1} x _ {1} + a _ {n, 2} x _ {2} + \ldots + a _ {n, n} x _ {n} = b _ {n} \end{array} \right.
$$

is equivalent to 

$$
\left[ \begin{array}{c} x _ {1} \\ \vdots \\ x _ {n} \end{array} \right] \left[ \begin{array}{c c c} a _ {1, 1} & \dots & a _ {1, n} \\ \vdots & \ddots & \vdots \\ a _ {n, 1} & \dots & a _ {n, n} \end{array} \right] = x _ {1} \left[ \begin{array}{c} a _ {1, 1} \\ a _ {2, 1} \\ \vdots \\ a _ {n, 1} \end{array} \right] + x _ {2} \left[ \begin{array}{c} a _ {1, 2} \\ a _ {2, 2} \\ \vdots \\ a _ {n, 2} \end{array} \right] + \ldots + x _ {n} \left[ \begin{array}{c} a _ {1, n} \\ a _ {2, n} \\ \vdots \\ a _ {n, n} \end{array} \right] = \left[ \begin{array}{c} b _ {1} \\ \vdots \\ b _ {n} \end{array} \right]
$$

i.e. to $X A = B$ where $X = ( x _ { i } ) , A = ( a _ { i , j } )$ and $B = \left( b _ { i } \right)$ . In particular, when $A$ is invertible there is a unique solution, so if we have at a some point in a problem we reach such a system of equations and have a trivial solution, then we know what the $x _ { i }$ are since it’s the only solution.

## Definition C.3.2 (Signature)

The signature ε(σ) of a permutation σ of [n] is 

$$
\prod_ {1 \leq i <   j \leq n} \frac {\sigma (i) - \sigma (j)}{i - j}.
$$

Note that since σ is a permutation, its signature is in $\{ - 1 , 1 \}$ . Thus, the signature of a permutation is −1 raised to its number of inversions, i.e. the number of $j > i$ such $\sigma ( j ) < \sigma ( i )$ (an inversion has a contribution of −1 in the signature). 

This definition of the signature is in fact not always convenient to work with, so we shall also mention another one. One can see that when we apply a transposition to $\sigma ,$ i.e. switch two of its values $\sigma ( i )$ and $\sigma ( j )$ , the signature is multiplied by −1. Since any permutation is a composition of transpositions, the signature is 1 if there are an even number of transpositions and −1 otherwise. In the first case we say the permutation is even, and in the second one that it is odd. 

In particular it does not depend on which transpositions we choose. for example, if one starts with the sequence $( 1 , \ldots , 2 m )$ and switches a pair of elements at each step, one will never be able to go back to the original tuple after an odd number of times since the signature will be −1 while the signature of the identity is 1. 

As another consequence of this characterisation, we see that the signature is a morphism of groups ${ \mathfrak { S } } _ { n } \to \{ - 1 , 1 \}$ : indeeed $\varepsilon ( \sigma \circ \sigma ^ { \prime } ) = \varepsilon ( \sigma ) \cdot \varepsilon ( \sigma ^ { \prime } )$ (this is obvious if you consider σ and $\sigma ^ { \prime }$ as a composition of transpositions).

## C.4 Linear Recurrences

In this short section, we derive the formula for linear recurrences using the Vandermonde determinant, which will be used a lot in this book.<sup>2</sup> 

## Definition C.4.1 (Linear Recurrences)

We say a sequence $( u _ { n } ) _ { n \in \mathbb { Z } }$ is a linear recurrence if there is some $k \geq 1$ and numbers $a _ { 0 } , \dotsc , a _ { k - 1 } \in$ K such that $a _ { 0 } \neq 0$ and 

$$
u _ {n + k} = \sum_ {i = 0} ^ {k - 1} a _ {i} u _ {n + i}
$$

for all i. The smallest such k is called the order of the linear recurrence, and the polynomial $X ^ { k } - a _ { k - 1 } X ^ { k - 1 } - . . . - a _ { 1 } X - a _ { 0 }$ is its characteristic polynomial. This polynomial is also called the characteristic polynomial of the above equation (and the equation is called the equation associated with f). 

## Theorem C.4.1 (Linear Recurrences)

Let $K$ be characteristic zero field and $( u _ { n } ) _ { n \in \mathbb { Z } }$ be a linear recurrence of elements of $K$ with characteristic polynomials $f .$ Suppose the distinct roots of $f$ are $\alpha _ { 1 } , \ldots , \alpha _ { r }$ with multiplicity $m _ { 1 } , \ldots , m _ { r }$ Then, there exist polynomials $f _ { 1 } , \ldots , f _ { r }$ of degrees less than $m _ { 1 } , \ldots , m _ { \tau }$ respectively such that 

$$
u _ {n} = f _ {1} (n) \alpha_ {1} ^ {n} + \ldots + f _ {r} (n) \alpha_ {r} (n)
$$

for all $n \in \mathbb { Z } .$ 

## Proof

Let d be the degree of $f .$ Consider the $K \cdot$ -vector space of sequences satisfying the equation associated with $f$ (which is indeed a vector space as it is closed under addition). This space has dimension d: indeed for any $( x _ { 0 } , \dots , x _ { d - 1 } ) \in K ^ { d }$ there is a unique sequence solution to the recurrence $( u _ { n } ) _ { n }$ such that $u _ { 0 } = x _ { 0 } , \ldots , u _ { d - 1 } = x _ { d - 1 }$ . Thus, the dimension of this space is the same as dim $K ^ { d } = d$ 

Now we prove that all sequences of the form $u _ { n } = f _ { 1 } ( n ) \alpha _ { 1 } ^ { n } + . . . + f _ { k } ( n ) \alpha _ { r } ^ { n }$ are solutions. Since these sequences also form a K-vector space with generating family given by 

$$
u _ {n} = n (n - 1) \cdot \ldots \cdot (n - (k - 1)) \alpha_ {i} ^ {n}
$$

for $k = 0 , \ldots , m _ { i } - 1$ and $i = 1 , \ldots , r .$ Thus we want to have 

$$
(n + d) (n + d - 1) \cdot \ldots \cdot (n + d - (k - 1)) \alpha_ {i} ^ {n + j} = \sum_ {j = 0} ^ {d - 1} (n + j) (n + j - 1) \cdot \ldots \cdot (n + j - (k - 1)) \alpha_ {i} ^ {n + j}
$$

which is equivalent to 

$$
(X ^ {n} f) ^ {(k)} (\alpha_ {i}) = 0
$$

and that’s true because $\alpha _ { i }$ is a root of multiplicity $m _ { i } > k$ of $X ^ { n } f .$ 

Finally, to show that all solutions have this form we want to prove that the dimension of the space of solution of this form is the same as the dimension of the space of all solutions, i.e. d. Since our generating family had exactly $m _ { 1 } + \ldots + m _ { r } = d$ elements, this is equivalent to it being a basis. 

Thus, we want to show it is linearly indepndent. Suppose that a linear combination was zero, i.e. 

$$
u _ {n} \sum_ {i} f _ {i} (n) \alpha_ {i} ^ {n} = 0
$$

for all n. We shall prove that $f _ { i } ( n ) = 0$ for all n and each i, thus implying that $f _ { i } = 0$ since $K$ has characteristic zero. We proceed by induction on $\textstyle \sum _ { i } \deg f _ { i } ,$ the base case follows from the Vandermonde determinant C.3.2. For the induction step, suppose deg $f _ { 1 } \geq 1$ without loss of generality. Consider the sequence 

$$
v _ {n} = u _ {n + 1} - \alpha_ {1} u _ {n} = \sum_ {i} (\alpha_ {i} f _ {i} (n + 1) - \alpha_ {1} f _ {i} (n)) \alpha_ {i} ^ {n}.
$$

Since $\deg ( \alpha _ { i } f _ { i } ( X + 1 ) - \alpha _ { 1 } f _ { i } ) \leq \deg f _ { i } { \mathrm { ~ f o r ~ } } i \geq 1 { \mathrm { ~ a n d ~ } } \deg ( \alpha _ { 1 } ( f _ { i } ( X + 1 ) - f _ { i } ) ) \leq \deg f _ { i } - 1$ , by the induction hypothesis we have $\alpha _ { i } f _ { i } ( X + 1 ) - \alpha _ { 1 } f _ { i } = 0$ for all i. This means that they are constant, but we have already treated this case so we are done.

so we can pick the $u _ { i }$ inductively to get any f (equivalently, the matrix of the coeficients of $f$ represented as linear combinations of the $u _ { i }$ is upper-triangular with no zero coordinate on the diagonal so is invertible). 

On the other hand, since the roots of $\widehat g$ are the $\frac { 1 } { \alpha _ { i } }$ , by our characterisation of linear recurrences, there are polynomials $f _ { i }$ of degree at most $m _ { i } - 1$ such that $\begin{array} { r } { u _ { n } = \sum _ { i = 1 } ^ { r } f _ { i } ( n ) ( 1 / \alpha _ { i } ) ^ { n } } \end{array}$ . Hence, we 

also have 

$$
\begin{array}{c} h = \sum_ {n = 0} ^ {\infty} X ^ {n} \sum_ {i = 1} ^ {r} f _ {i} (n) (1 / \alpha_ {i}) ^ {n} \\ = \sum_ {i = 1} ^ {r} \sum_ {n = 0} ^ {\infty} f _ {i} (n) (X / \alpha_ {i}) ^ {n}. \end{array}
$$

Now, note that the $f _ { i }$ are linear combinations of $( X + k ) ( X + k - 1 ) \cdot \ldots \cdot ( X + 1 )$ so it sufices to prove that the result holds for these polynomials. For this, simply note that diferentiating k times 

$$
\sum_ {n = 0} ^ {\infty} (X / \alpha) ^ {n} = \frac {1}{1 - X / \alpha} = \frac {- \alpha}{X - \alpha}
$$

gives 

$$
\sum_ {n = 0} ^ {\infty} (n + k) (n + k - 1) \cdot \dots \cdot (n + 1) (X / \alpha) ^ {n} = \frac {k !}{(X - \alpha) ^ {k + 1}}
$$

as wanted.
