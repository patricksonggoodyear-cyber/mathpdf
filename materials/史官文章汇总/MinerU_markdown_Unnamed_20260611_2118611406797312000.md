解

记 $N = 2 n ^ { 2 } + 2 n + 1$ ，并记 $\tau ( N )$ 为 N 的正因数个数。注意到

$$
2 N = (2 n + 1) ^ {2} + 1
$$

考虑方程

$$
x ^ {2} + y ^ {2} = 2 N
$$

由于 N 是奇数，且对每个质数 $p \mid N$ 都有

$$
(2 n + 1) ^ {2} \equiv - 1 \pmod {p}
$$

所以 $p \equiv 1 { \pmod { 4 } }$ 。设 $\begin{array} { r } { N = \prod _ { i = 1 } ^ { s } p _ { i } ^ { e _ { i } } } \end{array}$ 。由二平方和表示数公式，方程 $x ^ { 2 } + y ^ { 2 } = 2 N$ 的有序整数解共有

$$
4 \prod_ {i = 1} ^ {s} (e _ {i} + 1) = 4 \tau (N)
$$

个；并且因为 $2 N \equiv 2 { \pmod { 4 } }$ ，每组解中的 $x , y$ 都是奇数。

如果 N 是质数，那么 $\tau ( N ) = 2$ 。平凡表示

$$
2 N = (2 n + 1) ^ {2} + 1 ^ {2}
$$

交换坐标并改变正负号，恰好给出全部 8 个有序整数解。因此任何表示

$$

$$

都使 $k , m$ 中至少一个等于 0，不可能有正整数解。

如果 N 是合数，那么 $\tau ( N ) > 2$ ，故存在不由平凡表示产生的解 $( x , y )$ 。此时 $x , y$ 均非零，并且

$$
(2 k + 1) ^ {2} + (2 m + 1) ^ {2} = 2 N = (2 n + 1) ^ {2} + 1
$$

化简即得 $n ( n + 1 ) = k ( k + 1 ) + m ( m + 1 )$ 。命题得证。

答案： $p = q = 5$ 。

$$
R (n) = \left\lfloor \frac {1}{2} (\alpha_ {1} + 1) (\alpha_ {2} + 1) \dots (\alpha_ {k} + 1) \right\rfloor
$$

回到原题。存在正整数 $x , y , z$ 使得 $2 p - 1 = x ^ { 2 } , 2 q - 1 = y ^ { 2 } , 2 p q - 1 = z ^ { 2 }$ 。显然 $x , y , z$ 都是奇数，因此可写成 $x = 2 a + 1 , y = 2 b + 1 , z = 2 c + 1$ ，其中 $a , b , c$ 是正整数。于是

$$
p = 2 a ^ {2} + 2 a + 1 = a ^ {2} + (a + 1) ^ {2}
$$

$$
q = 2 b ^ {2} + 2 b + 1 = b ^ {2} + (b + 1) ^ {2}
$$

$$
p q = 2 c ^ {2} + 2 c + 1 = c ^ {2} + (c + 1) ^ {2}
$$

利用拉格朗日恒等式

$$
(a ^ {2} + b ^ {2}) (c ^ {2} + d ^ {2}) = (a d - b c) ^ {2} + (a c + b d) ^ {2} = (a c - b d) ^ {2} + (a d + b c) ^ {2}
$$

可得

$$
\begin{array}{r l} p q & = [ a ^ {2} + (a + 1) ^ {2} ] [ b ^ {2} + (b + 1) ^ {2} ] \\ & = (a - b) ^ {2} + (2 a b + a + b + 1) ^ {2} \\ & = (a + b + 1) ^ {2} + (2 a b + a + b) ^ {2} \end{array}
$$

另一方面， $p q = c ^ { 2 } + ( c + 1 ) ^ { 2 }$ C

先设 $a = b ,$ ，于是 $p = q _ { \mathfrak { c } }$ 。由上面的表示数公式， $R ( p ^ { 2 } ) = 1 { \mathfrak { c } }$ 。因此

再设 $a \ne b \textmd { ‰}$ 不妨设 $a > b$ ，此时 $p , q$ 是不同的模 4 余 1 的质数，故 $R ( p q ) = 2 { \cdot }$ 。上面由拉格朗日恒等式得到的两种表示都是由两个不同正整数的平方组成，并且彼此不同，所以它们已经是 $p q$ 的全部表示。然而第一种表示中的两个底数之差为

$$

$$

因此二者都不可能等于 $c ^ { 2 } + ( c + 1 ) ^ { 2 }$ ，矛盾。故只能有 $p = q = 5$ ；直接检验可知它确实满足条件。

(1) 先确定集合 $S _ { \circ }$ 。设 $m , m + 1 \in { \mathcal { F } } ( n )$ ，则存在非负整数 $p , q$ ，使得

$$
m ^ {2} - 4 n = p ^ {2}, \qquad (m + 1) ^ {2} - 4 n = q ^ {2}
$$

两式相减得到 $q ^ { 2 } - p ^ { 2 } = 2 m + 1$ ，故 $p , q$ 奇偶性相反。可以设

$$
q - p = 2 a + 1, \qquad q + p = 2 b + 1
$$

其中 $b \geqslant a \geqslant 0$ 。于是 $p = b - a$ ，且

$$
m = 2 a b + a + b
$$

进而

$$
4 n = m ^ {2} - p ^ {2} = (m - p) (m + p) = 4 a (a + 1) b (b + 1)
$$

$$
