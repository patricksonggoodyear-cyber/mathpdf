求证：如果非零数 $a _ { 1 } , a _ { 2 } , \cdots , a _ { m }$ ，使得对任何 $k = 0 , 1 , 2 , \cdots , n \ ( n < m - 1 )$ ，都有

$$
a _ {1} + a _ {2} \cdot 2 ^ {k} + a _ {3} \cdot 3 ^ {k} + \dots + a _ {m} \cdot m ^ {k} = 0
$$

那么在 $a _ { 1 } , a _ { 2 } , \cdots , a _ { m }$ 中至少有 n+1 对符号相反的相邻项。

解

可以认为 $a _ { m } > 0$ ，因若不然，只需将 $a _ { 1 } , a _ { 2 } , \cdots , a _ { m }$ 都乘以 −1。

任取 $n + 1$ 个实数 $c _ { 0 } , c _ { 1 } , \cdots , c _ { n } $ ，并令 $b _ { i } = \sum _ { j = 0 } ^ { \mathrm { { \prime } } \mathrm { { \prime } } } c _ { j } i ^ { j }$ ，其中 $i = 1 , 2 , \cdots , n$ 。由题意知

$$
\begin{array}{c} \sum_ {i = 1} ^ {m} a _ {i} b _ {i} = \sum_ {i = 1} ^ {m} a _ {i} \sum_ {j = 0} ^ {n} c _ {j} i ^ {j} = \sum_ {i = 1} ^ {m} \sum_ {j = 0} ^ {n} a _ {i} c _ {j} i ^ {j} \\ = \sum_ {j = 0} ^ {n} c _ {j} \sum_ {i = 1} ^ {m} a _ {i} i ^ {j} = \sum_ {j = 0} ^ {n} c _ {j} \cdot 0 = 0 \end{array}
$$

意即，对任意次数不超过 n 的实系数多项式 P 均有

$$
\sum_ {i = 1} ^ {m} a _ {i} P (i) = 0
$$

现在，如果 $a _ { 1 } , a _ { 2 } , \cdots , a _ { m }$ 中符号相反的相邻项不超过 n 对，我们可以构造一个多项式 P使得 $P ( i )$ 与 $a _ { i }$ 同号。具体操作如下，设在 $a _ { 1 } , a _ { 2 } , \cdots , a _ { m }$ 中有 k 对符号相反的相邻项，并且$i _ { 1 } , i _ { 2 } , \cdots , i _ { k }$ 是这些对中的前面一项的角标，现在令

$$
f (x) = \left(x - i _ {1} - \frac {1}{2}\right) \left(x - i _ {2} - \frac {1}{2}\right) \dots \left(x - i _ {k} - \frac {1}{2}\right)
$$

是一个次数不超过 n 的多项式。

函数 f 在点 $i _ { j } + 1 / 2$ 处改变符号，并且仅在这些点处变号，其中 $j = 1 , 2 , \cdots , k _ { \circ }$ 记$b _ { i } = f ( i )$ ，则因此 $b _ { i }$ 与 $b _ { i + 1 }$ 的符号相反，当且仅当在 i 与 $i + 1$ 之间有着某个点 $i _ { l } + 1 / 2$ ，亦即 $i = i _ { l } \ ( l = 1 , 2 , \cdots , k )$ 。由此可知 $a _ { 1 } , a _ { 2 } , \cdots , a _ { m }$ 与 $b _ { 1 } , b _ { 2 } , \cdots , b _ { m }$ 在具有相同脚标的相邻对之间发生变号。由于 $a _ { m } > 0 , b _ { m } > 0$ ，所以 $a _ { i }$ 与 $b _ { i }$ 全都同号，其中 $i = 1 , 2 , \cdots , m$ ，从而$\sum _ { i = 1 } ^ { m } a _ { i } b _ { i } > 0$ ，矛盾！
