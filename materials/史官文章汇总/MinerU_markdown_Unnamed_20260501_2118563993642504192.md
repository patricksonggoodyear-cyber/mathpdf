不能。

注意 $3 7 \cdot 2 7 0 2 7 0 + 4 = 9 9 9 9 9 9 4$ ，而 $3 7 \cdot 2 7 0 2 7 1 + 4 = 1 0 0 0 0 0 3 1$ 。这是夹住目标区间的两个相邻的模 37 余 4 的整数，所以区间 (10000000,10000020) 内不存在模 37 余 4 的整数。因此不可能得到符合要求的数。

## British 1st Round 2021 P1

Alice 与 Bob 轮流在黑板上写数。Alice 先在黑板上写下一个 −100 至 100 之间 (含端点)的整数 $a \mathrm { _ c }$ 。在 Bob 的每一轮中，他写下 Alice 上一轮所写数的两倍；在 Alice 此后的每一轮中，她写下比 Bob 上一轮所写数小 45 的数。在某个时刻，数 a 第二次出现在黑板上。求 a的所有可能取值。

## 解

答案为 a ∈ {0, 30, 42, 45}。

记 $x _ { 0 } = a$ ，并用 $x _ { k }$ 表示 Alice 此后第 k 次写下的数。Bob 在这两次 Alice 写数之间写下$2 x _ { k }$ ，所以 $x _ { k + 1 } = 2 x _ { k } - 4 5$ 。为了消去常数项，令 $y _ { k } = x _ { k } - 4 5$ ，便有 $y _ { k + 1 } = 2 y _ { k }$ ，从而

$$
x _ {k} = 4 5 + 2 ^ {k} (a - 4 5), \qquad k \geqslant 0
$$

如果 a 再次由 Alice 写出，则存在 $k \geqslant 1$ 使 $x _ { k } = a$ ，即 $( 2 ^ { k } - 1 ) ( a - 4 5 ) = 0$ ，所以 $a = 4 5$ 0反过来， $a = 4 5$ 时，最初三次写出的数为 45,90,45，确实符合要求。

如果 a 再次由 Bob 写出，设这是 Bob 第 k 次写数，其中 k $\geqslant 1$ 。此时他写下的是 $2 x _ { k - 1 } ,$ 故

$$
a = 2 x _ {k - 1} = 9 0 + 2 ^ {k} (a - 4 5) \quad \Longleftrightarrow \quad (2 ^ {k} - 1) (4 5 - a) = 4 5
$$

因此 $2 ^ { k } - 1$ 是 45 的正约数。45 的正约数为 1,3,5,9,15,45，其中加上 1 后为 2 的幂的只有1, 3, 15。所以 k 分别为 1, 2, 4，相应的 $a = 4 5 - 4 5 / ( 2 ^ { k } - 1 )$ 分别为 0, 30, 42。

这些初值均在 [−100,100] 内。将它们代入上面的公式可知，Bob 分别在第 1,2,4 次写数时写回初值。因此所有可能的初值恰为 0,30,42,45。
