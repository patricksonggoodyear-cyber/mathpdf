IMOSL 1968 Q16 

设

$$
p (x) = a _ {0} x ^ {k} + a _ {1} x ^ {k - 1} + \dots + a _ {k}
$$

是整系数多项式，m 是正整数。如果对每个整数 x 都有 $m \mid p ( x )$ ，则称多项式 $p ( x )$ 被 m 整除。证明：如果 $p ( x )$ 被 m 整除，那么 $m \mid k ! a _ { 0 } { \circ }$ 。反之，给定非负整数 a ,k 和正整数 m，如果 $m \mid k ! a _ { 0 }$ ，那么存在形如 $p ( x ) = a _ { 0 } x ^ { k } + \cdot \cdot \cdot + a _ { k }$ 的整系数多项式，使 $p ( x )$ 被 m 整除。

解

定义多项式的向前差分为

$$
\Delta p (x) = p (x + 1) - p (x)
$$

若对每个整数 t 都有 $m \mid p ( t )$ ，则对每个整数 t 都有 $m \mid \Delta p ( t )$ 。反复使用这一结论，可知$m \mid \Delta ^ { j } p ( t )$ 对任意非负整数 j 和任意整数 t 都成立。

若一个 r 次多项式的首项系数为 a，则

$$
\Delta (a x ^ {r}) = a r x ^ {r - 1} + \mathrm{低次项}
$$

所以每作一次差分，多项式的次数降低 1，首项系数乘以原来的次数。因此

$$
\Delta^ {k} p (x) = k! a _ {0}
$$

这是一个常数多项式。它在整数点上的值仍被 m 整除，故 $m \mid k ! a _ { 0 }$ 

下面证明反向结论。若 $k \geqslant 1$ ，构造

$$
p (x) = a _ {0} x (x - 1) \dots (x - k + 1)
$$

这是形如 $a _ { 0 } x ^ { k } + \cdots + a _ { k }$ 的整系数多项式。若整数 $t \geqslant k$ ，则

$$
t (t - 1) \dots (t - k + 1) = k! \binom {t} {k}
$$

若 $0 \leqslant t < k$ ，则乘积中含有因子 0。若 $t = - s < 0$ ，其中 s 为正整数，则

$$
t (t - 1) \dots (t - k + 1) = (- 1) ^ {k} k! \binom {s + k - 1} {k}
$$

因此对每个整数 t，总存在整数 $q _ { t }$ ，使 $p ( t ) = k ! a _ { 0 } q _ { t }$ 。由 $m \mid k ! a _ { 0 }$ ，得到 $m \mid p ( t )$ ，所以 $p ( x )$ 被 m 整除。当 $k = 0$ 时，取常数多项式 $p ( x ) = a _ { 0 }$ ，结论同样成立。

Putnam 1974 A6 

设 n 为正整数。令 $f ( n )$ 为满足下列条件的整系数首一多项式 $p ( x )$ 的最低次数：对每个整数 $m$ ，都有 $n \mid p ( m )$ 。求 f(n)，并计算 f(1000000)。

解

令

$$
N = \min \{r \geqslant 0: n \mid r! \}
$$

其中约定 0! = 1。下面证明 $f ( n ) = N$ 

先证 $f ( n ) \leqslant N$ 。若 $N \geqslant 1$ ，构造

$$
p _ {N} (x) = x (x - 1) \dots (x - N + 1)
$$

这是一个 N 次整系数首一多项式。若整数 $m \geqslant N$ ，则 $p _ { N } ( m ) = N ! { \binom { m } { N } }$ ；若 $0 \leqslant m < N$ ，则乘积中含有因子 0；若 $m = - t < 0$ ，其中 t 为正整数，则

$$
p _ {N} (- t) = (- 1) ^ {N} N! \binom {t + N - 1} {N}
$$

因此对每个整数 m，都有 $N ! \mid p _ { N } ( m )$ 。由 $n \mid N !$ ，可知 $n \mid p _ { N } ( m )$ ，故 $f ( n ) \leqslant N _ { \circ }$ 当 $N = 0$ 时，必有 $n = 1$ ，取常数首一多项式 $p _ { 0 } ( x ) = 1$ 即可。

再证 $f ( n ) \geqslant N .$ 。设 $p ( x )$ 是任意满足条件的 d 次整系数首一多项式，并定义 $\Delta p ( x ) =$ $p ( x + 1 ) - p ( x )$ 。由于每个 $p ( m )$ 都被 n 整除，所以每一级差分在整数点上的值也都被 n 整除，特别地，

$$
n \mid \Delta^ {d} p (0)
$$

若一个 r 次多项式的首项系数为 a，则其向前差分是首项系数为 ra 的 $r - 1$ 次多项式。因此首一 d 次多项式连续作 d 次向前差分后得到常数 $\Delta ^ { d } p ( x ) = d !$ ，所以 $n \mid d !$ 。由 N 的最小性，必有 $d \geqslant N$ ，故

$$
f (n) = \min \{N \geqslant 0: n \mid N! \}
$$

最后计算 f(1000000)。因为 $1 0 0 0 0 0 0 = 2 ^ { 6 } \cdot 5 ^ { 6 }$ ，而

$$
\nu_ {5} (2 4!) = 4 <   6
$$

所以 1000000 ∤ 24!。另一方面，

$$
\nu_ {5} (2 5!) = \left\lfloor \frac {2 5}{5} \right\rfloor + \left\lfloor \frac {2 5}{2 5} \right\rfloor = 6
$$

并且

$$
\nu_ {2} (2 5!) = \left\lfloor \frac {2 5}{2} \right\rfloor + \left\lfloor \frac {2 5}{4} \right\rfloor + \left\lfloor \frac {2 5}{8} \right\rfloor + \left\lfloor \frac {2 5}{1 6} \right\rfloor = 2 2
$$

故 1000000 | 25!，从而 $f ( 1 0 0 0 0 0 0 ) = 2 5$ 

高联 2011 P2

证明：对任意整数 $n \geqslant 4$ ，存在一个 n 次多项式

$$
f (x) = x ^ {n} + a _ {n - 1} x ^ {n - 1} + \dots + a _ {1} x + a _ {0}
$$

具有下列性质：

(1) $a _ { 0 } , a _ { 1 } , \cdots , a _ { n - 1 }$ 均为正整数；

(2) 对任意正整数 m、任意整数 $k \geqslant 2$ 以及任意 k 个互不相同的正整数 $r _ { 1 } , r _ { 2 } , \cdots , r _ { k }$ ，都有

$$
f (m) \neq f (r _ {1}) f (r _ {2}) \dots f (r _ {k})
$$

解

构造

$$
f (x) = (x + 1) (x + 2) \dots (x + n) + 2
$$

将右端展开可知，f(x) 是首项系数为 1 的 n 次多项式，并且其余各项的系数都是正整数，所以性质 (1) 成立。

对任意整数 $t , \ t + 1 , t + 2 , \cdot \cdot \cdot , t + n$ 是 n 个连续整数。由于 $n \geqslant 4$ ，其中至少有一个数被 4 整除，所以 $f ( t ) \equiv 2 { \pmod { 4 } }$ 

现在任取正整数 m、整数 $k \geqslant 2$ 以及互不相同的正整数 $r _ { 1 } , r _ { 2 } , \cdots , r _ { k }$ 。由上述同余式，

$$
f (r _ {1}) f (r _ {2}) \dots f (r _ {k}) \equiv 2 ^ {k} \equiv 0 \pmod {4}
$$

而 $f ( m ) \equiv 2 { \pmod { 4 } }$ ，所以 $f ( m ) \neq f ( r _ { 1 } ) f ( r _ { 2 } ) \cdot \cdot \cdot f ( r _ { k } )$ ，故所构造的多项式满足全部要求。

CTST 2006 P22 

设奇数 $k \geqslant 3 .$ 求证：存在一个 k 次非整系数整值多项式 f(x)，满足 $f ( 0 ) = 0 , f ( 1 ) = 1$ 并且有无穷多个正整数 n，使得若方程

$$
n = f (x _ {1}) + f (x _ {2}) + \dots + f (x _ {s})
$$

有整数解 $x _ { 1 } , x _ { 2 } , \cdots , x _ { s }$ ，则 $s \geqslant 2 ^ { k } - 1$ 。

解

对整数 $i \geqslant 0$ ，定义

$$
F _ {0} (x) = 1, \quad F _ {i} (x) = \frac {x (x - 1) \cdots (x - i + 1)}{i !}
$$

先证明每个 $F _ { i }$ 都是整值多项式。当整数 $x \geqslant 0$ 时，若 $x \geqslant i$ ，则 $\begin{array} { r } { F _ { i } ( x ) = { \binom { x } { i } } } \end{array}$ ；若 $0 \leqslant x < i$ 则分子中含有因子 $0 \phantom { . 0 }$ 。当 $x = - m < 0$ ，其中 m 为正整数时，

$$
F _ {i} (- m) = (- 1) ^ {i} \binom {m + i - 1} {i}
$$

所以 $F _ { i } ( x )$ 对每个整数 x 都取整数值。

构造

$$
f (x) = \sum_ {i = 1} ^ {k} (- 2) ^ {i - 1} F _ {i} (x)
$$

由于各个系数 $( - 2 ) ^ { i - 1 }$ 都是整数，f 是整值多项式。由 $F _ { i } ( 0 ) = 0 ~ ( i \geqslant 1 ) , ~ F _ { 1 } ( 1 ) = 1$ 及$F _ { i } ( 1 ) = 0 \ ( i \geq 2 )$ ，可得 $f ( 0 ) = 0 , f ( 1 ) = 1$ 。只有 $F _ { k }$ 含有 k 次项，所以 f 的次数恰为 k。它的首项系数为

$$
\frac {(- 2) ^ {k - 1}}{k !} = \frac {2 ^ {k - 1}}{k !}
$$

由于 $k \geqslant$ 3，k! 含有质因数 3，而 $2 ^ { k - 1 }$ 不被 3 整除，所以该首项系数不是整数。

由帕斯卡恒等式，

$$
F _ {i} (x + 2) - F _ {i} (x) = 2 F _ {i - 1} (x) + F _ {i - 2} (x)
$$

其中约定 $F _ { - 1 } ( x ) = 0$ 。令 $a _ { i } = ( - 2 ) ^ { i - 1 }$ 。由于 $a _ { i + 1 } = - 2 a _ { i }$ ，所以

$$
\begin{array}{l} f (x + 2) - f (x) = \sum_ {i = 1} ^ {k} a _ {i} \big (2 F _ {i - 1} (x) + F _ {i - 2} (x) \big) \\ \qquad = 2 a _ {k} F _ {k - 1} (x) + \sum_ {i = 1} ^ {k - 1} (2 a _ {i} + a _ {i + 1}) F _ {i - 1} (x) \\ \qquad = 2 ^ {k} F _ {k - 1} (x) \end{array}
$$

最后一步使用了 k 为奇数。由于 $F _ { k - 1 } ( x )$ 在整数点上取整数值，结合 $f ( 0 ) = 0 , f ( 1 ) = 1$ ，可得

$$
f (x) \equiv {\left\{ \begin{array}{l l} {0} & {{(\mathrm{mod} 2 ^ {k})}, x {\text {为偶数}}} \\ {1} & {{(\mathrm{mod} 2 ^ {k})}, x {\text {为奇数}}} \end{array} \right.}
$$

对任意正整数t，令 $n _ { t } = 2 ^ { k } t - 1$ 。若 $n _ { t } = f ( x _ { 1 } ) + f ( x _ { 2 } ) + \cdot \cdot \cdot + f ( x _ { s } )$ ，并记r 为 $x _ { 1 } , x _ { 2 } , \cdots , x _ { s }$ 中奇数的个数，则对等式取模 $2 ^ { k }$ 得

$$
r \equiv n _ {t} \equiv - 1 \pmod {2 ^ {k}}
$$

所以 $s \geqslant r \geqslant 2 ^ { k } - 1$ 。又由 $f ( 1 ) = 1$ ，每个 $n _ { t }$ 都确实可以表示为若干个函数值之和。由于 t可以任意取正整数，满足要求的正整数 n 有无穷多个。

求所有满足下列条件的正整数 n：对任意次数不超过 n 的整系数首一多项式 $P ( x )$ ，都存在正整数 $k \leqslant n$ 及 $k + 1$ 个两两不同的整数 $x _ { 1 } , x _ { 2 } , \cdots , x _ { k + 1 }$ ，使得

$$
P (x _ {1}) + P (x _ {2}) + \dots + P (x _ {k}) = P (x _ {k + 1})
$$

解

答案是 $n = 2$ 

先证明 $n = 2$ 满足条件。若 $P ( x ) = 1$ ，任取两个不同的整数 $x _ { 1 } , x _ { 2 }$ 即有 $P ( x _ { 1 } ) = P ( x _ { 2 } )$ o若 $P ( x ) = x + c ,$ ，其中 c 是整数，则

$$
P (c - 1) + P (c + 1) = P (3 c)
$$

三个整数 $c - 1 , c + 1 , 3 c$ 两两不同。若 $P ( x ) = x ^ { 2 } + q x + r$ ，其中 $q , r$ 是整数，则恒有 $P ( x ) =$ $P ( - x - q )$ ；取满足 $2 x + q \neq 0$ 的整数 x，便得到两个不同整数处的函数值相等。因此 $n = 2$ 满足条件。

$n = 1$ 时取 $P ( x ) = x$ ，此时只能取 $k = 1$ ，而 P 在整数集上是单射，所以条件不成立。

对于 $n \geqslant 3$ ，只需构造一个次数不超过 n 的整系数首一多项式 P，使它在整数集上是单射，并且 $P ( x ) \equiv 1 { \pmod { n } }$ 对每个整数 x 都成立。事实上，若题设等式成立，对它取模 n 可得 $k \equiv 1 { \pmod { n } }$ 。结合 $1 \leqslant k \leqslant n$ ，只能有 $k = 1$ ，于是 $P ( x _ { 1 } ) = P ( x _ { 2 } )$ ，与单射性矛盾。

当 $n = 4$ 时，取

$$
P (x) = x ^ {4} + 7 x ^ {2} + 4 x + 1
$$

对任意整数 x，数 $x ^ { 4 } - x ^ { 2 }$ 被 4 整除，所以 $P ( x ) \equiv 1 { \pmod { 4 } }$ 。另一方面，

$$
P (x) - P (y) = (x - y) \big ((x + y) (x ^ {2} + y ^ {2} + 7) + 4 \big)
$$

若 $x + y = 0$ ，则第二个因子等于 4；若 $x + y \neq 0$ ，则 $| ( x + y ) ( x ^ { 2 } + y ^ { 2 } + 7 ) | \geqslant 7$ ，所以第二个因子也不为 0。因此 P 在整数集上是单射。

以下设 $n \geqslant 3$ 且 $n \neq 4 .$ 。对正整数 r，令

$$
G _ {r} (x) = (x - 1) (x - 2) \dots (x - r)
$$

若 r 为奇数，则

$$
G _ {r} (x + 1) - G _ {r} (x) = r (x - 1) (x - 2) \dots (x - r + 1) \geqslant 0
$$

对每个整数 x 都成立，所以 $G _ { r }$ 在整数集上单调不减。

当 n 为奇数时，取

$$
P (x) = G _ {n} (x) + n x + 1
$$

$G _ { n } ( x )$ 在每个整数点上的值都被 $n !$ 整除，所以 $P ( x ) \equiv 1 { \pmod { n } }$ 。又因 $G _ { n }$ 单调不减，

$$
P (x + 1) - P (x) = G _ {n} (x + 1) - G _ {n} (x) + n > 0
$$

所以 P 在整数集上严格递增。

当 n 为偶数且 $n \geqslant 6$ 时，取

$$
P (x) = G _ {n - 1} (x) + n x + 1
$$

每个合数 $n > 4$ 都满足 $n \mid ( n - 1 ) !$ ：若 $n = a b$ ，其中 $2 \leqslant a < b < n$ ，则 $( n - 1 ) !$ 中含有因子$a , b ;$ 若 $n = a ^ { 2 }$ ，则 $( n - 1 ) !$ 中含有因子 $a , 2 a$ 。又因为 $G _ { n - 1 } ( x )$ 在整数点上的值总被 $( n - 1 ) !$ 整除，所以 $P ( x ) \equiv 1 { \pmod { n } }$ 。由于 $n - 1$ 为奇数， $G _ { n - 1 }$ 单调不减，从而 P 在整数集 $\pm \vec { p } ^ { \mathrm { m } }$ 格递增。

由此，对于每个 $n \neq 2$ ，都存在一个反例多项式，所以唯一满足条件的正整数是 2。
