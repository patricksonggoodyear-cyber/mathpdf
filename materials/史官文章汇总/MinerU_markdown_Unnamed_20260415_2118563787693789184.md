在由 0 和 1 交替组成的 2k 项圆周中，将任意一项复制一次并放在它的旁边，便得到恰有一对相邻项相等、其余相邻项都不相等的 $2 k + 1$ 元组，此时 $2 E = 2 k$ 。所以 $M _ { 2 k + 1 } = k .$ o

最后确定奇数情形的全部取等元组。若 $E = k$ ，则上述两个不等式都取等：删去 $x _ { 2 }$ 后的每一对相邻项之差的绝对值都是1，故余下各项均为0或1，且严格交替；同时 $( x _ { 1 } - x _ { 2 } ) ( x _ { 2 } - x _ { 3 } ) =$ 0，故 $x _ { 2 }$ 等于 $x _ { 1 }$ 或 $x _ { 3 } .$ 。将 $x _ { 2 }$ 放回后，恰有一对相邻项相等，其余相邻项均不相等。反之，任何满足这一条件的 $0 , 1$ 元组都有 2k 对相邻项不相等，故 $E = k \mathrm { { \Omega } }$

给定整数 $n \geqslant 4$ ，设 $a _ { 1 } , a _ { 2 } , \cdots , a _ { n }$ 是 $1 , 2 , \cdots , n$ 的一个排列，求

$$
\sum_ {i = 1} ^ {n} \left| a _ {i} - a _ {i + 1} + a _ {i + 2} - a _ {i + 3} \right|
$$

的最大值，下标模 n 理解。

解

记待求的和为 S，并令 $\begin{array} { r } { d _ { i } = a _ { i } - a _ { i + 1 } \mathrm { ~ , ~ } T = \sum _ { i = 1 } ^ { n } \left| d _ { i } \right| } \end{array}$ ，下标均循环理解。先估计 $T _ { \circ }$ 。在 n个数 $\operatorname* { m i n } \{ a _ { i } , a _ { i + 1 } \}$ 中，每个排列元素最多出现两次，因为它只与前后两条边相接。将这些最小值递增排列为 $b _ { 1 } \leqslant \cdots \leqslant b _ { n }$ ，便有 $b _ { j } \geqslant \lceil j / 2 \rceil$ 。因此

$$
\begin{array}{l} T = \sum_ {i = 1} ^ {n} (a _ {i} + a _ {i + 1}) - 2 \sum_ {i = 1} ^ {n} \min \{a _ {i}, a _ {i + 1} \} \\ \leqslant n (n + 1) - 2 \sum_ {j = 1} ^ {n} \lceil j / 2 \rceil = \left\lfloor \frac {n ^ {2}}{2} \right\rfloor \end{array}
$$

若 $n = 2 m$ ，则由三角不等式得 $S \leqslant 2 T \leqslant n ^ { 2 }$ 。取

$$
(a _ {1}, \dots , a _ {n}) = (1, m + 1, 2, m + 2, \dots , m, 2 m)
$$

小数 $1 , \cdots , m$ 与大数 $m + 1 , \cdots , 2 m$ 交替出现，故 $\begin{array} { r } { T = 2 \sum _ { j = m + 1 } ^ { 2 m } j - 2 \sum _ { j = 1 } ^ { m } j = n ^ { 2 } / 2 } \end{array}$ ；同时$d _ { i } , d _ { i + 2 }$ 始终同号，故 $S = 2 T = n ^ { 2 }$ o

若 $n = 2 m + 1$ ，则每个 $d _ { i }$ 都是非零整数，且 $\textstyle \sum _ { i } d _ { i } = 0$ 。至少存在一个下标i，使 $d _ { i } d _ { i + 2 } < 0$ 。否则所有 $d _ { i } , d _ { i + 2 }$ 都同号；由于 n 为奇数，每隔两个下标会遍历全部下标，所有 $d _ { i }$ 便同号，与它们的和为 0 矛盾。又因为

$$
\prod_ {i = 1} ^ {n} d _ {i} d _ {i + 2} = \prod_ {i = 1} ^ {n} d _ {i} ^ {2} > 0
$$

负乘积的个数为偶数，所以至少有两个。对异号非零整数 $u , v$ ，有 $| u + v | = | u | + | v | -$ $2 \operatorname* { m i n } \{ | u |$ , |v|} $\leqslant | u | + | v | - 2$ 。于是

$$
S = \sum_ {i = 1} ^ {n} \left| d _ {i} + d _ {i + 2} \right| \leqslant 2 T - 4 \leqslant n ^ {2} - 5
$$

下面给出对所有 $m \geqslant 2$ 都有效的取等构造。令

$$
\begin{array}{c c c} a _ {1} = m, & a _ {2} = m + 1, & a _ {3} = m + 2 \\ a _ {2 j + 2} = j, & a _ {2 j + 3} = m + j + 2 & (1 \leqslant j \leqslant m - 1) \end{array}
$$

这里开头三项连续递增，其余位置大小交替。每个小数 1,··· ,m 都是其两条相邻边的较小端点，而 $m + 1$ 是边 $\{ m + 1 , m + 2 \}$ 的较小端点，所以

$$
T = n (n + 1) - 2 \left(2 \sum_ {j = 1} ^ {m} j + m + 1\right) = 2 m (m + 1)
$$

此时 $d _ { 1 } = d _ { 2 } = - 1 , d _ { 3 } , \cdot \cdot \cdot , d _ { n }$ 正负交替且首尾均为正。只有 $i = 1 , n$ 时 $d _ { i } , d _ { i + 2 }$ 异号，这两处的绝对值较小者都为 1，因此 $S = 2 T - 4 = n ^ { 2 } - 5$ 0

综上，当 n 为偶数时最大值为 $n ^ { 2 }$ ，当 n 为奇数时最大值为 $n ^ { 2 } - 5$
