解

把每个复数 $a _ { n }$ 看作复平面上的点，并以它为圆心作半径为 $1 / 2$ 的闭圆盘

$$
D _ {n} = \{w \in \mathbb {C}: | w - a _ {n} | \leqslant 1 / 2 \}
$$

若 $m \neq n$ 且 $D _ { m } \cap D _ { n } \neq \emptyset$ ，则由三角不等式可得 $| a _ { m } - a _ { n } | \leqslant 1$ ，与题设矛盾。因此这些圆盘两两不交，每个圆盘的面积均为 $\pi / 4$

对于正整数 N，记

$$
S _ {N} = \{n \in \mathbb {Z} _ {+}: N \leqslant | a _ {n} | <   N + 1 \}, \quad M _ {N} = | S _ {N} |
$$

若 $n \in S _ { N }$ 且 $w \in D _ { n }$ ，则

$$
N - \frac {1}{2} \leqslant | w | <   N + \frac {3}{2}
$$

因此这些 $D _ { n }$ 全部包含在内外半径分别为 $N - 1 / 2$ 与 $N + 3 / 2$ 的环带内。由圆盘两两不交及面积比较，得到

$$
\frac {M _ {N} \pi}{4} \leqslant \pi \left[ \left(N + \frac {3}{2}\right) ^ {2} - \left(N - \frac {1}{2}\right) ^ {2} \right] = (4 N + 2) \pi
$$

从而 $M _ { N } \leqslant 1 6 N + 8$ 。于是

$$
\sum_ {n \in S _ {N}} \left| \frac {1}{a _ {n} ^ {3}} \right| = \sum_ {n \in S _ {N}} \frac {1}{| a _ {n} | ^ {3}} \leqslant \frac {M _ {N}}{N ^ {3}} \leqslant \frac {1 6}{N ^ {2}} + \frac {8}{N ^ {3}}
$$

由于级数 $\sum _ { N = 1 } ^ { \infty } ( 1 6 / N ^ { 2 } + 8 / N ^ { 3 } )$ 收敛，故 $\sum _ { n = 1 } ^ { \infty } | 1 / a _ { n } ^ { 3 } |$ 收敛。因此原级数绝对收敛，进而收敛。

$$

$$

$$

Zhautykov 2022 P6 

是否存在两个有界数列 $a _ { 1 } , a _ { 2 } , \cdots$ 与 $b _ { 1 } , b _ { 2 } , \cdots$ ，使得对任意正整数 $n < m$ ，不等式 $\left| a _ { m } - \right.$ $a _ { n } | > 1 / { \sqrt { n } }$ 与 $| b _ { m } - b _ { n } | > 1 / { \sqrt { n } }$ 中至少有一个成立？

## 解

答案是否定的。

反设存在满足条件的两个有界数列。对每个正整数 n，在平面上取点 $P _ { n } = ( a _ { n } , b _ { n } )$ ，并以$P _ { n }$ 为中心作边与坐标轴平行的闭正方形

$$
Q _ {n} = \left\{(x, y): | x - a _ {n} | \leqslant \frac {1}{2 \sqrt {n}}, | y - b _ {n} | \leqslant \frac {1}{2 \sqrt {n}} \right\}
$$

下面证明这些正方形两两不交。任取正整数 $n < m$ 。若 $Q _ { n }$ 与 $Q _ { m }$ 有公共点，则由三角不等式， $| a _ { m } - a _ { n } | \leqslant 1 / ( 2 \sqrt { n } ) + 1 / ( 2 \sqrt { m } ) < 1 / \sqrt { n } ;$ ；同理， $| b _ { m } - b _ { n } | < 1 / { \sqrt { n } }$ 。这与题设矛盾，故 $Q _ { n }$ 与 $Q _ { m }$ 不相交。

由于两个数列都有界，存在常数 $C > 0$ ，使得对每个正整数 n 都有 $\left| a _ { n } \right| \leqslant C$ 且 $| b _ { n } | \leqslant C$ 又因为 $1 / ( 2 { \sqrt { n } } ) \leqslant 1 / 2$ ，所以所有正方形 $Q _ { n }$ 都包含在固定正方形 $[ - C - 1 / 2 , C + 1 / 2 ] ^ { 2 }$ 内。正方形 $Q _ { n }$ 的边长为 $1 / \sqrt { n }$ ，面积为 $1 / n$ ，故由 $Q _ { 1 } , Q _ { 2 } , \cdots , Q _ { N }$ 两两不交可得

$$
\sum_ {n = 1} ^ {N} \frac {1}{n} \leqslant (2 C + 1) ^ {2}
$$

对每个正整数 N 都成立。然而调和级数发散，取充分大的 N 即可使左边大于 $( 2 C + 1 ) ^ { 2 }$ ，矛盾。因此，不存在满足条件的两个有界数列。

设 n 为正整数。求关于 n 的最大整数 m，使得可以在一个 m 行 n 列的表格中填入实数，并满足：任取不同的两行 $[ a _ { 1 } , a _ { 2 } , \cdots , a _ { n } ]$ 与 $\left[ b _ { 1 } , b _ { 2 } , \cdots , b _ { n } \right]$ ，均有

$$
\max \{| a _ {1} - b _ {1} |, | a _ {2} - b _ {2} |, \dots , | a _ {n} - b _ {n} | \} = 1
$$

## 解

所求最大值为 $2 ^ { n }$ 。

设表格的第 i 行对应点 $P _ { i } = ( a _ { i 1 } , a _ { i 2 } , \cdot \cdot \cdot , a _ { i n } ) \in \mathbb { R } ^ { n }$ ，其中 $1 \leqslant i \leqslant m$ 。题设说明，对任意 $1 \leqslant i , j \leqslant m$ 及 1 $\leqslant k \leqslant n$ 均有 $| a _ { i k } - a _ { j k } | \leqslant 1$ 。对每个 k，令 $c _ { k } = \operatorname* { m i n } _ { 1 \leqslant i \leqslant m } a _ { i k }$ ，则所有点 $P _ { i }$ 都位于 n 维单位立方体

$$
C = [ c _ {1}, c _ {1} + 1 ] \times [ c _ {2}, c _ {2} + 1 ] \times \dots \times [ c _ {n}, c _ {n} + 1 ]
$$

以每个 $P _ { i }$ 为中心作边长为 1、各边平行于坐标轴的闭立方体

$$
Q _ {i} = \prod_ {k = 1} ^ {n} \left[ a _ {i k} - \frac {1}{2}, a _ {i k} + \frac {1}{2} \right]
$$

这些立方体的内部两两不交。事实上，若 $Q _ { i }$ 与 $Q _ { j }$ 的内部相交，则对每个k 都有 $| a _ { i k } - a _ { j k } | < 1$ 于是

$$
\max _ {1 \leqslant k \leqslant n} | a _ {i k} - a _ {j k} | <   1
$$

这与题设矛盾。

下面估计 $Q _ { i } \cap C$ 的体积。用过点 $P _ { i }$ 且平行于各坐标超平面的 n 个超平面，将 $Q _ { i }$ 分成$2 ^ { n }$ 个边长为 $1 / 2$ 的小立方体。对每个坐标 k，若 $a _ { i k } \leqslant c _ { k } + 1 / 2$ ，就选取区间 $[ a _ { i k } , a _ { i k } + 1 / 2 ]$ 若 $a _ { i k } \geqslant c _ { k } + 1 / 2$ ，就选取区间 $[ a _ { i k } - 1 / 2 , a _ { i k } ]$ 。所选区间均包含在 $[ c _ { k } , c _ { k } + 1 ]$ 中，因此它们的笛卡儿积是上述 $2 ^ { n }$ 个小立方体之一，并且完全包含在 $Q _ { i } \cap C$ 中。故

$$
\operatorname{vol} \left(Q _ {i} \cap C\right) \geqslant \left(\frac {1}{2}\right) ^ {n} = 2 ^ {- n}
$$

各 $Q _ { i }$ 的内部两两不交，因而各 $Q _ { i } \cap C$ 除边界外也两两不交。立方体的边界体积为 0，所以

$$
1 = \operatorname{vol} (C) \geqslant \sum_ {i = 1} ^ {m} \operatorname{vol} (Q _ {i} \cap C) \geqslant m \cdot 2 ^ {- n}
$$

从而 $m \leqslant 2 ^ { n }$ 。

最后，取所有 $2 ^ { n }$ 个由 0 和 1 组成的 n 元组作为表格的各行。任意两个不同的元组在每个坐标上的差的绝对值均不超过 1，并且至少有一个坐标上的差的绝对值等于 1，所以它们满足题设条件。因此 $m = 2 ^ { n }$ 可以达到，所求最大值为 $2 ^ { n }$
