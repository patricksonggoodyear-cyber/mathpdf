IMOSL 2010 C3 

在 $1 0 0 \times 1 0 0$ 国际象棋棋盘上放置 2500 个王，使任意两王不能互相攻击，且每行、每列恰有 25 个王。问共有多少种放法？旋转或反射后不同仍视为不同。

## 解

答案为 2。将原棋盘的行、列分别从上到下、从左到右编号，并把棋盘固定分成 $5 0 \times 5 0$ 个互不相交的 $2 \times 2$ 小块

$$
Q _ {i j} = \{2 i - 1, 2 i \} \times \{2 j - 1, 2 j \} \quad (1 \leqslant i, j \leqslant 5 0)
$$

同一小块内任意两个不同小格都有公共顶点，所以每个小块至多有一个王。小块总数与王的总数同为 2500，故每个小块恰有一个王。

按照王在 $Q _ { i j }$ 的上行或下行，分别称它为 T 块或 B 块；按照王在左列或右列，分别称它为 L 块或 R 块。令 $x _ { i j } = 0 , 1$ 分别表示 $Q _ { i j }$ 为 $T , B$ 块，令 $y _ { i j } = 0 , 1$ 分别表示 $Q _ { i j }$ 为 $L , R$ 块。

若上下相邻的两个小块中，上块为 B 块而下块为 T 块，则两个王所在的原棋盘行相邻，所在列相同或相邻，因而能够互相攻击。左右方向同理：左块为 R 块而右块为 $L$ 块也不可能。因此

$$
x _ {i j} \leqslant x _ {i + 1, j}, \quad y _ {i j} \leqslant y _ {i, j + 1}
$$

其中第一个不等式适用于 $1 \leqslant i \leqslant$ 49，第二个适用于 $1 \leqslant j \leqslant 4 9$ 

固定块行 i。其中 50 个小块各有一个王，而原棋盘第 2i−1 行与第 2i 行各有 25 个王，所以该块行恰有 25 个 T 块和 25 个 B 块。类似地，每个块列恰有 25 个 L 块和 25 个 R 块，即

$$
\sum_ {j = 1} ^ {5 0} x _ {i j} = 2 5, \quad \sum_ {i = 1} ^ {5 0} y _ {i j} = 2 5
$$

对相邻两个块行的第一个单调关系求和，得到

$$
0 \leqslant \sum_ {j = 1} ^ {5 0} (x _ {i + 1, j} - x _ {i j}) = 2 5 - 2 5 = 0
$$

故每一项都为 0，即 $x _ { i + 1 , j } = x _ { i j }$ 。于是同一块列中的所有小块具有相同的 $T / B$ 类型。对固定的相邻块列 $j , j + 1$ ，将第二个单调关系对 i 求和，同样有

$$
0 \leqslant \sum_ {i = 1} ^ {5 0} (y _ {i, j + 1} - y _ {i j}) = 2 5 - 2 5 = 0
$$

因此 $y _ { i , j + 1 } = y _ { i j }$ ，同一块行中的所有小块具有相同的 $L / R$ 类型。于是，全部小块可由 50 个块列类型 $C _ { 1 } , \cdot \cdot \cdot , C _ { 5 0 } \in \{ T , B \}$ 和 50 个块行类型 $H _ { 1 } , \cdot \cdot \cdot , H _ { 5 0 } \in \{ L , R \}$ 唯一描述；块列中恰有 25 个 T 列和 25 个 B 列，块行中恰有 25 个 L 行和 25 个 R 行。

现在考察对角相邻的两个小块。若相邻块列 $j , j + 1$ 的类型依次为T,B，相邻块行 $i , i + 1$ 的类型依次为 $L , R$ ，则 $Q _ { i , j + 1 }$ 中的王位于原棋盘的 (2i,2j+1)，而 $Q _ { i + 1 , j }$ 中的王位于 $( 2 i + 1 , 2 j )$ ；这两个小格有公共顶点，矛盾。类似地，若块列类型依次为 $B , T$ ，块行类型依次为 R,L，则$Q _ { i j }$ 与 $Q _ { i + 1 , j + 1 }$ 中的王分别位于 $( 2 i , 2 j )$ 与 $( 2 i + 1 , 2 j + 1 )$ ，仍会互相攻击。由此得到两条禁配关系

$$
\begin{array}{l l l l}{{(\mathrm{T} \rightarrow \mathrm{B}) _ {\text {块列}}}}&{{\text {不能与}}}&{{(\mathrm{L} \rightarrow \mathrm{R}) _ {\text {块行}}}}&{{\text {并存}}}\\{{(\mathrm{B} \rightarrow \mathrm{T}) _ {\text {块列}}}}&{{\text {不能与}}}&{{(\mathrm{R} \rightarrow \mathrm{L}) _ {\text {块行}}}}&{{\text {并存}}}\end{array}
$$

由于块列类型中 T,B 都出现，必有一对相邻块列的类型不同。先设某处出现 $T \to B .$ 。第一条禁配关系表明，块行类型序列中不能出现 $L  R ;$ ；而 L,R 各有 25 个，所以所有 R 必须排在所有 L 之前，即

$$
H _ {1} = \dots = H _ {2 5} = R, \qquad H _ {2 6} = \dots = H _ {5 0} = L
$$

特别地，第 25,26 个块行之间出现 $R \to L$ 。第二条禁配关系随即表明，块列类型序列中不能出现 $B  T$ ，故所有 T 必须排在所有 B 之前，即

$$
C _ {1} = \dots = C _ {2 5} = T, \qquad C _ {2 6} = \dots = C _ {5 0} = B
$$

若某处出现 $B  T$ ，同理先由第二条禁配关系、再由第一条禁配关系得到

$$
H _ {1} = \dots = H _ {2 5} = L, \quad H _ {2 6} = \dots = H _ {5 0} = R
$$

以及

$$
C _ {1} = \dots = C _ {2 5} = B, \qquad C _ {2 6} = \dots = C _ {5 0} = T
$$

所以至多有这两种摆法，而且每种类型序列都唯一确定每个小块中王的位置。

IMOSL 1996 C2 

设 $n \geqslant 2 .$ 。将一个 $( n - 1 ) \times ( n - 1 )$ 正方形按通常方式分成 $( n - 1 ) ^ { 2 }$ 个单位正方形。这些单位正方形共有 $n ^ { 2 }$ 个顶点，现将每个顶点染成红色或蓝色。求满足下列条件的染色方法数：每个单位正方形的四个顶点中恰有两个红色顶点。

解

答案： $2 ^ { n + 1 } - 2$ 种。

将红色记为 1，蓝色记为 0。考察任意相邻的两条水平点阵行，设下行的颜色依次为$x _ { 1 } , x _ { 2 } , \cdots , x _ { n }$ ，上行的颜色依次为 $y _ { 1 } , y _ { 2 } , \cdots , y _ { n }$ 。第 $j$ 个单位正方形恰有两个红色顶点，等价于

$$
x _ {j} + x _ {j + 1} + y _ {j} + y _ {j + 1} = 2\tag{1}
$$

如果下行存在一对相邻同色点，例如 $x _ { k } = x _ { k + 1 }$ ，则由式 (1) 可知 $y _ { k } = 1 - x _ { k }$ 且 $y _ { k + 1 } =$ $1 - x _ { k + 1 }$ 。若已经知道 $y _ { j } = 1 - x _ { j }$ ，再由式 (1) 得

$$
y _ {j + 1} = 2 - x _ {j} - x _ {j + 1} - y _ {j} = 1 - x _ {j + 1}
$$

同理也可以向左传播。因此整条上行被唯一确定为下行的逐点反色。

如果下行红蓝相间，则对每个 j 都有 $x _ { j } + x _ { j + 1 } = 1$ ，式 (1) 便化为 $y _ { j } + y _ { j + 1 } = 1$ 。所以此时上行也必须红蓝相间，但可以任选以红色或蓝色开头。

现在按最下面一行分类。如果最下面一行不是红蓝相间，那么它有 $2 ^ { n } - 2$ 种选择。其上每一行都被唯一确定为前一行的逐点反色，所以这一类共有 $2 ^ { n } - 2$ 种染色。

如果最下面一行红蓝相间，则每一条水平行都必须红蓝相间。反过来，只要每一行都红蓝相间，每个单位正方形的上下两边便各有一个红色顶点，条件自动成立。每一行可以独立选择以红色或蓝色开头，共有 $2 ^ { n }$ 种染色。

综上，染色方法总数为

$$
(2 ^ {n} - 2) + 2 ^ {n} = 2 ^ {n + 1} - 2
$$

Russian Federal 2000 Grade 9 P8 

$2 0 0 \times 2 0 0$ 的方格表中的每个方格都被染为黑白二色之一，其中黑格恰比白格多 404 个。

求证：可以找到一个 $2 \times 2$ 的正方形，其中白格数目为奇数。

## 解

反证法。假设所述的正方形不存在，则每个 $2 \times 2$ 正方形中都有偶数个白格。

考察任意相邻的两行。对于这两行与任意相邻两列交出的 $2 \times 2$ 正方形，其中白格数为偶数，所以两行在左列的两个方格同色，当且仅当它们在右列的两个方格同色。从最左一列开始逐列递推可知，这两行要么逐格同色，要么逐格异色；后一种情形中，一行恰为另一行的逐格反色。

这一结论对每对相邻行都成立。逐行递推，并利用逐格反色两次便回到原行，可知表中的每一行都等于第一行或第一行的逐格反色。

设在第一行中有 a 个黑格，在表中该种类型有 b 行。于是，表中的黑格数目为

$$
a b + (2 0 0 - a) (2 0 0 - b)
$$

而白格数目为

$$
a (2 0 0 - b) + b (2 0 0 - a)
$$

由题意知，它们的差为 404，亦即

$$
4 a b - 4 0 0 (a + b) + 4 0 0 0 0 = 4 0 4 \iff (a - 1 0 0) (b - 1 0 0) = 1 0 1
$$

注意到 101 是质数，上式要求 |a−100| 与 |b−100| 中一个为 1，另一个为 101；这与 $| a - 1 0 0 | \leqslant$ $1 0 0 , | b - 1 0 0 | \leqslant 1 0 0$ 矛盾。

故而原命题得证。

设 m,n 为正整数。一张 2m×2n 方格表按通常的棋盘方式染成黑白两色。在白格上放置mn 枚棋子，每格至多放一枚，且任意两枚棋子所在的白格不能斜向相邻。求放置方法数。

## 解

答案： $\binom { m + n } { m }$ 种。

把棋盘按每两行、每两列分成 mn 个互不相交的 2×2 基本块。每个基本块中的两个白格斜向相邻，所以每块至多放一枚棋子。棋子总数与基本块数同为 mn，故每个基本块中恰有一枚棋子。

不妨设每个基本块的左上格和右下格为白格。若棋子位于左上格，就称该块为 UL 型；若棋子位于右下格，就称该块为 LR 型。

若某个基本块为 UL 型，则它上方和左方的相邻基本块只要存在，也必须为 UL 型。事实上，如果其中某块为 LR 型，则两块中的棋子将斜向相邻。类似地，若某块为 LR 型，则它下方和右方的相邻基本块也必须为 LR 型。

因此，所有 UL 型基本块构成一个向左、向上封闭的区域，所有 LR 型基本块构成一个向右、向下封闭的区域。两个区域之间的边界是一条从基本块阵列左下角到右上角、每步向右或向上的单调格路。

反过来，任取一条这样的单调格路，把路径左上方的基本块全部定为 UL 型，把右下方的基本块全部定为 LR 型。区域的封闭性排除了相邻基本块中可能造成斜向相邻的 LR、UL型组合，故所得放置合法。因此合法放置与这些单调格路一一对应。

每条路径包含 n 个横步和 m 个纵步，所以路径数为

$$
\binom{m + n}{m}
$$

这就是所求的放置方法数。

British 2nd Round 2020 P3 

一个 $2 0 1 9 \times 2 0 1 9$ 方格表的每个单位格被染成黑色或白色。若对于每个 $1 \leqslant k \leqslant 2 0 1 9$ ，任意一个由连续 k 行和连续 k 列构成的 $k \times k$ 子方格表中，黑格数与白格数之差的绝对值都不超过 1，则称该染色是平衡的。求平衡染色的总数。

## 解

答案： $2 ^ { 1 0 1 2 } - 6$ 种。

每个 $2 \times 2$ 子方格表共有 4 格，黑白格数之差是偶数，所以平衡条件迫使其中恰有两个黑格和两个白格。

如果某一列中出现两个竖直相邻的同色格，那么与它们处在同一个 $2 \times 2$ 子方格表中的另外两个格必须同色且颜色相反。沿左右方向重复这一推理，可知这两行完全相同，而且每行均黑白相间。再考察这两行与其他相邻行组成的 $2 \times 2$ 子方格表，可逐步推出所有行都黑白相间。

对称地，如果某一行中出现两个水平相邻的同色格，那么所有列都黑白相间。方格表中不可能同时出现竖直相邻的同色格和水平相邻的同色格，否则前一种情形迫使所有行黑白相间，与后一对水平相邻同色格矛盾。如果两种同色相邻格都不存在，则整个方格表只能是两种标准棋盘染色之一。

因此，除两种标准棋盘染色外，所有平衡染色恰分为两类：第一类中所有行都黑白相间，并且存在一对完全相同的相邻行；第二类中所有列都黑白相间，并且存在一对完全相同的相邻列。这两类由转置一一对应，下面只计数第一类。

令 $2 0 1 9 = 2 r + 1$ ，其中 $r = 1 0 0 9$ 。用 $\varepsilon _ { i } \in \{ - 1 , 1 \}$ 表示第 i 行最左格的颜色。由于每行都黑白相间，整幅染色由序列

$$
\varepsilon_ {1}, \varepsilon_ {2}, \dots , \varepsilon_ {2 0 1 9}
$$

唯一确定。

若 k 为偶数，则一个 $k \times k$ 子方格表的每一行都有相同数量的黑格和白格，所以它自动平衡。若 k 为奇数，则每一行在该子方格表内的黑白格数之差为 $\varepsilon _ { i }$ 或 $- \varepsilon _ { i }$ ，符号只取决于子方格表从哪一列开始。因此，所有奇数阶子方格表平衡，当且仅当序列 $\left( \varepsilon _ { i } \right)$ 的每个奇数长度连续片段之和都等于 1 或 −1。

定义

$$
D = \left\{i: \varepsilon_ {i} = \varepsilon_ {i + 1} \right\}
$$

于是 $i \in D$ 当且仅当第 i 行和第 $i + 1$ 行完全相同。

引理：当 $D \neq \emptyset$ 时，序列 $\left( \varepsilon _ { i } \right)$ 的每个奇数长度连续片段之和都等于 1 或 −1，当且仅当D 中所有元素具有相同的奇偶性。

先证必要性。若 D 中既有奇数又有偶数，则可在按大小排列的 D 中取两个相邻元素$i < j$ ，使 $i , j$ 奇偶性不同。此时 $j - i$ 为奇数，而 i 与 j 之间的每一步都改变符号。结合$\varepsilon _ { i } = \varepsilon _ { i + 1 }$ 与 $\varepsilon _ { j } = \varepsilon _ { j + 1 }$ ，得到

$$
\varepsilon_ {i} + \varepsilon_ {i + 1} + \dots + \varepsilon_ {j + 1} = 3 \varepsilon_ {i}
$$

左边是一个长度为 $j - i + 2$ 的奇数长度连续片段之和，其绝对值为 3，矛盾。

再证充分性。若 D 中所有元素都是奇数，则每个偶数 t 都不属于 D，从而 $\varepsilon _ { t } + \varepsilon _ { t + 1 } = 0$ 在任意奇数长度连续片段中，可以沿这些偶数下标的相邻位置把除一个以外的所有项两两配对，每对之和为 0，故整个片段之和为 1 或 −1。若 D 中所有元素都是偶数，沿奇数下标的相邻位置配对即可。引理成立。

在 1,2,··· ,2018 中，奇数指标和偶数指标各有 1009 个。先指定 D 中元素的共同奇偶性，再从相应的 1009 个指标中任选一个非空子集作为 D，最后任选 $\varepsilon _ { 1 }$ 的符号。知道 D 和 $\varepsilon _ { 1 }$ 后，每一步保持符号还是改变符号都被唯一确定。因此第一类染色共有

$$
2 \cdot (2 ^ {1 0 0 9} - 1) \cdot 2 = 2 ^ {1 0 1 1} - 4
$$

种。第二类染色同样有 $2 ^ { 1 0 1 1 } - 4$ 种。最后加上两种标准棋盘染色，平衡染色的总数为

$$
2 (2 ^ {1 0 1 1} - 4) + 2 = 2 ^ {1 0 1 2} - 6
$$

EGMO 2015 P2 

多米诺骨牌是一个 2×1 或 1×2 的方格块。设 n 为正整数，在一张 $2 n \times 2 n$ 方格表上放置恰好 $n ^ { 2 }$ 块互不重叠的多米诺骨牌，使得每个 $2 \times 2$ 子方格表中都至少有两个未被覆盖且位于同一行或同一列的单位方格。问共有多少种放置方法？

解

答案： $\textstyle { { \binom { 2 n } { n } } ^ { 2 } }$ 种。

先按每两行、每两列将整个方格表周期性地分成 $n ^ { 2 }$ 个互不相交的 $2 \times 2$ 基本块。题设表明每个基本块中至多有两个方格被骨牌覆盖；另一方面， $n ^ { 2 }$ 块骨牌一共覆盖 $2 n ^ { 2 }$ 个方格。因此每个基本块中恰有两个方格被覆盖，而另外两个未覆盖格同行或同列，所以两个被覆盖格也同行或同列。

还需证明每个基本块中的两个被覆盖格属于同一块骨牌。把所有被覆盖格组成的集合记为 S。原有骨牌把 S 中的方格两两配对；同时，在每个基本块内将其中两个相邻的被覆盖格配成一对，这又给出一种配对。若两种配对不同，就把两种配对的连边叠在一起并删去重合的边，所得图中至少有一条两种连边交替出现的闭路。方格表中的有限闭路必有转角，转角处连续的三个方格占据某个 $2 \times 2$ 子方格表的三个位置，而它们全被覆盖，这与题设矛盾。因此两种配对相同，即每个基本块内恰有一块完整的骨牌。

对于任意 $2 \times 2$ 子方格表，题设条件等价于其中不存在位于一条对角线两端的两个被覆盖格。事实上，若存在同排或同列的两个未覆盖格，显然不可能有一条覆盖对角线；反过来，若不存在覆盖对角线，则至多有两个方格被覆盖，并且当恰有两个方格被覆盖时它们同行或同列，故未覆盖格中总能找到同行或同列的两个。

按照骨牌位于基本块的下边、右边、上边、左边这四种情形，依次把基本块记为A,B,C,D。将基本块的行从上到下编号、列从左到右编号，并定义 $p _ { i , j } = 1$ 当且仅当第 $( i , j )$ 个基本块为A 或 B，定义 $q _ { i , j } = 1$ 当且仅当它为 A 或 $D$ 。

考察跨过两个相邻基本块公共边界的 $2 \times 2$ 子方格表。对于左右相邻的两块，出现覆盖对角线恰好对应 p 从 1 变为 0，或 q 从 0 变为 1；对于上下相邻的两块，出现覆盖对角线恰

好对应 p 或 q 从 1 变为 0。因此

$$
\begin{array}{l l} p _ {i, j} \leqslant p _ {i, j + 1} & q _ {i, j} \geqslant q _ {i, j + 1} \\ p _ {i, j} \leqslant p _ {i + 1, j} & q _ {i, j} \leqslant q _ {i + 1, j} \end{array}
$$

于是， $p = 1$ 的基本块构成一个向右、向下封闭的区域，其边界是一条从左下角到右上角、每步向右或向上的单调格路； $q = 1$ 的基本块构成一个向左、向下封闭的区域，其边界是一条从左上角到右下角、每步向右或向下的单调格路。四种基本块及这两条边界的示意图如下。

反过来，任取上述两条单调格路，令它们确定相应的 0-1 数组 $p , q$ ，再按照

$$
(p, q) = (1, 1), (1, 0), (0, 0), (0, 1) \quad \Longleftrightarrow \quad A, B, C, D
$$

在每个基本块内放置骨牌，就得到唯一一种配置。下面验证它必满足题意。对于位于同一基本块内的 $2 \times 2$ 子方格表，结论显然；若它只跨过一条基本块边界，则由上述单调性可知没有覆盖对角线。若一个 $2 \times 2$ 子方格表的四格分别来自西北、东北、西南、东南四个基本块，则其一条对角线同时被覆盖将迫使 $p _ { \mathrm { N W } } = 1 , p _ { \mathrm { S E } } = 0$ ，另一条对角线同时被覆盖将迫使 $q _ { \mathrm { N E } } = 1 , q _ { \mathrm { S W } } = 0$ 也都与单调性矛盾。因此任意 $2 \times 2$ 子方格表中都没有覆盖对角线，配置合法。
