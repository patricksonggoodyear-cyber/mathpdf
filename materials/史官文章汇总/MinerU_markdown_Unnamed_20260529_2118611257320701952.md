$$
f (2) = 0\tag{1}
$$

$$
f (x f (y)) f (y) = f (x + y) \quad \forall x, y\tag{2}
$$

$$
f (x) \neq 0 \quad \forall 0 \leqslant x <   2\tag{3}
$$

解

取 $y = 2$ 。由于 $f ( 2 ) = 0$ ，原方程给出 $f ( x + 2 ) = 0 \ ( x \geqslant 0 )$ 。结合条件 (3) 及函数值非负，f 的零点集恰为 $[ 2 , + \infty )$ ，而 $f ( t ) > 0 \ ( 0 \leqslant t < 2 )$ 

固定 $0 \leqslant y < 2$ ，则 $f ( y ) > 0$ 。对任意 $x \geqslant 0$ ，由原方程和零点集的描述，

$$
x + y \geqslant 2 \quad \Longleftrightarrow \quad f (x + y) = 0 \quad \Longleftrightarrow \quad f (x f (y)) = 0 \quad \Longleftrightarrow \quad x f (y) \geqslant 2
$$

因此，作为 x 的两个条件 $x \geqslant 2 - y$ 和 $x \geqslant 2 / f ( y )$ 在非负实数范围内等价，阈值必相同，即$2 - y = 2 / f ( y )$ 。于是 $f ( y ) = 2 / ( 2 - y )$ 。综上，唯一可能的函数是

$$
f (x) = \left\{ \begin{array}{l l} \frac {2}{2 - x}, & 0 \leqslant x <   2, \\ 0, & x \geqslant 2. \end{array} \right.
$$

下面验证。显然 $f ( 2 ) = 0$ ，且在 [0,2) 上 f 不为零。若 $y \geqslant 2$ ，则 $f ( y ) = f ( x + y ) = 0$ 原方程成立。若 $0 \leqslant y < 2$ 且 $x + y \geqslant 2$ ，则 $x f ( y ) = 2 x / ( 2 - y ) \geqslant 2$ ，等式两边均为零。若$x + y < 2$ ，则 $x f ( y ) < 2$ ，并且

$$
f (x f (y)) f (y) = \frac {2}{2 - 2 x / (2 - y)} \cdot \frac {2}{2 - y} = \frac {2}{2 - x - y} = f (x + y)
$$

故此函数确实满足全部条件。
