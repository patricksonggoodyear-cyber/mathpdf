Moscow MO 1981 Grade 10 P4 

在边长为 1 的正方形内有一条长度不小于 200 的无自交折线。证明：存在一条平行于正方形某条边的直线，与这条折线至少相交于 101 个点。

## 解

设折线共有 n 条线段，顶点依次为 $P _ { i } = ( x _ { i } , y _ { i } )$ ，其中 $i = 0 , 1 , \cdots , n _ { \circ }$ 若其中有一条线段平行于正方形的某条边，则这条线段所在的直线与折线有无穷多个公共点，结论立即成立。以下设每条线段都不平行于正方形的边。

记第 i条线段的长度为 $l _ { i } ,$ ，它在水平方向和竖直方向上的投影长度分别为 $a _ { i } = \left| x _ { i } - x _ { i - 1 } \right|$ 与 $b _ { i } = | y _ { i } - y _ { i - 1 } | ,$ 。此时 $a _ { i } , b _ { i } > 0$ ，所以 $l _ { i } = \sqrt { a _ { i } ^ { 2 } + b _ { i } ^ { 2 } } < a _ { i } + b _ { i } \nonumber$ 。令 $\textstyle X = \sum _ { i = 1 } ^ { n } a _ { i } , \ Y =$ $\textstyle \sum _ { i = 1 } ^ { n } b _ { i } $ ，并记折线总长度为 L，则

$$
X + Y > \sum_ {i = 1} ^ {n} l _ {i} = L \geqslant 2 0 0
$$

因此 $X > 1 0 0$ 与 $Y > 1 0 0$ 中至少有一个成立。

引理： 单位线段内有有限个开区间。若这些开区间的长度之和大于 100，则单位线段上有一点至少属于其中 101 个开区间。

事实上，用所有区间的端点把单位线段分成有限个小区间。在每个小区间内部，覆盖它的开区间数是一个常数。若这些常数都不超过 ，则把各小区间的长度乘以相应的覆盖数再求和，可知原来所有开区间的长度之和不超过单位线段长度的 100 倍，即不超过 100，矛盾。引理成立。

不妨设 $X > 1 0 0$ 。把每条折线段在水平方向上的投影去掉两个端点，得到单位线段内的一个开区间。这些开区间的长度之和为 $X > 1 0 0$ 。由引理，存在 $t \in ( 0 , 1 )$ ，它属于至少 101个这样的投影开区间。于是竖直直线 $x = t$ 与相应的至少 101 条折线段都相交，并且每个交点都位于相应线段的内部。由于原折线没有自交，不同线段给出的这些交点彼此不同。因此直线 $x = t$ 与折线至少相交于 101 个点。

若 $Y > 1 0 0$ ，对各线段在竖直方向上的投影作同样的论证，即可得到一条满足要求的水平直线。

German National 1999 P4 

一个凸多边形 P 位于单位正方形 Q 内。证明：P 的周长不超过 4。

## 解

取 Q 的两组边所在方向作为坐标轴方向。设 P 在横坐标方向上的取值范围为 $[ x _ { - } , x _ { + } ]$ 在纵坐标方向上的取值范围为 $[ y _ { - } , y _ { + } ]$ ，并记 $w = x _ { + } - x .$ $h = y _ { + } - y .$ 。由于 P 位于单位正方形内，故 $w \leqslant 1$ 且 $h \leqslant 1$ o

先计算 P 的各边在横坐标方向上的投影长度之和。对于任意 $t \in ( x _ { - } , x _ { + } )$ ，直线 $x = t$ 与 P 所围成的闭凸区域的交集是一条线段。这些线段的上、下端点分别描出 P 的两条边界链；除去可能位于直线 $x = x _ { - }$ 或 $x = x _ { + }$ 上的竖直边，P 的整个边界正由这两条链组成。在每条链上，横坐标都从 $x _ { - }$ 单调变化到 $x _ { + }$ ，所以每条链的各边横向投影长度之和均为 $w .$ 。两端竖直边的横向投影长度为 0，因此 P 的所有边的横向投影长度之和恰为 $2 w$ 。同理，所有边的纵向投影长度之和恰为 2h。

设 P 的顶点按边界顺序为 $A _ { i } = \left( x _ { i } , y _ { i } \right)$ ，其中 $1 \leqslant i \leqslant n$ ，并令 $A _ { n + 1 } = A _ { 1 }$ 。记边 $A _ { i } A _ { i + 1 }$ 的横向、纵向投影长度分别为 $p _ { i } = | x _ { i + 1 } - x _ { i } | \ L _ { \circ } \ L _ { i } = | y _ { i + 1 } - y _ { i } |$ ，则

$$
\left| A _ {i} A _ {i + 1} \right| = \sqrt {p _ {i} ^ {2} + q _ {i} ^ {2}} \leqslant p _ {i} + q _ {i}
$$

而上述投影总量的计算给出

$$
\sum_ {i = 1} ^ {n} p _ {i} = 2 w, \qquad \sum_ {i = 1} ^ {n} q _ {i} = 2 h
$$

于是 P 的周长满足

$$
\sum_ {i = 1} ^ {n} \left| A _ {i} A _ {i + 1} \right| \leqslant \sum_ {i = 1} ^ {n} (p _ {i} + q _ {i}) = 2 w + 2 h \leqslant 4
$$

Kurschak 1968 P2 

设 n 为正整数。在半径为 n 的圆盘内放置了 4n 条长度均为 1 的线段。证明：对于任意给定的直线 L，都存在该圆的一条弦，它平行于 L 或垂直于 L，并且至少与其中两条线段相交。

## 解

取相互垂直的 x 轴和 y 轴，使 x 轴平行于 $L _ { \circ }$ 。将第 i 条线段分别正投影到两轴上，所得闭区间记为 $I _ { i } , J _ { i }$ ，长度分别记为 $a _ { i } , b _ { i }$ 。由于原线段的长度为 1，故

$$
a _ {i} + b _ {i} \geqslant \sqrt {a _ {i} ^ {2} + b _ {i} ^ {2}} = 1
$$

对所有线段求和，得到

$$
\sum_ {i = 1} ^ {4 n} a _ {i} + \sum_ {i = 1} ^ {4 n} b _ {i} \geqslant 4 n
$$

因此两个方向中至少有一个方向的投影总长不小于 $2 n$ 。

不妨设 $\textstyle \sum _ { i = 1 } ^ { 4 n } a _ { i } \geqslant 2 n$ 。圆盘在 x 轴上的投影是一个长度为 $2 n$ 的闭区间 D，而每个 $I _ { i }$ 都包含在 D 中。若所有 $I _ { i }$ 两两不交，则将它们依次排列后，相邻闭区间之间均存在正长度的空隙，故

$$
\sum_ {i = 1} ^ {4 n} a _ {i} <   | D | = 2 n
$$

这与假设矛盾。因此存在两个投影区间 $I _ { i } , I _ { j }$ 相交。

还需排除公共点只是 D 的端点的情形。若一条单位线段的投影包含 D 的某个端点，则原线段包含圆盘在该方向上的极端点。圆盘在该点处的切线与圆盘只有一个公共点，因此这条正长度线段的投影不可能退化为该端点。于是两个都包含该端点的投影区间必在 D 的内部发生重叠。故可以取 $x _ { 0 } \in D$ 的内部，使 $x _ { 0 } \in I _ { i } \cap I _ { j }$ 

过 $x _ { 0 }$ 作垂直于 x 轴的直线。由于 $x _ { 0 }$ 同时属于两条线段的投影，该直线与这两条线段都相交；又因 $x _ { 0 }$ 位于 D 的内部，它在圆盘中截出一条非退化弦。这条弦垂直于 L，满足要求。若投影总长不小于 $2 n$ 的是 y 方向，同理可得到一条平行于 $L$ 的弦。

## Romania TST 1998 P4

平面上给定有限条线段，它们的长度之和小于 $\sqrt { 2 }$ 。证明：可以在平面上作一个无限单位正方形网格，使所有网格线都不与这些线段相交。

解

设给定线段为 $S _ { 1 } , S _ { 2 } , \cdots , S _ { m }$ ，其长度分别为 $l _ { 1 } , l _ { 2 } , \cdots , l _ { m }$ 。对于方向角 $\theta _ { ; }$ ，取方向分别为 θ 和 $\theta + \pi / 2$ 的两条正交坐标轴，并将所有给定线段在这两个方向上的投影长度之和分别记为 $A ( \theta )$ 和 $B ( \theta )$ 

函数 $A ( \theta )$ 与 $B ( \theta )$ 都连续，并且旋转坐标轴 $9 0 ^ { \circ }$ 后两个投影总长互换，即

$$
A (\theta + \pi / 2) = B (\theta), \qquad B (\theta + \pi / 2) = A (\theta)
$$

因此连续函数 $A ( \theta ) - B ( \theta )$ 在相差 $\pi / 2$ 的两个方向上取相反数，故存在方向角 $\theta _ { 0 }$ ，使 $A ( \theta _ { 0 } ) =$ $B ( \theta _ { 0 } )$ 0

固定这组正交坐标轴。设第 i 条线段在两轴上的投影长度为 $a _ { i } , b _ { i }$ 。由 Cauchy 不等式，

$$
a _ {i} + b _ {i} \leqslant \sqrt {2} \sqrt {a _ {i} ^ {2} + b _ {i} ^ {2}} = \sqrt {2} l _ {i}
$$

从而

$$
A \left(\theta_ {0}\right) + B \left(\theta_ {0}\right) = \sum_ {i = 1} ^ {m} \left(a _ {i} + b _ {i}\right) \leqslant \sqrt {2} \sum_ {i = 1} ^ {m} l _ {i} <   2
$$

结合 $A ( \theta _ { 0 } ) = B ( \theta _ { 0 } )$ ，可知两个方向上的投影总长都小于 1。

将第一方向取作 x 轴，并把每条线段在 x 轴上的投影记为闭区间 $I _ { i }$ 。把这些区间按模 1映射到圆周 R $\cdot / \mathbb { Z }$ 上，所得圆弧覆盖的总长度不超过 $\begin{array} { r } { \sum _ { i = 1 } ^ { m } | I _ { i } | = A ( \theta _ { 0 } ) < 1 } \end{array}$ ，所以它们不能覆盖整个单位圆周。于是可以选取 $\alpha \in$ R，使 α 的剩余类不属于任何一个投影区间的像。此时对于任意整数 k，数 $\alpha + k$ 都不属于任何 $I _ { i }$ ，所以所有直线 $x = \alpha + k$ 都不与给定线段相交。

同理，由所有线段在 y 轴上的投影总长小于 1，可以选取 $\beta \in$ R，使所有直线 $y = \beta + k$ 都不与给定线段相交，其中 $k \in \mathbb { Z }$ 。两族直线 $x = \alpha + k$ 与 $y = \beta + k$ 共同组成一个无限单位正方形网格，并且所有网格线均避开给定线段。

Moscow MO 1964 Grade 11 P1 

从平面上的点 O 引出若干个向量，它们的长度之和为 4。证明：可以选出其中若干个向量(也可以只选一个)，使所选向量之和的长度大于 1。

## 解

若给定向量中有零向量，删去它们既不改变向量长度之和，也不影响所要证明的结论。因此不妨设所有给定向量均非零。

以 O 为原点选取一组互相垂直的坐标轴。由于给定向量只有有限个，可以适当转动坐标轴，使每个向量在两个坐标轴方向上的投影都不为 0。设这些向量为 $\vec { v } _ { i } = ( x _ { i } , y _ { i } )$ ，其中1 ⩽ i ⩽ n。

分别考虑横轴正向、横轴负向、纵轴正向、纵轴负向这四条射线。对于每条射线，将在该方向上投影为正的所有向量的投影长度相加，并分别记所得总量为

$$
\begin{array}{l l} X _ {+} = \sum_ {x _ {i} > 0} x _ {i}, & X _ {-} = \sum_ {x _ {i} <   0} (- x _ {i}) \\ Y _ {+} = \sum_ {y _ {i} > 0} y _ {i}, & Y _ {-} = \sum_ {y _ {i} <   0} (- y _ {i}) \end{array}
$$

每个向量的两个坐标均非零，故

$$
| x _ {i} | + | y _ {i} | > \sqrt {x _ {i} ^ {2} + y _ {i} ^ {2}} = | \vec {v} _ {i} |
$$

于是

$$
X _ {+} + X _ {-} + Y _ {+} + Y _ {-} = \sum_ {i = 1} ^ {n} (| x _ {i} | + | y _ {i} |) > \sum_ {i = 1} ^ {n} | \vec {v} _ {i} | = 4
$$

所以 $X _ { + } , X _ { - } , Y _ { + } , Y _ { - }$ 中至少有一个大于 1。

不妨设 $X _ { + } > 1$ ，并选取所有满足 $x _ { i } > 0$ 的向量。这些向量之和在横轴正向上的投影长度恰为 $X _ { + }$ ，因此

$$
\left| \sum_ {x _ {i} > 0} \vec {v} _ {i} \right| \geqslant X _ {+} > 1
$$

其余三种情形完全相同，故总能选出满足要求的若干个向量。

TOT 2012 Spring Senior A-Level P4 

在一个空心单位立方体的六个面上各标记一点。将位于相邻两个面上的任意两个标记点用线段连接。证明：所得十二条线段的长度之和不小于 $6 \sqrt { 2 }$ o

## 解

把单位立方体置于空间直角坐标系中，使它为 $[ 0 , 1 ] ^ { 3 }$ 。对于 $i = 0 , 1$ ，分别把位于平面$x = i , \ y = i , \ z = i$ 上的标记点记为 $A _ { i } , \ B _ { i } , \ C _ { i }$ 。这样，题中的十二条线段恰好分为三组：四条 $A _ { i } B _ { j }$ 、四条 $A _ { i } C _ { j }$ 和四条 $B _ { i } C _ { j }$ ，其中 $i , j \in \{ 0 , 1 \}$ 。

先考虑四条 $A _ { i } B _ { j }$ 。将它们正投影到 $x y$ 平面，并把 $A _ { i } , \ B _ { j }$ 的投影分别记为 $A _ { i } ^ { \prime } , \ B _ { j } ^ { \prime }$ 。点$A _ { 0 } ^ { \prime }$ $B _ { 0 } ^ { \prime }$ $A _ { 1 } ^ { \prime }$ $B _ { 1 } ^ { \prime }$ 分别位于单位正方形的左、下、右、上四条边上，而四条线段的投影组成闭折线

$$
A _ {0} ^ {\prime} B _ {0} ^ {\prime} A _ {1} ^ {\prime} B _ {1} ^ {\prime} A _ {0} ^ {\prime}
$$

正投影不会增加线段的长度，所以四条 $A _ { i } B _ { j }$ 的长度之和不小于这条闭折线的长度。

对于闭折线的任意一条边 e，设它在横、纵方向上的投影长度分别为 $p _ { e } , \ q _ { e }$ ，则

$$
| e | = \sqrt {p _ {e} ^ {2} + q _ {e} ^ {2}} \geqslant \frac {p _ {e} + q _ {e}}{\sqrt {2}}
$$

沿闭折线依次从左边到下边、从下边到右边、从右边到上边、再从上边回到左边时，横向投影长度之和恰为 2，纵向投影长度之和也恰为 2。因此这四条投影线段的长度之和至少为

$$
\frac {2 + 2}{\sqrt {2}} = 2 \sqrt {2}
$$

从而四条 $A _ { i } B _ { j }$ 的长度之和不小于 $2 \sqrt { 2 }$ 

同理，把四条 $A _ { i } C _ { j }$ 正投影到 $x z$ 平面，把四条 $B _ { i } C _ { j }$ 正投影到 $y z$ 平面，可以分别得到另外两个单位正方形中的同类闭折线。因此，这两组线段的长度之和也都不小于 $2 \sqrt { 2 }$ 。

三组共包含题中的全部十二条线段，故它们的长度之和不小于

$$
3 \cdot 2 \sqrt {2} = 6 \sqrt {2}
$$

Putnam 1969 B4 

设 Γ 是一条长度为 1 的平面曲线。证明：存在一个面积为 $1 / 4$ 的闭矩形区域包含 Γ。

## 解

设曲线 Γ 的两个端点为 S,T。若 S,T 不重合，就以直线 $S T$ 的方向为横轴方向；若二者重合，就任取一条过该点的直线作为横轴。经过平移后，可以设两个端点都位于横轴上。

在这个坐标系中，取包含 的最小轴平行闭矩形 ，并设它的横、纵边长分别为 $a , b _ { \circ }$ 在曲线上分别选取横坐标最小、横坐标最大、纵坐标最小和纵坐标最大的点，把这些点连同两个端点按照它们在曲线上的实际出现顺序排列，并依次连接相邻的点，得到一条折线。若其中有重合的点，就删去重复项。设这条折线的长度为 $L _ { 0 }$ ，则每条弦的长度都不超过它所截取的相应曲线段的长度，因此 $L _ { 0 } \leqslant 1$ o

设折线各边在横、纵方向上的投影长度分别为 $u _ { k } , v _ { k }$ ，并令

$$
P = \sum_ {k} u _ {k}, \qquad Q = \sum_ {k} v _ {k}
$$

由于折线经过曲线的横坐标最小点和最大点，故 $P \geqslant a .$ 。又因为折线从横轴出发，经过纵坐标最小点和最大点，最后回到横轴，所以无论这两个极值点出现的先后顺序如何，都有$Q \geqslant 2 b$ 

对平面向量 $( u _ { k } , v _ { k } )$ 使用三角形不等式，可得

$$
L _ {0} = \sum_ {k} \sqrt {u _ {k} ^ {2} + v _ {k} ^ {2}} \geqslant \sqrt {\left(\sum_ {k} u _ {k}\right) ^ {2} + \left(\sum_ {k} v _ {k}\right) ^ {2}} = \sqrt {P ^ {2} + Q ^ {2}} \geqslant \sqrt {a ^ {2} + 4 b ^ {2}}
$$

因此 $a ^ { 2 } + 4 b ^ { 2 } \leqslant 1$ 。另一方面，由 $( a - 2 b ) ^ { 2 } \geqslant 0$ 可知

$$
4 a b \leqslant a ^ {2} + 4 b ^ {2} \leqslant 1
$$

所以矩形 R 的面积 $a b$ 不超过 $1 / 4 { \mathrm { { c } } }$ 。若其面积小于 $1 / 4$ ，只需将矩形的一条边向外扩大，便可得到一个仍包含 Γ 且面积恰为 $1 / 4$ 的闭矩形区域。
