高联 2010 P4

设整数 n ⩾ 3。一种密码锁的密码设置是在正 n 边形 $A _ { 1 } A _ { 2 } \dotsm A _ { n }$ 的每个顶点处赋值 0 或1，同时将每个顶点涂成红、蓝两种颜色之一，使得任意相邻两个顶点的数字或颜色中至少有一个相同。问：这种密码锁共有多少种不同的密码设置？

## 解

约定 $A _ { n + 1 } = A _ { 1 }$ 。对每条边 $A _ { i } A _ { i + 1 }$ ，若两端点的数字不同而颜色相同，就在这条边上标记 $a ;$ ；若数字相同而颜色不同，就标记 $b ;$ ；若数字和颜色都相同，就标记 $c _ { \circ }$ 。题设排除了数字和颜色同时不同的情形，因此每条边恰好得到 $a , b , c$ 中的一种标记。

固定顶点 $A _ { 1 }$ 的数字与颜色后，沿正 n 边形依次读取各边的标记，就能唯一确定其余顶点的数字与颜色。绕行一周后回到 $A _ { 1 }$ 的初始状态，当且仅当标记 $a$ 的边数与标记 b 的边数均为偶数。

记所有长度为 n 的字母串 $w \in \{ a , b , c \} ^ { n }$ 构成的集合为 W，并以 $N _ { a } ( w ) , N _ { b } ( w )$ 分别表示$w$ 中字母 $a , b$ 的出现次数。设其中 $N _ { a } ( w ) , N _ { b } ( w )$ 均为偶数的字母串有 $E _ { n }$ 个。利用奇偶筛，有

$$
\begin{array}{l} 4 E _ {n} = \sum_ {w \in W} \big (1 + (- 1) ^ {N _ {a} (w)} \big) \big (1 + (- 1) ^ {N _ {b} (w)} \big) \\ \qquad = 3 ^ {n} + (- 1 + 1 + 1) ^ {n} + (1 - 1 + 1) ^ {n} + (- 1 - 1 + 1) ^ {n} \\ \qquad = 3 ^ {n} + 2 + (- 1) ^ {n} \end{array}
$$

这里第二个等号中，四项分别对应展开括号后 $1 , ( - 1 ) ^ { N _ { a } ( w ) } , ( - 1 ) ^ { N _ { b } ( w ) } , ( - 1 ) ^ { N _ { a } ( w ) + N _ { b } ( w ) }$ 在所有字母串上的求和。

顶点 $A _ { 1 }$ 的数字与颜色共有 4 种选择，而每个符合双偶条件的边标记串与每种 $A _ { 1 }$ 的初始状态唯一对应一种密码设置。因此密码设置的总数为

$$
4 E _ {n} = 3 ^ {n} + 2 + (- 1) ^ {n} = \left\{ \begin{array}{l l} 3 ^ {n} + 1, & n \text {为奇数} \\ 3 ^ {n} + 3, & n \text {为偶数} \end{array} \right.
$$

设正整数 n,k 满足 $k \geqslant n$ 且同奇偶。有编号 $1 , \cdots , 2 n$ 的灯，初始全灭，每一步切换一盏灯的状态。记 N 为恰经 k 步后前 n 盏灯亮、后 n 盏灯灭的操作序列数，M 为其中从未操作后 n 盏灯的序列数。求 $N / M$ 4

## 解

一盏灯从灭变亮当且仅当被切换奇数次，从灭变灭当且仅当被切换偶数次。因此，符合终态要求的序列中，前 n 盏灯各被切换奇数次，后 n 盏灯各被切换偶数次。由于 $k - n$ 是非负偶数，先将前 n 盏灯各切换一次，再将第 1 盏灯切换 $k - n$ 次，就得到一种从未操作后 $n$ 盏灯的合格序列，故 $M > 0$ 0

固定一条这样的受限合格序列，设第 i 盏灯被切换 $k _ { i }$ 次，其中 $1 \leqslant i \leqslant n$ 。每个 $k _ { i }$ 都是正奇数，且 $k _ { 1 } + \cdots + k _ { n } = k { \mathrm { ~ o ~ } }$ 。从第 i 盏灯的 $k _ { i }$ 次操作中任选偶数次，改为操作与之配对的第 $n + i$ 盏灯，则终态不变。偶数大小的子集恰有 $2 ^ { k _ { i } - 1 }$ 个，因为任选一个指定的操作位置并改变其是否入选，便将所有子集两两配成一奇一偶。各对灯的选择相互独立，因此这条受限序列对应的合格序列数为

$$
\prod_ {i = 1} ^ {n} 2 ^ {k _ {i} - 1} = 2 ^ {k - n}
$$

反过来，对于任一合格序列，把其中所有对第 n+i 盏灯的操作改为对第 i 盏灯的操作。由于第 $n + i$ 盏灯原本被切换偶数次，所得序列仍使第 i 盏灯被切换奇数次，从而是一条唯一确定的受限合格序列；原序列也唯一确定了每对灯中被改动的偶数大小子集。因此每条受限合格序列恰对应 $2 ^ { k - n }$ 条合格序列，故 $N / M = 2 ^ { k - n }$ 0

IMC 2020 P1 

设 n 为正整数。由字母 $a , b , c , d$ 构成的长度为 n 的词中，字母 a 与字母 b 都出现偶数次的词有多少个？

## 解

记所有长度为 n 的四字母词构成的集合为 W。对 $w \in W$ ，分别以 $N _ { a } ( w ) , N _ { b } ( w )$ 表示字母 $a , b$ 在 w 中的出现次数。由于 $\left( 1 + ( - 1 ) ^ { k } \right) / 2$ 在 k 为偶数时等于 1，在 k 为奇数时等于 0，所求词数 $E _ { n }$ 满足

$$
4 E _ {n} = \sum_ {w \in W} \left(1 + (- 1) ^ {N _ {a} (w)}\right) \left(1 + (- 1) ^ {N _ {b} (w)}\right)
$$

将乘积展开。全部词的个数为 $4 ^ { n }$ 。对每个位置，求和 $( - 1 ) ^ { N _ { a } ( w ) }$ 时，选 a 的权重为 −1，选$b , c , d$ 的权重均为 1，所以这一项在所有词上的和为 $( - 1 + 1 + 1 + 1 ) ^ { n } = 2 ^ { n }$ ；同理， $( - 1 ) ^ { N _ { b } ( w ) }$ 的和也为 $2 ^ { n }$ 。最后，对每个位置， $( - 1 ) ^ { N _ { a } ( w ) + N _ { b } ( w ) }$ 的四种字母权重之和为 $- 1 - 1 + 1 + 1 = 0$ 故其在所有词上的和为 0，这里用到了 $n \geqslant 1$ 。因此

$$
E _ {n} = \frac {4 ^ {n} + 2 ^ {n} + 2 ^ {n}}{4} = 4 ^ {n - 1} + 2 ^ {n - 1}
$$

Iran 2nd Round 2007 P2 

设 $O , A$ 是单位正方体同一面上的两个对角顶点。称顶点序列 $V _ { 0 } , V _ { 1 } , \cdots , V _ { n }$ 为一条 n 步路径，如果每两个相邻顶点均为正方体一条棱的两个端点。问：从 O 出发走 1386 步最终回到 O 的路径数，与从 O 出发走 1386 步最终到达 A 的路径数，哪个更多？

## 解

以 O 为原点，沿经过 O 的三条棱建立坐标系，使正方体的顶点坐标属于 $\{ 0 , 1 \} ^ { 3 }$ ，并不妨设 $A = ( 1 , 1 , 0 )$ 。把一次沿第一、第二、第三坐标方向走棱分别记为字母 $x , y , z _ { \mathrm { { o } } }$ 于是从 O 出发的每条 1386 步路径与一个长度为 1386 的字母串 $w \in \{ x , y , z \} ^ { 1 3 8 6 } \textrm { -- }$ 一对应。记$N _ { x } ( w ) , N _ { y } ( w ) , N _ { z } ( w )$ 为三种字母在 w 中的出现次数。每走一次相应方向的棱，就翻转该坐标，因此路径回到 O 当且仅当三个次数均为偶数；路径到达 A 当且仅当 $N _ { x } ( w ) , N _ { y } ( w )$ 均为奇数且 $N _ { z } ( w )$ 为偶数。

分别记上述两类路径数为 $R , S$ 。由于总步数 1386 为偶数，只要 $N _ { z } ( w )$ 为偶数， $N _ { x } ( w )$ 与 $N _ { y } ( w )$ 就同奇偶，故这样的字母串恰好对应这两类路径。利用奇偶筛，得到

$$
R + S = \sum_ {w \in \{x, y, z \} ^ {1 3 8 6}} \frac {1 + (- 1) ^ {N _ {z} (w)}}{2} = \frac {3 ^ {1 3 8 6} + (1 + 1 - 1) ^ {1 3 8 6}}{2} = \frac {3 ^ {1 3 8 6} + 1}{2}
$$

又因为在这些字母串中， $( - 1 ) ^ { N _ { x } ( w ) }$ 对回到 O 的路径取值为 1，对到达 A 的路径取值为 −1，再次利用奇偶筛可得

$$
R - S = \sum_ {w \in \{x, y, z \} ^ {1 3 8 6}} \frac {1 + (- 1) ^ {N _ {z} (w)}}{2} (- 1) ^ {N _ {x} (w)} = \frac {(- 1 + 1 + 1) ^ {1 3 8 6} + (- 1 + 1 - 1) ^ {1 3 8 6}}{2} = 1
$$

所以 $R = ( 3 ^ { 1 3 8 6 } + 3 ) / 4 , \ S = ( 3 ^ { 1 3 8 6 } - 1 ) / 4$ 。从 O 出发走 1386 步最终回到 O 的路径恰比最终到达 A 的路径多 1 条。
