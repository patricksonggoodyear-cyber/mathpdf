这些题都通过依次控制最小分母，证明固定项数的有理式只有有限种正整数表示。

Romania National 2017 Grade 9 P3 

给定两个正整数 a,n，求证：

(a) 存在 n 个正整数 $a _ { 1 } , a _ { 2 } , \cdots , a _ { n }$ ，使得

$$
1 + \frac {1}{a} = \prod_ {i = 1} ^ {n} \left(1 + \frac {1}{a _ {i}}\right)
$$

(b) 只有有限个正整数组 $( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ ，使得

$$
1 + \frac {1}{a} = \prod_ {i = 1} ^ {n} \left(1 + \frac {1}{a _ {i}}\right)
$$

解

(a) 取 $a _ { k } = n a + k - 1 \ ( k = 1 , 2 , \cdot \cdot \cdot \ , n )$ ，则

$$
\prod_ {i = 1} ^ {n} \left(1 + \frac {1}{a _ {i}}\right) = \prod_ {i = 1} ^ {n} \frac {n a + i}{n a + i - 1} = \frac {n a + n}{n a} = 1 + \frac {1}{a}
$$

(b) 我们将证明更强的命题：对于给定的 n 和 $\gamma \in \mathbb { Q }$ ，至多只有有限个有序正整数组$( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ ，使得

$$
\gamma = \prod_ {i = 1} ^ {n} \left(1 + \frac {1}{a _ {i}}\right)\tag{1}
$$

对 n 用数学归纳法。当 $n = 1$ 时，使得 $\gamma = 1 + 1 / a _ { 1 }$ 成立的正整数 $a _ { 1 }$ 至多有一个，结论成立。假设命题对 $n - 1 \ ( n \geqslant 2 )$ 成立，下面考虑 n 的情形。

当 $\gamma \leqslant 1$ 时，显然不存在正整数组 $( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ 满足式 (1)。

当 $\gamma > 1$ 时，若存在正整数组 $( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ 满足式 (1)，考虑到坐标的排列只有有限种，不妨设 $a _ { 1 } = \operatorname* { m i n } _ { 1 \leqslant i \leqslant n } a _ { i }$ ，则

$$
\gamma \leqslant \left(1 + \frac {1}{a _ {1}}\right) ^ {n}, \Longrightarrow a _ {1} \leqslant \frac {1}{\sqrt [ n ]{\gamma} - 1}
$$

记 $M = \left\lfloor { \frac { 1 } { \sqrt [ n ] { \gamma } - 1 } } \right\rfloor$ ，故 $a _ { 1 } \in \{ 1 , 2 , \cdots , M \}$ ，即 $a _ { 1 }$ 的值只有有限个。

对于 $a _ { 1 }$ 的每个取值，由归纳假设，知均只有有限多个正整数组 $( a _ { 2 } , a _ { 3 } , \cdots , a _ { n } )$ ，满足

$$
\gamma \cdot \frac {a _ {1}}{1 + a _ {1}} = \prod_ {i = 2} ^ {n} \left(1 + \frac {1}{a _ {i}}\right)\tag{2}
$$

因此，取 n 时命题成立。

CTST 2012 P10 

给定整数 $n \geqslant 2$ ，求证：只有有限个 n 元正整数组 $( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ 同时满足如下条件：

(I) $a _ { 1 } > a _ { 2 } > \cdots > a _ { n } ;$ 

(II) $\operatorname* { g c d } ( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } ) = 1$ 

(III) $a _ { 1 } = \sum _ { i = 1 } ^ { n } \operatorname* { g c d } ( a _ { i } , a _ { i + 1 } )$ ，其中 $a _ { n + 1 } = a _ { 1 } { \mathrm { ~ c ~ } }$ 

解

设数组 $( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ 满足条件。由条件 (I) 可知，对 $i = 1 , 2 , \cdots , n - 1$ ，有 $a _ { i } - a _ { i + 1 } > 0$ 故 $\operatorname* { g c d } ( a _ { i } , a _ { i + 1 } ) = \operatorname* { g c d } ( a _ { i } - a _ { i + 1 } , a _ { i + 1 } ) \leqslant a _ { i } - a _ { i + 1 }$ ，从而

$$
\sum_ {i = 1} ^ {n} \operatorname * {g c d} (a _ {i}, a _ {i + 1}) \leqslant \sum_ {i = 1} ^ {n - 1} \operatorname * {g c d} (a _ {i}, a _ {i + 1}) + \operatorname * {g c d} (a _ {n}, a _ {1}) \leqslant (a _ {1} - a _ {n}) + a _ {n} = a _ {1}\tag{1}
$$

结合条件 (III) 可知，(1) 中不等号均取到等号，即存在 $b , b _ { 1 } , b _ { 2 } , \cdot \cdot \cdot , b _ { n - 1 } \in \mathbb { N } ^ { * }$ ，使得 $a _ { 1 } =$ $b a _ { n } , a _ { i + 1 } = ( a _ { i } - a _ { i + 1 } ) b _ { i } , \ i = 1 , 2 , \cdot \cdot \cdot , n - 1$ 。于是有

$$
{\frac {a _ {i}}{a _ {i + 1}}} = 1 + {\frac {1}{b _ {i}}}, \quad i = 1, 2, \dots , n - 1\tag{2}
$$

从而 n−1 元正整数组 $( b _ { 1 } , b _ { 2 } , \cdots , b _ { n - 1 } )$ 满足

$$
\prod_ {i = 1} ^ {n - 1} \left(1 + \frac {1}{b _ {i}}\right) = \prod_ {i = 1} ^ {n - 1} \frac {a _ {i}}{a _ {i + 1}} = \frac {a _ {1}}{a _ {n}} = b \in \mathbb {N} ^ {*}\tag{3}
$$

反之，对任意一组满足 (3) 的 n − 1 元正整数组 $( b _ { 1 } , b _ { 2 } , \cdots , b _ { n - 1 } )$ ，满足 (2) 并满足$\operatorname* { g c d } ( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } ) = 1$ 的 n 元正整数组 $( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ 必被唯一确定。

于是只需证明使 $\textstyle \prod _ { i = 1 } ^ { n - 1 } ( 1 + 1 / b _ { i } ) \in \mathbb { N } ^ { * }$ 成立的 $n - 1$ 元正整数组 $( b _ { 1 } , b _ { 2 } , \cdots , b _ { n - 1 } )$ 只有有限组。考虑到 $b _ { 1 } , b _ { 2 } , \cdots , b _ { n - 1 }$ 的排列不多于 $( n - 1 ) !$ 种，故只需在 $b _ { 1 } \leqslant b _ { 2 } \leqslant \cdots \leqslant b _ { n } .$ <sub>1</sub> 的情况下证明即可。

引理：对任意 $i \in \{ 1 , 2 , \cdots , n - 1 \}$ 及任意正实数 r，必存在正整数 $N = N ( r , i )$ ，使得当$b _ { i } > N$ 时， $r \prod _ { j = i } ^ { n - 1 } ( 1 + 1 / b _ { j } )$ ̸∈ N∗。

引理证明：记 $\omega _ { r } = ( \lfloor r \rfloor + 1 ) / r > 1$ ，取正整数 $N > \frac { 1 } { \sqrt [ n - i ] { \omega _ { r } } - 1 }$ ，则当 $b _ { i } > N$ 时，有

$$
1 + \frac {1}{b _ {i}} <   1 + \frac {1}{N} <   1 + \left(^ {n - i} \sqrt {\omega_ {r}} - 1\right) = ^ {n - i} \sqrt {\omega_ {r}}
$$

故

$$
\lfloor r \rfloor <   r \prod_ {j = i} ^ {n - 1} \left(1 + \frac {1}{b _ {j}}\right) \leqslant r \left(1 + \frac {1}{b _ {i}}\right) ^ {n - i} <   r \omega_ {r} = \lfloor r \rfloor + 1
$$

下证 $( b _ { 1 } , b _ { 2 } , \cdots , b _ { n - 1 } )$ 组数的有限性。

在引理中令 $r = 1 , i = 1$ ，可取正整数 $N _ { 1 }$ ，使得式 (3) 蕴含 $b _ { 1 } \leqslant N _ { 1 }$ 。设 $2 \leqslant l \leqslant n - 1$ 且 $N _ { 1 } , N _ { 2 } , \cdots , N _ { l - 1 }$ 已经取定。满足 $b _ { j } \leqslant N _ { j } \ ( 1 \leqslant j < l )$ 的前缀 $( b _ { 1 } , b _ { 2 } , \cdots , b _ { l - 1 } )$ 只有有限种；对每一种前缀，在引理中取

$$
r = \prod_ {j = 1} ^ {l - 1} \left(1 + \frac {1}{b _ {j}}\right), \quad i = l
$$

再把所得有限多个界的最大值记为 $N _ { l }$ ，即可保证式 (3) 蕴含 $b _ { l } \leqslant N _ { l } .$ 。依次进行，得到 $b _ { i } \leqslant$ $N _ { i } ( i = 1 , 2 , \cdots , n - 1 )$ ，故递增排列的 $n - 1$ 元正整数组至多有 $N _ { 1 } N _ { 2 } \cdots N _ { n - 1 }$ 组。

综上所述，满足条件的数组 $( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ 仅有有限组。

CTST 2014 P8 

给定整数 $a \geqslant 9$ 。证明：至多存在有限个正整数 n 同时满足

(I) $\tau ( n ) = a$ 

(II) $n \mid \varphi ( n ) + \sigma ( n )$ 

其中 $\tau ( n )$ 表示 n 的正约数个数， $\varphi ( n )$ 表示不超过 n 且与 n 互质的正整数的个数， $\sigma ( n )$ 表示n 的所有正约数之和。

解

设 $\varphi ( n ) + \sigma ( n ) = n s$ ，其中 $s \in \mathbb { N } ^ { * }$ 。于是

$$
s = \frac {\varphi (n) + \sigma (n)}{n} = \frac {1}{n} \left(\sum_ {d | n} \mu (d) \frac {n}{d} + \sum_ {d | n} \frac {n}{d}\right) = \sum_ {d | n} \frac {\mu (d) + 1}{d}
$$

这里 $\mu$ 为 Möbius 函数。将 n 的所有满足 $\mu ( d ) \neq - 1$ 的正约数依次记为 $d _ { 1 } < d _ { 2 } < \dots < d _ { m }$ 。先证 $\mu ( n ) = 0$ ，即 n 有平方因子。反设 n 无平方因子，写成 $n = p _ { 1 } p _ { 2 } \cdots p _ { k }$ ，其中$p _ { 1 } < p _ { 2 } < \cdots < p _ { k }$ 为质数。由 $\tau ( n ) = 2 ^ { k } \geqslant 9$ 知 $k \geqslant 4$ ，且

$$
(p _ {1} - 1) \dots (p _ {k} - 1) + (p _ {1} + 1) \dots (p _ {k} + 1) = p _ {1} p _ {2} \dots p _ {k} s
$$

若 n 为奇数，则 $2 ^ { k } \mid s$ ，故 $s \geqslant 2 ^ { k }$ ；但

$$
s = \prod_ {i = 1} ^ {k} \left(1 - \frac {1}{p _ {i}}\right) + \prod_ {i = 1} ^ {k} \left(1 + \frac {1}{p _ {i}}\right) <   1 + \left(\frac {4}{3}\right) ^ {k} <   2 ^ {k}
$$

矛盾。若 n 为偶数，则 $p _ { 1 } = 2$ ，且 $2 ^ { k - 2 } \mid s$ ，故 $s \geqslant 2 ^ { k - 2 }$ ；但

$$
s = \frac {1}{2} \prod_ {i = 2} ^ {k} \left(1 - \frac {1}{p _ {i}}\right) + \frac {3}{2} \prod_ {i = 2} ^ {k} \left(1 + \frac {1}{p _ {i}}\right) <   \frac {1}{2} + \frac {3}{2} \cdot \frac {4}{3} \left(\frac {6}{5}\right) ^ {k - 2} <   2 ^ {k - 2}
$$

也矛盾。因此 $\mu ( n ) = 0$ ，特别地， $d _ { m } = n \mathfrak { c }$ 

回到原式，有

$$
s = \sum_ {i = 1} ^ {m} \frac {\mu (d _ {i}) + 1}{d _ {i}}
$$

下面证明

$$
d _ {i} \leqslant (2 m) ^ {2 ^ {i - 1}} \quad (i = 1, 2, \dots , m)
$$

当 i = 1 时，

$$
1 \leqslant s = \sum_ {i = 1} ^ {m} \frac {\mu (d _ {i}) + 1}{d _ {i}} \leqslant \frac {2 m}{d _ {1}}
$$

故 $d _ { 1 } \leqslant 2 m$ 。假设 $m \geqslant i > 1$ ，且结论对 $1 \leqslant j < i$ 均成立，则

$$
\frac {2 m}{d _ {i}} \geqslant \frac {2 (m - i + 1)}{d _ {i}} \geqslant \sum_ {j = i} ^ {m} \frac {\mu \left(d _ {j}\right) + 1}{d _ {j}} = s - \sum_ {j = 1} ^ {i - 1} \frac {\mu \left(d _ {j}\right) + 1}{d _ {j}}
$$

右端为正有理数，且其分母整除 $d _ { 1 } d _ { 2 } \cdots d _ { i - 1 }$ ，故它不小于 $1 / ( d _ { 1 } d _ { 2 } \cdot \cdot \cdot d _ { i - 1 } )$ 。于是

$$
d _ {i} \leqslant 2 m d _ {1} d _ {2} \dots d _ {i - 1} \leqslant (2 m) ^ {1 + 1 + 2 + \dots + 2 ^ {i - 2}} = (2 m) ^ {2 ^ {i - 1}}
$$

归纳完成。特别地，

$$
n = d _ {m} \leqslant (2 m) ^ {2 ^ {m - 1}} \leqslant (2 a) ^ {2 ^ {a - 1}}
$$

故满足条件的 n 只能有有限多个。

CTST 2020 P4 

求证：如下方程只有有限组正整数解 $( t , A , x , y , z )$ 

$$
\sqrt {t (1 - A ^ {- 2}) (1 - x ^ {- 2}) (1 - y ^ {- 2}) (1 - z ^ {- 2})} = (1 + x ^ {- 1}) (1 + y ^ {- 1}) (1 + z ^ {- 1})
$$

解

首先注意，当 $A , x , y , z$ 中有一个等于 1 时，方程左边为 0 而右边为正数，故这四个数均不小于 2。将方程两边平方并化简，得

$$
{ \begin{array}{r l} & {t = \left(1 + {\frac {1}{x}}\right) ^ {2} \left(1 + {\frac {1}{y}}\right) ^ {2} \left(1 + {\frac {1}{z}}\right) ^ {2} \cdot {\frac {A ^ {2}}{A ^ {2} - 1}} \cdot {\frac {x ^ {2}}{x ^ {2} - 1}} \cdot {\frac {y ^ {2}}{y ^ {2} - 1}} \cdot {\frac {z ^ {2}}{z ^ {2} - 1}}} \\ & {\quad = {\frac {x + 1}{x - 1}} \cdot {\frac {y + 1}{y - 1}} \cdot {\frac {z + 1}{z - 1}} \cdot {\frac {A ^ {2}}{A ^ {2} - 1}}} \\ & {\quad = \left(1 + {\frac {1}{x}}\right) \left(1 + {\frac {1}{x - 1}}\right) \left(1 + {\frac {1}{y}}\right) \left(1 + {\frac {1}{y - 1}}\right) \left(1 + {\frac {1}{z}}\right) \left(1 + {\frac {1}{z - 1}}\right) \left(1 + {\frac {1}{A ^ {2} - 1}}\right)} \end{array} }
$$

因此，只需证明满足

$$
\prod_ {j = 1} ^ {7} \left(1 + \frac {1}{b _ {j}}\right) \in \mathbb {N} ^ {*}
$$

的七元正整数组 $( b _ { 1 } , b _ { 2 } , \cdots , b _ { 7 } )$ 只有有限组。考虑到排列数有限，不妨设 $b _ { 1 } \leqslant b _ { 2 } \leqslant \cdots \leqslant b _ { 7 }$ 。

引理：对任意 $i \in \{ 1 , 2 , \cdots , 7 \}$ 及任意正实数 r，必存在正整数 $N = N ( r , i )$ ，使得当$b _ { i } > N$ 时， $r \prod _ { j = i } ^ { 7 } ( 1 + 1 / b _ { j } ) \not \in \mathbb { N } ^ { \ast }$ 

引理证明：记 $\omega _ { r } = ( \lfloor r \rfloor + 1 ) / r > 1$ ，取正整数 $N > \frac { 1 } { \sqrt [ 3 ] { \omega _ { r } } - 1 }$ 。当 $b _ { i } > N$ 时，由$b _ { i } \leqslant b _ { i + 1 } \leqslant \cdots \leqslant b _ { 7 }$ ，有

$$
1 + \frac {1}{b _ {i}} <   1 + \frac {1}{N} <   \sqrt [ 8 - i ]{\omega_ {r}}
$$

故

$$
\lfloor r \rfloor <   r \prod_ {j = i} ^ {7} \left(1 + \frac {1}{b _ {j}}\right) \leqslant r \left(1 + \frac {1}{b _ {i}}\right) ^ {8 - i} <   r \omega_ {r} = \lfloor r \rfloor + 1
$$

从而该乘积不可能是正整数。

在引理中令 $r = 1 , i = 1$ ，可取正整数 $N _ { 1 }$ ，使得正整数条件蕴含 $b _ { 1 } \leqslant N _ { 1 }$ 。设 $2 \leqslant l \leqslant 7$ 且 $N _ { 1 } , N _ { 2 } , \cdots , N _ { l - 1 }$ 已经取定。满足 $b _ { j } \leqslant N _ { j } \ ( 1 \leqslant j < l )$ 的前缀 $( b _ { 1 } , b _ { 2 } , \cdots , b _ { l - 1 } )$ 只有有限种；对每一种前缀，在引理中取

$$
r = \prod_ {j = 1} ^ {l - 1} \left(1 + \frac {1}{b _ {j}}\right), \quad i = l
$$

再把所得有限多个界的最大值记为 $N _ { l }$ ，即可保证正整数条件蕴含 $b _ { l } \leqslant N _ { l }$ 。依次进行到 $l = 7$ 得到 $b _ { i } \leqslant N _ { i } \ ( i = 1 , 2 , \cdots , 7 )$ 

因此递增排列的七元组至多有 $N _ { 1 } N _ { 2 } \cdots N _ { 7 }$ 组，恢复原顺序后至多有 $7 ! N _ { 1 } N _ { 2 } \cdots N _ { 7 }$ 组。每一组原顺序中的七个分母至多对应一个 $( A , x , y , z )$ ，而 t 又由上式唯一确定，故原方程只有有限组正整数解。
