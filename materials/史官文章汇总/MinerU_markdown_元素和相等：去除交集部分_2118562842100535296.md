IMO 1972 P1 & Q12 

求证：从十个不同的两位数中总能选出两个无共同元素的子集，它们的元素和相等。

## 解

设这十个不同的两位数为 $\{ a _ { 1 } , a _ { 2 } , \cdots , a _ { 1 0 } \}$ 考虑它们所有子集的元素和。

易知十个元素的子集共有 $2 ^ { 1 0 } = 1 0 2 4$ 个（包括空集）。

另一方面，因为这 10 个数都是不同的两位数，所以它们的总和至多为最大的 10 个两位数之和：

$$
a _ {1} + \dots + a _ {1 0} \leqslant 9 0 + 9 1 + \dots + 9 9 = 9 4 5
$$

因此任一子集的元素和只能取 0,1,2,...,945 中的某一个值，共最多 946 种可能。但子集共有 1024 个，而子集和至多只有 946 种。由抽屉原理，必存在两个不同的子集 A,B，使得

$$
\sum_ {x \in A} x = \sum_ {x \in B} x
$$

现在把它们的公共元素去掉。令 $C = A \setminus B , \qquad D = B \setminus A$ 。则 $C , D$ 显然互不相交，并且

$$
\sum_ {x \in C} x = \sum_ {x \in A} x - \sum_ {x \in A \cap B} x = \sum_ {x \in B} x - \sum_ {x \in A \cap B} x = \sum_ {x \in D} x
$$

所以 $C , D$ 是两个无共同元素且元素和相等的子集。还需说明 C,D 都不是空集。若 $C = \varnothing$ 则 $A \subseteq B .$ 。由于所有数都是正整数，且 $A \neq B$ ，必有

$$
\sum_ {x \in A} x <   \sum_ {x \in B} x
$$

这与两者元素和相等矛盾。因此 $C , D$ 都非空。

故总能选出两个无共同元素的子集，它们的元素和相等。

Russian Federal 2001 Grade 11 P8 

求证：在任何由 117 个互不相同的三位数所构成的数集中，都能找到 4 个两两不交的子集，它们中的数的和彼此相等。

## 解

先证明一个引理：引理： 从任何 61 个不同的 3 位数中都可以挑出两个不相交的数对，使这两对数的和相等。

引理之证： 61 个数共可形成 $\binom { 6 1 } { 2 } = 1 8 3 0$ 个不同的数对，每对数的和都介于 200 和 2000之间，因此，其中必有某两对数的和相等。显然，这两个数对是不会相交的，因若不然，由$x + y = x + z$ 即可推出 $y = z$ ，从而变为相同的数对。引理证毕。

从所给的 117 个不同的 3 位数中一次又一次地取出和数相同的不同数对，每次取后不放回，如此共可取出 15 对数对偶 (每次取走 4 个数，14 次后刚好还剩 61 个数，所以还可再取一次)。如果 15 个和数不全不同，则至少有两次所取的数对偶，其中每个数对的和数相同，如此就有 4 个数对具有相同的和数，这 4 个数对即可作为所求的 4 个子集。

如果 15 个和数各不相同，我们来构造两个数对的集合 $N _ { 1 }$ 与 $N _ { 2 } \colon$ ：每个数对偶中的两个对数的和数相等，将其中一个数对归于 $N _ { 1 }$ ，另一个归于 $N _ { 2 }$ ，于是 $N _ { 1 }$ 与 $N _ { 2 }$ 皆由 15 个数对构成。观察第一个数对集 $N _ { 1 }$ ，它具有 $2 ^ { 1 5 }$ 个子集，每个子集中的所有数对之和的总和均不超过 $3 \times 1 0 ^ { 4 }$ (共有不超过 30 个数，每个数小于 1000)。

由于 $2 ^ { 1 5 } > 3 \times 1 0 ^ { 4 }$ ，因此， $N _ { 1 }$ 中有两个子集，它们中的数对之和的总和相同。在这两个子集中分别去掉它们的交，得到两个保持原来性质的不交子集 $M _ { 1 }$ 和 $M _ { 2 }$ 

现在，再自 $N _ { 2 }$ 中分别取出与集合 $M _ { 1 }$ 和 $M _ { 2 }$ 中的数对相对应的数对，得到数对子集 $M _ { 3 }$ 和 $M _ { 4 }$ 。于是，由 $M _ { 1 } , M _ { 2 } , M _ { 3 } , M _ { 4 }$ 中的数对中的数所构成的数集即为所求。

## CTST 2015 P11

设 S 是集合 {1,2,··· ,2015} 的一个 68 元子集。求证：存在 S 的三个互不相交的非空子集 A,B,C，满足 $| A | = | B | = | C |$ ，且 $\textstyle \sum _ { a \in A } a = \sum _ { b \in B } b = \sum _ { c \in C } c \circ$ 

解

考虑 S 的所有 ${ \binom { 6 8 } { 3 } } = 5 0 1 1 6$ 个三元集，每个三元集的所有元素之和都在 $1 + 2 + 3 = 6$ 到$2 0 1 5 + 2 0 1 4 + 2 0 1 3 = 6 0 4 2$ 之间。由于 $5 0 1 1 6 > 8 \times ( 6 0 4 2 - 6 + 1 )$ ，故由抽屉原理知，存在九个三元集 $X _ { 1 } , X _ { 2 } , \cdots , X _ { 9 }$ ，它们的元素和彼此相等。

若有某个数 a 在 $X _ { 1 } , X _ { 2 } , \cdots , X _ { 9 }$ 中至少出现了三次，不妨设 a 同时在 $X _ { 1 } , X _ { 2 } , X _ { 3 }$ 中，则除去 a 后这三个集合的元素彼此不同 (否则若还有两个集合有相同元素，由元素和相等知，它们的第三个元素也相同，即这两个集合相同，矛盾！)。令 $A = X _ { 1 } \setminus \{ a \}$ $B = X _ { 2 } \setminus \{ a \}$ $C = X _ { 3 } \setminus \{ a \}$ ，则 A,B,C 即为满足条件的三个集合。

下面假设每个数在 $X _ { 1 } , X _ { 2 } , \cdots , X _ { 9 }$ 中都至多出现两次，故在 $X _ { 2 } , X _ { 3 } , \cdots , X _ { 9 }$ 中与 $X _ { 1 }$ 有公共元素的集合不超过三个，不妨设 $X _ { 5 } , X _ { 6 } , X _ { 7 } , X _ { 8 } , X _ { 9 }$ 均与 $X _ { 1 }$ 无公共元素。类似可知，在$X _ { 6 } , X _ { 7 } , X _ { 8 } , X _ { 9 }$ 中，与 $X _ { 5 }$ 有公共元素的集合不超过三个，不妨设 $X _ { 9 }$ 与 $X _ { 5 }$ 没有公共元素。于是，令 $A = X _ { 1 } , B = X _ { 5 } , C = X _ { 9 }$ ，则 A,B,C 即为满足条件的三个集合，证毕。

## Polish Final Round 2001 P6

$$
| A | = | B |, \quad \sum_ {a \in A} a = \sum_ {b \in B} b, \quad \sum_ {a \in A} a ^ {2} = \sum_ {b \in B} b ^ {2}

$$
s _ {0} (X) = | X |, \quad s _ {1} (X) = \sum_ {x \in X} x, \quad s _ {2} (X) = \sum_ {x \in X} x ^ {2}

我们先证明，存在两个不同的子集 $C , D$ ，使得 $s _ { i } ( C ) = s _ { i } ( D )$ ，其中 $i = 0 , 1 , 2$ o

$$
\begin{array}{c} s _ {0} (X) <   1 0 ^ {4} \\ s _ {1} (X) <   2 0 0 0 \cdot 1 0 ^ {1 0 0} <   1 0 ^ {1 0 4} \\ s _ {2} (X) <   2 0 0 0 \cdot 1 0 ^ {2 0 0} <   1 0 ^ {2 0 4} \end{array}
$$

定义 $S ( X ) = s _ { 0 } ( X ) + 1 0 ^ { 4 } s _ { 1 } ( X ) + 1 0 ^ { 1 0 8 } s _ { 2 } ( X )$ 。于是

$$
