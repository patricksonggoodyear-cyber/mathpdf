## TOT 1991 Spring Junior A3

一排放有 30 只靴子，其中 15 只左脚靴、15 只右脚靴。证明：其中存在连续的 10 只靴子，左脚靴与右脚靴各有 5 只。

解

从左到右把这 30 只靴子依次编号为 1,2,··· ,30，并定义

$$
\varepsilon_ {i} = \left\{ \begin{array}{l l} 1, & \text {第} i \text {只靴子为右脚靴} \\ - 1, & \text {第} i \text {只靴子为左脚靴} \end{array} \right. \quad H _ {0} = 0, \quad H _ {i} = \sum_ {j = 1} ^ {i} \varepsilon_ {j}
$$

从原点 $P _ { 0 } = ( 0 , 0 )$ 出发，依次连接格点 $P _ { i } = ( i , H _ { i } )$ ，便得到一条每步为 (1,1) 或 (1,−1) 的单位斜步折线。由于左右脚靴各有 15 只，故 $H _ { 3 0 } = 0$ 

从第 i+1 只到第 i+10 只这段连续的 10 只靴子中，右脚靴数减去左脚靴数为 $H _ { i + 1 0 } - H _ { i }$ 0因此，所求结论等价于证明折线上存在一条横向跨度为 10 的水平弦，也就是存在 $0 \leqslant i \leqslant 2 0$ 使 $H _ { i + 1 0 } = H _ { i }$ 。

对 $0 \leqslant i \leqslant$ 20 定义

$$
d _ {i} = \frac {H _ {i + 1 0} - H _ {i}}{2}
$$

十步的高度变化是偶数，所以每个 $d _ { i }$ 都是整数。当 $0 \leqslant i < 2 0$ 时，将弦的两个端点同时向右移动一步，其有向高度差的变化满足

$$
d _ {i + 1} - d _ {i} = \frac {\varepsilon_ {i + 1 1} - \varepsilon_ {i + 1}}{2} \in \{- 1, 0, 1 \}
$$

另一方面，最初三段各含 10 步的子折线首尾相接，故

$$
d _ {0} + d _ {1 0} + d _ {2 0} = \frac {(H _ {1 0} - H _ {0}) + (H _ {2 0} - H _ {1 0}) + (H _ {3 0} - H _ {2 0})}{2} = 0
$$

若 $d _ { 0 } , d _ { 1 0 } , d _ { 2 0 }$ 中有一项为 0，则结论已经成立。否则这三项中既有正数又有负数，因而相邻的两项 $d _ { 0 } , d _ { 1 0 }$ 或 $d _ { 1 0 } , d _ { 2 0 }$ 必异号。由于整数序列 $( d _ { i } )$ 每向前一步至多改变 1，它在这两项之间必取到 0。

于是存在 $0 \leqslant i \leqslant 2 0$ 使 $H _ { i + 1 0 } = H _ { i }$ 。折线从 $P _ { i }$ 到 $P _ { i + 1 0 }$ 的十步中上升步与下降步各有 5步，对应的连续 10 只靴子中右脚靴与左脚靴各有 5 只。

## Putnam 1996 B5

对于一个由符号 X 和 O 组成的有限字符串 S，记 $\Delta ( S )$ 为 S 中 X 的个数减去 O 的个数。如果 S 的每一个连续子串 T 都满足 $| \Delta ( T ) | \leqslant 2$ ，则称 S 是平衡的。求长度为 n 的平衡字符串的个数，其中 n 为正整数。

## 解

设字符串为 $s _ { 1 } s _ { 2 } \cdots s _ { n }$ 。从原点 $P _ { 0 } = ( 0 , 0 )$ 出发，在坐标平面内依次作格点折线：读到 X时走向量 (1,1)，读到 O 时走向量 (1,−1)。记第 k 个顶点为 $P _ { k } = ( k , y _ { k } )$ ，则每个字符串与这样一条长为 n 的折线一一对应。

任取 $0 \leqslant i < j \leqslant n .$ 。从 $P _ { i }$ 到 $P _ { j }$ 的这段折线中，上升步数减去下降步数为 $y _ { j } - y _ { i }$ ；另一方面，这也正是连续子串 $s _ { i + 1 } s _ { i + 2 } \cdot \cdot \cdot s _ { j }$ 中 X 的个数减去 O 的个数。因此，字符串平衡当且仅当任意两个顶点的纵坐标之差的绝对值都不超过 2。令

$$
m = \min _ {0 \leqslant k \leqslant n} y _ {k}, \quad M = \max _ {0 \leqslant k \leqslant n} y _ {k}
$$

那么平衡条件等价于 $M - m \leqslant 2$ 。由于 $y _ { 0 } = 0$ ，故 $m \leqslant 0 \leqslant M$ 。再由所有纵坐标均为整数可知 $m \in \{ - 2 , - 1 , 0 \}$ ：当 $m = - 2 , - 1 , 0$ 时，分别有 $M \leqslant 0 , 1 , 2$ 。所以每条平衡折线必完全落在以下三个水平带之一：

$$
- 2 \leqslant y \leqslant 0, \quad - 1 \leqslant y \leqslant 1, \quad 0 \leqslant y \leqslant 2
$$

反之，完全落在其中任一水平带内的折线，任意两个顶点的纵坐标之差都不超过 2，故其对应字符串平衡。

每一步都使纵坐标改变 1，故 $y _ { k } \equiv k { \pmod { 2 } }$ 。先计算完全落在中间水平带 $- 1 \leqslant y \leqslant .$ 1内的折线数。每个偶数编号顶点的纵坐标只能是 0，而每个奇数编号顶点的纵坐标都可以独立地取 −1 或 1，故共有 $2 ^ { \lceil n / 2 \rceil }$ 条。

对于完全落在上方水平带 $0 \leqslant y \leqslant 2$ 内的折线，每个奇数编号顶点的纵坐标只能是 1，每个正偶数编号顶点的纵坐标都可以独立地取 0 或 2，故共有 $2 ^ { \lfloor n / 2 \rfloor }$ 条。下方水平带 $- 2 \leqslant y \leqslant 0$ 与上方水平带关于横轴对称，故其中也有 $2 ^ { \lfloor n / 2 \rfloor }$ 条折线。

下方水平带与中间水平带的公共折线只能在纵坐标 $0 , - 1$ 之间交替，恰有一条；中间水平带与上方水平带的公共折线只能在纵坐标 0,1 之间交替，也恰有一条。由于 n 为正整数，上方水平带与下方水平带没有公共折线。由容斥原理，所求个数为

$$
2 ^ {\lceil n / 2 \rceil} + 2 \cdot 2 ^ {\lfloor n / 2 \rfloor} - 2 = \left\{ \begin{array}{l l} {3 \cdot 2 ^ {n / 2} - 2,} & {n \text {为偶数}} \\ {2 ^ {(n + 3) / 2} - 2,} & {n \text {为奇数}} \end{array} \right.
$$

IMOSL 2025 C3 

一排放有 2025 个白球和 2025 个黑球。若一段连续非空的球中白球数与黑球数相同，则称其为平衡段。一次平衡删除是指：选取一个平衡段 S，移去 S 中的所有球，再将原来位于S 右侧的球整体向左移动，使剩余的球仍排成连续的一排。

求具有如下性质的最小正整数 N：对任意一种黑白球排列，以及任意满足 $0 \leqslant$ k ⩽ 2025的整数 k，都存在至多 N 次平衡删除，使操作后恰好剩下 2k 个球。

## 解

最小的 N 为 2。

先说明一次删除不总是够。取排列 $W ^ { 2 } B ^ { 2 0 2 5 } W ^ { 2 0 2 3 }$ ，其中 W,B 分别表示白球、黑球，并令 $k = 1$ 。若一次删除后只剩两个球，就必须删除一个长度为 4048 的连续段；这样的段只有三个，而每个都含 2025 个黑球和 2023 个白球，均不平衡。因此 $N \geqslant$ 2。

下面用折线法证明两次删除总是足够。从原点 $P _ { 0 } = ( 0 , 0 )$ 出发，依次读这一排球：遇到黑球走向量 (1,1)，遇到白球走向量 (1,−1)。记所得格点折线的顶点依次为 $P _ { j } = ( j , y _ { j } )$ 。由于黑、白球各有 2025 个，终点为 $P _ { 4 0 5 0 } = ( 4 0 5 0 , 0 )$ 。一段从第 $r + 1$ 个球到第 s 个球的连续段平衡，当且仅当 $y _ { r } = y _ { s }$ ；在折线上，这正是顶点 $P _ { r } , P _ { s }$ 位于同一条水平线上。

称不能分成前后两个平衡段的平衡段为极小平衡段。它所对应的子折线除两个端点外不再接触端点所在的水平线，因而所有内部顶点都严格位于这条水平线的同一侧。

引理：一个含 2m 个球的极小平衡段中，对每个 $1 \leqslant \ell \leqslant m$ ，都含有长度为 2ℓ 的平衡段。引理证明：平移并在必要时关于横轴反射相应子折线，可以设其顶点为 $Q _ { j } = ( j , z _ { j } )$ ，其中 $z _ { 0 } = z _ { 2 m } = 0$ ，且 $z _ { j } > 0$ 对 $1 \leqslant j < 2 m$ 成立。若 $\ell = m$ ，结论显然成立。以下设 $\ell < m$ 并对 $0 \leqslant i \leqslant 2 m - 2 \ell$ 定义

$$
d _ {i} = \frac {z _ {i + 2 \ell} - z _ {i}}{2}
$$

由于下标 i 与 $i + 2 \ell$ 同奇偶， $d _ { i }$ 是整数；又有 $d _ { 0 } > 0$ 以及 $d _ { 2 m - 2 \ell } < 0 .$ 。相邻两项满足

$$
d _ {i + 1} - d _ {i} = \frac {(z _ {i + 2 \ell + 1} - z _ {i + 2 \ell}) - (z _ {i + 1} - z _ {i})}{2} \in \{- 1, 0, 1 \}
$$

因此，整数序列 $d _ { 0 } , d _ { 1 } , \dotsb , d _ { 2 m - 2 \ell }$ 从正数变到负数时必经过 0。若 $d _ { i } = 0$ ，则 $Q _ { i } , Q _ { i + 2 \ell }$ 等高，它们之间的 2ℓ 步恰对应一个长度为 2ℓ 的平衡段。引理得证。

现在在原折线上依次记录回到横轴的顶点，并写成

$$
0 = s _ {0} <   s _ {1} <   \dots <   s _ {p} = 2 0 2 5
$$

其中横坐标为 $2 s _ { i }$ 的顶点都在横轴上，两个相邻这样的顶点之间正对应一个极小平衡段。给定 k，令 $d = 2 0 2 5 - k$ 。若 $d = 0$ ，不作删除即可。若 $d = s _ { i } > 0$ ，则最前面的 2d 个球构成平衡段，删除一次即可。否则存在唯一的 i 使 $s _ { i } < d < s _ { i + 1 }$ 。由引理，第 $i + 1$ 个极小平衡段中含有一个长度为 $2 ( d - s _ { i } )$ 的平衡段；删去这一段后，若 $s _ { i } > 0$ ，再删去仍位于最前面的 $2 s _ { i }$ 个球。总共删去 2d 个球，恰好剩下 2k 个球，且所用删除次数至多为 2。因此 $N \leqslant 2$ ，结合下界即得 $N = 2$

## 解

先把若干个标号 1 暂时改成 −1，使标号 −1 的点恰有 661 个。若修改后的标号中存在好点，则把这些标号改回 1 只会使有关部分和增大，故该点对原标号仍是好点。因此只需处理恰有 661 个点标号为 −1 的情形；此时其余 1324 个点标号为 1，一周的标号和为 663。

沿圆周任选一个方向，把标号周期延拓成双向无穷序列 $( a _ { i } ) _ { i \in \mathbb { Z } }$ ，其中 $a _ { i + 1 9 8 5 } = a _ { i }$ 。令$S _ { 0 } = 0$ ，并对所有整数 i 规定 $S _ { i } - S _ { i - 1 } = a _ { i }$ 。在坐标平面内依次连接格点 $P _ { i } = ( i , S _ { i } )$ ，便得到一条双向无穷的单位斜步折线，而且

$$
S _ {i + 1 9 8 5} = S _ {i} + 6 6 3
$$

由于一个周期内只有 661 个下降步和 1324 个上升步，对 $0 \leqslant r < 1 9 8 5$ 有

$$
- 6 6 1 \leqslant S _ {r} \leqslant 1 3 2 4

考察整数高度 1, 2, · · · , 663000。从 $P _ { 0 }$ 到 $P _ { 1 9 8 5 0 0 0 }$ ，折线的高度由 0 变为 663000，且每一步的纵坐标只改变 1，所以这些高度中的每一个都至少被某个顶点达到一次。若 $S _ { i } = h$ ，其中 $1 \leqslant h \leqslant 6 6 3 0 0 0$ ，将 i 唯一写成 $i = 1 9 8 5 q + r$ ，其中 $0 \leqslant r < 1 9 8 5$ ，则 $h = 6 6 3 q + S _ { r }$ 。由上面的界可得 $- 1 \leqslant q \leqslant 1 0 0 0$ ，所以这些高度的所有出现位置总共只能落在至多

$$
1 0 0 2 \cdot 1 9 8 5 = 1 9 8 8 9 7 0
$$

个顶点中。然而

$$
3 \cdot 6 6 3 0 0 0 = 1 9 8 9 0 0 0 > 1 9 8 8 9 7 0
$$

故至少有一个整数高度 h 被折线达到至多两次。

若 $k = l$ ，或者 $k < l$ 且 $P _ { k } P _ { k + 1 } \cdots P _ { l }$ 的内部顶点全在直线 $y = h$ 上方，则标号为 $a _ { k }$ 的点是好点。事实上，此时 $S _ { k - 1 } = h - 1$ ，并且对任意正整数 t，沿两个方向得到的相应部分和分别为

$$

$$

余下的情形是 $k < l ;$ ，且 $P _ { k } P _ { k + 1 } \cdots P _ { l }$ 的内部顶点全在直线 $y = h$ 下方。此时标号为 $a _ { l + 1 }$ 的点是好点。事实上， $S _ { l + 1 } = h + 1$ ，并且对任意正整数 t，沿两个方向得到的相应部分和分别为

$$

$$

故 M 的好女伴与折线从下向上穿过同一条水平线 $y = 1 / 2$ 的边一一对应。

在一个周期内，折线从高度 0 出发又回到高度 0，所以它向上穿过水平线 $y = 1 / 2$ 的次数与向下穿过这条水平线的次数相等。后者恰为 10，故前者也恰为 10，从而男孩 M 恰好属于 10 个好对。

IMOSL 2011 C2 

1000 名学生围成一圈。证明存在 $1 0 0 \leqslant k \leqslant 3 0 0$ ，使某连续 2k 人中前 k 人与后 k 人的女生数相同。

解

沿圆周固定一个方向，把学生用整数周期编号为 $K _ { i }$ ，其中 $K _ { i + 1 0 0 0 } = K _ { i }$ 。定义

$$
\varepsilon_ {i} = \left\{ \begin{array}{l l} 1, & K _ {i} \text {是女生} \\ - 1, & K _ {i} \text {是男生} \end{array} \right.
$$

令 $H _ { 0 } = 0$ ，并对所有整数 i 规定 $H _ { i + 1 } - H _ { i } = \varepsilon _ { i }$ 。依次连接格点 $P _ { i } = ( i , H _ { i } )$ ，便得到一条经过原点、每步为 (1,1) 或 (1,−1) 的双向单位斜步折线。

对正整数 m 及整数 t，记

$$
\Delta_ {m} (t) = H _ {t + m} - H _ {t} = \sum_ {q = 0} ^ {m - 1} \varepsilon_ {t + q}
$$

这就是弦 $P _ { t } P _ { t + m }$ 的有向高度差。以 $K _ { t }$ 开始的连续 m 名学生中，女生数为 $( m + \Delta _ { m } ( t ) ) / 2$ 因此，题目所求等价于找到满足 $1 0 0 \leqslant k \leqslant 3 0 0$ 的整数 k 及整数 t，使

$$
\Delta_ {k} (t) = \Delta_ {k} (t + k)
$$

从几何上看，这表示两条首尾相接且横向跨度均为 k 的弦有相同的高度增量；换言之，中间顶点 $P _ { { t + k } }$ 是另外两个端点的中点。

反设不存在这样的 $k , t _ { \circ }$ 数列 $\Delta _ { 1 0 0 } ( t )$ 以 1000 为周期，故可取整数 i，使 $\Delta _ { 1 0 0 } ( i )$ 达到最大值。由于反设也排除了 $k = 1 0 0$ ，所以

$$
\Delta_ {1 0 0} (i - 1 0 0) <   \Delta_ {1 0 0} (i), \quad \Delta_ {1 0 0} (i) > \Delta_ {1 0 0} (i + 1 0 0)
$$

令

$$
d _ {t} = \Delta_ {1 0 0} (t) - \Delta_ {1 0 0} (t + 1 0 0)
$$

则 $d _ { i - 1 0 0 } < 0 < d _ { i }$ 。反设说明所有 $d _ { t }$ 都不为 0，所以存在 $i - 1 0 0 \leqslant j < i$ ，使 $d _ { j } < 0 < d _ { j + 1 }$ 

每个 $\Delta _ { 1 0 0 } ( t )$ 都是 100 个 ±1 之和，故 $d _ { t }$ 是偶数，从而 $d _ { j } \leqslant - 2$ 且 $d _ { j + 1 } \geqslant 2$ 。另一方面，把所比较的两条横向跨度为 100 的弦同时向右移动一步，得到

$$
d _ {j + 1} - d _ {j} = 2 \varepsilon_ {j + 1 0 0} - \varepsilon_ {j} - \varepsilon_ {j + 2 0 0} \leqslant 4
$$

因此上面的不等式只能全部取等号，即

$$
d _ {j} = - 2, \qquad d _ {j + 1} = 2, \qquad \varepsilon_ {j} = - 1, \qquad \varepsilon_ {j + 1 0 0} = 1, \qquad \varepsilon_ {j + 2 0 0} = - 1
$$

把 $d _ { j } = - 2$ 展开可得

$$
- 2 = (- 1 + \Delta_ {9 9} (j + 1)) - (1 + \Delta_ {9 9} (j + 1 0 1))
$$

所以两条横向跨度为 99 的弦有相同的高度增量：

$$
\Delta_ {9 9} (j + 1) = \Delta_ {9 9} (j + 1 0 1)
$$

设 p 是使 $\varepsilon _ { j - p } = 1$ 的最小正整数，ℓ 是使 $\varepsilon _ { j + \mathrm { { 2 0 0 } + } \ell } = 1$ 的最小正整数。这样的 $p , \ell$ 由标号的周期性及 $\varepsilon _ { j + 1 0 0 } = 1$ 必然存在。若 $p \geqslant 2 0 0$ ，则 $K _ { j - 1 9 9 } , K _ { j - 1 9 8 } , \cdot \cdot \cdot , K _ { j }$ 是连续 200 名男生，于是

$$
\Delta_ {1 0 0} (j - 1 9 9) = \Delta_ {1 0 0} (j - 9 9) = - 1 0 0
$$

这已经给出两段相邻的、各含 100 人且女生数相同的队列，与反设矛盾。同理，若 $\ell \geqslant 2 0 0$ 则从 $K _ { j + 2 0 0 }$ 开始也有连续 200 名男生，仍得到矛盾。因此

$$
1 \leqslant p \leqslant 1 9 9, \quad 1 \leqslant \ell \leqslant 1 9 9
$$

由 $p , \ell$ 的最小性， $K _ { j - p + 1 } , \cdots , K _ { j }$ 以及 $K _ { j + 2 0 0 } , \cdot \cdot \cdot , K _ { j + 2 0 0 + \ell - 1 }$ 都是男生，而 $K _ { j - p }$ 与$K _ { j + 2 0 0 + \ell }$ 都是女生。

若 $p \leqslant \ell$ ，令 $k = 1 0 0 + p$ 。利用两条 99 步弦的高度增量相等，可得

$$
\Delta_ {k} (j - p) = 1 - p + \Delta_ {9 9} (j + 1) = 1 - p + \Delta_ {9 9} (j + 1 0 1) = \Delta_ {k} (j + 1 0 0)
$$

且 $( j - p ) + k = j + 1 0 0$ ，所以这里得到的正是两段首尾相接、各含 k 名学生的队列。

若 $p > \ell _ { : }$ ，令 $k = 1 0 0 + \ell$ ，则

$$
\Delta_ {k} (j - \ell + 1) = - \ell + \Delta_ {9 9} (j + 1) + 1 = - \ell + \Delta_ {9 9} (j + 1 0 1) + 1 = \Delta_ {k} (j + 1 0 1)
$$

且 $( j - \ell + 1 ) + k = j + 1 0 1$ ，同样得到两段首尾相接、各含 k 名学生的队列。两种情形下都有 $1 0 1 \leqslant k \leqslant 2 9 9$ ，且两段中的女生数相同，均与反设矛盾。

因此所求的 k 必然存在。事实上，上述证明还给出了更强的上界 $k \leqslant 2 9 9$
