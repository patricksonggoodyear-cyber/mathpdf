CMO 1990 P6 

凸 n 边形及其 n 3 条在形内不相交的对角线组成的图形称为一个剖分图。

求证：当且仅当 3 n 时，存在一个剖分图可以一笔画 (最后回到出发点)。

## 解

先证明当 3 n 时，存在一个剖分图可以一笔画且最后回到出发点。

对 n 归纳。当 n = 3 时，结论显然成立。假设结论对 n 成立，来看 $n + 3$ 时的情形。

设凸 n + 3 边形为 $A _ { 1 } A _ { 2 } \dotsm A _ { n + 3 }$ ，连 $A _ { 2 } A _ { 4 } , A _ { 2 } A _ { n + 3 } , A _ { 4 } A _ { n + 3 }$ 。由归纳假设，凸 n 边形$A _ { 4 } A _ { 5 } \cdots A _ { n + 3 }$ 存在一个剖分图可以从 $A _ { n + 3 }$ 出发经过每条边最后回到 $A _ { n + 3 }$ 。再依次经过顶点$A _ { 2 } , A _ { 4 } , A _ { 3 } , A _ { 2 } , A _ { 1 } , A _ { n + 3 }$ ，即可经过其余所有边且回到 $A _ { n + 3 }$ 。归纳证毕。

再证明当存在一个剖分图可以一笔画且最后回到出发点时，3 n。

因为该图可以一笔画，所以此时每个顶点均连出偶数，因此对于多边形的每个顶点，以该顶点为顶点的三角形有奇数个。

注意到对一般的三角剖分，总可将每个三角形二染色，使得有公共边的两个三角形不同色。这是因为存在三角形含凸 n 边形的连续两条边，再归纳即可。

由于以每个顶点为顶点的三角形有奇数个，所以凸 n 边形的边都属于同种颜色的三角形，于是另一种颜色的三角形的所有边都是凸 边形的对角线。因为每条对角线两侧的三角形不同色，所以对角线的条数 n 3 是另一种颜色的三角形的边数，为 3 的倍数，故 3 n。

综上，命题得证。

IMC 2006 P7 

设 $n \geqslant 3$ ，V 是一个凸 n 边形。用若干条内部互不相交的对角线将 V 分成三角形，称为V 的一个三角剖分。

(1) 若 $3 \mid n$ ，证明：可以对 V 作三角剖分，使每个顶点均属于奇数个小三角形。

(2) 若 $3 \nmid n ,$ ，证明：可以对 V 作三角剖分，使恰有两个顶点属于偶数个小三角形。

解

对 n 作步长为 3 的归纳。先验证 $n = 3 , 4 , 5$ 

当 $n = 3$ 时，整个多边形本身就是一个三角形，每个顶点均属于 1 个小三角形，结论成立。

当 $n = 4$ 时，依次将顶点记为 $P _ { 1 } , P _ { 2 } , P _ { 3 } , P _ { 4 }$ ，作对角线 $P _ { 1 } P _ { 3 }$ 。各顶点所属的小三角形数依次为 2,1,2,1，故恰有两个顶点属于偶数个小三角形。

当 $n = 5$ 时，依次将顶点记为 $P _ { 1 } , P _ { 2 } , P _ { 3 } , P _ { 4 } , P _ { 5 }$ ，作对角线 $P _ { 1 } P _ { 3 }$ 和 $P _ { 1 } P _ { 4 }$ 。所得三个小三角形为 $P _ { 1 } P _ { 2 } P _ { 3 } , P _ { 1 } P _ { 3 } P _ { 4 } , P _ { 1 } P _ { 4 } P _ { 5 }$ ，各顶点所属的小三角形数依次为 3,1,2,2,1，故仍恰有两个顶点属于偶数个小三角形。

现在假设结论对某个 k ⩾ 3 成立，考虑顶点依次为 $P _ { 1 } , P _ { 2 } , \cdots , P _ { k + 3 }$ 的凸 (k + 3) 边形。作对角线 $P _ { 1 } P _ { k }$ ，并按照归纳假设对凸 k 边形 $P _ { 1 } P _ { 2 } \cdots P _ { k }$ 作三角剖分。剩余区域是五边形$P _ { 1 } P _ { k } P _ { k + 1 } P _ { k + 2 } P _ { k + 3 }$ ，再作对角线 $P _ { k } P _ { k + 2 }$ 和 $P _ { 1 } P _ { k + 2 }$ ，将其剖分成以下三个小三角形：

$$
P _ {1} P _ {k} P _ {k + 2}, \qquad P _ {k} P _ {k + 1} P _ {k + 2}, \qquad P _ {1} P _ {k + 2} P _ {k + 3}
$$

在这一扩充过程中， $P _ { 1 }$ 和 $P _ { k }$ 各新增属于两个小三角形，故其所属小三角形数的奇偶性不变； $P _ { 2 } , P _ { 3 } , \cdots , P _ { k - 1 }$ 所属的小三角形数不变；三个新顶点 $P _ { k + 1 } , P _ { k + 2 } , P _ { k + 3 }$ 所属的小三角形数依次为 1,3,1，均为奇数。因此，从 k 边形扩充到 (k+3) 边形后，属于偶数个小三角形的顶点数保持不变。

又因为 k 与 $k + 3$ 除以 3 的余数相同，所以若 3  k，则构造出的凸 (k + 3) 边形没有顶点属于偶数个小三角形；若 3 ∤ k，则构造出的凸 (k+3) 边形恰有两个这样的顶点。由 $n = 3 , 4 , 5$ 三个初始情形，结论对所有 n ⩾ 3 成立。

## Middle European 2014 Individual P2

考虑用 n 3 条内部互不相交的对角线把正 n 边形分成 n 2 个三角形。若将这些三角形染成黑色或白色，并使任意两个有公共边的三角形异色，则称之为一个二染色三角剖分。称正整数 $n \geqslant 4$ 是可剖分的，如果每个正 n 边形都存在一个二染色三角剖分，使得对于多边形的每个顶点 A，以 A 为顶点的黑色三角形数都严格多于以 A 为顶点的白色三角形数。求所有可剖分的整数 n。

## 解

答案： $n = 3 m$ ，其中 $m \geqslant 2$ 为整数。

先证必要性。设一个正 n 边形存在满足条件的二染色三角剖分。固定多边形的一个顶点 A，将所有以 $A$ 为顶点的三角形从 A 所在的一条多边形边到另一条多边形边依次记为$T _ { 1 } , T _ { 2 } , \cdots , T _ { r }$ 。相邻两个三角形共有一条从 A 引出的对角线，故它们的颜色交替。由于其中黑色三角形数严格多于白色三角形数，必有 r 为奇数，且 $T _ { 1 } , T _ { r }$ 均为黑色。

三角形 $T _ { 1 } , T _ { r }$ 分别含有 A 所在的两条多边形边，因此每条多边形边所邻接的三角形都是黑色，从而每个白色三角形的三条边都是对角线。另一方面，每条对角线是两个异色三角形的公共边，故恰为一个白色三角形的边。设白色三角形共有 w 个，对白色三角形与作为其边的对角线作双计数，得到 $3 w = n - 3$ ，所以 $3 \mid n$ 。

再证充分性。事实上，我们将证明当 $n \geqslant 6$ 且 $3 \mid n$ 时，每个凸 n 边形都有满足条件的二染色三角剖分。

当 $n = 6$ 时，设六边形的顶点依次为 $A _ { 1 } , A _ { 2 } , \cdots , A _ { 6 }$ 。连接 $A _ { 1 } A _ { 3 } , A _ { 3 } A _ { 5 } , A _ { 5 } A _ { 1 }$ ，将中央三角形 $A _ { 1 } A _ { 3 } A _ { 5 }$ 染成白色，将其余三个三角形染成黑色。相邻的三角形异色；对于偶数下标的顶点，只有一个黑色三角形以它为顶点，对于奇数下标的顶点，则有两个黑色三角形和一个白色三角形以它为顶点。因此结论成立。

假设结论对某个 n 成立，现考虑一个凸 (n + 3) 边形。

在其边界上依次取五个相邻顶点 A,X,Y,Z,B，连接 AB。删去 X,Y,Z 后，其余 n 个顶点构成一个凸 n 边形；按归纳假设将它剖分并染色。由必要性证明中的观察，边 AB 所邻接的旧三角形为黑色。

再连接 AY,YB，把 AXY,YZB 染成黑色，把 AYB 染成白色。沿新出现的三条内部边AB,AY,YB，两侧的三角形均异色，故所得仍为二染色三角剖分。在 A,B 处各新增一个黑色三角形和一个白色三角形，原有差值不变；X,Z 处各只有一个黑色三角形，Y 处有两个黑色三角形和一个白色三角形，其余顶点不受影响。因此条件仍成立。
