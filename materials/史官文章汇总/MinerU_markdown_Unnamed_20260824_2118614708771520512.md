Russian Federal 2004 Grade 10 P4 

在平面上有 N 个给定点，今知在它们的两两距离之中一共只有不超过 n 种不同的距离值。求证： $N \leqslant ( n + 1 ) ^ { 2 }$ 0

## 解

反设 $N > ( n + 1 ) ^ { 2 }$ 。由给定点确定的直线只有有限条，可适当旋转坐标轴，使任意两个给定点的横坐标不同，纵坐标也不同；旋转不改变点间的欧氏距离。按横坐标递增的顺序将各点记为 $P _ { i } = ( x _ { i } , y _ { i } ) ~ ( i = 1 , 2 , \cdot \cdot \cdot , N )$ ，于是 $x _ { 1 } < x _ { 2 } < \dots < x _ { N }$ ，且 $y _ { 1 } , y _ { 2 } , \cdots , y _ { N }$ 两两不同。下面用 Erdős–Szekeres 单调子列定理的经典标号法提取单调点链。对每个 i，分别以$a _ { i } , b _ { i }$ 表示序列 $y _ { 1 } , y _ { 2 } , \cdots , y _ { i }$ 中以 $y _ { i }$ 结尾的最长 $\overrightharpoon { j } ^ { \mathbb { E } }$ 格递增子列与最长严格递减子列的长度。若 $i ~ < ~ j$ ，则当 $y _ { i } ~ < ~ y _ { j }$ 时有 $a _ { j } ~ \geqslant ~ a _ { i } + 1$ ，当 $y _ { i } ~ > ~ y _ { j }$ 时有 $b _ { j } ~ \geqslant ~ b _ { i } + 1$ ，所以有序对$( a _ { 1 } , b _ { 1 } ) , ( a _ { 2 } , b _ { 2 } ) , \cdots , ( a _ { N } , b _ { N } )$ 两两不同。若所有 $a _ { i } , b _ { i }$ 都不超过 $n + 1$ ，则这些有序对至多有 $( n + 1 ) ^ { 2 }$ 种，与 $N > ( n + 1 ) ^ { 2 }$ 矛盾。因此某个 $a _ { i }$ 或 $b _ { i }$ 至少为 $n + 2$ ，从而存在下标$i _ { 1 } < i _ { 2 } < \cdots < i _ { n + 2 }$ ，使得

$$
y _ {i _ {1}} <   y _ {i _ {2}} <   \dots <   y _ {i _ {n + 2}} \quad \text {或} \quad y _ {i _ {1}} > y _ {i _ {2}} > \dots > y _ {i _ {n + 2}}
$$

对任意 $2 \leqslant j < k \leqslant n + 2$ ，由横坐标与纵坐标的上述单调性可知

$$
0 <   x _ {i _ {j}} - x _ {i _ {1}} <   x _ {i _ {k}} - x _ {i _ {1}}, \quad 0 <   | y _ {i _ {j}} - y _ {i _ {1}} | <   | y _ {i _ {k}} - y _ {i _ {1}} |
$$

故从 $P _ { i _ { 1 } }$ 到这条单调点链上其余各点的欧氏距离严格递增，即

$$
P _ {i _ {1}} P _ {i _ {2}} <   P _ {i _ {1}} P _ {i _ {3}} <   \dots <   P _ {i _ {1}} P _ {i _ {n + 2}}
$$

这就产生了 $n + 1$ 种不同的距离，与题设至多只有 n 种不同距离矛盾。因此 $N \leqslant ( n + 1 ) ^ { 2 }$ 。

所以存在 $i < j < k < l$ ，使 $y _ { i } , y _ { j } , y _ { k } , y _ { l }$ 不减或不增。由于相应的横坐标不减，曼哈顿距离沿这条四点链可加，从而

USA TST 2008 P3 

对坐标平面上两点 $A ( x _ { 1 } , y _ { 1 } ) , B ( x _ { 2 } , y _ { 2 } )$ ，定义

$$
d (A, B) = | x _ {1} - x _ {2} | + | y _ {1} - y _ {2} |
$$

若 $1 < d ( A , B ) \leqslant 2$ ，则称无序点对 $( A , B )$ 为调和点对。求平面上 100 个点中调和点对数目的最大值。

解

答案为 3750。

以这 100 个点为顶点构造简单图 G，当且仅当两个点构成调和点对时在相应顶点之间连边。先证明 G 不含 $K _ { 5 } .$ 。反设五个点 $P _ { 1 } , P _ { 2 } , \cdots , P _ { 5 }$ 两两构成调和点对，写成 $P _ { i } = ( x _ { i } , y _ { i } )$ ，并重新编号使 $x _ { 1 } \leqslant x _ { 2 } \leqslant \cdots \leqslant x _ { 5 }$ 。由 Erdős–Szekeres 单调子列定理的 $5 = ( 3 - 1 ) ^ { 2 } + 1$ 情形，存在 $i < j < k$ ，使 $y _ { i } , y _ { j } , y _ { k }$ 单调不减或单调不增。若它们单调不减，则

$$
d \left(P _ {i}, P _ {k}\right) = \left(x _ {k} - x _ {i}\right) + \left(y _ {k} - y _ {i}\right) = d \left(P _ {i}, P _ {j}\right) + d \left(P _ {j}, P _ {k}\right) > 2
$$

若它们单调不增，则同理有

$$
d (P _ {i}, P _ {k}) = (x _ {k} - x _ {i}) + (y _ {i} - y _ {k}) = d (P _ {i}, P _ {j}) + d (P _ {j}, P _ {k}) > 2
$$

这都与 $( P _ { i } , P _ { k } )$ 是调和点对矛盾。因此 G 不含 $K _ { 5 }$ 。由 Turán 定理，不含 $K _ { 5 }$ 的 100 阶简单图边数至多等于平衡完全四部图的边数，故

$$
e (G) \leqslant \left(1 - \frac {1}{4}\right) \frac {1 0 0 ^ {2}}{2} = 3 7 5 0
$$

下面构造达到此上界的点集。令

$$
T = \left\{0, \frac {1}{1 0 0}, \frac {2}{1 0 0}, \dots , \frac {2 4}{1 0 0} \right\}, \quad \Phi (u, v) = \left(\frac {u + v}{2}, \frac {u - v}{2}\right)
$$

并取

$$
\mathcal {P} = \{\Phi (t, t), \Phi (2 - t, t), \Phi (t, 2 - t), \Phi (2 - t, 2 - t) \mid t \in T \}
$$

这是由四组各 25 个点组成的 100 个两两不同的点。直接计算可得

$$
d \big (\Phi (u _ {1}, v _ {1}), \Phi (u _ {2}, v _ {2}) \big) = \max \{| u _ {1} - u _ {2} |, | v _ {1} - v _ {2} | \}
$$

同组两点的距离至多为 $2 4 / 1 0 0 \mathrm { ~ < ~ } 1$ 。对不同组的两点，至少有一个变换后的坐标分别属于$[ 0 , 2 4 / 1 0 0 ]$ 与 $[ 1 7 6 / 1 0 0 , 2 ]$ ，故其距离大于 1；又所有变换后的坐标都属于 [0,2]，故其距离不超过 2。所以恰有不同组之间的点对是调和点对，其数目为

$$
\binom {4} {2} \cdot 2 5 ^ {2} = 3 7 5 0
$$
