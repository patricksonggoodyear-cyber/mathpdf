Middle European 2020 Individual P1 

求所有正整数 k，使得存在函数 $f , g : \mathbb { Z } _ { + } \to \mathbb { Z } _ { + }$ ，满足 g 的值域是无限集，并且

$$
f ^ {g (n)} (n) = f (n) + k
$$

对任意正整数 n 成立。其中 $f ^ { m }$ 表示函数 f 的 m 次迭代。

解

答案是所有满足 $k \geqslant 2$ 的正整数。

先证明 $k = 1$ 时不存在所求函数。此时题设等式变为

$$
f ^ {g (n)} (n) = f (n) + 1
$$

引理一：函数 f 没有周期点，即不存在正整数 $m , n$ 使得 $f ^ { m } ( n ) = n$ 

引理一证明：反设 $f ^ { m } ( n ) = n$ 。令

$$
A = \{n, f (n), f ^ {2} (n), \dots , f ^ {m - 1} (n) \}
$$

则 n 的所有迭代值都属于有限集 A。取 $t = \operatorname* { m a x } A = f ^ { s } ( n )$ ，其中 $0 \leqslant s < m$ ，并令 $u =$ $f ^ { s + m - 1 } ( n )$ 。由 $f ^ { m } ( n ) = n$ 可得 $u \in A$ 且 $f ( u ) = t .$ 。把 u 代入题设等式，得到

$$
t + 1 = f (u) + 1 = f ^ {g (u)} (u) \in A
$$

这与 $t = \operatorname* { m a x } A$ 矛盾。因此 f 没有周期点。

引理二：对任意正整数 n，都有 $f ( n ) \geqslant n + 1 \mathfrak { c }$ 

引理二证明：假设某个正整数 n 满足 $f ( n ) \leqslant n .$ 。我们证明：对每个非负整数 r，都存在正整数 s，使得

$$
f ^ {s} (n) = f (n) + r
$$

当 $r = 0$ 时取 $s = 1$ 即可。若对某个 r 已有 $f ^ { s } ( n ) = f ( n ) + r$ ，令 $v = f ^ { s - 1 } ( n )$ ，则题设等式给出

$$
f ^ {g (v) + s - 1} (n) = f ^ {g (v)} (v) = f (v) + 1 = f ^ {s} (n) + 1 = f (n) + r + 1
$$

故归纳成立。取 $r = n - f ( n )$ ，便得到某个 $s \geqslant 1$ 使得 $f ^ { s } ( n ) = n$ ，与引理一矛盾。因此$f ( n ) > n ;$ ；由于函数值均为整数，必有 $f ( n ) \geqslant n + 1$ o

由引理二，对任意正整数 $m , n$ 均有

$$
f ^ {m} (n) \geqslant f ^ {m - 1} (n) + 1 \geqslant \dots \geqslant f (n) + m - 1
$$

令 $m = g ( n )$ ，结合题设等式可得

$$
f (n) + 1 = f ^ {g (n)} (n) \geqslant f (n) + g (n) - 1
$$

所以 $g ( n ) \leqslant 2$ 对所有正整数 n 成立，于是 g 的值域包含于 $\{ 1 , 2 \}$ ，与其值域为无限集矛盾。因此 $k = 1$ 不可行。

下面对任意给定的正整数 $k \geqslant 2$ 构造所求函数。把所有不能被 k 整除的正整数依次记为

$$
a _ {1} <   a _ {2} <   a _ {3} <   \dots
$$

具体地，当 $q \geqslant 0$ 且 $1 \leqslant r \leqslant k - 1$ 时，

$$
a _ {q (k - 1) + r} = q k + r
$$

现在重新排列全体正整数：对每个 $i \geqslant 1$ ，依次写下区块

$$
i k, a _ {(i - 1) ^ {2} + 1}, a _ {(i - 1) ^ {2} + 2}, \dots , a _ {i ^ {2}}
$$

所得数列的开头为

$$
k, a _ {1}, 2 k, a _ {2}, a _ {3}, a _ {4}, 3 k, a _ {5}, \dots , a _ {9}, 4 k, a _ {1 0}, \dots , a _ {1 6}, 5 k, \dots
$$

其中每个 k 的正倍数恰出现一次，而指标区间 $( ( i - 1 ) ^ { 2 } , i ^ { 2 } ]$ 两两不交且覆盖全体正整数指标，所以每个 $a _ { j }$ 也恰出现一次。因此这个数列恰好是全体正整数的一个排列。

对任意正整数 n，数 $n + k$ 都出现在 n 之后。事实上，若 $n = i k$ ，则 $( i + 1 ) k = n + k$ 出现在后面的区块中；若 $n = a _ { j }$ ，写成 $j = q ( k - 1 ) + r$ ，其中 $q \geqslant 0$ 且 $1 \leqslant r \leqslant k - 1$ ，则

$$
n + k = (q + 1) k + r = a _ {j + k - 1}
$$

而 $j + k - 1 > j$ ，故 $n + k$ 同样出现在 n 之后。

定义 $f ( n )$ 为 n 在上述排列中的后继项。对每个正整数 n，定义 $g ( n )$ 为该排列中从 $f ( n )$ 到 $f ( n ) + k$ 的项数，并把两端都计入。由于 $f ( n ) + k$ 位于 $f ( n )$ 之后， $g ( n )$ 是良定义的正整数。从 n 开始，每作用一次 f 就沿排列前进一步，因而

$$
f ^ {g (n)} (n) = f (n) + k
$$

最后证明 g 的值域是无限集。数 $a _ { i ^ { 2 } }$ 是第 i 个区块的末项，所以 $f ( a _ { i ^ { 2 } } ) = ( i + 1 ) k$ 。从$( i + 1 ) k$ 到 (i + 2)k 的相应片段为

$$
(i + 1) k, a _ {i ^ {2} + 1}, a _ {i ^ {2} + 2}, \dots , a _ {(i + 1) ^ {2}}, (i + 2) k
$$

中间共有 $( i + 1 ) ^ { 2 } - i ^ { 2 } = 2 i + 1$ 个数，连同两端共有 2i+3 项。因此

$$
g (a _ {i ^ {2}}) = 2 i + 3
$$

对所有正整数 i 成立。故 g 取到无穷多个不同的值，构造完成。

USAMO 2019 P1 

设函数 $f : \mathbb { Z } _ { + } \to \mathbb { Z } _ { + }$ 满足：对任意正整数 n，均有

$$
f ^ {f (n)} (n) = \frac {n ^ {2}}{f (f (n))}
$$

其中 $f ^ { k }$ 表示 f 的 k 次迭代。求 f(1000) 的所有可能值。

解

答案：f(1000) 可以取任意正偶数，即 2, 4, 6, · · · 。

将题设等式改写为

$$
f ^ {f (n)} (n) f ^ {2} (n) = n ^ {2}
$$

先证明 $f$ 是单射。若 $f ( a ) = f ( b )$ ，则 $f ^ { 2 } ( a ) = f ^ { 2 } ( b )$ ；又因为迭代次数 $f ( a )$ 与 $f ( b )$ 相同，而且第一次迭代后的值也相同，所以 $f ^ { f ( a ) } ( a ) = f ^ { f ( b ) } ( b )$ 。分别把 $a , b$ 代入上式，得到 $a ^ { 2 } = b ^ { 2 }$ 由于 $a , b$ 均为正整数，故 $a = b $ 。因此 f 以及 f 的每个正整数次迭代都是单射。

下面对正奇数 n 作强归纳，证明 $f ( n ) = n$ 。假设所有小于 n 的正奇数都是 f 的不动点。由

$$
f ^ {f (n)} (n) f ^ {2} (n) = n ^ {2}
$$

可知左边的两个因子都是正奇数。若其中一个因子小于 n，则它是 $f$ 的不动点。设这个因子为 s，并设它等于 $f ^ { r } ( n )$ ，其中 r 为正整数。于是 $f ^ { r } ( s ) = s = f ^ { r } ( n )$ ，这与 $f ^ { r }$ 的单射性矛盾。因此两个因子都不小于 $n ;$ ；它们的乘积为 $n ^ { 2 }$ ，故

$$
f ^ {f (n)} (n) = f ^ {2} (n) = n
$$

这一论证也涵盖 n = 1 的情形。

令 $y = f ( n )$ ，则 $f ( y ) = n$ 。把 y 代入题设等式的改写形式，得到

$$
y ^ {2} = f ^ {f (y)} (y) f ^ {2} (y) = f ^ {n} (y) y
$$

由 $f ^ { 2 } ( n ) = n$ 可知 n,y 在迭代中交替出现。因为 n 是奇数，所以 $f ^ { n } ( y ) = n$ ，从而 $y ^ { 2 } = n y$ 由 $y > 0$ 得 $y = n$ ，即 $f ( n ) = n$ 。强归纳完成，故每个正奇数都是 f 的不动点。

若某个偶数 u 满足 $f ( u )$ 为奇数，则已经证明的结论给出 $f ( f ( u ) ) = f ( u )$ 。于是 f 在 u与 f(u) 处的值相同，由单射性得 $u = f ( u )$ ，这与两边奇偶性不同矛盾。因此 f 把偶数映为偶数，特别地， $f ( 1 0 0 0 )$ 必为正偶数。

最后证明每个正偶数都能取得。任取正偶数 c。若 $c = 1 0 0 0$ ，取恒等函数；若 $c \neq 1 0 0 0$ 定义 f 交换 1000 与 c，并固定其余所有正整数。这样构造的 f 固定每个奇数，在偶数集上是对合，因而 $f ^ { 2 } ( n ) = n$ 对所有正整数 n 成立。当 n 为奇数时， $f ( n ) = n$ ；当 n 为偶数时，$f ( n )$ 为偶数，所以 $f ^ { f ( n ) } ( n ) = n \circ$ 。在两种情形下都有

$$
f ^ {f (n)} (n) = n = \frac {n ^ {2}}{f ^ {2} (n)}
$$

故该构造满足题设，且 $f ( 1 0 0 0 ) = c _ { \circ }$ 因此所有正偶数都可以取得。
