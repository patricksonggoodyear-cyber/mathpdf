试问：是否存在这样的整系数二次三项式 $P ( x )$ ，使得对任何十进制表达式中的各位数字都是 1 的正整数 n，在 $P ( n )$ 的十进制表达式中的各位数字也都是 1？

解

观察二次三项式 $P ( x ) = x ( 9 x + 2 )$ 。如果 $n = \sum _ { i = 0 } ^ { k } 1 0 ^ { i }$ ，则 $9 n + 2 = 1 0 ^ { k + 1 } + 1$ ，因而

$$
P (n) = \left(\sum_ {i = 0} ^ {k} 1 0 ^ {i}\right) \cdot \left(1 0 ^ {k + 1} + 1\right) = \sum_ {i = 0} ^ {2 k + 1} 1 0 ^ {i}
$$

这表明 P(x) 满足题中条件。

Putnam 1989 A1 

在十进制表示中，数码 1 与 0 交替出现，且首位和末位都是 1 的正整数中，有多少个质数？

解

答案为 1 个，即 101。

设 $N _ { k }$ 是含有 k 个数码 1 的这种正整数，其中 k $\geqslant 1$ 。把它写成以 100 为公比的等比数列之和，得到

$$
N _ {k} = 1 + 1 0 0 + \dots + 1 0 0 ^ {k - 1} = \frac {1 0 0 ^ {k} - 1}{9 9}
$$

当 $k = 1$ 时， $N _ { 1 } = 1$ 不是质数。当 $k = 2$ 时， $N _ { 2 } = 1 0 1$ ；由于 $\sqrt { 1 0 1 } < 1 1$ ，且 101 不能被2,3,5,7 中任何一个质数整除，所以 101 是质数。

以下设 k $\geqslant 3 .$ 若 k 为偶数，则 $k \geqslant 4$ ，并且

$$
N _ {k} = (1 + 1 0 0) \left(1 + 1 0 0 ^ {2} + \dots + 1 0 0 ^ {k - 2}\right)
$$

等式右端的两个因数都大于 1，故 $N _ { k }$ 是合数。

若 k 为奇数，则

$$
N _ {k} = \frac {1 0 0 ^ {k} - 1}{9 9} = \frac {1 0 ^ {k} - 1}{9} \cdot \frac {1 0 ^ {k} + 1}{1 1}
$$

其中第一个因数是整数；又因 $1 0 \equiv - 1 { \pmod { 1 1 } }$ 且 k 为奇数，第二个因数也是整数。由 k ⩾ 3可知两个因数都大于 1，所以 $N _ { k }$ 也是合数。

综上，符合条件的质数只有 101，因此所求质数的个数为 1。

Putnam 2020 A1 

有多少个正整数 N 同时满足下列三个条件？

(1) N 能被 2020 整除；

(2) N 的十进制表示至多有 2020 位；

(3) N 的十进制表示由一串连续的数字 1 后接一串连续的数字 0 构成，其中后一串允许为空。

## 解

答案为 508536。

设 N 的十进制表示中有 m 个数字 1，随后有 n 个数字 0，其中 $m \geqslant 1 , n \geqslant 0 $ ，且$m + n \leqslant 2 0 2 0$ 。于是

$$
N = (1 + 1 0 + \dots + 1 0 ^ {m - 1}) 1 0 ^ {n} = \frac {1 0 ^ {m} - 1}{9} \cdot 1 0 ^ {n}
$$

数 $( 1 0 ^ { m } - 1 ) / 9$ 是奇数且不能被 5 整除。又因为 $2 0 2 0 = 2 ^ { 2 } \cdot 5 \cdot 1 0 1$ ，所以 $2 0 \mid N$ 当且仅当n ⩾ 2。

另一方面，101 与 9·10 互质，故

$$
1 0 1 \mid N \Longleftrightarrow 1 0 ^ {m} \equiv 1 \pmod {1 0 1}
$$

由于 $1 0 ^ { 2 } \equiv - 1 { \pmod { 1 0 1 } }$ ，而 $1 0 \not \equiv 1 \ ( \mathrm { m o d } \ 1 0 1 )$ ，所以 10 模 101 的阶为 4。因此 $1 0 1 \mid N$ 当且仅当 $4 \mid m .$ 。

令 $m \ = \ 4 r .$ 。由 $m + n \leqslant 2 0 2 0$ 及 $n \geqslant 2$ 可知 $1 \leqslant r \leqslant 5 0 4$ 。固定 r 后，n 可以取$2 , 3 , \cdots , 2 0 2 0 - 4 r$ ，共有 2019−4r 种取法。因此满足条件的正整数共有

$$
\sum_ {r = 1} ^ {5 0 4} (2 0 1 9 - 4 r) = 2 0 1 9 \cdot 5 0 4 - 4 \cdot \frac {5 0 4 \cdot 5 0 5}{2} = 5 0 4 \cdot 1 0 0 9 = 5 0 8 5 3 6
$$

一个 2000 位正整数的末 k 位均为 2，其余各位均为 1。求所有满足 1 ⩽ k ⩽ 2000 的整数k，使这个数减去由 1001 个数字 2 组成的正整数后为完全平方数。

解

答案： $k = 2$ 

记 $R _ { m } = ( 1 0 ^ { m } - 1 ) / 9 = \underbrace { 1 1 \cdots 1 } _ { }$ ，并以 $N _ { k }$ 表示题中所给的差。

若 k > 1000，则被减数的末 1001 位均为 2，所以相减后 $N _ { k }$ 恰有 1001 个末尾零。完全平方数末尾零的个数必为偶数，故这种情形不可能。

以下设 $k \leqslant$ 1000。被减数可写成 $R _ { 2 0 0 0 } + R _ { k }$ ，因而

$$
N _ {k} = R _ {2 0 0 0} + R _ {k} - 2 R _ {1 0 0 1} = 1 0 ^ {k} \left(R _ {2 0 0 0 - k} - 2 R _ {1 0 0 1 - k}\right)
$$

括号内的数模 10 余 9，故 $N _ { k }$ 恰有 k 个末尾零。若 $N _ { k }$ 是完全平方数，则 k 必为偶数。令$k = 2 l$ ，其中 $1 \leqslant l \leqslant 5 0 0$ ，并记

$$
A = R _ {2 0 0 0 - 2 l} - 2 R _ {1 0 0 1 - 2 l}
$$

由于 $1 0 ^ { 2 l }$ 是完全平方数， $N _ { k }$ 是完全平方数当且仅当 A 是完全平方数。又

$$
9 A = 1 0 ^ {2 0 0 0 - 2 l} - 2 \cdot 1 0 ^ {1 0 0 1 - 2 l} + 1
$$

令 $X = 1 0 ^ { 1 0 0 0 - l }$ ，则

$$
9 A = X ^ {2} - 2 X \cdot 1 0 ^ {1 - l} + 1
$$

若 l = 1，则

$$
9 A = (X - 1) ^ {2}
$$

而 $3 \mid X - 1$ ，故 $A = ( ( X - 1 ) / 3 ) ^ { 2 }$ ，从而 k = 2 确实满足条件。

若 $l \geqslant 2$ ，则

$$
9 A - (X - 1) ^ {2} = 2 X \left(1 - 1 0 ^ {1 - l}\right) > 0
$$

并且由 $l \leqslant$ 500 可得

$$
X ^ {2} - 9 A = 2 \cdot 1 0 ^ {1 0 0 1 - 2 l} - 1 > 0
$$

所以

$$
(X - 1) ^ {2} <   9 A <   X ^ {2}
$$

数 9A 介于两个相邻的完全平方数之间，因而不是完全平方数，A 也不是完全平方数。

综上，唯一答案为 k = 2。
