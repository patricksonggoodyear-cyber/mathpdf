在有限种连线构形中，为局部换边寻找严格下降的势函数，从而控制变换次数或排除交叉。

## Putnam 1966 B5

平面上给定 $n \geqslant 3$ 个点，任意三点不共线。证明：可以把它们依次记作 $P _ { 1 } , P _ { 2 } , \cdots , P _ { n }$ 使折线 $P _ { 1 } P _ { 2 } \cdots P _ { n } P _ { 1 }$ 构成一个不自交的多边形。

## 解

考虑所有按某种顺序经过每个点一次再回到起点的闭折线。这样的顺序只有有限种，所以可取总长度最小的一条，记作 $P _ { 1 } P _ { 2 } \cdots P _ { n } P _ { 1 }$ o

若两条不相邻的边 AB,CD 相交，记它们的端点沿闭折线依次为 A,B,C,D，交点为 X。由于任意三点不共线，X 在两边内部。把 $A B , C D$ 换成 $A C , B D$ ，并将原来从 B 到 C 的那段路径反向，仍得到一条经过每个点一次的闭折线。由严格三角不等式，

$$
A C + B D <   A X + X C + B X + X D = A B + C D
$$

路径中其余边的总长度不变，便与原闭折线总长度最小矛盾。因此最短闭折线没有相交的非相邻边。相邻边也不会在公共端点之外相交，故它是不自交的多边形。

## Putnam 1979 A4

平面上有 2n 个点，其中 n 个染成红色，另 n 个染成蓝色，且任意三点不共线。证明：可以将这些点配成 n 对，每对恰有一个红点和一个蓝点，使得连接各对点所得的 n 条线段两两没有公共点。

## 解

设红点为 $A _ { 1 } , A _ { 2 } , \cdots , A _ { n }$ ，蓝点为 $B _ { 1 } , B _ { 2 } , \cdots , B _ { n }$ 。在所有红蓝一一配对中，取所连线段总长度最小的一种，并适当调整蓝点的编号，使这些线段为 $A _ { i } B _ { i } \ ( 1 \leqslant i \leqslant n )$ 。

若其中两条线段 $A _ { i } B _ { i }$ 与 $A _ { j } B _ { j }$ 相交，设交点为 X。由于各端点互异且任意三点不共线，X 位于两条线段的内部。由严格三角不等式，

$$
A _ {i} B _ {j} + A _ {j} B _ {i} <   A _ {i} X + X B _ {j} + A _ {j} X + X B _ {i} = A _ {i} B _ {i} + A _ {j} B _ {j}
$$

因此将原来的两对改为 $( A _ { i } , B _ { j } )$ 与 $( A _ { j } , B _ { i } )$ ，其余配对保持不变，就得到总长度更小的红蓝一一配对，矛盾。故所取线段两两没有公共点。

## TOT 1984 Autumn Junior A3

平面上有有限个点，任意三点不共线。连接其中一些点，每个点至多是其中一条线段的端点。如果两条线段 AB,CD 相交，允许删去它们，改连四边形 ACBD 的两条对边 AC,BD，以后还可重复这样的变换。问：能否无限次地进行变换？

## 解

不能。设 AB,CD 的交点为 X。由于每个点至多属于一条线段，四个端点互异；又因任意三点不共线，X 位于两条线段的内部。由严格三角不等式，

$$
A C + B D <   A X + X C + B X + X D = A B + C D
$$

所以每次变换都使所有线段的长度之和严格下降。点集有限，各点至多连接一条线段的配置也只有有限种。如果变换能无限进行，就会有某个配置重复出现，但其长度和不可能在严格下降后恢复原值，矛盾。

## RMM 2016 P6

欧氏三维空间中有n个点，任意四点不共面，分成A,B 两组。称连接这些点的n 1条线段构成一棵AB 树，如果每条线段的一端属于A、另一端属于B，且其中不存在闭折线。一次变换是在树中选取依次相连的三条不同线段 $A _ { 1 } B _ { 1 } , B _ { 1 } A _ { 2 } , A _ { 2 } B _ { 2 }$ ，满足 $A _ { 1 } B _ { 1 } + A _ { 2 } B _ { 2 } > A _ { 1 } B _ { 2 } + A _ { 2 } B _ { 1 }$ 然后删去 $A _ { 1 } B _ { 1 }$ ，加入 $A _ { 1 } B _ { 2 }$ 。证明：从任意一棵 AB 树出发，无论怎样连续进行这种变换，经过有限步后都不能再进行变换。

## 解

把线段视为图的边。由于共有 n 个顶点、n 1 条边且没有回路，每个 AB 树都是连通的。对树 T 的每条边 $e _ { : }$ ，删去 e 后，令 $p _ { T } ( e )$ 为包含 e 的 A 端点的那个连通分支内的 A 点数。定义势函数

$$
\Phi (T) = \sum_ {e \in E (T)} p _ {T} (e) | e |
$$

其中 e 表示边 e 的长度。

设一次变换涉及路径 $A _ { 1 } B _ { 1 } A _ { 2 } B _ { 2 }$ ，变换后的树为 $T ^ { \prime }$ ，并记 $k = p _ { T } ( A _ { 1 } B _ { 1 } ) > 0$ 。删去 $A _ { 1 } B _ { 1 }$ 后，包含 $A _ { 1 }$ 的分支有 k 个 A 点，而 $B _ { 2 }$ 在另一分支中；用 $A _ { 1 } B _ { 2 }$ 接回去后，所得图仍是一棵 AB 树。这个含 k 个 A 点的分支，原来接在 $B _ { 1 }$ ，现在接在 $B _ { 2 }$ 。因此新边 $A _ { 1 } B _ { 2 }$ 的权数为k，边 $B _ { 1 } A _ { 2 }$ 的权数增加 k，边 $A _ { 2 } B _ { 2 }$ 的权数减少 k，其余边的权数不变。于是

$$
\Phi (T ^ {\prime}) - \Phi (T) = k (A _ {1} B _ {2} + A _ {2} B _ {1} - A _ {2} B _ {2} - A _ {1} B _ {1}) <   0
$$

所有可能的 AB 树只有有限棵，而每次变换的势都严格下降，故变换不可能无限进行。

IMOSL 2014 C7 

设 M 是平面上 n ⩾ 4 个点的集合，任意三点不共线。开始时用 n 条线段连接这些点，使每点恰为两条线段的端点。每一步可选两条内部相交的线段 AB,CD，若 AC,BD 当前都不存在，就用 AC,BD 替换它们。证明：不可能进行不少于 $n ^ { 3 } / 4$ 步。

## 解

把经过 M 中两点的直线称为红线。对线段 UV，令 $X _ { U V }$ 为与 UV 的内部交于恰好一点的红线集合，即不计与 UV 重合的直线；记 $v ( U V ) = | X _ { U V } |$ ，并把各线段的 v 值之和作为总势。红线共有 ${ \binom { n } { 2 } } < n ^ { 2 } / 2$ 条，故初始 n 条线段的总势小于 $n ^ { 3 } / 2$ 

考虑一步 $A B , C D  A C , B D$ ，设两旧线段交于内部点 S。若红线穿过 AC 的内部，则它从三角形ACS 的另一边穿出时，必穿过AS 或CS 的内部，或者经过S，所以属于 $X _ { A B } \cup X _ { C D }$ 对 BD 同理。红线 AB 穿过旧线段 CD 的内部，红线 CD 穿过旧线段 AB 的内部，而它们都不穿过两条新线段的内部。因此

$$
\left| X _ {A C} \cup X _ {B D} \right| + 2 \leqslant \left| X _ {A B} \cup X _ {C D} \right|
$$

若一条红线同时穿过 AC 与 BD 的内部，由于对角线 AB 把 C,D 分开，CD 把 $A , B$ 分开，该直线也必穿过 AB 与 CD 的内部。故 $X _ { A C } \cap X _ { B D } \subseteq X _ { A B } \cap X _ { C D }$ 。将并集与交集的计数相加，得到

$$
v (A C) + v (B D) + 2 \leqslant v (A B) + v (C D)
$$

所以每步总势至少下降 2。势始终非负，故步数严格小于 $( n ^ { 3 } / 2 ) / 2 = n ^ { 3 } / 4$
