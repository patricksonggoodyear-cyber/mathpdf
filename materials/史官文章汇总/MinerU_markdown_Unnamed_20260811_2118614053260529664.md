借助一个球建立不同平面之间点的对应关系，这正是 Pak–Pinchasi 的“倒塌墙定理”所体现的思想。

## Moscow MO 1952 Grade 10 P1

一个 n 棱锥有内切球。将各个侧面绕相应的底棱旋转到底面所在平面，使旋转后的侧面与底面位于相应底棱的同侧。证明：

（1）各侧面与内切球的切点在旋转后重合于同一点 H；

（2）各侧面中不属于底面的顶点在旋转后的像位于一个以 H 为圆心的圆上。

## 解

设内切球与底面切于点 H，并约定 $A _ { n + 1 } = A _ { 1 }$ 。设内切球与侧面 $S A _ { i } A _ { i + 1 }$ 切于点 $T _ { i }$ 。将侧面 $S A _ { i } A _ { i + 1 }$ 绕底棱 $A _ { i } A _ { i + 1 }$ 旋转到底面所在平面，记 $T _ { i }$ 和 $S$ 在旋转后的像分别为 $T _ { i } ^ { \prime }$ 和$S _ { i }$ 。

从点 $A _ { i }$ 向内切球引出的切线段长度相等，故 $A _ { i } T _ { i } = A _ { i } H$ ；同理， $A _ { i + 1 } T _ { i } = A _ { i + 1 } H$ 。旋转保持距离，因此

$$
A _ {i} T _ {i} ^ {\prime} = A _ {i} H, \qquad A _ {i + 1} T _ {i} ^ {\prime} = A _ {i + 1} H
$$

点 $T _ { i } ^ { \prime }$ 与 H 又位于直线 $A _ { i } A _ { i + 1 }$ 的同侧，所以 $T _ { i } ^ { \prime } = H$ 。这对每个 i 都成立，故各侧面的切点在旋转后均重合于点 $H$ 。

另一方面，旋转保持距离，所以 $H S _ { i } = T _ { i } S$ 。从棱锥顶点 S 向内切球引出的所有切线段长度相等，因而 $T _ { i } S$ 与 i 无关。于是所有点 $S _ { i }$ 到 H 的距离相等，它们均位于一个以 H 为圆心的圆上。

## Iran 3rd Round 2009 P7

已知 P 为一个球外切多面体，现将 P 的每个面染成黑色或白色，使得任意两个黑面均没有公共棱。求证：黑面的总面积小于等于白面的总面积。

## 解

对于多面体的每个面，将该面与内切球的切点同该面的每个顶点相连，从而把每个面划分成若干个三角形。

考虑黑面 $A _ { 1 } A _ { 2 } \dotsm A _ { k }$ ，设该面与内切球切于点 $T _ { \circ }$ 。棱 $A _ { 1 } A _ { 2 }$ 的另一个邻面必为白面，设它与内切球切于点 $T ^ { \prime } { _ { c } }$ 。从 $A _ { 1 }$ 和 $A _ { 2 }$ 分别向内切球引切线，利用同一点引出的切线段长度相

等，可得

$$
A _ {1} T = A _ {1} T ^ {\prime}, \quad A _ {2} T = A _ {2} T ^ {\prime}, \quad \triangle T A _ {1} A _ {2} \cong \triangle T ^ {\prime} A _ {1} A _ {2}
$$

因此，每一个黑三角形都对应于相邻白面中一个与其全等的白三角形。每个这样的三角形由其底棱唯一确定，而一条棱的另一侧只有一个邻面，故不同的黑三角形对应不同的白三角形。因此，黑面的总面积不大于白面的总面积。

## All-Russian 2012 Grade 11 P4

$S A _ { 1 } A _ { 2 } \dotsm A _ { n }$ 是一个以凸多边形 $A _ { 1 } A _ { 2 } \dotsm A _ { n }$ 为底的 n 棱锥，约定 $A _ { n + 1 } = A _ { 1 }$ 。对每个$i = 1 , 2 , \cdots , n$ ，存在底面所在平面上的一点 $X _ { i }$ 满足： $\triangle X _ { i } A _ { i } A _ { i + 1 } \cong \triangle S A _ { i } A _ { i + 1 }$ ，且 $X _ { i }$ 与多边形 $A _ { 1 } A _ { 2 } \dotsm A _ { n }$ 位于直线 $A _ { i } A _ { i + 1 }$ 的同侧。

求证：三角形 $X _ { i } A _ { i } A _ { i + 1 } \ ( i = 1 , 2 , \cdot \cdot \ , n )$ 的并覆盖多边形 $A _ { 1 } A _ { 2 } \dotsm A _ { n }$ 

## 解

任取底面多边形内部一点 P，在棱锥内部作一个与底面切于 P 的小球。保持切点 $P$ 不变，逐渐增大球的半径，直到球首次与某个侧面相切。不妨设球与侧面 $S A _ { 1 } A _ { 2 }$ 切于点 $Q .$ 。底面所在平面与侧面 $S A _ { 1 } A _ { 2 }$ 所在平面都是该球的切平面，因此，对任意点 $D \in A _ { 1 } A _ { 2 }$ ，从 D引出的两条切线段长度相等，即 $D P = D Q$ 。特别地，

$$
Q A _ {1} = P A _ {1}, \quad Q A _ {2} = P A _ {2}
$$

故 $\triangle P A _ { 1 } A _ { 2 } \cong \triangle Q A _ { 1 } A _ { 2 }$ 。当侧面 $S A _ { 1 } A _ { 2 }$ 绕直线 $A _ { 1 } A _ { 2 }$ 旋转到底面所在平面，使其与底面位于该直线的同侧时，S 旋转到 $X _ { 1 }$ ，而 $Q$ 旋转到 $P _ { c }$ 。因此，P 位于三角形 $X _ { 1 } A _ { 1 } A _ { 2 }$ 内（含边界）。
