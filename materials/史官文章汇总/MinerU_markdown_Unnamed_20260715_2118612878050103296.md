$$
\int_ {0} ^ {\pi} f (x) \sin x \mathrm{d} x = \int_ {0} ^ {\pi} f (x) \cos x \mathrm{d} x = 1

$$
\min _ {f \in \mathcal {M}} \int_ {0} ^ {\pi} f ^ {2} (x) \mathrm{d} x
$$

解

令

$$
u (x) = \frac {2}{\pi} (\sin x + \cos x)
$$

对任意 $f \in \mathcal { M }$ ，利用题设的两个积分条件以及

$$
\int_ {0} ^ {\pi} \sin^ {2} x \mathrm{d} x = \int_ {0} ^ {\pi} \cos^ {2} x \mathrm{d} x = \frac {\pi}{2}, \quad \int_ {0} ^ {\pi} \sin x \cos x \mathrm{d} x = 0

$$

\int_ {0} ^ {1} f (x) \mathrm{d} x = \int_ {0} ^ {1} x f (x) \mathrm{d} x = 1

$$
\int_ {0} ^ {1} f ^ {2} (x) \mathrm{d} x \geqslant 4

解

若 $\textstyle \int _ { 0 } ^ { 1 } f ^ { 2 } ( x ) \mathrm { d } x = + \infty$ ，结论显然成立。以下设该积分有限。由题设两个积分等式，

$$
\int_ {0} ^ {1} (6 x - 2) f (x) \mathrm{d} x = 6 \int_ {0} ^ {1} x f (x) \mathrm{d} x - 2 \int_ {0} ^ {1} f (x) \mathrm{d} x = 4

$$

$$

所以 $\begin{array} { r } { \int _ { 0 } ^ { 1 } f ^ { 2 } ( x ) \mathrm { d } x \geqslant 4 . } \end{array}$ 。等号在 $f ( x ) = 6 x - 2$ 时可以取得。

(a) 设 $u , v : [ 0 , 1 ] \to$ R 为连续函数。证明柯西不等式

$$
\left(\int_ {0} ^ {1} u (x) v (x) \mathrm{d} x\right) ^ {2} \leqslant \left(\int_ {0} ^ {1} u (x) ^ {2} \mathrm{d} x\right) \left(\int_ {0} ^ {1} v (x) ^ {2} \mathrm{d} x\right)
$$

(b) 设 为所有满足下述条件的函数 $f : [ 0 , 1 ] $ R 组成的集合： $f$ 可导， $f ^ { \prime }$ 在 $[ 0 , 1 ]$ 上连续，且 $f ( 0 ) = 0 , f ( 1 ) = 1$ 。求

$$
\min _ {f \in \mathcal {C}} \int_ {0} ^ {1} \sqrt {1 + x ^ {2}} \left(f ^ {\prime} (x)\right) ^ {2} \mathrm{d} x
$$

并求出使该最小值取得的所有函数 $f \in { \mathcal { C } } .$ o

解

(a) 对任意实数 t，被积函数 $( u ( x ) + t v ( x ) ) ^ { 2 }$ 非负，故

$$
\int_ {0} ^ {1} u (x) ^ {2} \mathrm{d} x + 2 t \int_ {0} ^ {1} u (x) v (x) \mathrm{d} x + t ^ {2} \int_ {0} ^ {1} v (x) ^ {2} \mathrm{d} x \geqslant 0
$$

若 $\begin{array} { r } { \int _ { 0 } ^ { 1 } v ( x ) ^ { 2 } \mathrm { d } x = 0 } \end{array}$ ，则由连续性可知 $v \equiv 0$ ，结论显然成立。否则，上式是关于 t 的二次式，并且对一切实数 t 非负，所以其判别式不大于 0。这恰好给出

$$
\left(\int_ {0} ^ {1} u (x) v (x) \mathrm{d} x\right) ^ {2} \leqslant \left(\int_ {0} ^ {1} u (x) ^ {2} \mathrm{d} x\right) \left(\int_ {0} ^ {1} v (x) ^ {2} \mathrm{d} x\right)
$$

(b) 对任意 $f \in { \mathcal { C } }$ ，在 (a) 中取

$$
u (x) = (1 + x ^ {2}) ^ {1 / 4} f ^ {\prime} (x), \qquad v (x) = (1 + x ^ {2}) ^ {- 1 / 4}
$$

便有

$$
1 = (f (1) - f (0)) ^ {2} = \left(\int_ {0} ^ {1} f ^ {\prime} (x) \mathrm{d} x\right) ^ {2} \leqslant \left(\int_ {0} ^ {1} \sqrt {1 + x ^ {2}} (f ^ {\prime} (x)) ^ {2} \mathrm{d} x\right) \left(\int_ {0} ^ {1} \frac {\mathrm{d} x}{\sqrt {1 + x ^ {2}}}\right)
$$

而

$$
\int_ {0} ^ {1} \frac {\mathrm{d} x}{\sqrt {1 + x ^ {2}}} = \operatorname{arsinh} 1 = \ln (1 + \sqrt {2})
$$

所以所求积分不小于 $1 / \ln ( 1 + { \sqrt { 2 } } )$ o

柯西不等式取等号当且仅当上述两个函数 u,v 成比例，即存在常数 c 使

$$
f ^ {\prime} (x) = \frac {c}{\sqrt {1 + x ^ {2}}}
$$

由 $f ( 0 ) = 0$ 与 $f ( 1 ) = 1$ 得

$$
f (x) = \frac {\operatorname{arsinh} x}{\operatorname{arsinh} 1} = \frac {\ln (x + \sqrt {1 + x ^ {2}})}{\ln (1 + \sqrt {2})}
$$

此函数确实属于 并使等号成立。因此最小值为 $1 / \ln ( 1 + { \sqrt { 2 } } )$ ，且使最小值取得的函数只有上式所给的一个。

$$

解

由分部积分以及 $f ( 1 / 2 ) = 0$ ，可得

$$
\int_ {0} ^ {1 / 2} f (x) \mathrm{d} x = - \int_ {0} ^ {1 / 2} x f ^ {\prime} (x) \mathrm{d} x
$$

以及

$$
\int_ {1 / 2} ^ {1} f (x) \mathrm{d} x = \int_ {1 / 2} ^ {1} (1 - x) f ^ {\prime} (x) \mathrm{d} x
$$

定义

$$
w (x) = \left\{ \begin{array}{l l} - x, & 0 \leqslant x \leqslant 1 / 2 \\ 1 - x, & 1 / 2 <   x \leqslant 1 \end{array} \right.
$$

则

$$
\int_ {0} ^ {1} f (x) \mathrm{d} x = \int_ {0} ^ {1} w (x) f ^ {\prime} (x) \mathrm{d} x
$$

而

$$
\int_ {0} ^ {1} w (x) ^ {2} \mathrm{d} x = \int_ {0} ^ {1 / 2} x ^ {2} \mathrm{d} x + \int_ {1 / 2} ^ {1} (1 - x) ^ {2} \mathrm{d} x = \frac {1}{1 2}
$$

由柯西不等式，

$$
\left(\int_ {0} ^ {1} f (x) \mathrm{d} x\right) ^ {2} \leqslant \left(\int_ {0} ^ {1} w (x) ^ {2} \mathrm{d} x\right) \left(\int_ {0} ^ {1} \left(f ^ {\prime} (x)\right) ^ {2} \mathrm{d} x\right) = \frac {1}{1 2} \int_ {0} ^ {1} \left(f ^ {\prime} (x)\right) ^ {2} \mathrm{d} x
$$

移项即得题设不等式。

$$
\int_ {0} ^ {1} \left(x f ^ {\prime} (x)\right) ^ {2} d x \geq 1 2 \left(\int_ {0} ^ {1} x f (x) d x\right) ^ {2}

$$

$$
\begin{array}{r l} \left(\int_ {0} ^ {1} x ^ {2} f ^ {\prime} (x) \mathrm{d} x\right) ^ {2} & = \left(\int_ {0} ^ {1} x \cdot x f ^ {\prime} (x) \mathrm{d} x\right) ^ {2} \\ & \leqslant \left(\int_ {0} ^ {1} x ^ {2} \mathrm{d} x\right) \left(\int_ {0} ^ {1} \left(x f ^ {\prime} (x)\right) ^ {2} \mathrm{d} x\right) \\ & = \frac {1}{3} \int_ {0} ^ {1} \left(x f ^ {\prime} (x)\right) ^ {2} \mathrm{d} x \end{array}

这就是所证不等式。

$$
