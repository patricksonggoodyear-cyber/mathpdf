IMOSL 2005 A2 

求所有的函数 $f : \mathbb { R } _ { + } \to \mathbb { R } _ { + }$ ，使得对任意正实数 $x , y$ 均有

$$
f (x) f (y) = 2 f (x + y f (x))
$$

解

固定 $y > 0$ ，设 $\Phi _ { y } ( x ) = x + y f ( x )$ 。若 $\Phi _ { y } ( x _ { 1 } ) = \Phi _ { y } ( x _ { 2 } )$ ，则原方程给出 $f ( x _ { 1 } ) f ( y ) =$ $f ( x _ { 2 } ) f ( y )$ ；因 $f ( y ) > 0$ ，有 $f ( x _ { 1 } ) = f ( x _ { 2 } )$ ，进而 $x _ { 1 } = x _ { 2 } \circ$ 所以 $\Phi _ { y }$ 为单射。若存在 $0 < a < b$ 而 $f ( a ) > f ( b )$ ，取 $y = ( b - a ) / [ f ( a ) - f ( b ) ] > 0$ ，便有 $\Phi _ { y } ( a ) = \Phi _ { y } ( b )$ ，矛盾。因此 f 单调不减。

由 $x + y f ( x ) > x$ 及单调性，原方程给出 $f ( x ) f ( y ) = 2 f ( x + y f ( x ) ) \geqslant 2 f ( x )$ ，故 $f ( y ) \geqslant 2$ 对所有 $y > 0$ 成立。交换 $x , y$ 后再用单调性，得到

$$
f (x + y f (x)) = f (y + x f (y)) \geqslant f (2 x)
$$

固定 $x > 0$ ，单调性保证有限的右极限 $L _ { x } = \operatorname* { l i m } _ { t \downarrow x } f ( t )$ 存在。令 $y \downarrow 0$ ，上式左边趋于 $L _ { x }$ ，所以 $L _ { x } \geqslant f ( 2 x )$ 。而对每个 $x < t \leqslant 2 x$ ，单调性又给出 $L _ { x } \leqslant f ( t ) \leqslant f ( 2 x )$ 。因此 f 在 $( x , 2 x ]$ 上恒为 $f ( 2 x )$ 

任取 $a > 0 .$ 。区间 $( 3 a / 4 , 3 a / 2 ]$ 包含a与 $3 a / 2$ ，区间 $( a , 2 a ]$ 包含 $3 a / 2$ 与 $2 a$ ，故 $f ( a ) = f ( 2 a )$ 从而 f 在 $[ a , 2 a ]$ 上为常数。区间 $[ a , 2 a ] , [ 2 a , 4 a ] , [ 4 a , 8 a ] , \cdot \cdot \cdot$ 逐段相接，且 a 可以任取，故 f在整个正实数集上为常数。将 $f \equiv k > 0$ 代回原方程，得 $k ^ { 2 } = 2 k$ ，所以 $k = 2$ 。函数 $f \equiv 2$ 显然满足题意。

IMOSL 2020 A8 

求所有的函数 $f : \mathbb { R } _ { + } \to \mathbb { R } _ { + }$ ，使得对任意正实数 x,y 均有

$$
f (x + f (x y)) + y = f (x) f (y) + 1
$$

解

答案为 $f ( x ) = x + 1$ ，直接代入可验。令 $x = 1$ ，原式可整理为

$$
y = f (1) f (y) + 1 - f (1 + f (y))
$$

因此f 为单射。固定 $y > 0$ ，题设还给出 $f ( x + f ( x y ) ) = f ( x ) f ( y ) + 1 - y$ ，所以映射 $x \mapsto x + f ( x y )$ 也为单射。若存在 $0 < z _ { 1 } < z _ { 2 }$ 使 $f ( z _ { 1 } ) > f ( z _ { 2 } )$ ，取 $y = ( z _ { 2 } - z _ { 1 } ) / ( f ( z _ { 1 } ) - f ( z _ { 2 } ) ) > 0$ 及$x _ { i } = z _ { i } / y$ ，便有 $x _ { 1 } + f ( x _ { 1 } y ) = x _ { 2 } + f ( x _ { 2 } y )$ ，矛盾。故 f 单调不减；再由单射性知它严格递增。记 $p = \dim _ { t  0 + } f ( t )$ 。由于 f 严格递增且取正值，此极限存在且 $p \geqslant 0 .$ 。又因 $x + f ( x y ) > p$ 且 $x + f ( x y ) \to p ,$ ，令 $q = \operatorname* { l i m } _ { t  p + } f ( t )$ ；当 $p = 0$ 时，这个极限就是 $p ,$ ，当 $p > 0$ 时，单调性保证它存在且有限。固定 $y > 0$ ，在题设等式中令 $x \to 0 +$ ，得到

$$
q + y = p f (y) + 1
$$

若 $p = 0$ ，则 $q = 0$ ，上式要求所有正实数 y 都等于 1，矛盾。因此 $p > 0$ $f ( y ) = ( q + y - 1 ) / p$ 即 f 为一次函数。写 $f ( x ) = a x + b$ ，其中 $a = 1 / p > 0$ ，代入原式并比较 $x , y$ 的系数，得到

$$
a = a b, \qquad 1 = a b
$$

故 $a = b = 1$ 

CTST 2016 P18 

求所有函数 $f : \mathbb { R } _ { + } \to \mathbb { R } _ { + }$ 对任意三个互不相同的正实数 $a , b , c$ 满足：三条长度为 $a , b , c$ 的线段能构成三角形，当且仅当三条长度为 $f ( a ) , f ( b ) , f ( c )$ 的线段能构成三角形。

## 解

先证明 f 在任意区间 $( M , \infty )$ 上都无界。否则，记 $L = \operatorname* { l i m } \operatorname* { s u p } _ { x \to \infty } f ( x )$ ，则 L 为有限非负数。若 $L > 0$ ，任取 $0 < \varepsilon < L / 3$ ，可选出充分大且互不相同的 $a , b ,$ ，使 $L - \varepsilon < f ( a ) , f ( b ) < L + \varepsilon _ { \ast }$ 当 $z \geqslant a + b$ 足够大时， $f ( z ) ~ < ~ L + \varepsilon ~ < ~ f ( a ) + f ( b )$ ，而 $( a , b , z )$ 不能构成三角形，故$( f ( a ) , f ( b ) , f ( z ) )$ 也不能构成三角形。这只能是 $f ( z ) \leqslant | f ( a ) - f ( b ) | < 2 \varepsilon$ ，于是 $L \leqslant 2 \varepsilon < L$ 矛盾。若 $L = 0$ ，则 $f ( z ) \to 0 ,$ 。固定 $s > t > 0$ ，当 z 足够大时， $( s , z , z + t )$ 能构成三角形，但 $f ( z ) + f ( z + t ) < f ( s )$ ，仍矛盾。

其次证明 $\textit { f } \overrightarrow  \} ^ { \mathrm { \scriptsize { m } } }$ 格递增。任取 $a < b$ ，由上一步可选 $c > b$ ，使 $f ( c ) > \operatorname* { m a x } \{ f ( a ) , f ( b ) \}$ 。在$( c - b , c - a )$ 中取与 $a , b , c$ 均不相同的 x。此时 $( b , c , x )$ 能构成三角形， $( a , c , x )$ 不能构成三角形。若 $f ( a ) \geqslant f ( b )$ ，由于 $f ( c ) > f ( a )$ ，把三角形 $( f ( b ) , f ( c ) , f ( x ) )$ 中长度为 $f ( b )$ 的一边增至$f ( a )$ 后仍能构成三角形，矛盾。因此 $f ( a ) < f ( b )$ 。

对任意不同的正数 $u , v , \ ( u , v , u + v )$ 不能构成三角形。因 f 严格递增， $f ( u + v )$ 是对应三边中的最大者，故

$$
f (u + v) \geqslant f (u) + f (v)
$$

对整数 $n \geqslant 3$ ，依次把1拆成 $( n - 1 ) / n + 1 / n \cdot ( n - 1 ) / n = ( n - 2 ) / n + 1 / n$ ，直至 $3 / n = 2 / n { + } 1 / n$ 再用 $f ( 2 / n ) > f ( 1 / n )$ ，可得 $f ( 1 ) \geqslant ( n - 1 ) f ( 1 / n )$ 。于是 $f ( 1 / n ) \to 0$ ；由单调性知 $f ( h ) \to 0$ $( h \downarrow 0 )$ 

再证明 f 连续。固定 $t > 0$ ，取 $0 < \varepsilon < t / 3$ ，则 $( t , t + \varepsilon , 2 \varepsilon )$ 和 $\left( t - \varepsilon , t , 2 \varepsilon \right)$ 均为三边互不相同的三角形。由单调性和对应的三角不等式，

$$
0 <   f (t + \varepsilon) - f (t) <   f (2 \varepsilon), \quad 0 <   f (t) - f (t - \varepsilon) <   f (2 \varepsilon)
$$

令 $\varepsilon \downarrow 0 ;$ ，即得 f 在 t 处连续。

仍取 $u \ne v _ { \mathsf { c } }$ 。令 w 从小于 $u + v$ 的一侧趋于 $u + v$ ，并始终满足 $w > \operatorname* { m a x } \{ u , v \}$ 。此时$( u , v , w )$ 能构成三角形，故 $f ( w ) < f ( u ) + f ( v )$ 。利用连续性，得到 $f ( u + v ) \leqslant f ( u ) + f ( v )$ 结合前述反向不等式，便有 $f ( u + v ) = f ( u ) + f ( v )$ 。再令 $v  u$ ，可知此式在 $u = v$ 时也成立。正实数上的正值可加函数必为 $f ( x ) = k x$ ，其中 $k = f ( 1 ) > 0$ ；这些函数显然都满足题意。
