IMOSL 1979 Q26 

求证：以下两个定义在 R 上的泛函方程是等价的：

$$
f (x + y) = f (x) + f (y)\tag{1}
$$

$$
f (x + y + x y) = f (x) + f (y) + f (x y)\tag{2}
$$

解

先设式 (1) 成立。由可加性，对任意实数 x,y 均有

$$
f (x + y + x y) = f (x + y) + f (x y) = f (x) + f (y) + f (x y)
$$

故式 (1) 蕴含式 (2)。

反过来，设式 (2) 对任意实数 x,y 成立。取 $x = y = 0$ ，得到 $f ( 0 ) = 3 f ( 0 )$ ，故 $f ( 0 ) = 0$ o再取 $y = - 1$ ，得到

$$
f (- 1) = f (x) + f (- 1) + f (- x)
$$

从而 $f ( - x ) = - f ( x )$ ，即 f 为奇函数。

记 $c = f ( 1 )$ 。在式 (2) 中取 $y = 1$ ，得到

$$
f (2 t + 1) = 2 f (t) + c\tag{3}
$$

对任意实数 $u , v$ ，先在式 (3) 中令 $t = u + v + u v$ ，再使用式 (2)，得到

$$
\begin{array}{r l} & f \big (2 (u + v + u v) + 1 \big) = 2 f (u + v + u v) + c \\ & \qquad = 2 f (u) + 2 f (v) + 2 f (u v) + c \end{array}
$$

另一方面，在式 (2) 中取 $( x , y ) = ( u , 2 v + 1 )$ ，并使用式 (3)，得到

$$
\begin{array}{r l} f \big (2 (u + v + u v) + 1 \big) & = f (u) + f (2 v + 1) + f (2 u v + u) \\ & = f (u) + 2 f (v) + c + f (2 u v + u) \end{array}
$$

比较以上两式可得

$$
f (2 u v + u) = f (u) + 2 f (u v)\tag{4}
$$

在式 (4) 中取 $v = - 1 / 2$ ，利用 $f ( 0 ) = 0$ 及 f 的奇性，得到

$$
0 = f (u) + 2 f (- u / 2) = f (u) - 2 f (u / 2)
$$

因此对任意实数 t 均有 $f ( 2 t ) = 2 f ( t )$ 。于是式 (4) 可改写为

$$
f (2 u v + u) = f (2 u v) + f (u)\tag{5}
$$

现任取实数 $a , b _ { \circ }$ 若 $b \neq 0$ ，在式 (5) 中取 $u = b , \ v = a / ( 2 b )$ ，则 $2 u v = a$ ，故

$$
f (a + b) = f (a) + f (b)
$$

若 $b = 0$ ，该等式由 f(0) = 0 立即成立。因此式 (2) 蕴含式 (1)，两个泛函方程在 R 上等价。

求所有函数 $f : \mathbb { R } \to [ 0 , + \infty )$ ，使得对任意实数 x, y 均有

$$
f (x ^ {2} + y ^ {2}) = f (x ^ {2} - y ^ {2}) + f (2 x y)
$$

解

答案为 $f ( x ) = c x ^ { 2 }$ ，其中 c 为任意非负实数。

任取 $u , v \in \mathbb { R }$ ，记 $r = \sqrt { u ^ { 2 } + v ^ { 2 } }$ ，并令

$$
\varepsilon = \left\{ \begin{array}{l l} 1, & v \geqslant 0 \\ - 1, & v <   0 \end{array} \right. \quad x = \sqrt {\frac {r + u}{2}}, \quad y = \varepsilon \sqrt {\frac {r - u}{2}}
$$

由于 $r \geqslant | u |$ ，这里的 x,y 均为实数，而且

$$
x ^ {2} - y ^ {2} = u, \qquad 2 x y = \varepsilon \sqrt {r ^ {2} - u ^ {2}} = v, \qquad x ^ {2} + y ^ {2} = r
$$

代入题设等式可得，对任意 $u , v \in$ R 均有

$$
f \left(\sqrt {u ^ {2} + v ^ {2}}\right) = f (u) + f (v)\tag{1}
$$

在式 (1) 中取 $u \ : = \ : v \ : = \ : 0$ ，得到 $f ( 0 ) ~ = ~ 2 f ( 0 )$ ，所以 $f ( 0 ) = 0 { \mathrm { { } } }$ 。再取 $v = 0$ ，得到$f ( | u | ) = f ( u )$ ，故 f 为偶函数。

定义函数 $G : [ 0 , + \infty )  [ 0 , + \infty )$ 为 $G ( t ) = f ( { \sqrt { t } } )$ 。任取 $a , b \geqslant 0$ ，在式 (1) 中取 $u = { \sqrt { a } }$ $v = { \sqrt { b } }$ ，得到

$$
G (a + b) = G (a) + G (b)\tag{2}
$$

由于 G 非负，若 $0 \leqslant a \leqslant b$ ，则 $G ( b ) = G ( a ) + G ( b - a ) \geqslant G ( a )$ ，所以 G 在 $[ 0 , + \infty )$ 上单调不减。

令 $c = G ( 1 ) \geqslant 0$ 。由式 (2)，对任意非负整数 $m$ 和正整数 n 均有 $G ( m / n ) = c m / n$ 。任取t $\geqslant 0$ ，令 $m _ { n } = \lfloor n t \rfloor$ ，由单调性可得

c \frac {m _ {n}}{n} \leqslant G (t) \leqslant c \frac {m _ {n} + 1}{n}
$$

$$
f (x) = f (| x |) = G (x ^ {2}) = c x ^ {2}
$$

$$
f (x ^ {2} - y ^ {2}) + f (2 x y) = c (x ^ {2} - y ^ {2}) ^ {2} + c (2 x y) ^ {2} = c (x ^ {2} + y ^ {2}) ^ {2} = f (x ^ {2} + y ^ {2})
$$

所以这些函数均满足题意。

求所有的函数 $f : \mathbb { R } _ { > 0 }  \mathbb { R } _ { > 0 }$ 使得

$$
f \left(x + \frac {1}{y}\right) + f \left(y + \frac {1}{z}\right) + f \left(z + \frac {1}{x}\right) = 1
$$

对任意满足 $x y z = 1$ 的正实数 $x , y , z$ 成立。

解

答案为：存在常数 λ 满足 $- 1 / 2 \leqslant \lambda \leqslant 1$ ，使得

$$
f (t) = \frac {\lambda}{t + 1} + \frac {1 - \lambda}{3} \qquad (t > 0)
$$

任取正实数 $u , v , w$ 满足 $u + v + w = 1$ ，令 $x = u / v , \ y = v / w , \ z = w / u$ ，则 $x y z = 1$ ，且

$$
x + \frac {1}{y} = \frac {1}{v} - 1, \qquad y + \frac {1}{z} = \frac {1}{w} - 1, \qquad z + \frac {1}{x} = \frac {1}{u} - 1
$$

定义 $g : ( 0 , 1 )  ( 0 , \infty )$ 为 $g ( t ) = f ( 1 / t - 1 )$ ，由原条件可得

$$
g (u) + g (v) + g (w) = 1 \quad (u, v, w > 0, u + v + w = 1)\tag{1}
$$

对任意 $t \in ( 0 , 1 )$ ，在 (1) 中取 $u = t , \ v = w = ( 1 - t ) / 2$ ，由 $g$ 恒取正值可知 $0 < g ( t ) < 1$ 。定义 $h : ( - 1 / 3 , 2 / 3 ) \to \mathbb { R }$ 为

$$
h (t) = g \left(t + \frac {1}{3}\right) - \frac {1}{3}
$$

于是 $- 1 / 3 < h ( t ) < 2 / 3$ ，并且对定义域内任意满足 $a + b + c = 0$ 的 $a , b , c ;$ ，均有

$$
h (a) + h (b) + h (c) = 0\tag{2}
$$

在 (2) 中先后取 $( a , b , c ) = ( 0 , 0 , 0 )$ 与 $( t , - t , 0 )$ ，可得 $h ( 0 ) = 0$ ，且当 $\vert t \vert < 1 / 3$ 时有 $h ( - t ) =$ $- h ( t )$ 。若 $0 < a , b < 1 / 3$ ，则把 $( - a , - b , a + b )$ 代入 (2)，得到 $h ( a + b ) = h ( a ) + h ( b )$ 。进而，对任意正实数 a, b 满足 $a + b < 2 / 3$ ，由于 $a / 2 , b / 2 , ( a + b ) / 2$ 均小于 1/3，有

$$
h (a + b) = 2 h \left(\frac {a + b}{2}\right) = 2 h \left(\frac {a}{2}\right) + 2 h \left(\frac {b}{2}\right) = h (a) + h (b)\tag{3}
$$

下面利用h的有界性说明(3)迫使h为线性函数。任给 $\varepsilon > 0$ ，取正整数N 使 $2 / ( 3 N ) < \varepsilon$ o当 $0 < t < 2 / ( 3 N )$ 时，由 (3) 反复相加可得 $h ( N t ) = N h ( t )$ ，故

$$
| h (t) | = \frac {| h (N t) |}{N} <   \frac {2}{3 N} <   \varepsilon
$$

因此 $h ( t ) \to 0$ 当 $t \to 0 ^ { + }$ 。令 $\lambda = 3 h ( 1 / 3 )$ 。对任意正有理数 $r = p / q < 2 / 3$ ，反复应用 (3) 可得

$$
h \left(\frac {1}{3}\right) = q h \left(\frac {1}{3 q}\right), \quad h \left(\frac {p}{q}\right) = 3 p h \left(\frac {1}{3 q}\right) = \lambda \frac {p}{q}
$$

对任意 $t \in ( 0 , 2 / 3 )$ ，取一列正有理数 $r _ { n }$ t。由 (3) 和上述右连续性，

$$
h (t) - h (r _ {n}) = h (t - r _ {n}) \longrightarrow 0
$$

故 $h ( t ) = \lambda t .$ 。再由 $h ( - t ) = - h ( t )$ ，这一结论对全部 $t \in ( - 1 / 3 , 2 / 3 )$ 都成立。还原 $g$ 与 $f ,$ ，得到

$$
g (t) = \frac {1}{3} + \lambda \left(t - \frac {1}{3}\right), \quad f (t) = \frac {\lambda}{t + 1} + \frac {1 - \lambda}{3}
$$

由 $g ( t ) > 0$ 令 $t \to 0 ^ { + }$ 与 $t  1 ^ { - }$ ，分别得到 $1 - \lambda \geqslant 0$ 与 $1 + 2 \lambda \geqslant 0$ ，所以 $- 1 / 2 \leqslant \lambda \leqslant 1$ 

最后验证所得函数。对这个范围内的 λ，当 $\lambda = 1$ 与 $\lambda = - 1 / 2$ 时，函数分别为 $1 / ( t + 1 )$ 与 $t / ( 2 t + 2 )$ ，均恒取正值；关于 λ 的线性性说明区间内其余函数也恒取正值。若 $x y z = 1$ ，则

$$
\frac {1}{1 + x + 1 / y} + \frac {1}{1 + y + 1 / z} + \frac {1}{1 + z + 1 / x} = 1
$$

所以三个函数值之和为 $\lambda + 1 - \lambda = 1$ 。因此上述函数恰为全部解。

Korea Final Round 2020 P3 

求所有的函数 $f : \mathbb { Q } _ { > 0 } \to$ R 使得

$$
f (x) + f (y) + f (z) = 1
$$

对任意满足关系式 $x + y + z + 1 = 4 x y z$ 的正有理数 $x , y , z$ 成立。

解

答案为：对任意常数 $\lambda \in$ R，函数

$$
f (t) = \frac {\lambda}{1 + 2 t} + \frac {1 - \lambda}{3} \qquad (t \in \mathbb {Q} _ {> 0})
$$

先将题设中的三元约束标准化。通分可知，对正有理数 $x , y , z $ ，有

$$
x + y + z + 1 = 4 x y z \quad \Longleftrightarrow \quad \frac {1}{1 + 2 x} + \frac {1}{1 + 2 y} + \frac {1}{1 + 2 z} = 1\tag{1}
$$

映射 $x \mapsto 1 / ( 1 + 2 x )$ 是 $\mathbb { Q } _ { > 0 }$ 到 $\mathbb { Q } \cap ( 0 , 1 )$ 的双射，其逆映射为 $u \mapsto ( 1 - u ) / ( 2 u )$ 。定义$g : \mathbb { Q } \cap ( 0 , 1 ) \to$ R 为

$$
g (u) = f \left(\frac {1 - u}{2 u}\right)
$$

由 (1)，原条件等价于

$$
g (u) + g (v) + g (w) = 1\tag{2}
$$

对任意满足 $u + v + w = 1$ 的正有理数 $u , v , w$ 成立。

定义 $h : \mathbb { Q } \cap ( - 1 / 3 , 2 / 3 ) \to$ R 为

$$
h (t) = g \left(t + \frac {1}{3}\right) - \frac {1}{3}
$$

那么对定义域内任意满足 $a + b + c = 0$ 的有理数 $a , b , c ,$ 均有

$$
h (a) + h (b) + h (c) = 0\tag{3}
$$

在 (3) 中先后取 $( a , b , c ) = ( 0 , 0 , 0 )$ 与 $( t , - t , 0 )$ ，可得 $h ( 0 ) = 0$ ，且当 $\vert t \vert < 1 / 3$ 时有 $h ( - t ) =$ $- h ( t )$ 。若正有理数 $a , b$ 满足 $0 < a , b < 1 / 3$ ，则把 $( - a , - b , a + b )$ 代入 (3)，得到 $h ( a + b ) =$ $h ( a ) + h ( b )$ 。进而，对任意正有理数 $a , b$ 满足 $a + b < 2 / 3$ ，由于 $a / 2 , b / 2 , ( a + b ) / 2$ 均小于 $1 / 3$ ，有

$$
h (a + b) = 2 h \left(\frac {a + b}{2}\right) = 2 h \left(\frac {a}{2}\right) + 2 h \left(\frac {b}{2}\right) = h (a) + h (b)\tag{4}
$$

令 $\lambda = 3 h ( 1 / 3 )$ 。对任意正有理数 $r = p / q < 2 / 3$ ，反复应用 (4) 可得

$$
h \left(\frac {1}{3}\right) = q h \left(\frac {1}{3 q}\right), \quad h \left(\frac {p}{q}\right) = 3 p h \left(\frac {1}{3 q}\right) = \lambda \frac {p}{q}
$$

所以 $h ( r ) = \lambda r$ 对全部正有理数 $r < 2 / 3$ 成立；再由 $h ( - r ) = - h ( r )$ ，这一结论对整个定义域都成立。还原 $g$ 与 $f$ ，便得到

$$
g (u) = \frac {1}{3} + \lambda \left(u - \frac {1}{3}\right), \quad f (t) = \frac {\lambda}{1 + 2 t} + \frac {1 - \lambda}{3}
$$

由于 $f$ 的值域为 R，参数 λ 不受其他限制。

最后，任取 $\lambda \in$ R 并按上述公式定义 $f _ { \circ }$ 。若正有理数 $x , y , z$ 满足题设约束，则由 (1) 可得

$$
f (x) + f (y) + f (z) = \lambda \left(\frac {1}{1 + 2 x} + \frac {1}{1 + 2 y} + \frac {1}{1 + 2 z}\right) + 1 - \lambda = 1
$$

故上述函数全部满足要求，因而它们恰为所有解。
