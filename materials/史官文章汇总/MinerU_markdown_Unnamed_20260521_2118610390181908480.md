IMOSL 1997 Q22 

是否存在这样的函数对 $f , g$ : R → R，使得对一切实数 x 都有

$$
\begin{array}{r l} {f (g (x)) = x ^ {2}} & {\quad (1)} \\ {g (f (x)) = x ^ {k}} & {\quad (2)} \end{array}
$$

请分别回答：(a) 当 k = 3 时，是否存在？(b) 当 k = 4 时，是否存在？

解

答案为：(a) 不存在；(b) 存在。

(a) 设 $k = 3$ 。若 $f ( a ) = f ( b )$ ，则由式 (2) 有 $a ^ { 3 } = g ( f ( a ) ) = g ( f ( b ) ) = b ^ { 3 }$ ，从而 $a = b$ 故 f 是单射。

另一方面，对式 (2) 的两边作用 f，并在式 (1) 中以 f(x) 代替 x，得到

$$
f (x ^ {3}) = f (g (f (x))) = f (x) ^ {2}
$$

分别取 $x = - 1 , 0 , 1$ 。由于这三个数都满足 $x ^ { 3 } = x$ ，相应的三个函数值都满足 $f ( x ) = f ( x ) ^ { 2 }$ 因而

$$
f (- 1), f (0), f (1) \in \{0, 1 \}
$$

三个互异的自变量只能得到两个可能的函数值，这与 f 的单射性矛盾。因此当 k = 3 时不存在这样的函数对。

(b) 设 $k = 4$ 。定义函数 $p , q$ : R → R 为

$$
p (t) = 2 \operatorname{sgn} (t) \sqrt {| t |}, \qquad q (t) = t | t |
$$

其中 $\operatorname { s g n } ( 0 ) = 0$ 。直接计算可知，对任意实数 t 都有

$$
p (q (t)) = 2 t, \qquad q (p (t)) = 4 t
$$

令 $f ( 0 ) = g ( 0 ) = 0$ ，并对 $x \neq 0$ 定义

$$
f (x) = \exp \bigl (p (\ln | x |) \bigr), \quad g (x) = \exp \bigl (q (\ln | x |) \bigr)
$$

任取 $x \neq 0$ ，记 $t = \ln \left| x \right| .$ 。由于 $f ( x ) , g ( x ) > 0$ ，由上述两个复合关系可得

$$
f (g (x)) = \exp (p (q (t))) = \exp (2 t) = x ^ {2}
$$

以及

$$
g (f (x)) = \exp (q (p (t))) = \exp (4 t) = x ^ {4}
$$

当 $x = 0$ 时这两个等式也显然成立。因此当 k = 4 时所求函数对存在。
