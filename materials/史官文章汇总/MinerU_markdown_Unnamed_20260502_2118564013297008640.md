Saint Petersburg MO 2008 Grade 11 P4 

圆周上放着 100 个正整数，其中任何一个都不可被任何另一个整除。在每两个相邻的数之间 (同时) 写出 (按顺时针方向) 后边一个数被它们的最大公约数除的商，此后擦去原来的100 个数。此种操作相继进行若干次。试问：沿着圆周最多可能出现多少个 1？

## 解

答案为 98。

将每轮的数按顺时针编号为 $a _ { 0 } , a _ { 1 } , \cdots , a _ { 9 9 }$ ，并把旧第 i−1 位与第 i 位之间的新数记作新第 i 位，下标按模 100 计算。于是操作为 $a _ { i } ^ { \prime } = a _ { i } / \operatorname* { g c d } ( a _ { i - 1 } , a _ { i } )$ 。固定质数 $p { : }$ ，记 $e _ { i } = \nu _ { p } ( a _ { i } )$ 则相应的指数操作为

$$
e _ {i} ^ {\prime} = \max (e _ {i} - e _ {i - 1}, 0)
$$

因此，某一位置的指数一旦变为 0，以后便始终为 $0 \phantom { . 0 }$ 。此外，若一轮的指数不全相等，则沿圆周既存在严格上升的一对相邻指数，也存在严格下降的一对相邻指数，故下一轮既有正项又有零项。此时必有一个正项的前一项为 0，而这个正项以后永远不变。由此可知，初始非恒定的指数环不可能全部变为 0。

假设某时出现至少 99 个 1，选取位置 $j$ ，使其余 99 个位置均为 1。初始各数两两互不整除，特别地，初始第 $j - 1$ 个数不整除第 $j$ 个数，所以存在质数 $p _ { : }$ ，使其初始指数满足 $e _ { j } < e _ { j - 1 } { \circ { } _ { } }$ 于是第一轮后第 $j$ 位的 $p$ 指数便为 0，以后也一直为 0。但这个初始指数环非恒定，不可能全部变为 0，与该时刻其余各位均为 1 矛盾。因此最多出现 98 个 1。

最后，取初始数 $a _ { i } = 2 ^ { i } 3 ^ { 1 0 0 - i }$ ，其中 $0 \leqslant i \leqslant 9 9$ 。当 $i < j$ 时， $a _ { i }$ 的 2 指数较小而 3 指数较大，故这些数两两互不整除。第一轮得到 $3 ^ { 9 9 } , 2 , \cdots , 2$ ，第二轮得到 $3 ^ { 9 9 } , 2 , 1 , \cdots , 1$ ，其中恰有 98 个 1，所以上界可以达到。

Putnam 2008 A3 

从一个正整数数列 $a _ { 1 } , a _ { 2 } , \cdots , a _ { n }$ 开始。若存在 $j < k$ ，使 $a _ { j }$ 不整除 $a _ { k }$ ，则允许把这两项分别替换为 $\operatorname* { g c d } ( a _ { j } , a _ { k } )$ 与 $\operatorname { l c m } ( a _ { j } , a _ { k } )$ 。证明：无论每一步怎样选择，反复操作都必定终止，

并且最终数列与选择过程无关。

## 解

设 P 为初始各数中出现的质数的集合。操作不会引入新的质因数。对每个 $p \in P$ ，记当前第 i 项的指数为 $e _ { p , i } = \nu _ { p } ( a _ { i } )$ 。对位置 $j < k$ 进行一次操作，恰好把每个质数对应的两个指数变为

$$
(e _ {p, j}, e _ {p, k}) \longmapsto \left(\min (e _ {p, j}, e _ {p, k}), \max (e _ {p, j}, e _ {p, k})\right)
$$

因此，对每个质数 $p ,$ ，指数的多重集始终不变。

先证明过程必定终止。考虑非负整数

$$
\Phi = \sum_ {p \in P} \sum_ {i = 1} ^ {n} (n - i) e _ {p, i}
$$

一次操作之后， $\Phi$ 减少了

$$
(k - j) \sum_ {p \in P} \max (e _ {p, j} - e _ {p, k}, 0)
$$

由于 $a _ { j }$ 不整除 $a _ { k }$ ，至少存在一个质数 $p$ 使 $e _ { p , j } > e _ { p , k }$ ，故上述减少量为正整数。因此每次操作都使 Φ 严格减少，过程只能进行有限次。

设终态为 $b _ { 1 } , b _ { 2 } , \cdots , b _ { n }$ 。此时任意 $j < k$ 都有 $b _ { j } \ | \ b _ { k }$ ，所以对每个 $p \in P$ ，数列 $( \nu _ { p } ( b _ { i } ) ) _ { i = 1 } ^ { n }$ 单调不减。将初始的 $p$ 指数从小到大排列为 $c _ { p , 1 } , c _ { p , 2 } , \cdots , c _ { p , n }$ ，由指数多重集不变可知 $\nu _ { p } ( b _ { i } ) =$ $c _ { p , i } .$ 。因此

$$
b _ {i} = \prod_ {p \in P} p ^ {c _ {p, i}}, \quad 1 \leqslant i \leqslant n
$$

终态的每一项都由初始数列唯一确定，与操作过程无关。

## IMO 2026 P1

黑板上写有 2026 个大于 1 的整数，它们不必互不相同。每次操作从不同位置选取两个大于 1 的数 m,n，擦去它们，然后写上 $\operatorname* { g c d } ( m , n )$ 和 $\operatorname { l c m } ( m , n ) / \operatorname* { g c d } ( m , n )$ 。只要还能操作，就继续进行。

(1) 证明：无论每次如何选择，过程都在有限步后终止，并且终止时恰有一个数 $M > 1$ 。

(2) 证明：M 的值与操作过程无关。

## 解

对正整数 x，定义 $\begin{array} { r } { \Omega ( x ) = \sum _ { p } \nu _ { p } ( x ) } \end{array}$ ，其中求和遍历所有质数，特别地 $\Omega ( 1 ) = 0$ 。若当前黑板上的数为 $b _ { 1 } , b _ { 2 } , \cdots , b _ { 2 0 2 6 }$ ，考虑非负整数

$$
\Phi = \sum_ {i = 1} ^ {2 0 2 6} \Omega (b _ {i}) + \# \{i: b _ {i} > 1 \}
$$

一次操作选取 $m , n > 1$ ，记 $d = \operatorname* { g c d } ( m , n )$ 。新写入两数的乘积为 $m n / d _ { i }$ ，所以各数的 Ω 之和减少 $\Omega ( d )$ ，而大于 1 的数的个数不会增加。若 $d > 1$ ，则 $\Omega ( d ) \geqslant 1$ ；若 $d = 1$ ，则新写入的两数为 1,mn，大于 1 的数的个数恰好减少 1。因此每次操作都使 $\Phi \bar { p } ^ { \mathrm { u } \bar { \mathrm { \varepsilon } } }$ 格减少，过程必在有限步后终止。

终止时至多有一个数大于 1。每次操作所得的两个数不可能同时等于 1：若 $d > 1$ ，第一个数便大于 1；若 $d = 1$ ，第二个数为 $m n > 1 { \mathrm { . } }$ 。故黑板上始终至少有一个数大于 1，从而终止时恰有一个数 $M > 1$ ，第一问得证。

下面证明第二问。记初始各数为 $a _ { 1 } , a _ { 2 } , \cdots , a _ { 2 0 2 6 }$ 。固定质数 $p ,$ ，若被操作两数的 $p$ 指数分别为 $u , v ,$ ，则操作后两指数变为 $\operatorname* { m i n } ( u , v )$ 和 $\lvert u - v \rvert$ 。由于

$$
\operatorname * {g c d} \bigl (\min (u, v), | u - v | \bigr) = \operatorname * {g c d} (u, v)
$$

黑板上所有数的 $p$ 指数的最大公因数始终不变。终止时除 M 外的各数均为 1，所以

$$
\nu_ {p} (M) = \operatorname * {g c d} \bigl (\nu_ {p} (a _ {1}), \nu_ {p} (a _ {2}), \dots , \nu_ {p} (a _ {2 0 2 6}) \bigr)
$$

设 $P$ 为初始各数中出现的质数的集合，操作不会引入新的质因数，因此

$$
M = \prod_ {p \in P} p ^ {\operatorname * {g c d} (\nu_ {p} (a _ {1}), \nu_ {p} (a _ {2}), \dots , \nu_ {p} (a _ {2 0 2 6}))}
$$

右端完全由初始状态确定，与操作过程无关。

Korea National 2024 P8 

黑板上写着 $1 , 2 , \cdots , 1 0 .$ 。每次操作选取两个互不整除的数，擦去它们，然后写上它们的最大公因数和最小公倍数。当黑板上任意两个数都有一个整除另一个时，操作停止。求操作次数的最大可能值。

## 解

答案为 18。

操作不会引入新的质因数，故所有出现的质数均属于 $P = \{ 2 , 3 , 5 , 7 \}$ 。对每个 $p \in P$ ，操作把两个指数 $u , v$ 换成 $\operatorname* { m i n } ( u , v ) , \operatorname* { m a x } ( u , v )$ ，因此全部数的 p 指数的多重集不变。

定义 $\begin{array} { r } { \Omega ( a ) = \sum _ { p \in P } \nu _ { p } ( a ) } \end{array}$ ，并考虑势函数 $\begin{array} { r } { \Phi = \sum _ { a } { \binom { \Omega ( a ) } { 2 } } } \end{array}$ ，其中对黑板上的十个数按重数求和。一次操作选取 $a , b ,$ ，记 $d = \operatorname* { g c d } ( a , b )$ ，并令 $x = \Omega ( d ) , \ r = \Omega ( a / d ) , \ s = \Omega ( b / d )$ 。由于$a , b$ 互不整除， $r , s \geqslant 1$ 。这次操作使两个 Ω 值由 $x + r , x + s$ 变成 $x , x + r + s$ ，故

$$
\Delta \Phi = \binom{x}{2} + \binom{x + r + s}{2} - \binom{x + r}{2} - \binom{x + s}{2} = r s \geqslant 1
$$

所有数的 Ω 之和始终为 15，所以 $\Phi \leqslant { \binom { 1 5 } { 2 } }$ 。因此操作必在有限步后终止。

终态的十个数可以按整除关系排成一条链，所以对每个质数，其指数都已从小到大排列。由指数多重集不变，分别将初始的 2,3,5,7 指数排序，便得到唯一的终态

$$
1, 1, 1, 1, 1, 2, 2, 6, 6 0, 2 5 2 0
$$

初态与终态的 Ω 值从小到大排列后分别为

相应的 Φ 分别为 7、28。将一步中的 $r s - 1$ 称为该步的额外增量。若操作次数为 N，则

$$
2 1 = N + \sum_ {\text {各步}} (r s - 1)
$$

下面证明额外增量总和至少为 3，从而得到 $N \leqslant 1 8 .$ 

反设额外增量总和不超过 2。从终态逆向考察 Ω 值，每步将 $x , x + r + s$ 变成 $x + r , x + s$ 新数均介于原来两个数之间。其中 $r s = 1$ 的步骤只能是 $( k - 1 , k + 1 ) \mapsto ( k , k )$ ，称为单位步。其余步骤的额外增量为正，所以最多只能有两个 $r s = 2$ 的步骤，或者一个 $r s = 3$ 的步骤。

先观察两种不能仅靠单位步使所有数都变成不超过 3 的状态：

(i) 有 6,4，其余数均不超过 2。要改变 6，必须先保留唯一的 4，然后作 $( 4 , 6 ) \mapsto ( 5 , 5 )$ ，此后其余数均不超过 2，两个 5 都无法再改变。若在改变 6 之前先用掉 4，只能作 $( 2 , 4 ) \mapsto ( 3 , 3 )$ 此后其余数均不超过 3，也不可能再通过单位步改变 6。

(ii) 有 6,4,3，其余数均不超过 1。首个单位步或者是 $( 1 , 3 ) \mapsto ( 2 , 2 )$ ，归入情形 (i)；或者是$( 4 , 6 ) \mapsto ( 5 , 5 )$ 。后一情况下，若再作 $( 1 , 3 ) \mapsto ( 2 , 2 )$ ，两个 5 便无法改变；若作 $( 3 , 5 ) \mapsto ( 4 , 4 )$ 则留下 5,4,4 和若干不超过 1 的数，已经没有单位步可做。因此这种状态也不可能达到要求。

现在从 7,4,2,1,1,0,0,0,0,0 出发逆向操作。必须在某一步首次改变 7；在此之前，其余数均不超过 4，因为每个逆向步骤都不会增加所选两数的最大值。在额外增量总和至多为 2 的限制下，首次改变 7 只有以下两种可能。

第一种是 $( 4 , 7 ) \mapsto ( 5 , 6 )$ ，其额外增量为 1。此前唯一的 4 必须一直保留，因而其余数始终不超过 2，且至多有一个 2；此前所作的步骤只能是单位步。此时单位步无法改变 5,6，所以必须再使用一个非单位步。在剩余额外增量至多为 1 的限制下，这一步只能是 $( 2 , 5 ) \mapsto ( 3 , 4 )$ 得到的状态含有 6,4,3，其余数均不超过 1；之后只允许单位步，与情形 (ii) 矛盾。

第二种是 $( 3 , 7 ) \mapsto ( 4 , 6 )$ ，其额外增量为 2，所以其他步骤全部是单位步。此前的 3 必须由唯一的 2,4 经单位步变成 3,3 而产生。另一个 3 若仍然保留，首次改变 7 后便得到情形(ii)；若它已经通过 $( 1 , 3 ) \mapsto ( 2 , 2 )$ 消失，则其余数均不超过 2，得到情形 (i)。两种情况下都不可能仅靠单位步回到初态。

矛盾说明额外增量总和至少为 3，所以操作次数至多为 $2 1 - 3 = 1 8 .$ 

最后给出达到 18 次的操作。依次选择下列数对，每次将所选两数替换为它们的最大公因数和最小公倍数：

$$
(2, 3), (4, 6), (2, 5), (6, 9), (8, 1 2), (4, 1 0),
$$

$$
(2, 3), (6, 1 0), (2, 7), (2 0, 3 0), (2 4, 6 0), (1 2, 1 8),
$$

$$
(6, 1 0), (3 0, 3 6), (6, 1 4), (1 2 0, 1 8 0), (4 2, 6 0), (3 6 0, 4 2 0)
$$

逐步检查可知，每一步所需的两个数都在黑板上且互不整除，最后所有数两两有整除关系。因此操作次数的最大可能值为 18。
