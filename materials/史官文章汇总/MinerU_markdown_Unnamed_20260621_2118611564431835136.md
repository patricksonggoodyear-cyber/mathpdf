设 $n \geqslant 2$ 为整数。已知对所有满足 $0 \leqslant k \leqslant \sqrt { n / 3 }$ 的整数 k， $k ^ { 2 } + k + n$ 都是质数。证明：对所有满足 $0 \leqslant k \leqslant n - 2$ 的整数 k， $k ^ { 2 } + k + n$ 也都是质数。

## 解

记 $F ( t ) = t ^ { 2 } + t + n _ { \circ }$ 反设结论不成立，令 k 为 $0 \leqslant k \leqslant n - 2$ 中使 $F ( k )$ 为合数的最小整数。由于题设保证 $F ( 0 ) = n$ 为质数，所以 $k \geqslant 1$ ，且所有 $0 \leqslant t < k$ 的 $F ( t )$ 都是质数。设$q$ 为 $F ( k )$ 的最小质因数。因 F(k) 为合数，故 $q ^ { 2 } \leqslant F ( k )$ 。

首先证明 $q > k .$ 。若 $q \leqslant k ,$ ，令 s 为 k 除以 q 的最小非负余数，则 $0 \leqslant s < q \leqslant k$ ，且$F ( s ) \equiv F ( k ) \equiv 0 { \pmod { q } }$ 。然而 $F ( s )$ 是质数，且 $F ( s ) \geqslant n \geqslant k + 2 > q$ ，不可能被 $q$ 整除。

再证明 $q > 2 k$ 。若 $k < q \leqslant 2 k$ ，令 $t = q - 1 - k$ ，则 $0 \leqslant t < k$ 。这是 k 作为二次同余$F ( x ) \equiv 0 { \pmod { q } }$ 的根关于对称轴反射得到的另一个根，因为

$$
F (t) - F (k) = (t - k) (t + k + 1) = (t - k) q
$$

于是 $q \mid F ( t )$ 。由 $t < k$ 知 F(t) 是质数，只能有 $F ( t ) = q = t + k + 1$ ；但 $k \leqslant n - 2$ 给出

$$
F (t) - q = t ^ {2} + n - k - 1 \geqslant t ^ {2} + 1 > 0
$$

矛盾。

因此 $q \geqslant 2 k + 1$ ，从而

$$
k ^ {2} + k + n = F (k) \geqslant q ^ {2} \geqslant (2 k + 1) ^ {2}
$$

这意味着 $n \geqslant 3 k ^ { 2 } + 3 k + 1 > 3 k ^ { 2 }$ ，即 $k < \sqrt { n / 3 }$ 。按照题设，F(k) 应为质数，再次矛盾，命题得证。

证明：存在无穷多个正整数 n，使得 $n ^ { 2 } + 1$ 有一个大于 $2 n + { \sqrt { 2 n } }$ 的质因数。解

先构造无穷多个满足 $p \equiv 1 { \pmod { 8 } }$ 且 $x ^ { 2 } \equiv - 1 { \pmod { p } }$ 有解的质数 $p _ { \mathfrak { c } }$ 。质数 $1 7$ 满足这些条件。若已找到互异的 $p _ { 1 } , \cdots , p _ { s }$ ，令 $A = 2 p _ { 1 } \cdots p _ { s }$ ，取 $A ^ { 4 } + 1$ 的任一质因数 $p _ { \circ }$ 。由于$A ^ { 4 } + 1 \equiv 1 { \pmod { p _ { i } } }$ ， $p$ 与各 $p _ { i }$ 不同。又因 $A ^ { 4 } \equiv - 1 { \pmod { p } }$ ，A 模 $p$ 的乘法阶恰为 8，从而 $8 \mid p - 1$ ；同时 $A ^ { 2 }$ 是同余 $x ^ { 2 } \equiv - 1 { \pmod { p } }$ 的一个根。如此便可不断得到新的质数 $p _ { \circ }$

从而 $p = 2 n + d > 2 n + \sqrt { 1 0 n } > 2 n + \sqrt { 2 n }$ ，甚至得到比题目要求更强的界。

设 k 为正整数，S 是由奇质数组成的有限集合。证明：至多有一种方法 (不计旋转和翻转) 把 S 中的质数排在圆周上，使任意两个相邻质数之积都可写成 $x ^ { 2 } + x + k$ ，其中 x 为正整数。

解

允许 $x = 0$ ，证明更强的结论。称一对不同的奇质数 $\{ p , q \}$ 为特殊对，如果存在非负整数x 使得 $p q = x ^ { 2 } + x + k$ C

引理：对任意奇质数 r，至多有两个小于 r 的质数能与 r 组成特殊对；如果恰有两个这样的质数 $p , q$ ，那么 $\{ p , q \}$ 也是特殊对。

引理证明：若质数 $p < r$ 与 r 组成特殊对，则存在非负整数 x 使得 $p r = x ^ { 2 } + x + k < r ^ { 2 }$ 从而 $0 \leqslant x \leqslant r - 1$ ，并且

$$
x ^ {2} + x + k \equiv 0 \pmod {r}
$$

由于二次同余模质数至多有两个根，而 $x ^ { 2 } + x + k$ 在非负整数上严格递增，故这样的质数 $p$ 至多有两个。

设 $p < q < r$ 都与 r 组成特殊对，即

$$
x ^ {2} + x + k = p r, \qquad y ^ {2} + y + k = q r
$$

其中 $x , y$ 为非负整数。由上面的大小估计和单调性， $\begin{array} { r } { 0 \leqslant x < y \leqslant r - 1 } \end{array}$ 。两数是同余 $t ^ { 2 } + t + k \equiv 0$ (mod r) 的两个不同根，因此由根与系数的关系， $x + y \equiv - 1 { \pmod { r } }$ 。结合 $1 \leqslant x + y \leqslant 2 r - 3$ 得到

$$
x + y = r - 1
$$

令 $K = 4 k - 1 , \ X = 2 x + 1 , \ Y = 2 y + 1$ ，则

$$
4 p r = X ^ {2} + K, \qquad 4 q r = Y ^ {2} + K, \qquad X + Y = 2 r
$$

利用恒等式

$$
(X ^ {2} + K) (Y ^ {2} + K) = (X Y - K) ^ {2} + K (X + Y) ^ {2}
$$

可得

$$
1 6 p q r ^ {2} = (X Y - K) ^ {2} + 4 K r ^ {2}
$$

又因为 $Y \equiv - X { \pmod { r } }$ 且 $r \ | \ X ^ { 2 } + K$ ，所以 $r \ | \ X Y \ - \ K$ ；而 $X , Y , K$ 都是奇数，故$2 r \mid X Y - K$ 。于是

$$
Z = \frac {X Y - K}{2 r}
$$

为整数，并且

$$
4 p q = Z ^ {2} + K
$$

由于 $K \equiv 3 { \pmod { 4 } }$ ，由 $4 p q = Z ^ { 2 } + K$ 可知 $Z ^ { 2 } \equiv 1 { \pmod { 4 } }$ ，所以Z 为奇数。令 $z = ( | Z | { - } 1 ) / 2$ 则 z 为非负整数，且

$$
p q = z ^ {2} + z + k
$$

所以 $\{ p , q \}$ 也是特殊对，引理得证。

现在对 |S| 归纳。当 $| S | \leqslant 3$ 时结论显然。设 $| S | \geqslant 4$ ，并令 r 为 S 中的最大质数。在任意可行圆排列中，r 的两个邻点都是小于 r 且与 r 组成特殊对的质数；由引理，它们由集合S 唯一确定。再由引理的第二部分，这两个邻点本身也是特殊对，所以删去 r 并将它们直接相连后，得到 $S \setminus \{ r \}$ 的可行圆排列。这正是二次同余的根反射在本题中的作用：它把两条经过最大质数 r 的特殊边转化为一条绕过 r 的特殊边。

由归纳假设，删去 r 后的圆排列至多有一种；而 r 只能重新插在上述两个邻点之间，故原圆排列也至多有一种。
