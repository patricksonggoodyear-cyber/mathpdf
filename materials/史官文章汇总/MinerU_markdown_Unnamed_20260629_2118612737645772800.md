把每个面当前占据或指向的棱编码为球面对偶图中的动态出边，再利用相邻面方向相反、球面平面性及出边按循环次序变化形成的有限状态约束，迫使公共棱相遇、顶点完全相遇或某根指针最终停止。

原始论文：这一方法的高等原型是 Klyachko 的球面车流完全碰撞引理，最初发表于 A.A. Klyachko, A Funny Property of Sphere and Equations over Groups, Communications inAlgebra 21(7) (1993), 2555–2575。Roger Fenn 与 Colin Rourke 后在 Klyachko’s Methods andthe Solution of Equations over Torsion-Free Groups, L’Enseignement Mathématique 42(1–2)(1996), 49–74 中对这一方法作了系统整理与推广。

高等背景：在组合群论中，群上方程或相对群表示可以编码为球面上的 van Kampen 图及其对偶图示，关系式中变量的循环出现则可转化为各面边界上的车流；完全碰撞会迫使图示中出现具有特殊标号的顶点，从而排除假想反例。这一思想被用于证明无挠群上指数和为± 的幺模方程可在某个扩群中求解，并推出无挠群情形的 Kervaire 猜想；本词条中的动态出边、有向圈收缩与有限状态分类，可以看作这一球面图方法的初等离散版本。

## Moscow MO 2011 Grade 11 P11

一个三棱锥的每个面上各有一只甲虫。每只甲虫始终沿所属面的边界按固定方向循环爬行，并且相邻两面上的甲虫沿公共棱爬行时方向相反。证明：如果每只甲虫的速度 (可以变化)始终大于 1cm/s，那么无论三棱锥的形状、甲虫的初始位置及速度如何，终有两只甲虫相遇。

## 解

记三棱锥为 ABCD。由公共棱上的方向相反这一条件，适当选取字母次序后，四个面上的爬行方向可以同时写成

$$
A B C: A \to B \to C \to A \qquad A C D: A \to C \to D \to A
$$

$$
A D B: A \to D \to B \to A \qquad B D C: B \to D \to C \to B
$$

事实上，先规定 ABC 上的方向，邻面在公共棱上的方向便被唯一确定；依次确定其余三面后，所得方向正如上式，而且在最后一条公共棱上仍相反。

反设四只甲虫永不相遇。先说明一个以后反复使用的事实：在足够晚的任一非顶点时刻，两只甲虫不可能位于同一条棱。设一条棱长为 l，取坐标 $x \in [ 0 , l ]$ ，使第一只甲虫沿 x 增大的方向爬行。若两只甲虫同时在这条棱上，则第二只沿 x 减小的方向爬行。记它们的位置为$x _ { 1 } , x _ { 2 }$ 。若某时刻 $x _ { 1 } \leqslant x _ { 2 }$ ，则到其中一只首次离开该棱时已有 $x _ { 1 } \geqslant x _ { 2 }$ ，由位置的连续性，中间必有 $x _ { 1 } = x _ { 2 }$ 。若某时刻 $x _ { 1 } > x _ { 2 }$ ，考察两只甲虫本次进入该棱的时刻中较晚的一个；在那个时刻必有 $x _ { 1 } \leqslant x _ { 2 }$ ，故在此后到当前时刻之间也必有 $x _ { 1 } = x _ { 2 }$ 。每只甲虫的速度大于 $\mathrm { 1 ~ c m / s }$ 所以它在有限时间内必到达当前棱的下一顶点。因而可先等到四只甲虫都至少经过一次顶点，再选取一个没有甲虫位于顶点的时刻；这样的时刻必然存在，因为每只甲虫始终向前运动，每个指定顶点在每一圈中至多经过一次，四只甲虫经过顶点的时刻至多可数。从所选时刻起，上述两次进入该棱的时刻都确实存在。于是，只要以后出现两只甲虫同在一条棱上的情形，便已经得到矛盾。下文称此为同棱矛盾。

在所选时刻，四只甲虫占据四条互异的棱。把这四条棱看成顶点集为 {A,B,C,D} 的图。若某顶点的度数为 3，这四条棱由该顶点发出的三条棱及其对面三角形的一条棱组成，称为星形。若没有顶点的度数为 3，则各顶点度数至多为 2；度数和等于 8，所以四个顶点的度数都等于 2，这四条棱组成一个四边形。故除此两类外没有别的构型。

先考察以 A 为中心的星形。不妨第四条棱为 BC。面 BDC 上的甲虫只能位于 BC；其余三面与 AB,AC,AD 的匹配只有以下两种：

$$
(A B C, A C D, A D B) \longleftrightarrow (A B, A C, A D)
$$

或

$$
(A B C, A C D, A D B) \longleftrightarrow (A C, A D, A B)
$$

由四个面的方向可见，第一种匹配中三只甲虫都离开 A，第二种匹配中三只甲虫都趋向 A。因此星形必为离心星或向心星，不存在混合方向。

若出现向心星，考察三只趋向中心的甲虫到达中心的最早时刻；该时刻有限。若至少两只同时到达，它们就在中心相遇。否则，唯一最先到达的甲虫转入另一条以中心为端点的棱，而那条棱上仍有一只甲虫正向中心爬行，于是产生同棱矛盾。因此向心星不可能出现。

再考察四边形。重新命名顶点后，其四条棱可写成 AB,AC,DB,DC。由各面所含的棱可知，四个面与这四条棱的匹配恰有以下两种：

$$
(A B C, A C D, A D B, B D C) \longleftrightarrow (A B, A C, D B, D C)
$$

或

$$
(A B C, A C D, A D B, B D C) \longleftrightarrow (A C, D C, A B, D B)
$$

在第二种匹配中同时交换 A,B 以及 C,D，就得到第一种匹配及其全部爬行方向。因此不妨设四只甲虫分别为

$$
\begin{array}{l l} A B C: A B (A \to B) & A C D: A C (A \to C) \\ A D B: D B (D \to B) & B D C: D C (D \to C) \end{array}
$$

考察这四只甲虫首次到达各自当前棱终点的时刻，所有这些时刻都有限。若最早到达者唯一，则位于 AC 或 DB 上的甲虫会分别转入仍被占据的 CD 或 BA，产生同棱矛盾；位于 AB 上的甲虫到达 B 后转入 BC，此时 $A C , B C , D C$ 上的三只甲虫都趋向 C，形成向心星；位于 DC上的甲虫到达 C 后转入 CB，此时 AB,DB,CB 上的三只甲虫都趋向 B，也形成向心星。

还须处理并列最早到达。若 AB,DB 上的两只甲虫同时到达 B，或 $A C , D C$ 上的两只甲虫同时到达 C，它们已经相遇。否则，并列者中有一只到达 B，另一只到达 C。若恰有两只并列，四种可能的棱对依次为 (AB,AC),(AB,DC),(DB,AC),(DB,DC)：第一种中 AC 上的甲虫转入仍被占据的 CD；第二种中两只甲虫从两端同时转入 BC；第三种中两只甲虫分别转入仍被占据的 AB,CD；第四种中 DB 上的甲虫转入仍被占据的 AB。每一种都产生同棱矛盾。若有至少三只并列，则它们只可能到达 $B , C$ 两点，其中至少两只到达同一点并在那里相遇。因此四边形也不可能出现。

最后考察离心星。设中心为 A，于是三只甲虫分别沿 AB,AC,AD 离开 A，第四只甲虫在对面三角形 BCD 的边界上按 $B  D  C  B$ 的方向爬行。等到前三只中最早的一只到达对面顶点；在此之前，第四只甲虫无论经过多少个顶点，构型仍是离心星。先设唯一最早的是 AB 上的甲虫，它到达 B 后转入 BC。若此刻第四只甲虫在 BC 内，则产生同棱矛盾；若它在 CD 内，则 $A C , B C , D C$ 上的三只甲虫都趋向 C，形成向心星；若它在 BD 内，则 $A C , A D , B C , B D$ 组成四边形。若第四只甲虫恰在顶点，则它在 B 时已经与第一只甲虫相遇，在 C 时转入 CB 而产生同棱矛盾，在 D 时转入 DC 而形成以 C 为中心的向心星。因此唯一最早到达的其余两种情形完全相同。

若离心星中恰有两只甲虫同时最早到达，不妨设这两只分别位于 AB 和 AC 上。它们分别转入 $B C , C D$ 。第四只甲虫若在这两条棱之一，便产生同棱矛盾；若在第三条外棱 BD，则它与仍在 AD 上的甲虫以及刚转入 CD 的甲虫都趋向 D，形成向心星。第四只甲虫若恰在 B或 C，已发生相遇；若恰在 D，则它转入 DC，与刚转入 CD 的甲虫产生同棱矛盾。若三只离心星甲虫同时到达 B,C,D，它们分别转入 $B C , C D , D B$ ，而第四只甲虫此时若在某条外棱内便与其中一只同棱，若在某个顶点便与刚到达该顶点的甲虫相遇。因此离心星也必立即导致相遇、同棱矛盾、向心星或四边形。

最初的构型必为星形或四边形；向心星和四边形均直接导致矛盾，离心星又必在有限时间内转化为这两类构型或直接导致矛盾。故四只甲虫永不相遇的假设不成立，终有两只甲虫相遇。

## Korea Final Round 2018 P6

边长为 的正二十面体的每个面上各有一只蚂蚁。每只蚂蚁沿自己所在面的边界按逆时针方向不断爬行，并且任一时刻的速度至少为 。禁止两只蚂蚁在非顶点处相遇。称五只蚂蚁同时在同一顶点相遇为一次碰撞。是否存在一种使蚂蚁永远运动而不发生碰撞的策略？

## 解

答案是否定的。反设存在一种满足题意的无限运动。

先注意，同一条棱的内部不可能同时有两只蚂蚁。事实上，相邻两面上的蚂蚁沿公共棱爬行时方向相反。若它们同时在棱内停留了一段非空时间，就沿其中一只蚂蚁的前进方向给这条棱取坐标，并把两只蚂蚁的坐标分别记为 $x _ { 1 } , x _ { 2 }$ 。在两个停留时间区间的交集起点有 $x _ { 1 } < x _ { 2 }$ 在交集终点有 $x _ { 1 } > x _ { 2 } ;$ ；又因为 $x _ { 1 } \ \overrightharpoon { j ^ { \mathrm { L } } }$ 格增大而 $x _ { 2 }$ 严格减小，由连续性可知中间必有 $x _ { 1 } = x _ { 2 } { \mathrm { . } }$ 这个相遇点在棱的内部，与题设矛盾。

只考察没有蚂蚁位于顶点的普通时刻。由于蚂蚁速度恒为正，每只蚂蚁通过一个顶点只占一个瞬间，故普通时刻可以取得任意靠后。对正二十面体作球面上的对偶图：在每个面 F内取面心 $O _ { F }$ ，相邻两面的面心用一条横穿其公共棱的对偶边连接。若面 F 上的蚂蚁位于 F与 $F ^ { \prime }$ 的公共棱，就把相应对偶边定向为 $O _ { F } \longrightarrow O _ { F ^ { \prime } }$ 。由上一段，同一条对偶边不会同时取得两个相反方向。每个面心恰有一条出边，所以从任意面心沿出边不断前进，有限步后必然

得到一个有向简单闭路。

这个对偶图是正十二面体图，它的每个面恰对应正二十面体的一个顶点。任一对偶简单闭路把球面分成两个闭圆盘：删去闭路的一条边后，余下的简单折线弧可加厚成一个闭圆盘，其补集也是闭圆盘；删去的那条边在补集圆盘内连接两个边界点，因而把它切成两个闭圆盘。由于闭路沿对偶图的边行走，每个圆盘都是若干个对偶面的并。任取一个有向闭路时，它未必就是一个对偶面的边界，所以不能直接断言闭路上的各面共有一个顶点；下面用极小性补上这一点。

对任意 T，在所有普通时刻 $t \geqslant T .$ 、所有有向简单闭路及其两侧圆盘中，记圆盘所含对偶面数的最小值为 $m ( T )$ 。每个普通时刻都有有向闭路，而闭路两侧各至少含一个、至多含十一个对偶面，故 $m ( T ) \in \{ 1 , 2 , \cdot \cdot \cdot , 1 1 \}$ 。函数 m(T) 随 T 增大而不减，所以存在 $T _ { 0 }$ 与整数 $m$ ，使得 $T \geqslant T _ { 0 }$ 时恒有 $m ( T ) = m$ 。由 $m ( T _ { 0 } + 2 ) = m$ ，可取普通时刻 $t _ { 0 } \geqslant T _ { 0 } + 2$ ，并在该时刻取有向简单闭路 C 及其一侧圆盘 D，使 D 恰含 m 个对偶面。

把 C 上的面心依次记为 $O _ { F _ { 1 } } , O _ { F _ { 2 } } , \cdot \cdot \cdot , O _ { F _ { n } }$ ，使其有向边为 $O _ { F _ { i } } \longrightarrow O _ { F _ { i + 1 } }$ ，下标按模 n 计算，并记 $e _ { i } = F _ { i } \cap F _ { i + 1 }$ 。此时面 $F _ { i }$ 上的蚂蚁正在 $e _ { i }$ 上。沿 $e _ { i }$ 的前进方向看，面 $F _ { i }$ 位于左侧；在 $e _ { i }$ 与其对偶边交叉处作一个小平面图便可看出，蚂蚁前进方向所指的端点，正是有向对偶边 $O _ { F _ { i } } O _ { F _ { i + 1 } }$ 左侧的端点。因此，若 D 位于有向圈 C 的左侧，就向前推进时间；若 D 位于右侧，就向后倒推时间。这样，面 $F _ { i }$ 上的蚂蚁都朝 $e _ { i }$ 位于 D 一侧的端点 $V _ { i }$ 运动。棱长为1 且速度不小于 1，所以在所选时间方向上不超过 1 秒便有闭路上的蚂蚁到达相应的 $V _ { i }$ ；又因 $t _ { 0 } \geqslant T _ { 0 } + 2$ ，即使倒推，所考察的时刻仍大于 $T _ { 0 }$ 

设第一次到达发生在时刻 τ，并令 S 为此时到达相应 $V _ { i }$ 的下标集合，则 S 非空。若此时已经发生碰撞，结论成立；以下设没有碰撞，并取在所选时间方向上刚越过 $\tau$ 的一个普通时刻 $t _ { 1 }$ 。对于 $i \in S$ ，蚂蚁越过 $V _ { i }$ 后所进入的是三角形 $F _ { i }$ 在 $V _ { i }$ 处的另一条棱。观察面心 $O _ { F _ { i } }$ 周围的三条对偶边，这条新棱所对应的出边只有两种可能：其一是 C 的前一条边，但方向变为 $O _ { F _ { i } } \longrightarrow O _ { F _ { i - 1 } }$ ；其二是 $O _ { F _ { i } }$ 的第三条对偶边，而且这条边伸入 $D _ { \mathfrak { c } }$ 。这是因为新棱与 $e _ { i }$ 围成的角恰对应 $V _ { i }$ ，而 $V _ { i }$ 所对应的对偶面扇区就在 C 的 D 侧，所以新对偶边不可能伸向 D 外。

同时有多只蚂蚁过顶点也不会造成隐藏问题。若把同一时刻的转向暂时逐个记入有向图，某次转向与尚未记入的相邻面形成一对相反箭头，只可能是前者的新棱恰为后者的旧棱；两只蚂蚁在时刻 $\tau$ 必位于这条公共棱的同一端点。因此，这种先后依赖只会沿同一个正二十面体顶点周围的五个面传递；依赖形成闭环，当且仅当五个面上的蚂蚁同时到达该顶点，此时已经发生碰撞。无碰撞时依赖没有闭环，可以按依赖的拓扑顺序逐个记入。下面也可以等价地直接考察时刻 $t _ { 1 }$ 的最终有向图。

假设某个 $i \in S$ 的新出边属于第二种，即严格伸入 $D _ { \circ }$ 。在时刻 $t _ { 1 }$ ，C 上未转向的面心仍沿 C 指向下一面心，已经转向的面心则沿 C 反向指向前一面心或指向 D 内部。因此，C 上没有出边伸到 D 外；从上述伸入 D 的出边开始不断沿出边走，路径始终留在 D 中，并最终进入一个有向简单闭路 $C ^ { \prime }$ 。这个闭路必使用不属于 C 的边：否则它是无向圈 C 的一个子圈，只能等于整个 C 或是一条边上的二元闭路；前者不可能，因为 $O _ { F _ { i } }$ 的出边已伸入 D，后者又会表示同一条原棱内同时有两只蚂蚁。于是 $C ^ { \prime }$ 有一侧圆盘 $D ^ { \prime }$ 严格包含于 $D _ { \circ }$ 。两个圆盘均由对偶面组成，故 $D ^ { \prime }$ 至少含一个而至多含 $m - 1$ 个对偶面。这与 $t _ { 1 } \geqslant T _ { 0 }$ 时 $m ( T _ { 0 } ) = m$ 的极小性矛盾。所以每个 i ∈ S 都只能属于第一种，即转向后有 $O _ { F _ { i } } \longrightarrow O _ { F _ { i - 1 } }$ 0

若 $i \in S$ 而 i − 1 /∈ $S$ ，则在时刻 $t _ { 1 }$ 仍有 $O _ { F _ { i - 1 } } \longrightarrow O _ { F _ { i } }$ ，与刚得到的反向箭头组成二元闭路；这意味着面 $F _ { i - 1 }$ 与 $F _ { i }$ 上的两只蚂蚁同时位于公共棱的内部，矛盾。因此 $i \in S$ 必推出 $i - 1 \in S$ 。由于 S 非空，沿闭路循环应用可知 S 包含全部下标。

最后，对每个 i，第一种转向说明 $e _ { i - 1 }$ 与 $e _ { i }$ 在 D 一侧的端点相同，即 $V _ { i - 1 } = V _ { i }$ 。所以所有 $V _ { i }$ 都是同一个正二十面体顶点 V，所有面 $F _ { i }$ 都经过 V。经过 V 的五个面在对偶图中依次构成一个五边形，且其中没有其他相邻关系；既然 C 是简单闭路，它只能是这个五边形的整个边界，故 $n = 5$ 。而 S 包含全部下标，说明这五个面上的五只蚂蚁在时刻 τ 同时到达 V，恰好发生题目所说的碰撞。

这与反设矛盾，因此不存在满足题意的无限运动策略。

## KoMal A745

在一个凸多面体的每个面上都安装了一根指针。每根指针始终指向与该面有公共棱的某个相邻面。每一分钟结束时，恰有一根指针沿顺时针方向转向下一个相邻面。已知任意两个相邻面上的指针始终不会相互指向。证明：至少有一根指针只转动有限次。

## 解

反设每根指针都转动无限多次。在多面体的每个面内取一个点，并把相邻两面内的点用一条穿过其公共棱的弧连接，使这些弧除端点外互不相交。这样在多面体表面得到一个球面图，称为原多面体的对偶图。它的顶点对应多面体的面，边对应公共棱，顶点周围各边的顺时针次序也正是相邻面的顺时针次序。

在任意时刻，若面 A 上的指针指向相邻面 B，就在对偶图中画有向边 $A  B _ { \circ }$ 每个顶点恰有一条出边，所以从任一顶点不断沿出边前进，经过有限步后必有顶点重复；从第一次重复处起便得到一个有向圈。题设排除了两个相邻面相互指向，故有向圈的长度至少为 3。同一状态下两个不同的有向圈也不可能共享顶点，因为从一个公共顶点起沿唯一的出边前进，它们便必定重合。

先说明有向圈在球面上的分离方式。对偶图中的简单圈是一条无自交闭折线。取出它的一条边后，余下部分是一条无自交折线弧；给这条弧加上一个充分窄的带状邻域，所得区域是一个闭圆盘，其在球面上的补集也是一个闭圆盘。取出的那条边在后一个圆盘内连接边界上的两个点，沿它剪开便把这个圆盘分成两个闭圆盘。缩去带状邻域后可知，原来的简单圈恰把球面分成两个闭圆盘。沿有向圈行进时，把右手边的闭圆盘记为 R(C)，左手边的闭圆盘记为 L(C)。

在对偶图每个面内任意添加互不相交的边，把它剖分成有限个小三角形。定义有向圈 C的大小 $s ( C )$ 为 $R ( C )$ 中小三角形的个数。以后只比较以对偶图的圈为边界的圆盘，因此若$R ( C ^ { \prime } )$ 是 R(C) 的真子集，两者之间至少有一个小三角形，从而 $s ( C ^ { \prime } ) < s ( C )$ 。

称有向圈 C 为极小圈，如果 R(C) 的内部没有别的有向圈；称它为极大圈，如果 L(C)的内部没有别的有向圈。每个状态下至少有极小圈或极大圈。事实上，从任一有向圈及其一个闭圆盘开始，只要该圆盘内部还有有向圈，就在其中选一个，并改取这个新圈的两个圆盘中包含在原圆盘内的那个。每次所得圆盘都是真子集，所含小三角形数严格减少，所以过程必定停止；停止时，最后一个圆盘若是右圆盘，其边界就是极小圈，若是左圆盘，其边界就是极大圈。

下面分析一次指针转动怎样改变有向圈。设本次转动发生在顶点 $x _ { \mathrm { ~ } }$ 。只有 $x$ 的出边改变，所以不经过 x 的旧有向圈仍是有向圈；至多破坏一个经过 x 的旧有向圈，也至多产生一个经过 x 的新有向圈。

设转动前 x 位于有向圈 C 上。圈从 x 的入边进入，再沿 x 的出边离开；从出边开始顺时针转到入边所扫过的局部扇形恰在 $R ( C )$ 一侧。转动后的出边是旧出边的下一条顺时针边。它不可能就是 C 的入边，否则 x 会与圈中它的前一个顶点形成长度为 2 的有向圈，表示两个相邻面的指针相互指向。因此新出边严格进入 $R ( C )$ 。从 $x$ 沿新出边继续循着各顶点的出边前进，在遇到 C 以前不可能越过 $C .$ 

现在设 $C$ 是极小圈。若在 $C$ 上的顶点 x 转动，则上述有向路必定再次遇到 $C ;$ ；否则有限图中的这条路会在 $R ( C )$ 内进入一个不经过 x 的有向圈，而这个圈在转动前已经存在，与极小性矛盾。把这条路与 C 上从相遇处回到 x 的有向段合起来，得到新的有向圈 $C ^ { \prime }$ 。由出边进入右侧这一局部位置以及两个圈的分离可知

$$
R (C ^ {\prime}) \subsetneq R (C)
$$

而 $R ( C ^ { \prime } )$ 内不可能还有别的有向圈，否则该圈不经过 $x _ { i }$ ，在转动前也已位于 $R ( C )$ 内。因此$C ^ { \prime }$ 仍是极小圈，并且 $s ( C ^ { \prime } ) < s ( C )$ 

还要考察不在 $C$ 上的转动。若转动后 C 不再极小，就有一个新有向圈 D 出现在 $R ( C )$ 内，而且 D 必经过 $x _ { \circ }$ 。在 $D$ 的顶点 x 处，旧出边是新出边的上一条逆时针边，因而进入 $L ( D )$ 它也不可能是 $D$ 的入边，否则转动前已经出现长度为 2 的有向圈。从 x 沿旧出边循着转动前的出边前进。若这条路一直不遇到 $C ,$ ，它最终会在 $R ( C )$ 内进入一个旧有向圈，与 $C$ 的极小性矛盾，故它必定遇到 $C _ { \circ }$ 。在此以前，它若碰到 $D$ 的某个顶点，随后就会沿 D 回到 x，再接上 x 的旧出边，从而同样在转动前的 $R ( C )$ 内形成有向圈；而对偶图的边不会在内部相交，所以这条路也不可能从边的内部越过 $D _ { \mathsf { c } }$ 。因此它在遇到 $C$ 前始终位于 $L ( D )$ 一侧，故 C 位于 $L ( D )$ 一侧。于是

$$
R (D) \subsetneq R (C)
$$

并且与上一段同理，D 是新的极小圈。

因此，只要当前存在极小圈，所有极小圈中最小的大小 m 在每次转动后都不会增加；若一个大小为 $m$ 的极小圈上的指针转动，或者它因右圆盘内产生新圈而失去极小性， $m$ 就严格减小。由于 $m$ 是正整数，它从某一时刻起必定不再变化。此时任选一个大小为 $m$ 的极小圈$C _ { \circ }$ 以后任何不在 $C$ 上的转动都不能使它失去极小性，否则 m 会减小；任何在 C 上的转动也会使 m 减小。因此 C 上的所有指针从此都不能转动，这与每根指针都转动无限多次的反设矛盾。

只剩下说明某个时刻必会出现极小圈。反设从当前状态起始终没有极小圈；由前面证明的存在性，每个状态都有极大圈。若极大圈 C 以外的顶点 x 转动而使 C 不再极大，那么必有一个经过 $x$ 的新有向圈 D 出现在 $L ( C )$ 内。仍从 x 沿旧出边前进：旧出边进入 $L ( D )$ ，而转动前 $L ( C )$ 内没有有向圈，所以这条路必须遇到 $C _ { \textsf { c } }$ 。故 C 位于 $L ( D )$ 一侧， $R ( D )$ 是包含在 $L ( C )$ 内的那个圆盘；其中没有别的有向圈，于是 D 是极小圈。这与当前阶段的反设矛盾。因此，只要极小圈尚未出现，不经过本次转动顶点的每个旧极大圈都会保持为极大圈。

再看转动后新成为极大圈的圈 $D _ { \circ }$ 。如果 D 是本次新产生的圈，就从 x 沿旧出边前进。旧出边进入 $L ( D )$ ；若这条旧有向路不再遇到 $D$ ，它最终会进入一个不经过 x 的旧有向圈，该圈在转动后仍位于 $L ( D )$ 内，与 D 的极大性矛盾。因此旧有向路必定回到 D，并与 D 的一段组成一个经过 $x$ 的旧有向圈 $C _ { \mathfrak { c } }$ 。如果 D 原来已经是有向圈但尚非极大圈，那么转动前 $L ( D )$ 内至少有一个有向圈，而转动后这些圈必须全部消失；一次转动只能破坏经过 x 的那个旧有向圈，故此时也得到一个经过 x 的旧有向圈 $C _ { \circ }$ 。两种情形中都有

$$
L (C) \subsetneq L (D), \qquad R (D) \subsetneq R (C)
$$

第一种情形中的包含关系来自旧出边位于新圈 D 的左侧。第二种情形中，若包含在 $L ( D )$ 内的是 $R ( C )$ 而不是 $L ( C )$ ，则 $R ( C )$ 内的任何其他旧圈都会在转动后继续留在 $L ( D )$ 内；由 D的极大性可知这样的旧圈不存在，于是 C 在转动前已经是极小圈，同样矛盾。又因为 D 转动后是极大圈， $L ( C )$ 内原有的任何圈都会保留下来并仍位于 $L ( D )$ 内，所以 C 在转动前必为极大圈。不同极大圈的左圆盘内部两两不交，否则由前述分离方式，其中一个圈会落入另一个圈的左圆盘；故同一个被破坏的旧圈至多对应一个新成为极大圈的 $D$ 

令 S 为当前所有极大圈大小之和。在没有极小圈出现的这段过程中，不经过转动顶点的旧极大圈保持不变；每个新成为极大圈的圈都只能替代经过转动顶点的旧极大圈 C，而且由$R ( D ) \subsetneq R ( C )$ 得 $s ( D ) < s ( C )$ 。所以 S 不增加；若转动顶点位于某个极大圈上， $S \ \bar { p } ^ { \mathrm { u } \mathrm { \prime } }$ 格减小。正整数 S 也必从某一时刻起不再变化。此后任选一个极大圈，不在它上面的转动不能破坏它，而它上面的任一指针一旦转动就会使 S 减小。因此该圈上的指针从此都不能转动，再次与反设矛盾。

所以极小圈终会出现，而出现极小圈后又已导出矛盾。故反设不成立，至少有一根指针只转动有限次。
