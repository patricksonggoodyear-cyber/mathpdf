$$

设 n 为正整数， $a _ { 1 } , \cdots , a _ { n } , b _ { 1 } , \cdots , b _ { n } , c _ { 1 } , \cdots , c _ { n }$ 为任意实数。证明：

$$
\begin{array}{c} \sqrt {\sum_ {i = 1} ^ {n} (3 a _ {i} - b _ {i} - c _ {i}) ^ {2}} + \sqrt {\sum_ {i = 1} ^ {n} (3 b _ {i} - c _ {i} - a _ {i}) ^ {2}} + \sqrt {\sum_ {i = 1} ^ {n} (3 c _ {i} - a _ {i} - b _ {i}) ^ {2}} \\ \geqslant \sqrt {\sum_ {i = 1} ^ {n} a _ {i} ^ {2}} + \sqrt {\sum_ {i = 1} ^ {n} b _ {i} ^ {2}} + \sqrt {\sum_ {i = 1} ^ {n} c _ {i} ^ {2}} \end{array}
$$

解

将三组数记为向量 $a = ( a _ { 1 } , \cdots , a _ { n } ) \circ ( b _ { 1 } , \cdots , b _ { n } ) \circ c = ( c _ { 1 } , \cdots , c _ { n } )$ ，用 $\| \cdot \|$ 表示 R<sup>n</sup>中的欧氏范数。由 $( 3 a - b - c ) + b + c = 3 a$ 及范数的三角不等式，

$$
\| 3 a - b - c \| + \| b \| + \| c \| \geqslant \| (3 a - b - c) + b + c \| = 3 \| a \|
$$

将这个不等式分别对 $a , b , c$ 作循环轮换后相加，得到

$$
\left\| 3 a - b - c \right\| + \left\| 3 b - c - a \right\| + \left\| 3 c - a - b \right\| + 2 (\left\| a \right\| + \left\| b \right\| + \left\| c \right\|) \geqslant 3 (\left\| a \right\| + \left\| b \right\| + \left\| c \right\|)
$$

消去两端相同的部分，即得所求不等式。

给定正整数 n，求最大的常数 λ，使得以下命题成立：若正实数 $x _ { 1 } , x _ { 2 } , \cdots , x _ { 2 n }$ 满足

$$
\frac {1}{2 n} \sum_ {i = 1} ^ {2 n} (x _ {i} + 2) ^ {n} \geqslant \prod_ {i = 1} ^ {2 n} x _ {i}
$$

$$
\frac {1}{2 n} \sum_ {i = 1} ^ {2 n} (x _ {i} + 1) ^ {n} \geqslant \lambda \prod_ {i = 1} ^ {2 n} x _ {i}
$$

所求最大常数为 $\lambda = ( 3 / 4 ) ^ { n }$ 。取 $x _ { 1 } = x _ { 2 } = \cdot \cdot \cdot = x _ { 2 n } = 2$ ，题设条件取等号，故必有$\lambda \leqslant ( 3 / 4 ) ^ { n }$ o

记

$$
A = \left(\frac {1}{2 n} \sum_ {i = 1} ^ {2 n} (x _ {i} + 1) ^ {n}\right) ^ {1 / n}, \quad P = \left(\prod_ {i = 1} ^ {2 n} x _ {i}\right) ^ {1 / n}
$$

对向量 $( x _ { 1 } + 1 , \cdots , x _ { 2 n } + 1 )$ 与全 1 向量使用 $\ell _ { n }$ 范数的 Minkowski 不等式 (当 $n = 1$ 时就是和的恒等式)，得到

$$
\left(\frac {1}{2 n} \sum_ {i = 1} ^ {2 n} (x _ {i} + 2) ^ {n}\right) ^ {1 / n} \leqslant A + 1
$$

由题设条件，左端不小于 P，故 $A \geqslant P - 1$ 

另一方面，由平均值不等式及 Hölder 不等式，

$$
A \geqslant \left(\prod_ {i = 1} ^ {2 n} (x _ {i} + 1)\right) ^ {1 / (2 n)} \geqslant \left(\prod_ {i = 1} ^ {2 n} x _ {i}\right) ^ {1 / (2 n)} + 1 = \sqrt {P} + 1
$$

因此总有 $A \geqslant 3 P / 4$ 。两边取 n 次方，便得到题目所需的不等式，故 $\lambda = ( 3 / 4 ) ^ { n }$ 。

设非负实数 $a , b , c$ 满足 $a ^ { 2 } + b ^ { 2 } + c ^ { 2 } = 1$ 。证明：

$$
\sqrt {a + b} + \sqrt {b + c} + \sqrt {c + a} \geqslant 5 a b c + 2
$$

解

由对称性，不妨设 $a \geqslant b \geqslant c _ { \circ }$ 用 $\| \cdot \|$ 表示二维向量的欧氏范数，将三个根号分别识别为向量 $( { \sqrt { a } } , { \sqrt { b } } ) , \ ( { \sqrt { a } } , { \sqrt { c } } ) , \ ( { \sqrt { b } } , { \sqrt { c } } )$ 的范数。由 Minkowski 不等式及 ${ \sqrt { a b } } \geqslant b , { \sqrt { b c } } \geqslant c$ 

$$
\begin{array}{r l} & {\sqrt {a + b} + \sqrt {b + c} + \sqrt {c + a} \geqslant \sqrt {(2 \sqrt {a} + \sqrt {b}) ^ {2} + (\sqrt {b} + 2 \sqrt {c}) ^ {2}}} \\ & {\qquad = \sqrt {4 a + 2 b + 4 c + 4 \sqrt {a b} + 4 \sqrt {b c}}} \\ & {\qquad \geqslant \sqrt {4 a + 6 b + 8 c}} \end{array}
$$

下面证明 $4 a + 6 b + 8 c \geqslant ( 5 a b c + 2 ) ^ { 2 }$ 。因为 $b ^ { 2 } \leqslant a b \leqslant c ^ { 2 } \leqslant a c$ 

$$
\left(a + \frac {b + c}{2}\right) ^ {2} \geqslant a ^ {2} + a (b + c) \geqslant a ^ {2} + b ^ {2} + c ^ {2} = 1
$$

所以 $a + ( b + c ) / 2 \geqslant 1$ ，进而

$$
4 a + 6 b + 8 c = 4 \left(a + \frac {b + c}{2}\right) + 4 b + 6 c \geqslant 4 + 4 b + 6 c
$$

记 $t = a b c$ 。由平均值不等式， $0 \leqslant t \leqslant 1 / ( 3 \sqrt { 3 } )$ ，故

$$
2 5 t ^ {2} + 2 0 t \leqslant \left(2 0 + \frac {2 5}{3 \sqrt {3}}\right) t
$$

另一方面，由 $( b - c ) ^ { 2 } \geqslant 0$ 及平均值不等式，

$$
1 = a ^ {2} + b ^ {2} + c ^ {2} \geqslant a ^ {2} + \frac {(b + c) ^ {2}}{2} \geqslant 2 \sqrt {a ^ {2} \cdot \frac {(b + c) ^ {2}}{2}} = \sqrt {2} a (b + c)
$$

再分别使用平均值不等式，得到 $b + c \geqslant 2 { \sqrt { b c } } , \ 4 b + 6 c \geqslant 2 { \sqrt { 4 b \cdot 6 c } } = 4 { \sqrt { 6 b c } }$ ，所以

$$
(b + c) (4 b + 6 c) \geqslant (2 \sqrt {b c}) (4 \sqrt {6 b c}) = 8 \sqrt {6} b c
$$

于是

$$
4 b + 6 c \geqslant \sqrt {2} a (b + c) (4 b + 6 c) \geqslant 1 6 \sqrt {3} a b c \geqslant \left(2 0 + \frac {2 5}{3 \sqrt {3}}\right) t \geqslant 2 5 t ^ {2} + 2 0 t
$$

上述常数比较 $1 6 { \sqrt { 3 } } \geqslant 2 0 + 2 5 / ( 3 { \sqrt { 3 } } )$ 等价于 $1 1 9 \geqslant 6 0 \sqrt { 3 }$ ，平方即可验证。因此

$$
4 a + 6 b + 8 c \geqslant 4 + 2 5 t ^ {2} + 2 0 t = (5 t + 2) ^ {2}
$$

结合开头的 Minkowski 估计，便得到所求不等式。
