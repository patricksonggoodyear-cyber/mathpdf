Polish Final Round 1977 P6 

设多项式 $W ( x ) = ( x - a ) ^ { k } Q ( x )$ ，其中 $a \neq 0$ 并且 $Q ( x ) \not \equiv 0$ C

证明： $W ( x )$ 至少有 $k + 1$ 个非零系数。

## 解

设 $W ( x )$ 一共有 m 个非零系数。我们只需证明 $m \geqslant k + 1$ ，先证明如下引理。

引理： 一个只有 m 个非零项的多项式，在任何非零点处的根的重数都不超过 $m - 1$ o

引理证明： 对 m 作归纳。当 $m = 1$ 时，多项式形如 $f ( x ) = c x ^ { n }$ 其中 $c \neq 0$ ，它在任何非零点都不可能为零，因此在任何非零点处的根重数为 0，结论成立。

现在设结论对所有只有不超过 $m - 1$ 个非零项的多项式成立。考虑一个恰有 m 个非零项的多项式

$$
f (x) = c _ {1} x ^ {n _ {1}} + c _ {2} x ^ {n _ {2}} + \dots + c _ {m} x ^ {n _ {m}}
$$

其中 $0 \leqslant n _ { 1 } < n _ { 2 } < \cdot \cdot \cdot < n _ { m }$ 其中 $c _ { i } \neq 0 .$ 。把最低次幂提出来，得 $f ( x ) = x ^ { n _ { 1 } } g ( x )$ ，其中

$$
g (x) = d _ {0} + d _ {1} x ^ {t _ {1}} + \dots + d _ {m - 1} x ^ {t _ {m - 1}}
$$

并且 $d _ { 0 } \neq 0 , 0 < t _ { 1 } < \cdot \cdot \cdot < t _ { m - 1 }$ 。由于我们讨论的是非零点 $a \neq 0$ ，所以 a 在 $f ( x )$ 中的根重数与它在 $g ( x )$ 中的根重数相同。设 $a \neq 0$ 是 $g ( x )$ 的一个 r 重根，则 $g ^ { \prime } ( x )$ 在 a 处至少有$r - 1$ 重根。另一方面，

$$
g ^ {\prime} (x) = d _ {1} t _ {1} x ^ {t _ {1} - 1} + \dots + d _ {m - 1} t _ {m - 1} x ^ {t _ {m - 1} - 1}
$$

它恰有 $m - 1$ 个非零项。由归纳假设， $g ^ { \prime } ( x )$ 在任何非零点处的根重数都不超过 $( m - 1 ) - 1 =$ $m - 2 ,$ 。因此 $r - 1 \leqslant m - 2$ ，从而 $r \leqslant m - 1$ ，引理得证。

回到原题。由于 $W ( x ) = ( x - a ) ^ { k } Q ( x )$ ，可知 a 是 $W ( x )$ 的一个重数至少为 k 的非零根。而 $W ( x )$ 有 m 个非零系数，由引理可知其任一非零根的重数都不超过 $m - 1$ ，故 $k \leqslant m - 1$ 于是 $m \geqslant k + 1$ ，因此， $W ( x )$ 至少有 $k + 1$ 个非零系数，证毕。

Russian Federal 1996 Grade 11 P4 

n 次多项式 $P ( x )$ 有 n 个互不相同的实根。试问：它最多可能有多少项的系数为 0？

## 解

当 n 为偶数时，最多有 $n / 2$ 项；当 n 为奇数时，最多有 $( n + 1 ) / 2$ 。可以总结为，最多有 $\lceil n / 2 \rceil$ 。记 $P ^ { ( k ) } ( x )$ 为多项式 $P ( x )$ 的 k 次导函数。

我们先提出一个事实：在可导函数的任何两个实根之间，都有它的导函数的实根。它的证明是容易的。所以导函数 $P ^ { \prime } ( x )$ 至少有 $n - 1$ 个互不相同的实根。由于 $P ^ { \prime } ( x )$ 是 $n - 1$ 次的多项式，故由此可知，它的所有实根互不相同。再利用归纳法，可知对所有的导函数$P ^ { ( k ) } ( x ) ~ ( k = 2 , 3 , \cdot \cdot \cdot , n - 1 )$ 都有相同的结论。

而由此可以推知，在多项式 $P ( x )$ 的任何两个相邻项的系数中都至少有一个非零。事实上，如果 $P ( x )$ 的 $x ^ { k }$ 与 $x ^ { k + 1 }$ 项的系数都是 0，则 $P ^ { ( k ) } ( x )$ 的常数项与 x 项的系数就都是 0，于是 0 就是 $P ^ { ( k ) } ( x )$ 的重根，此与 $P ^ { ( k ) } ( x )$ 的所有实根互不相同的事实相矛盾！

将多项式 $P ( x )$ 的系数分成“相邻对” (当 n 为偶数时，让它的首项系数落单)。由于首项系数非 0，所以零系数的数目不多于“相邻对”的数目，即当 n 为偶数时，不多于 $n / 2$ ；当 n 为奇数时，不多于 $( n + 1 ) / 2$ o

另一方面，多项式

$$
(x ^ {2} - 1) (x ^ {2} - 4) \cdot \cdot \cdot (x ^ {2} - k ^ {2}), \quad \text {和} \quad x (x ^ {2} - 1) (x ^ {2} - 4) \cdot \cdot \cdot (x ^ {2} - k ^ {2})
$$

分别给出了 n 为偶数与 n 为奇数时，零系数的个数分别达到 $n / 2$ 和 $( n + 1 ) / 2$ 个的例子。

USAMO 2025 P2 

设正整数 $k < n , \ P ( x )$ 是 n 次实系数多项式，常数项非零，且没有重根。已经对任意实数 $a _ { 0 } , a _ { 1 } , \cdots , a _ { k }$ ，若多项式 $a _ { k } x ^ { k } + \cdot \cdot \cdot + a _ { 1 } x + a _ { 0 }$ 整除 $P ( x )$ ，则 $a _ { 0 } a _ { 1 } \cdot \cdot \cdot a _ { k }$ 等于 0。求证：$P ( x )$ 有非实根。

解

设 $Q ( x ) = ( x - x _ { 1 } ) ( x - x _ { 2 } ) \cdot \cdot \cdot ( x - x _ { k + 1 } )$ 是 $P ( x )$ 的一个 $k + 1$ 因式。

由条件，对 $1 \leqslant i \leqslant k + 1$ ，多项式 $Q _ { i } ( x ) = { \frac { Q ( x ) } { x - x _ { i } } }$ 有系数为 0。

因为 $Q _ { i } ( x )$ 是 k 次多项式，且首项系数与常数项均非零，所以由抽屉原理，可不妨设$Q _ { 1 } ( x )$ 与 $Q _ { 2 } ( x )$ 的 $x ^ { t }$ 项系数均为 0，其中 $0 < t < k$ 。设

$$
R (x) = \frac {Q (x)}{(x - x _ {1}) (x - x _ {2})} = x ^ {k - 1} + b _ {k - 2} x ^ {k - 2} + \dots + b _ {0}
$$

则 $Q _ { 1 } ( x ) = ( x - x _ { 2 } ) R ( x )$ 的 $x ^ { t }$ 项系数 $b _ { t - 1 } - x _ { 2 } b _ { t } = 0$ 。同理 $b _ { t - 1 } - x _ { 1 } b _ { t } = 0$ ，因为 $x _ { 1 } \neq x _ { 2 }$ 所以 $b _ { t - 1 } = b _ { t } = 0 .$ 

假设 $P ( x )$ 的根都是实数，则 $R ( x )$ 的根都是实数且互不相同，由 Rolle 定理可知， $R ( x )$ 的任意阶导数的根都是实数且互不相同。但由 $b _ { t - 1 } = b _ { t } = 0$ 知 0 是 $R ( x )$ 的 t−1 阶导数的至少二重根，矛盾！
