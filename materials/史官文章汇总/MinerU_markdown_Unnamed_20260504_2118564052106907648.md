设 $a , b , c , d > 1$ ，且 $\log _ { a } b \neq \log _ { c } d _ { \circ }$ 一台比较这两个对数大小的仪器按以下规则工作：

1. 若 $b > a$ 且 $d > c ,$ ，则改为比较 $\log _ { a } ( b / a )$ 与 $\log _ { c } ( d / c )$ 

2. 若 $b < a$ 且 $d < c ,$ ，则改为比较 $\log _ { d } c$ 与 $\log _ { b }$ a，即在取倒数后交换两个数的位置。

3. 若 $( b - a ) ( d - c ) \leqslant 0$ ，则直接给出比较结果。

每次变换后，对新的两个对数继续使用这些规则。证明：仪器一定在有限步后给出答案。

## 解

记 $x = \log _ { a } b , y = \log _ { c } d .$ 。题中的操作等价于：当 $x , y > 1$ 时，将 $( x , y )$ 替换为 $( x - 1 , y - 1 )$ ；当 $0 < x , y < 1$ 时，将其替换为 $( 1 / y , 1 / x )$ ；当 $( x - 1 ) ( y - 1 ) \leqslant 0$ 时停止。这两种替换都保持两个数的大小关系，因此只需证明操作不能无限进行。

反设操作无限进行。暂时忽略取倒数后的位置交换，分别追踪最初的两个数。对于当前一对正数，若其中一个是整数，则连续减 1 的过程中必有一个数等于 1，或者两数提前分居1 的两侧，操作都会停止。若两数都不是整数，但整数部分不同，则同时减去较小的整数部分后，一数小于 1，另一数大于 1，也会停止。因此，在无限进行的假设下，两数始终都不是整数，且具有相同的整数部分。

记这一共同整数部分为 $a _ { 0 }$ 。同时减去 $a _ { 0 }$ ，再取倒数，就得到下一对正数；继续如此，便得到两数共同的连分数部分商 $a _ { 0 } , a _ { 1 } , a _ { 2 } , \cdots$ ，其中 $a _ { 0 } \geqslant 0 , a _ { n } \geqslant 1 ( n \geqslant 1 )$ 。下面直接估计共同连分数前缀所能确定的区间长度。

令 $p _ { - 2 } = 0 \cdot \ p _ { - 1 } = 1 \cdot \ q _ { - 2 } = 1 \cdot \ q _ { - 1 } = 0$ ，并对 $n \geqslant 0$ 定义

$$
p _ {n} = a _ {n} p _ {n - 1} + p _ {n - 2}, \qquad q _ {n} = a _ {n} q _ {n - 1} + q _ {n - 2}
$$

递推可得 $p _ { n } q _ { n - 1 } - p _ { n - 1 } q _ { n } = ( - 1 ) ^ { n + 1 }$ 。由有限连分数的逐层代入，对于尾部完整商 $t > 1$ ，有

$$
[ a _ {0}; a _ {1}, \dots , a _ {n}, t ] = \frac {p _ {n} t + p _ {n - 1}}{q _ {n} t + q _ {n - 1}}
$$

右端关于 $t \ \overrightharpoon { \mathrm { ‰ ~ } }$ 格单调，因此，具有前缀 $a _ { 0 } , a _ { 1 } , \cdots , a _ { n }$ 的两个数都位于端点为 $p _ { n } / q _ { n }$ 与 $( p _ { n } +$ $p _ { n - 1 } ) / ( q _ { n } + q _ { n - 1 } )$ 的同一区间内。这个区间的长度为

$$
\left| \frac {p _ {n}}{q _ {n}} - \frac {p _ {n} + p _ {n - 1}}{q _ {n} + q _ {n - 1}} \right| = \frac {1}{q _ {n} (q _ {n} + q _ {n - 1})}
$$

又因 $q _ { 0 } = 1 , \ q _ { 1 } = a _ { 1 } \geqslant 1$ ，且 $q _ { n } \geqslant q _ { n - 1 } + q _ { n - 2 } \ ( n \geqslant 2 )$ ，故 $q _ { n } \to \infty$ 。于是对任意 n 都有

$$
| x - y | \leqslant \frac {1}{q _ {n} (q _ {n} + q _ {n - 1})} \longrightarrow 0
$$

从而 $x = y$ ，与题设矛盾。因此仪器必在有限步后停止。

设函数 $f : [ 0 , 1 ] \to$ R满足：存在常数 $K > 0$ ，使得对任意 $x , y \in [ 0 , 1 ]$ ，都有 $| f ( x ) - f ( y ) | \leqslant$ $K | x - y |$ ；并且对每个有理数 $r \in [ 0 , 1 ]$ ，都存在整数 $a , b$ ，使得 $f ( r ) = a + b r .$ 。证明：f 是有限分段线性函数，即存在 $0 = t _ { 0 } < t _ { 1 } < \cdot \cdot \cdot < t _ { N } = 1$ ，使得 $f$ 在每个区间 $[ t _ { i - 1 } , t _ { i } ]$ 上都可表示为 $A _ { i } + B _ { i } t$ ，其中 $A _ { i } , B _ { i }$ 为常数。

## 解

由题设，f 连续，且对所有 $t \in [ 0 , 1 ]$ 都有 $| f ( t ) | \leqslant | f ( 0 ) | + K$ 。记 $M = | f ( 0 ) | + K .$ C

任取无理数 $x \in ( 0 , 1 )$ ，令 $x _ { 0 } = x$ ，并递推定义 $a _ { n } = \left\lfloor x _ { n } \right\rfloor \mathrm { \boldsymbol { \cdot } } \ x _ { n + 1 } = 1 / ( x _ { n } - a _ { n } )$ 。各 $x _ { n }$ 都是无理数，故这一过程可以无限进行，且 $a _ { 0 } = 0 , \ a _ { n } \geqslant 1 , \ x _ { n } > 1$ 对 $n \geqslant 1$ 成立。定义

$$
p _ {- 2} = 0, \quad p _ {- 1} = 1, \quad q _ {- 2} = 1, \quad q _ {- 1} = 0
$$

$$
p _ {n} = a _ {n} p _ {n - 1} + p _ {n - 2}, \quad q _ {n} = a _ {n} q _ {n - 1} + q _ {n - 2} \quad (n \geqslant 0)
$$

这些递推式给出连分数的收敛分数 $r _ { n } = p _ { n } / q _ { n } = [ a _ { 0 } ; a _ { 1 } , \cdot \cdot \cdot , a _ { n } ] \in [ 0 , 1 ]$ 。归纳可得

$$
p _ {n} q _ {n - 1} - p _ {n - 1} q _ {n} = (- 1) ^ {n - 1}, \qquad x = \frac {p _ {n} x _ {n + 1} + p _ {n - 1}}{q _ {n} x _ {n + 1} + q _ {n - 1}}
$$

于是 $p _ { n } , q _ { n }$ 互质，且

$$
\left| x - \frac {p _ {n}}{q _ {n}} \right| = \frac {1}{q _ {n} (q _ {n} x _ {n + 1} + q _ {n - 1})} <   \frac {1}{q _ {n} ^ {2}}
$$

因为 $q _ { n } \geqslant q _ { n - 1 } + q _ { n - 2 }$ 对 $n \geqslant 2$ 成立，所以 $q _ { n } \to \infty$ ，进而 $r _ { n } \to x .$ 

由题设， $m _ { n } = q _ { n } f ( r _ { n } )$ 是整数。连接相邻两个图像点 $( r _ { n } , f ( r _ { n } ) )$ 与 $( r _ { n + 1 } , f ( r _ { n + 1 } ) )$ 的直线记为 $y = A _ { n } + B _ { n } t$ ，则

$$
\left\{ \begin{array}{l} q _ {n} A _ {n} + p _ {n} B _ {n} = m _ {n} \\ q _ {n + 1} A _ {n} + p _ {n + 1} B _ {n} = m _ {n + 1} \end{array} \right.
$$

该方程组的系数行列式为 $q _ { n } p _ { n + 1 } - p _ { n } q _ { n + 1 } = ( - 1 ) ^ { n }$ ，故 $A _ { n } , B _ { n }$ 均为整数。另一方面，题设中的不等式给出

$$
\left| B _ {n} \right| = \left| \frac {f (r _ {n + 1}) - f (r _ {n})}{r _ {n + 1} - r _ {n}} \right| \leqslant K, \quad \left| A _ {n} \right| = \left| f (r _ {n}) - B _ {n} r _ {n} \right| \leqslant M + K
$$

因此，无论 x 与 n 怎样选取，这些直线都属于有限集合

$$
\mathcal {L} = \{y = A + B t: A, B \in \mathbb {Z}, | A | \leqslant M + K, | B | \leqslant K \}
$$

对所选的无理数 x，必有 L 中的一条直线 $y = A + B t$ 在上述直线序列中出现无穷多次。沿相应子列令 $n \to \infty$ ，由 $r _ { n } \to x$ 与 f 的连续性，得到 $f ( x ) = A + B x$ 。所以所有无理数处的图像点都落在 L 中的直线之并上。有限条直线的并是闭集，再由无理数的稠密性和 f 的连续性，整个图像都包含在这个并中。

将这些不同直线两两交点在 (0,1) 内的横坐标与 0,1 一起从小到大排列为 $0 = t _ { 0 } < t _ { 1 } <$ $\cdots < t _ { N } = 1$ 。在任一开区间 $( t _ { i - 1 } , t _ { i } )$ 内，各条直线的函数值两两不同，因此图像点所属的直线是唯一的；又由 f 及这些线性函数的连续性，这条直线在每一点附近保持不变。由于该区间连通，整段图像只能属于同一条直线。最后由连续性将这个线性表达式延伸到两个端点，便知 f 在每个 $[ t _ { i - 1 } , t _ { i } ]$ 上都是线性函数，结论成立。

求所有函数 $f : ( 0 , \infty ) \to ( 0 , \infty )$ ，使得对任意正实数 x，都有

$$
f (x + 1) = f (x) + 1, \quad f \left(\frac {1}{f (x)}\right) = \frac {1}{x}
$$

解

唯一的函数是 $f ( x ) = x$ 

首先，由 $f ( 1 / f ( x ) ) = 1 / x$ 的右端取遍所有正实数可知，f 为满射。若 $f ( x ) = f ( y )$ ，则同一等式给出 $1 / x = 1 / y$ ，从而 $x = y$ ，故 f 也是单射。利用平移关系及满射性，得到

$$
f ((1, \infty)) = \{f (t) + 1: t > 0 \} = (1, \infty)
$$

结合单射性，便有 $f ( x ) > 1$ 当且仅当 $x > 1$ 。特别地， $c = f ( 1 ) \leqslant 1$ 。若 $c < 1$ ，则 $1 / c > 1$ 因而 $f ( 1 / c ) > 1$ ；但原式在 $x = 1$ 时给出 $f ( 1 / c ) = 1$ ，矛盾。因此 $f ( 1 ) = 1$ ，并且

$$
f (x) > 1 \Longleftrightarrow x > 1, \quad f (x) = 1 \Longleftrightarrow x = 1, \quad f (x) <   1 \Longleftrightarrow x <   1
$$

任取 $x > 0$ ，考虑数对 $( x , f ( x ) )$ 。只要 $( u , v )$ 满足 $v = f ( u )$ ，当 $u , v > 1$ 时，平移关系说明 $( u - 1 , v - 1 )$ 仍满足第二个数为第一个数的函数值；当 $u , v < 1$ 时，原式 $f ( 1 / v ) = 1 / u$ 说明 $( 1 / v , 1 / u )$ 也满足这一性质。因此，在同时减 1 或取倒数后交换位置的过程中，两数始终处于 1 的同侧，或者同时等于 1。

假设 $x \neq f ( x )$ 。这两种操作都保持两数不相等，所以操作中不可能出现两数同时等于 1，从而操作可以无限进行。忽略每次取倒数后的位置交换，分别追踪初始的两个数。若某次得到整数，连续减 1 后便会碰到 1；若某次两数的整数部分不同，连续减 1 后便会使两数分居 1的两侧。因此，无限进行时，两数的整数部分始终相同且两数均非整数。将每段连续减 1 和随后的取倒数合并，正是连分数算法，于是 x 与 $f ( x )$ 具有任意长的共同连分数前缀。

下面证明，这会迫使两个实数相等。将共同的部分商记作 $a _ { 0 } , a _ { 1 } , a _ { 2 } , \cdots$ ，其中 $a _ { 0 } ~ \geqslant ~ 0$ $a _ { n } \geqslant 1 ( n \geqslant 1 )$ 。令 $p _ { - 2 } = 0 \cdot \ p _ { - 1 } = 1 \cdot \ q _ { - 2 } = 1 \cdot \ q _ { - 1 } = 0$ ，并定义

$$
p _ {n} = a _ {n} p _ {n - 1} + p _ {n - 2}, \quad q _ {n} = a _ {n} q _ {n - 1} + q _ {n - 2} \quad (n \geqslant 0)
$$

由递推式得到 $p _ { n } q _ { n - 1 } - p _ { n - 1 } q _ { n } = ( - 1 ) ^ { n + 1 }$ 。逐层代入有限连分数，可得对任意尾部完整商 $t > 1$ 都有

$$
[ a _ {0}; a _ {1}, \dots , a _ {n}, t ] = \frac {p _ {n} t + p _ {n - 1}}{q _ {n} t + q _ {n - 1}}
$$

右端关于 $t ~ \bar { p } ^ { \pm }$ 格单调，所以拥有前缀 $a _ { 0 } , a _ { 1 } , \cdots , a _ { n }$ 的实数均处于端点为 $p _ { n } / q _ { n }$ 与 $( p _ { n } +$ $p _ { n - 1 } ) / ( q _ { n } + q _ { n - 1 } )$ 的区间内。该区间的长度为

$$
\left| \frac {p _ {n}}{q _ {n}} - \frac {p _ {n} + p _ {n - 1}}{q _ {n} + q _ {n - 1}} \right| = \frac {1}{q _ {n} (q _ {n} + q _ {n - 1})}
$$

又因 $q _ { 0 } = 1 , \ q _ { 1 } = a _ { 1 } \geqslant 1$ ，且 $q _ { n } \geqslant q _ { n - 1 } + q _ { n - 2 } \ ( n \geqslant 2 )$ ，故 $q _ { n } \to \infty$ 。因此

$$
| x - f (x) | \leqslant \frac {1}{q _ {n} (q _ {n} + q _ {n - 1})} \longrightarrow 0
$$

于是 $x = f ( x )$ ，与假设矛盾。故对所有正实数 x，均有 $f ( x ) = x .$ 。直接代入可知，该函数确实满足题中的两个条件。
