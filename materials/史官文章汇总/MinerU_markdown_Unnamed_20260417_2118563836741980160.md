Canada National 1981 P5 

十一个剧团参加艺术节。每天安排一些剧团演出，其余剧团观看。当艺术节结束时，每个剧团都至少观看过其他每个剧团的一场演出。艺术节至少需持续多少天？

## 解

答案为 6 天。设艺术节持续 d 天，剧团 i 的演出日期集合为 $S _ { i } \subseteq \{ 1 , \cdots , d \}$ 。剧团 i 观看过剧团 $j$ ，说明 $S _ { j } \setminus S _ { i } \ne \emptyset$ ，故十一个日期集合两两互不包含。

每个日期排列的全部前缀集合形成一条包含链，至多包含一个 $S _ { i }$ 。若 $| S _ { i } | ~ = ~ k$ ，恰有$k ! ( d - k ) !$ 个排列的前缀链包含它。对全部 d! 个排列计数并除以 d!，得到

$$
\frac {1 1}{\binom {d} {\lfloor d / 2 \rfloor}} \leqslant \sum_ {i = 1} ^ {1 1} \frac {1}{\binom {d} {| S _ {i} |}} \leqslant 1
$$

左侧不等式来自 ${ \binom { d } { k } } \leqslant { \binom { d } { \lfloor d / 2 \rfloor } }$ 。当 $d \leqslant 5$ 时，最大的二项式系数至多为 ${ \binom { 5 } { 2 } } = 1 0$ ，与上式矛盾，故至少需要六天。

反过来，从六个日期的二十个三元子集中任选十一个不同子集，分别作为十一个剧团的演出日期集合。任意两个不同的三元子集互不包含，所以对任意两个剧团，都有一天其中一个演出、另一个观看。因此六天能够实现要求。

高联 1993 P2

设 A 是一个 n 元集合，A 的 m 个子集 $A _ { 1 } , A _ { 2 } , \cdots , A _ { m }$ 两两互不包含，求证：

$$
\sum_ {i = 1} ^ {m} \binom {n} {| A _ {i} |} \geqslant m ^ {2}
$$

## 解

不妨设 $A = \{ 1 , 2 , \cdots , n \}$ 。每个排列 $\pi _ { 1 } , \pi _ { 2 } , \cdots , \pi _ { n }$ 的前缀集合 $\emptyset , \{ \pi _ { 1 } \} , \{ \pi _ { 1 } , \pi _ { 2 } \} , \cdot \cdot \cdot$ , A按包含关系组成一条链，故其中至多有一个属于题设的集合族。

固定 $A _ { i }$ ，以它为前 $| A _ { i } |$ 项集合的排列有 $\left| { { A _ { i } } } \right| ! ( n - \left| { { A _ { i } } } \right| ) !$ 个。对全部 n! 个排列计数，得到

$$
\sum_ {i = 1} ^ {m} | A _ {i} |! (n - | A _ {i} |)! \leqslant n!
$$

除以 n!，即得

$$
\sum_ {i = 1} ^ {m} \frac {1}{\binom {n} {| A _ {i} |}} \leqslant 1
$$

最后由 Cauchy 不等式，

$$
m ^ {2} \leqslant \left(\sum_ {i = 1} ^ {m} \binom {n} {| A _ {i} |}\right) \left(\sum_ {i = 1} ^ {m} \frac {1}{\binom {n} {| A _ {i} |}}\right) \leqslant \sum_ {i = 1} ^ {m} \binom {n} {| A _ {i} |}
$$

Iran 3rd Round 2006 C1 

设 A 是 $\{ 1 , \cdots , n \}$ 的子集族，其中没有一个成员包含于另一个成员。已知 $\vert { \mathcal { A } } \vert \leqslant { \binom { n } { \lfloor n / 2 \rfloor } }$ 求全部等号成立的子集族。

## 解

答案是全部 $\lfloor n / 2 \rfloor$ 元子集组成的族；当 n 为奇数时，也可取全部 $\lceil n / 2 \rceil$ 元子集组成的族。令 $m = \lfloor n / 2 \rfloor$ 。每个排列的前 $0 , 1 , \cdots , n$ 项集合组成一条极大链，每条链至多含有 A 的一个成员。固定一个 k 元集合，以它为前 k 项集合的排列有 $k ! ( n - k ) !$ 个。对全部排列计数并除以 $n !$ ，得到

$$
\sum_ {A \in \mathcal {A}} \frac {1}{\binom {n} {| A |}} \leqslant 1
$$

若 $| { \cal { A } } | = { \bf \Gamma } _ { m } ^ { n } $ ，由于每个 ${ \binom { n } { | A | } } \leqslant { \binom { n } { m } }$ ，左侧每项至少为 $1 / \binom { n } { m }$ ，故处处取等号。因此每个成员的大小都对应于最大的二项式系数，且每条极大链恰好含有一个成员。

当 $n = 2 m$ 时，成员只能位于第 m 层，所以必须取该层全部集合。

当 $n = 2 m + 1$ 时，成员只能位于第 m 层或第 $m + 1$ 层。若选入了一个 $m$ 元集合 L，则每个包含它的 $m + 1$ 元集合 U 都不能选入。对任意 m 元子集 $L ^ { \prime } \subset U$ ，取一条经过 $L ^ { \prime } , U$ 的极大链。它恰好含有一个选入成员，且允许选入的只有这两层；由于 U 未被选入，L′ 必被选入。

因此，从一个已选入的 m 元集合换出一个元素、换入一个新元素，得到的集合也必被选入。通过逐次交换可到达任意 m 元集合，故该层全部集合都被选入。若没有选入任何 m 元集合，则由成员总数可知，必须取全部 $m + 1$ 元集合。所列集合族显然都满足条件。

CSEMO 2004 P7 

n 支球队进行主客场双循环比赛 (即每两支球队比赛两场，其中各有一场主场比赛)。已知每支球队在一周 (从周日到周六的七天) 内可以进行多场客场比赛，但如果某周内某球队有主场比赛，那么在这一周内不能安排该球队的客场比赛。若 4 周内能够完成全部比赛，求 $n$ 的最大值。

## 解

答案为 $6 \textdegree$ 。对每支球队 i，令 $S _ { i } \subseteq \{ 1 , 2 , 3 , 4 \}$ 为它进行主场比赛的周次集合。球队 i 主场迎战球队 $j$ 的一周属于 $S _ { i } \setminus S _ { j }$ ，反向比赛所在的一周属于 $S _ { j } \setminus S _ { i }$ ，故任意两个周次集合互不包含。

任取四个周次的一个排列，其各个前缀集合构成一条包含链，至多含有一个 $S _ { i }$ 。若 $| S _ { i } | = k$ 恰有 $k ! ( 4 - k ) !$ 个排列的前缀链包含它。对全部 4! 个排列计数，得到

$$
4 n \leqslant \sum_ {i = 1} ^ {n} | S _ {i} |! (4 - | S _ {i} |)! \leqslant 4! = 2 4
$$

这里每一项至少为 $2 ! 2 ! = 4$ ，故 $n \leqslant$ 6。

将四个周次的全部六个二元子集分别分配给六支球队，规定球队 $i$ 在 $S _ { i }$ 所列周次只安排主场，其余周次只安排客场。对于球队 i 主场迎战球队 $j$ 的比赛，从非空集合 $S _ { i } \setminus S _ { j }$ 中任选一周安排它。这样全部比赛都已分配到四周中，而且每支球队在任何一周都不会兼有主场与客场比赛。

每周恰有三支指定主队和三支指定客队，分别编号为 $H _ { 0 } , H _ { 1 } , H _ { 2 }$ 与 $G _ { 0 } , G _ { 1 } , G _ { 2 }$ 。将本周已安排的 $H _ { i }$ 对 $G _ { j }$ 的比赛放在第 $1 + ( ( i + j ) \bmod 3 )$ 天。固定一支球队的各场比赛日期不同，故每天每队至多比赛一场，每周三天足够。因此上界可达。

Mathematical Reflections U225 

求一个超平面所能截得的 n 维单位立方体棱的最大条数。

## 解

令 $q = \lfloor ( n - 1 ) / 2 \rfloor$ ，答案为 $n { \binom { n - 1 } { q } }$ 。这里“截得”指超平面真正穿过棱的内部，即两端点位于超平面的严格两侧；仅接触端点或包含整条棱不计入。

单位立方体的顶点为 $\{ 0 , 1 \} ^ { n }$ 。超平面 $x _ { 1 } + \cdot \cdot \cdot + x _ { n } = q + 1 / 2$ 恰好截得连接第 q 层与第$q + 1$ 层的全部棱，其中第 r 层由恰有 r 个非零坐标的顶点组成。每个第 $q$ 层顶点有 $n - q$ 条这样的棱，所以截棱数为

$$
(n - q) \binom {n} {q} = n \binom {n - 1} {q}
$$

下面证明上界。设超平面 P 的方程为 $\textstyle \sum _ { i = 1 } ^ { n } a _ { i } x _ { i } = b $ 。对 $a _ { i } < 0$ 的坐标作反射 $x _ { i } \mapsto 1 - x _ { i }$ 保持立方体及截棱数不变，故可设所有 $a _ { i } \geqslant 0$ 0

从 $( 0 , \cdots , 0 )$ 到 $( 1 , \cdots , 1 )$ 的单调棱路依次把一个坐标由 0 改为 1，与 n 个坐标的排列一一对应，共有 n! 条。函数 $\sum a _ { i } x _ { i }$ 沿每条路不减，所以一条路至多有一次从小于 b 严格跨越到大于 b，即至多含一条被截棱。系数为零或超平面经过顶点，都不影响这一判断。

固定一条连接第 k 层与第 $k + 1$ 层的棱。经过它的路必须先改变其起点的 k 个非零坐标，再改变该棱对应的坐标，最后改变余下 $n - k - 1$ 个坐标，故这样的路共有 $k ! ( n - k - 1 ) !$ 条。若被截棱总数为 N，双计“被截棱及经过它的单调棱路”得到

$$
N \min _ {0 \leqslant k \leqslant n - 1} k! (n - k - 1)! \leqslant n!
$$

由于 $\binom { n - 1 } { k }$ 在 $k = q$ 时最大，上述阶乘乘积在此时最小，因此

$$
N \leqslant \frac {n !}{q ! (n - q - 1) !} = n \binom {n - 1} {q}
$$

结合构造，最大值即为所述数值。
