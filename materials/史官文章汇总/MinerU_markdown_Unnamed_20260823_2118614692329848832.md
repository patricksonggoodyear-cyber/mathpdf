解

答案： $\lfloor n / 2 \rfloor + 1$ 次。

自左至右依次将窗户编为 1,2,··· ,n 号。以 $k _ { i }$ 表示第 $i ( i = 1 , 2 , \cdots )$ 次射击时所射击的窗户的编号。不难看出，如下的射击方案即可保证射中目标：

$$
k _ {i} = 2 i - 1, \quad i \leqslant \left\lfloor \frac {n}{2} \right\rfloor ; \quad k _ {\lfloor n / 2 \rfloor + 1} = n
$$

事实上，如果一开始靶子在第 m 号窗户里，那么当 $m \leqslant \lfloor n / 2 \rfloor$ 时，我们可在第 m 次射击时击中它，而当 $m > \lfloor n / 2 \rfloor$ 时，我们可在第 $\lfloor n / 2 \rfloor + 1$ 次射击时击中它。

$$
k _ {i} \neq m _ {0} + i - 1, \quad i = 1, 2, \dots , \left\lfloor \frac {n}{2} \right\rfloor
$$

• 若所选钥匙孔与当前激活的钥匙孔位于同一行，则该行中与这两个钥匙孔均不同的第三个钥匙孔被激活；

• 若所选钥匙孔与当前激活的钥匙孔位于同一列，则该列中的第三个钥匙孔被激活；

• 若不属于以上两种情形，则恰有另一个钥匙孔既不与所选钥匙孔同行或同列，也不与当前激活的钥匙孔同行或同列，此钥匙孔被激活。

胡尚知道这个锁的规则，并想把锁打开。他每次都可以把钥匙插入任意一个钥匙孔，也可以再次选择已经尝试过的钥匙孔。证明胡尚可以采用某种策略，使得无论初始时哪个钥匙孔被激活，都一定能把锁打开。为保证锁被打开，他最少需要把钥匙插入钥匙孔多少次？

解

答案：9 次。

对任一钥匙孔 A，定义九个钥匙孔上的映射 $T _ { A }$ 。约定 $T _ { A } ( A ) = A$ ；若当前激活的钥匙孔为 $X \neq A$ ，则令 $T _ { A } ( X )$ 为把钥匙插入 A 后新激活的钥匙孔。由题中的三条规则可知， $T _ { A }$ 是一个对合。事实上，若 A,X 同行或同列，则 $T _ { A } ( X )$ 是该行或该列的第三个钥匙孔，再对 A 应用同一规则便回到 X；若 A,X 既不同行也不同列，则 $A , X , T _ { A } ( X )$ 分别占据三个不同的行和三个不同的列，再对 A 应用同一规则仍会回到 X。因此对每个钥匙孔 X 都有 $T _ { A } ( T _ { A } ( X ) ) = X$ 从而 $T _ { A }$ 是双射。

任意把九个钥匙孔依次记为 $P _ { 1 } , P _ { 2 } , \cdots , P _ { 9 }$ 。令 $\Phi _ { 0 }$ 为恒等映射。在锁尚未打开时递归地进行如下操作：第 k 次把钥匙插入 $A _ { k } = \Phi _ { k - 1 } ( P _ { k } )$ ；若这次仍然失败，就令 $\Phi _ { k } = T _ { A _ { k } } \circ \Phi _ { k - 1 }$ 然后继续。每个 $\Phi _ { k }$ 都是若干个双射 $T _ { A }$ 的复合，因而也是双射；而且对于任何能够避开前 k次尝试的初始激活孔 $P$ ，此时的激活孔正是 $\Phi _ { k } ( P )$ 

若初始激活孔为 $P _ { k }$ ，则对每个 $i < k$ ，第 i 次尝试前的激活孔为 $\Phi _ { i - 1 } ( P _ { k } )$ ，而胡尚选择的是 $\Phi _ { i - 1 } ( P _ { i } )$ 。由于 $\Phi _ { i } .$ 是双射且 $P _ { k } \neq P _ { i }$ ，这两个钥匙孔不同，所以前 k −1 次都不会打开锁；第 k 次选择的钥匙孔恰为 $\Phi _ { k - 1 } ( P _ { k } )$ ，锁便会打开。因此上述策略保证在至多 9 次内打开锁。

最后证明不能保证在少于 次内打开锁。考虑任意策略中锁始终没有打开的分支。在第k 次尝试前，把此前各次失败所对应的映射 $T _ { A }$ 依次复合，得到九个钥匙孔上的一个双射；每个仍然可能的初始激活孔在这个双射下的像，正是相应的当前激活孔。无论第 次选择哪个钥匙孔，这个钥匙孔在该双射下都只有一个原像，所以至多只有一种初始状态会在这次被命中。因此每次尝试至多新排除一种初始状态，少于 次不可能覆盖全部九种初始状态。故最少需要把钥匙插入 9 次。

## CWMI 2024 P6

魔术师和一名观众按如下规则表演一个互动魔术。有 101 个不同的帽子围成一圈，魔术开始前，一名观众将一只兔子藏在某个帽子里并选定一个正整数 n。在魔术表演的每个回合中，魔术师先选定一个帽子，如果帽子里有兔子，则魔术表演结束；如果帽子里没有兔子，那么魔术师蒙上眼睛，观众将兔子从当前的帽子按顺时针方向移动到之后第 n 个帽子里，然后开始下一回合。魔术师知道观众移动兔子的方式，但不知道 n 的值。

求证：魔术师可以制定一个策略，经过不超过 201 个回合找到兔子。

## 解

将 101 个帽子沿顺时针方向依次编号为 0,1,··· ,100，所有编号均模 101 计算。魔术师在前 101 个回合中始终检查编号为 0 的帽子。

设兔子最初在编号为 a 的帽子里。若 101 ∤ n，那么兔子在前 101 个回合被检查之前所在帽子的编号依次为 $a , a + n , \cdots , a + 1 0 0 n$ 。这些编号两两不同：若 $a + i n \equiv a + j n { \pmod { 1 0 1 } }$ 其中 $0 \leqslant i < j \leqslant 1 0 0$ ，则 $1 0 1 \mid ( j - i ) n \colon$ ；由于 101 是质数且 101 ∤ n，只能有 $1 0 1 \mid j - i $ ，这不可能。因此这些编号恰好遍历 0,1,··· ,100，兔子必在前 101 个回合中的某一回合位于编号为 0 的帽子里，从而被找到。

若前 101 个回合均未找到兔子，则由上面的论证可知 101 | n。此时兔子每次移动后实际上仍在原来的帽子里；又因为编号为 0 的帽子已经检查过，所以兔子位于其余 100 个帽子中的某一个。魔术师在接下来的 100 个回合中依次检查这 100 个帽子，必能找到兔子。

因此魔术师经过不超过 $1 0 1 + 1 0 0 = 2 0 1$ 个回合一定能找到兔子。

Baltic Way 2018 P8 

一个图有 N 个顶点，一只不可见的兔子藏在其中一个顶点上。一群猎人试图射杀兔子。每一轮，所有猎人同时射击，每名猎人各自瞄准一个顶点，并且他们协同选择这些目标顶点。如果射击时兔子位于某个被瞄准的顶点上，狩猎便结束；否则兔子可以留在原顶点，也可以跳到一个相邻顶点。已知猎人们有一种算法，能在不超过 N! 轮内射杀兔子。证明：他们也有一种算法，能在不超过 $2 ^ { N }$ 轮内射杀兔子。

## 解

在狩猎尚未结束时，猎人每轮得到的信息都只是“本轮没有命中”，所以一个保证成功的策略可以视为一列预先确定的射击方案。题设保证这样的有限序列存在；在所有保证成功的射击序列中，取轮数最少的一列，设其轮数为 T，第 t 轮被瞄准的顶点集合为 $H _ { t }$ 

设图的顶点集为 $V _ { \circ }$ 。对 $X \subseteq V$ ，记 $\Gamma ( X )$ 为 X 的闭邻域，即

$$
\Gamma (X) = X \cup \{y \in V: \text {存在} x \in X \text {使得} x y \text {是图的一条边} \}
$$

令 $P _ { 0 } = V$ 。对 $t = 1 , 2 , \cdots , T$ ，令 $P _ { t }$ 表示经历前 t 轮后仍未被击中的兔子在完成第 t 轮的停留或跳跃之后所有可能的位置；若不存在这样的逃生过程，就令 $P _ { t } = \emptyset$ 。于是

$$
P _ {t} = \Gamma (P _ {t - 1} \setminus H _ {t})
$$

因为这列射击方案保证在第 T 轮结束前命中兔子，所以 $P _ { T } = \emptyset$ 

下面证明 $P _ { 0 } , P _ { 1 } , \cdots , P _ { T }$ 两两不同。反设存在 $0 \leqslant i < j \leqslant T$ 使得 $P _ { i } = P _ { j }$ 。从原射击序列中删去第 $i + 1 , i + 2 , \cdots , j$ 轮，保留其余各轮。删去这些轮后，在完成原来的前 i 轮时，兔子的可能位置集合为 $P _ { i } = P _ { j }$ ；接着使用原来的第 $j + 1$ 轮及以后各轮，可能位置集合便依次与原序列中第 $j + 1$ 轮及以后的集合完全相同。因此删减后的序列仍保证射杀兔子，却比原序列更短，与 T 的最小性矛盾。

顶点集 V 共有 $2 ^ { N }$ 个子集，而上面的 $T + 1$ 个集合两两不同，故 $T + 1 \leqslant 2 ^ { N }$ ，从而$T \leqslant 2 ^ { N } - 1 < 2 ^ { N }$ 。所以猎人可以在不超过 $2 ^ { N }$ 轮内射杀兔子。
