解

方法一

答案是不能。

$f ( x ) = A x ^ { 2 } + B x + C$ ，其判别式为 $B ^ { 2 } - 4 A C ,$ 。在第一种变换之下，f(x) 变为$( A + B + C ) x ^ { 2 } + ( B + 2 A ) x + A$ 其判别式为

$$
(B + 2 A) ^ {2} - 4 A (A + B + C) = B ^ {2} + 4 A B + 4 A ^ {2} - 4 A ^ {2} - 4 A B - 4 A C = B ^ {2} - 4 A C
$$

在第二种变换之下，f(x) 变为 $C x ^ { 2 } + ( B - 2 C ) x + ( A - B + C )$ ，其判别式为

$$
(B - 2 C) ^ {2} - 4 C (A - B + C) = B ^ {2} - 4 B C + 4 C ^ {2} - 4 C A + 4 C B - 4 C ^ {2} = B ^ {2} - 4 A C
$$

所以所做的变换不改变二次三项式的判别式。

方法二

答案是不能。

令 $\varphi = { \frac { { \sqrt { 5 + 1 } } } { 2 } }$ 。易知

$$
\varphi = \frac {1}{\varphi} + 1, \quad \varphi - 1 = \frac {1}{\varphi}, \quad \varphi = \frac {1}{\varphi - 1}

所以所允许进行的两种变换就是把二次三项式在 $\varphi$ 处的值乘以或除以 $\varphi ^ { 2 }$ 。而这种变换是不能将 $\varphi ^ { 2 } + 4 \varphi + 3$ 变为 $\varphi ^ { 2 } + 1 0 \varphi + 9$ ，进而也不能变换两个多项式。

Zhautykov 2019 P6 

对一个三次多项式允许进行如下两种操作：

(1) 将 $P ( x )$ 变成 $x ^ { 3 } P ( 1 / x )$ 

(2) 将 $P ( x )$ 变成 $P ( x + 1 )$ 

问：能否经过有限次操作将 $x ^ { 3 } - 2$ 变为 $x ^ { 3 } - 3 x ^ { 2 } + 3 x - 3 ?$ 

解

设 $\alpha = \sqrt [ 3 ] { 2 }$ 是多项式 $x ^ { 3 } - 2$ 的实根。我们来分析题目中的两种操作对多项式根的影响：

(1) 若 $P ( x ) \mapsto x ^ { 3 } P ( 1 / x )$ ，则每个根 r 变为 $1 / r ;$ 

(2) 若 $P ( x ) \mapsto P ( x + 1 )$ ，则每个根 r 变为 $r - 1$ 

因此，经过任意有限次操作后，原多项式的所有根都会同时经过同一个分式线性变换 f 的作用，其中 $f$ 由

$$
T (x) = x - 1, \qquad S (x) = \frac {1}{x}
$$

经过有限次复合得到。于是 f 一定具有形式

$$
f (x) = \frac {a x + b}{c x + d}, \qquad a, b, c, d \in \mathbb {Z}, \quad a d - b c \neq 0
$$

另一方面，目标多项式为

$$
x ^ {3} - 3 x ^ {2} + 3 x - 3 = (x - 1) ^ {3} - 2
$$

因此它的唯一实根是 $\alpha + 1$ 。如果能够通过有限次操作将 $x ^ { 3 } - 2$ 变为 $x ^ { 3 } - 3 x ^ { 2 } + 3 x - 3$ ，那么原多项式的实根 $\alpha$ 必须在上述变换下变成 $\alpha + 1$ ，即 $f ( \alpha ) = \alpha + 1$ ，代入得到

$$
\frac {a \alpha + b}{c \alpha + d} = \alpha + 1
$$

两边交叉相乘，整理得到：

$$
0 = c \alpha^ {2} + (c + d - a) \alpha + (d - b)
$$

由于 $1 , \alpha , \alpha ^ { 2 }$ 在 $\mathbb { Q }$ 上线性无关，所以各项系数必须分别为零，即 $c = 0 , c + d - a = 0 , d - b = 0$ 。由 $c = 0$ 可知 $a = d , b = d$ ，因此

$$
f (x) = \frac {d x + d}{d} = x + 1
$$

也就是说，如果题目中的变换能够成功，那么由 $T ( x ) = x - 1$ 和 $S ( x ) = 1 / x$ 复合出来的变换中，必须出现 $x \mapsto x + 1$ 。下面说明这是不可能的。

考虑扩充实数集上的集合 $E = ( - \infty , 0 ] \cup \{ \infty \}$ ，这个集合对于 T 和 S 都封闭：

• 若 $x \leqslant 0$ ，则 $T ( x ) = x - 1 < 0 ;$ 

• 若 $x < 0$ ，则 $S ( x ) = 1 / x < 0$ 

• 并且 $S ( 0 ) = \infty , \ S ( \infty ) = 0 , \ T ( \infty ) = \infty .$ 

所以，任何由 T 和 S 有限次复合得到的变换 g，都满足 $g ( 0 ) \in E .$ 。但是若 $g ( x ) = x + 1$ ，则$g ( 0 ) = 1 \notin E$ ，矛盾！因此，变换 $x \mapsto x + 1$ 不可能由 $x \mapsto x - 1$ 和 $x \mapsto 1 / x$ 经过有限次复合得到，从而题目中的目标多项式也不可能通过有限次操作由 $x ^ { 3 } - 2$ 得到。
