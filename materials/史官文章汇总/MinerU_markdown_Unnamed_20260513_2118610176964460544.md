跟高斯取整相关的函数方程，先证明函数在基本区间内取值相同，再利用平移或缩放关系联系各个区间，确定整个函数。

IMO 2010 P1 

求所有函数 f : R R 使得对所有实数 $x , y \in \mathbb { R }$ 均有下式成立

$$
f (\lfloor x \rfloor y) = f (x) \lfloor f (y) \rfloor\tag{1}
$$

解

方法一

首先在 (1) 中令 $x \in [ 0 , 1 )$ 我们得到

$$
f (0) = f (x) \lfloor f (y) \rfloor\tag{2}
$$

对所有 $y \in \mathbb { R }$ 成立。现在我们分类讨论：

如果 $f ( 0 ) \neq 0$ ，我们再在 (2) 中取 $x = 0$ 可知 $\lfloor f ( y ) \rfloor = 1$ 对全体实数 y 成立。因此 (1) 改写为 $f ( \lfloor x \rfloor y ) = f ( x )$ ，在其中令 $y = 0$ 那么有 $f ( x ) = f ( 0 ) = C \neq 0$ 。最后，由 $\lfloor f ( y ) \rfloor = \lfloor C \rfloor = 1$ 获知 $1 \leqslant C < 2$ 。

如果 $f ( 0 ) = 0 \qquad $ C

假设存在 $0 < \beta < 1$ 使得 $f ( \beta ) \neq 0$ ，由式子 (2) 可知 $\lfloor f ( y ) \rfloor = 0$ 对全体实数 y 成立。因此在 (1) 中令 $x = 1$ 立即得到 $f \equiv 0$ ，但是 $f ( \beta ) \neq 0$ ，矛盾！

由此我们有 $f ( x ) = 0$ 对所有 $x \in [ 0 , 1 )$ 成立。注意到，所有实数 z 均可以表示成 $z = N \alpha$ 其中 $N \in \mathbb { Z } , \alpha \in [ 0 , 1 )$ ，所以

$$
f (z) = f (\lfloor N \rfloor \alpha) = f (N) \lfloor f (\alpha) \rfloor = 0
$$

直接验证可知，上式的函数均满足原方程。

方法二

假设 $\lfloor f ( y ) \rfloor = 0$ 对某些 y 成立，那么取 $x = 1$ 将得到 $f ( y ) = f ( 1 ) \lfloor f ( y ) \rfloor = 0$ 。因此如果对全体实数 y 均有 $\lfloor f ( y ) \rfloor = 0$ ，则 $f \equiv 0$ ，该函数满足要求。

如果存在某个实数 a 使得 $\lfloor f ( a ) \rfloor \neq 0$ ，那么我们有

$$
f (\lfloor x \rfloor a) = f (x) \lfloor f (a) \rfloor \implies f (x) = \frac {f (\lfloor x \rfloor a)}{\lfloor f (a) \rfloor}\tag{3}
$$

这意味着当 $\lfloor x _ { 1 } \rfloor = \lfloor x _ { 2 } \rfloor$ 时，有 $f ( x _ { 1 } ) = f ( x _ { 2 } )$ ，换言之 $f ( x ) = f ( \lfloor x \rfloor )$ 。同时我们可以假设 a是一个整数。

现在我们有

$$
f (a) = f \left(2 a \cdot \frac {1}{2}\right) = f (2 a) \lfloor f \left(\frac {1}{2}\right) \rfloor = f (2 a) \lfloor f (0) \rfloor
$$

推出 $\lfloor f ( 0 ) \rfloor \neq 0$ ，所以可以令 $a = 0$ 。因此等式 (3) 亦即

$$
f (x) = \frac {f (0)}{\lfloor f (0) \rfloor} = C \neq 0
$$

对所有 x 成立。此时原方程 (1) 变成 $C = C \lfloor C \rfloor$ ，由 $C \neq 0$ ，这等价于 $\lfloor C \rfloor = 1$ ，即 $1 \leqslant C < 2$ 综上，全部解为 $f \equiv 0$ ，以及常值函数 $f \equiv C$ ，其中 $1 \leqslant C < 2$ ；代回原方程均成立。

Zhautykov 2018 P5 

求所有实数 a，使得存在函数 f : R R，对任意实数 $x , y$ 都有

$$
f (x - f (y)) = f (x) + a \lfloor y \rfloor
$$

解

答案为 $a = - n ^ { 2 }$ ，其中 n 为任意整数。

当 $a = 0$ 时，取 $f \equiv 0$ 即可。以下设 $a \neq 0$ 

先证明对任意实数 u,v，都有

$$
f (u) = f (v) \quad \Longleftrightarrow \quad \lfloor u \rfloor = \lfloor v \rfloor\tag{1}
$$

若 $f ( u ) = f ( v )$ ，比较原方程中 $y = u$ 与 $y = v$ 的情形，可得 $a \lfloor u \rfloor = a \lfloor v \rfloor$ 。由 $a \neq 0$ ，得到$\lfloor u \rfloor = \lfloor v \rfloor$ 

反之，若 $\lfloor u \rfloor = \lfloor v \rfloor$ ，原方程给出 $f ( x - f ( u ) ) = f ( x - f ( v ) )$ 对任意实数 x 成立。由已经证明的方向可知

$$
\lfloor x - f (u) \rfloor = \lfloor x - f (v) \rfloor \quad (x \in \mathbb {R})
$$

分别取 $x = f ( u )$ 和 $x = f ( v )$ ，得到 $\lfloor f ( u ) - f ( v ) \rfloor = \lfloor f ( v ) - f ( u ) \rfloor = 0$ ，故 $f ( u ) - f ( v )$ 及其相反数均非负，只能有 $f ( u ) = f ( v )$ 。式 (1) 得证。特别地，f 在每个单位区间 $[ m , m + 1 )$ 上恒定，且不同单位区间的函数值不同。

接着证明 $f ( m ) \in \mathbb { Z }$ 对所有整数 m 成立。反设某个整数 m 满足 $f ( m ) = k + r$ ，其中$k \in \mathbb { Z }$ 且 $0 < r < 1$ 。由式 (1)，有 $f ( r ) = f ( 0 )$ 。在原方程中分别取 $( x , y ) = ( 0 , m )$ 和 $( r , m )$ 得到

$$
f (- f (m)) = f (0) + a m = f (r) + a m = f (r - f (m))
$$

然而 $\lfloor - f ( m ) \rfloor = - k - 1$ ，而 $\lfloor r - f ( m ) \rfloor = - k$ ，与式 (1) 矛盾。因此 f 在整数点的取值均为整数。

在原方程中取 $x = y = 0$ ，得到 $f ( - f ( 0 ) ) = f ( 0 )$ 。由式 (1)，有 $\lfloor - f ( 0 ) \rfloor = 0$ ，而 $f ( 0 ) \in \mathbb { Z }$ 故 $f ( 0 ) = 0$ 。记 $n = f ( 1 ) \in \mathbb { Z }$ 。再取 $( x , y ) = ( 0 , 1 )$ ，得到 $f ( - n ) = a$ ，所以 $a \in \mathbb { Z }$ 

以下将原方程限制在整数上。对任意整数 m，令 $x = f ( m ) , y = m$ ，可得

$$
f (f (m)) = - a m\tag{2}
$$

再在原方程中令 $y = f ( m )$ ，利用 $f ( m ) \in \mathbb { Z }$ 和式 (2)，得到

$$
f (x + a m) = f (x) + a f (m) \qquad (x, m \in \mathbb {Z})
$$

取 $m = 1$ ，便有 $f ( x + a ) = f ( x ) + a n$ 。结合 $f ( 0 ) = 0$ ，向正、负两个方向递推，得到 $f ( t a ) = t a n$ 对任意整数 t 成立。特别地， $f ( a ) = a n$ 且 $f ( a n ) = a n ^ { 2 }$ 。另一方面，在式 (2) 中取 $m = a$ ，可得

$$
a n ^ {2} = f (a n) = f (f (a)) = - a ^ {2}
$$

由 $a \neq 0$ ，得到 $a = - n ^ { 2 }$ 

最后，任取整数 n，令 $a = - n ^ { 2 }$ 并定义 $f ( x ) = n \lfloor x \rfloor$ 。由于 $n \lfloor y \rfloor$ 是整数，有

$$
\begin{array}{r l} f (x - f (y)) & = n \lfloor x - n \lfloor y \rfloor \rfloor \\ & = n \lfloor x \rfloor - n ^ {2} \lfloor y \rfloor \\ & = f (x) + a \lfloor y \rfloor \end{array}
$$

所以这些参数全部满足要求。

Mathematical Reflections J540 

求所有函数 $f : \mathbb { R } $ R，使得对任意实数 $x , y$ ，都有

$$
f (x + \lfloor y \rfloor) = \left\lfloor f (x) \right\rfloor + f (y)
$$

解

全部解为

$$
f (x) = k \lfloor x \rfloor + c \quad (k \in \mathbb {Z}, 0 \leqslant c <   1)
$$

在原方程中令 $x = y = 0$ ，得到 $\lfloor f ( 0 ) \rfloor = 0$ 。记 $c = f ( 0 )$ ，则 $0 \leqslant c < 1$ 。再令 $x = 0$ ，可得

$$
f (\lfloor y \rfloor) = \lfloor f (0) \rfloor + f (y) = f (y)
$$

因此 f 在每个单位区间 $[ m , m + 1 )$ 上恒定，整个函数由整数点上的取值确定。

记 $k = \lfloor f ( 1 ) \rfloor \in \mathbb { Z }$ 。对任意整数m，在原方程中取 $x = 1 , y = m$ ，得到 $f ( m + 1 ) = f ( m ) + k \mathrm { ~ , ~ }$ 由 $f ( 0 ) = c ;$ ，向正、负两个方向递推，便有 $f ( m ) = k m + c$ 对所有整数 m 成立。于是对任意实数 x，都有

$$
f (x) = f (\lfloor x \rfloor) = k \lfloor x \rfloor + c
$$

反之，任取整数 k 和实数 $c \in [ 0 , 1 )$ ，定义 $f ( x ) = k \lfloor x \rfloor + c _ { \circ }$ 由于 $k \lfloor x \rfloor$ 是整数，有$\lfloor f ( x ) \rfloor = k \lfloor x \rfloor$ ，从而

$$
\begin{array}{r l} f (x + \lfloor y \rfloor) & = k \lfloor x + \lfloor y \rfloor \rfloor + c \\ & = k \lfloor x \rfloor + k \lfloor y \rfloor + c \\ & = \lfloor f (x) \rfloor + f (y) \end{array}
$$

所以所列函数全部满足题意。
