All-Russian 2000 Grade 11 P8 

100×100 的方格表被染为 4 种颜色，每一行与每一列中都刚好有每种颜色的方格各 25个。求证：可以找到两行与两列，位于它们相交处的 4 个方格为 4 种不同颜色。

## 解

为方便起见，将 4 种颜色分别称为 1 至 4 号色。

假设不然，那么任何两行与任何两列相交处的 4 个方格中都有两个方格同色。我们将同一行中的两个异色方格称为一个“横对”，同一列中的两个异色方格称为一个“竖对”；同一行中的两个同色方格称为一对“横向重合”，同一列中的两个同色方格称为一对“纵向重合”。将异色方格对按颜色分为 6 种类型：{1, 2}, {1, 3}, {1, 4}, {2, 3}, {2, 4}, {3, 4}。

我们来考察表中的任意两行，并证明在它们中，至少有 25 对纵向重合。

首先，由我们的假设可知，由这两行中的方格构成的任何两个竖对中都有颜色相同的方格。于是不难看出，这两行中的竖对至多有三种不同类型：或者都含有某一种固定颜色 (以下以 1 号色为例)；或者皆为形如 {1,2},{1,3},{2,3} 的竖对 (当然也可以由另外三种颜色构成)。下面分别考察这两种情况。

如果所有的竖对中都含有 1 号色，那么异色对子的总数不会超过这两行中的 1 号色方格的总数，即 50。这就表明，这两行中至少有 50 对纵向重合。

再考虑所有的竖对皆为 {1,2},{1,3},{2,3} 的情况。此时，这两行中的所有的 4 号色的方格皆形成纵向重合，从而两行中至少有 25 对纵向重合。

这样，我们便证明了，任何两行中都至少有 25 对纵向重合。同理可证，任何两列中都至少有 25 对横向重合。如此一来，在我们的方格表中，共有不少于

$$
2 \cdot \binom {1 0 0} {2} \cdot 2 5 = 2 5 \cdot 9 9 \cdot 1 0 0
$$

对重合。但由于每一行与每一列中都刚好有每种颜色的方格各 25 个，重合的对子数目为

$$
2 0 0 \cdot \binom {2 5} {2} \cdot 4 = 2 4 \cdot 1 0 0 ^ {2}
$$

由于 $2 5 \cdot 9 9 > 2 4 \cdot 1 0 0$ ，所以产生矛盾！

因而，必有两行与两列，位于它们相交处的 4 个方格为 4 种不同颜色。

已知整数 n, k 满足 $n \geqslant 2 , k \geqslant \frac { 5 } { 2 } n - 1$ o

求证：任意选定 k 个整点 $( x , y ) \ ( 1 \leqslant x , y \leqslant n )$ ，总存在一个圆过至少四个选定的点。

解

设直线 $y = i$ 上有 $a _ { i }$ 个选定的点，并将这些点的横坐标按递增顺序记为 $x _ { 1 } ^ { ( i ) } < x _ { 2 } ^ { ( i ) } <$ $\cdots < x _ { a _ { i } } ^ { ( i ) }$ 。若 $a _ { i } \geqslant 3$ ，则

$$
x _ {1} ^ {(i)} + x _ {2} ^ {(i)} <   x _ {1} ^ {(i)} + x _ {3} ^ {(i)} <   \dots <   x _ {1} ^ {(i)} + x _ {a _ {i}} ^ {(i)} <   x _ {2} ^ {(i)} + x _ {a _ {i}} ^ {(i)} <   \dots <   x _ {a _ {i} - 1} ^ {(i)} + x _ {a _ {i}} ^ {(i)}
$$

所以这些横坐标中任意不同两项之和至少有 $2 a _ { i } - 3$ 个不同的值。当 $a _ { i } = 2$ 时结论显然成立；当 $a _ { i } \leqslant 1$ 时，右端不大于 0，结论仍成立。因此该估计对每个 i 都成立。由于 1,2,··· ,n 中任意不同两项之和的不同值恰有 $2 n - 3$ ，而

$$
\sum_ {i = 1} ^ {n} (2 a _ {i} - 3) = 2 \sum_ {i = 1} ^ {n} a _ {i} - 3 n = 2 k - 3 n \geqslant 5 n - 2 - 3 n = 2 n - 2 > 2 n - 3
$$

由抽屉原理知存在四个不同的点

$$
A = (x _ {u} ^ {(i)}, i), \quad B = (x _ {v} ^ {(i)}, i), \quad C = (x _ {r} ^ {(j)}, j), \quad D = (x _ {s} ^ {(j)}, j), \qquad i \neq j, \quad u \neq v, \quad r \neq s
$$

满足 $x _ { u } ^ { ( i ) } + x _ { v } ^ { ( i ) } = x _ { r } ^ { ( j ) } + x _ { s } ^ { ( j ) }$ 。记 $2 x _ { 0 } = x _ { u } ^ { ( i ) } + x _ { v } ^ { ( i ) } = x _ { r } ^ { ( j ) } + x _ { s } ^ { ( j ) }$ ，则直线 $x = x _ { 0 }$ 同时是线段$A B$ 与 CD 的垂直平分线。由于 $i \neq j$ ，可在这条直线上取一点 O，使得 $O A = O C ;$ ；于是$O A = O B = O C = O D$ ，故 $A , B , C , D$ 四点共圆。

CGMO 2016 P6 

求最大正整数 m，使得可以在 m 行 8 列的方格表的每个方格中填入 $C , G , M , O$ 这 4 个字母之一，并且具有如下性质：对于方格表的任意不同两行，至多存在一列，使得这两行在此列处的字母相同。

解

最大的 $m = 5$ ，首先给出构造，如下表。

$$
\begin{array}{c c c c c c c c} \hline C & C & C & C & G & G & G & G \\ \hline C & G & G & G & C & C & C & M \\ \hline G & C & M & M & C & M & M & C \\ M & M & C & O & M & C & O & C \\ \hline O & O & O & C & O & O & C & O \\ \hline \end{array}
$$

下面证明 $m \geqslant 6$ 无法满足题目要求。

事实上，若 $m = 6$ 时无法满足题目要求，当 $m > 6$ 时只需考虑其中 6 行即可说明无法满足题目要求，下面只需证明 $m = 6$ 时无法满足题目要求。

对任意整数 a，显然 $( a - 1 ) ( a - 2 ) \geqslant 0$ ，故 $a ( a - 1 ) \geqslant 2 ( a - 1 )$ ，即 ${ \binom { a } { 2 } } \geqslant a - 1$ 0考虑任意一列，设这一列的 $C , G , M , O$ 分别有 $a _ { 1 } , a _ { 2 } , a _ { 3 } , a _ { 4 }$ 个，则由上式知

$$
\binom {a _ {1}} {2} + \binom {a _ {2}} {2} + \binom {a _ {3}} {2} + \binom {a _ {4}} {2} \geqslant a _ {1} - 1 + a _ {2} - 1 + a _ {3} - 1 + a _ {4} - 1 = 2
$$

这说明至少有 2 个“行对”(即两个行组成的无序对)，每一对的两行在该列处的字母相同。由于 $2 \times 8 > { \binom { 6 } { 2 } }$ ，故存在两列，使得这两列对应的“行对”有重复，则对这个重复的“行对”所含的两行，至少有两列满足，这两行在此列的字母相同，矛盾！

综上所述，m 的最大值为 5。

设 n ⩾ 1。一个 $2 n \times 2 n$ 方格表的 $4 n ^ { 2 }$ 个单位方格分别被染成蓝色或红色。若由四个互不相同的单位方格组成的集合可以将其元素标记为 A,B,C,D，使得 A,B 位于同一行， $C , D$ 位于同一行， $A , C$ 位于同一列， $B , D$ 位于同一列，并且 A,D 为蓝色， $B , C$ 为红色，则称这个集合是“优美集合”。求优美集合数目的最大可能值。

## 解

所求的最大值为 $n ^ { 4 }$ 。

将方格表的行从上到下编号为 $1 , 2 , \cdots , 2 n$ 。对任意两行 $i < j$ ，设 $a _ { i , j }$ 为第 i 行是蓝色、第 $j$ 行是红色的列数， $b _ { i , j }$ 为第 i 行是红色、第 $j$ 行是蓝色的列数，并令 $d _ { i , j } = a _ { i , j } + b _ { i , j }$ 。

以第 $i , j$ 两行为所在行的优美集合恰有 $a _ { i , j } b _ { i , j }$ 个。事实上，它的两列中必须有一列的颜色从上到下依次为蓝、红，另一列的颜色从上到下依次为红、蓝；反过来，任取这样两列也唯一确定一个优美集合。由均值不等式及 $d _ { i , j }$ ⩽ 2n，有

$$
a _ {i, j} b _ {i, j} \leqslant \frac {(a _ {i , j} + b _ {i , j}) ^ {2}}{4} = \frac {d _ {i , j} ^ {2}}{4} \leqslant \frac {n d _ {i , j}}{2}
$$

下面对所有 $d _ { i , j }$ 的和进行双重计数。设第 k 列有 $x _ { k }$ 个蓝色方格，则这一列中异色方格对的数目为 $x _ { k } ( 2 n - x _ { k } ) \leqslant n ^ { 2 }$ 。因此

$$
\sum_ {1 \leqslant i <   j \leqslant 2 n} d _ {i, j} = \sum_ {k = 1} ^ {2 n} x _ {k} (2 n - x _ {k}) \leqslant 2 n ^ {3}
$$

设优美集合的总数为 N。每个优美集合的两行是唯一确定的，故

$$
N = \sum_ {1 \leqslant i <   j \leqslant 2 n} a _ {i, j} b _ {i, j} \leqslant \frac {n}{2} \sum_ {1 \leqslant i <   j \leqslant 2 n} d _ {i, j} \leqslant n ^ {4}
$$

最后说明此上界可以达到。将方格表的行和列都等分为两组，每组各有 n 行或 n 列；把左上、右下两个 $n \times n$ 子表全部染成蓝色，把右上、左下两个 $n \times n$ 子表全部染成红色。此时，四个方格构成优美集合，当且仅当它们所在的两行分属两个行组且所在的两列分属两个列组。因此优美集合恰有 $n ^ { 2 } \cdot n ^ { 2 } = n ^ { 4 }$ 个。

综上，优美集合数目的最大可能值为 $n ^ { 4 }$ 。

设 $S = \{ ( i , j ) | i , j = 1 , 2 , \cdots , 1 0 0 \}$ 是直角坐标系平面上的 $1 0 0 \times 1 0 0$ 个整点构成的集合。将 S 中的每个点染为给定的四种颜色之一。求以 S 中四个颜色互不相同的点为顶点，且边平行于坐标轴的矩形个数的最大可能值。

## 解

所求的最大值为 9,375,000。

设四种颜色为 A,B,C,D。令 $R _ { i } = \{ ( x , i ) | x = 1 , 2 , \cdot \cdot \cdot , 1 0 0 \}$ 为整点正方形的第 i 行，$T _ { j } = \{ ( j , y ) | y = 1 , 2 , \cdots , 1 0 0 \}$ 为整点正方形的第 j 列。称以 S 中四个颜色互不相同的点为顶点，且边平行于坐标轴的矩形为“四色矩形”。

引理：若 $R _ { i } , R _ { j }$ 恰好在 k 个位置上同色，则这两行产生的四色矩形的个数不超过 (100−$k ) ^ { 2 } / 4$ o

引理证明：若 $R _ { i } , R _ { j }$ 在某个位置上同色，则这两个点不可能属于一个四色矩形。

若 $( x , i ) , ( x , j )$ 为 A,B 两色，则当且仅当 $( y , i ) , ( y , j )$ 为 C,D 两色时这四点构成四色矩形。其他情形同理。

在 100 对格点 $( x , i ) , ( x , j )$ 中 $( 1 \leqslant x \leqslant 1 0 0 )$ ，设有 $l _ { 1 }$ 对格点为 A,B 两色，设有 $l _ { 2 }$ 对格点为 A,C 两色，设有 $l _ { 3 }$ 对格点为 A,D 两色，设有 $l _ { 4 }$ 对格点为 $B , C$ 两色，设有 $l _ { 5 }$ 对格点为 B,D 两色，设有 $l _ { 6 }$ 对格点为 C,D 两色。则 $l _ { 1 } + l _ { 2 } + \cdot \cdot \cdot + l _ { 6 } = 1 0 0 - k$ 

注意到 $R _ { i }$ 与 $R _ { j }$ 恰好生成 $l _ { 1 } l _ { 6 } + l _ { 2 } l _ { 5 } + l _ { 3 } l _ { 4 }$ 个四色矩形，而

$$
\begin{array}{r l} & l _ {1} l _ {6} + l _ {2} l _ {5} + l _ {3} l _ {4} \leqslant \frac {(l _ {1} + l _ {6}) ^ {2}}{4} + \frac {(l _ {2} + l _ {5}) ^ {2}}{4} + \frac {(l _ {3} + l _ {4}) ^ {2}}{4} \\ & \quad \leqslant \frac {(l _ {1} + l _ {2} + l _ {3} + l _ {4} + l _ {5} + l _ {6}) ^ {2}}{4} \\ & \quad = \frac {(1 0 0 - k) ^ {2}}{4} \end{array}
$$

故引理获证。

回到原题。设 $R _ { i }$ 与 $R _ { j }$ 在 $k _ { i , j }$ 个位置上同色，则 $\textstyle \sum _ { 1 \leqslant i < j \leqslant 1 0 0 } k _ { i , j }$ 恰为横坐标相同的同色点对的个数。我们从每一列出发对它进行计数，设 $T _ { j }$ 中 $A , B , C , D$ 四色各有 $a _ { j } , b _ { j } , c _ { j } , d _ { j }$ 个$( a _ { j } + b _ { j } + c _ { j } + d _ { j } = 1 0 0 )$ ，则 $T _ { j }$ 中同色点对恰有 $\textstyle { \binom { a _ { j } } { 2 } } + { \binom { b _ { j } } { 2 } } + { \binom { c _ { j } } { 2 } } + { \binom { d _ { j } } { 2 } }$ 个。从而

$$
\begin{array}{l} \sum_ {1 \leqslant i <   j \leqslant 1 0 0} k _ {i, j} = \sum_ {j = 1} ^ {1 0 0} \left(\binom {a _ {j}} {2} + \binom {b _ {j}} {2} + \binom {c _ {j}} {2} + \binom {d _ {j}} {2}\right) \\ \quad = \sum_ {j = 1} ^ {1 0 0} \left[ \frac {1}{2} (a _ {j} ^ {2} + b _ {j} ^ {2} + c _ {j} ^ {2} + d _ {j} ^ {2}) - \frac {1}{2} (a _ {j} + b _ {j} + c _ {j} + d _ {j}) \right] \\ \quad \geqslant \sum_ {j = 1} ^ {1 0 0} \left[ \frac {1}{8} (a _ {j} + b _ {j} + c _ {j} + d _ {j}) ^ {2} - \frac {1}{2} (a _ {j} + b _ {j} + c _ {j} + d _ {j}) \right] \\ \quad = 1 0 0 \left(\frac {1}{8} \cdot 1 0 0 ^ {2} - \frac {1}{2} \cdot 1 0 0\right) \\ \quad = 1 2 0, 0 0 0 \end{array}
$$

结合引理及上式可知四色矩形的个数不超过

$$
\begin{array}{l} \sum_ {1 \leqslant i <   j \leqslant 1 0 0} \frac {(1 0 0 - k _ {i , j}) ^ {2}}{4} \leqslant \sum_ {1 \leqslant i <   j \leqslant 1 0 0} \frac {1 0 0 (1 0 0 - k _ {i , j})}{4} \\ = 2 5 0 0 \binom {1 0 0} {2} - 2 5 \sum_ {1 \leqslant i <   j \leqslant 1 0 0} k _ {i, j} \\ \leqslant 9, 3 7 5, 0 0 0 \end{array}
$$
