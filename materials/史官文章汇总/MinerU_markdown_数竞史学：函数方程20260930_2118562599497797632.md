## 1.1 平移差分与可加增量

CTST 2019 P5 

设 Q 为全体有理数构成的集合。求所有函数 $f : \mathbb { Q } \to \mathbb { Q }$ ，满足对任意有理数 $x , y$ 均有

$$
4 f (x) f (y) + \frac {1}{2} = f \left(2 x y + \frac {1}{2}\right) + f (x - y)
$$

解

在原方程中令 $y = 0$ ，整理得

$$
(4 f (0) - 1) f (x) = f \left(\frac {1}{2}\right) - \frac {1}{2}
$$

若 f 为常数函数，设 $f ( x ) = c$ ，则 $4 c ^ { 2 } + 1 / 2 = 2 c$ ，但这个关于 c 的方程没有实数解。因此 f 不是常数函数。由上式可知 $4 f ( 0 ) - 1 = 0$ 且 $f ( 1 / 2 ) - 1 / 2 = 0$ ，即 $f ( 0 ) = 1 / 4$ $f ( 1 / 2 ) = 1 / 2$ 

在原方程中令 $y = 1 / 2$ ，得

$$
2 f (x) + \frac {1}{2} = f \left(x + \frac {1}{2}\right) + f \left(x - \frac {1}{2}\right)
$$

令 $g ( x ) = f ( x + 1 / 2 ) - f ( x )$ ，则

$$
g \left(x + \frac {1}{2}\right) = g (x) + \frac {1}{2}
$$

反复使用上式可得，对任意整数 k，均有 $g ( x + k / 2 ) = g ( x ) + k / 2$ 

在原方程中交换 $x , y$ ，比较所得等式与原式，得到 $f ( x - y ) = f ( y - x )$ 。由于 $x - y$ 可以遍历 $\mathbb { Q }$ ，故 f 为偶函数。再将原方程中的 y 换成 −y，并与原方程比较，得到

$$
f \left(2 x y + \frac {1}{2}\right) + f (x - y) = f \left(- 2 x y + \frac {1}{2}\right) + f (x + y)
$$

利用 f 的偶性以及 $g ( x - 1 / 2 ) = g ( x ) - 1 / 2$ ，可得

$$
\begin{array}{r l} f (x + y) - f (x - y) & = f \left(2 x y + \frac {1}{2}\right) - f \left(2 x y - \frac {1}{2}\right) \\ & = g (2 x y) + g \left(2 x y - \frac {1}{2}\right) \\ & = 2 g (2 x y) - \frac {1}{2} \end{array}
$$

令 $h ( x ) = g ( x ) - 1 / 4$ ，上式化为

$$
f (x + y) - f (x - y) = 2 h (2 x y)\tag{1}
$$

对任意正整数 n，在 (1) 中令 $y = n / 2$ ，并使用 $g ( x + k / 2 ) = g ( x ) + k / 2$ ，得到

$$
\begin{array}{l} 2 h (n x) = f \left(x + \frac {n}{2}\right) - f \left(x - \frac {n}{2}\right) \\ \qquad = \sum_ {i = - n} ^ {n - 1} \left[ f \left(x + \frac {i + 1}{2}\right) - f \left(x + \frac {i}{2}\right) \right] \\ \qquad = \sum_ {i = - n} ^ {n - 1} g \left(x + \frac {i}{2}\right) \\ \qquad = \sum_ {i = - n} ^ {n - 1} \left(g (x) + \frac {i}{2}\right) \\ \qquad = 2 n g (x) - \frac {n}{2} = 2 n h (x) \end{array}
$$

故 $h ( n x ) = n h ( x )$ 。在 (1) 中将 y 换成 −y，可知 $h ( - 2 x y ) = - h ( 2 x y )$ 。由于 2xy 可以遍历 $\mathbb { Q }$ ，故 h 是奇函数，从而对任意整数 n 和有理数 x，均有 $h ( n x ) = n h ( x )$ 

现在任取有理数 $r = p / q$ ，其中 $p \in \mathbb { Z } , q \in \mathbb { Z } _ { > 0 }$ 。由整数齐次性可得

$$
q h \left(\frac {p}{q} x\right) = h (p x) = p h (x)
$$

所以 $h ( r x ) = r h ( x )$ 。特别地，对任意 $t \in \mathbb { Q }$ ，有 $h ( t ) = t h ( 1 ) = 2 t h ( 1 / 2 )$ 

由 h 和 $g$ 的定义，

$$
h \left(\frac {1}{2}\right) = g \left(\frac {1}{2}\right) - \frac {1}{4} = f (1) - f \left(\frac {1}{2}\right) - \frac {1}{4} = f (1) - \frac {3}{4}
$$

在原方程中令 $x = y = 1 / 2$ ，由 $f ( 0 ) = 1 / 4$ 和 $f ( 1 / 2 ) = 1 / 2$ ，得到 $f ( 1 ) = 5 / 4$ ，因而$h ( 1 / 2 ) = 1 / 2$ 。于是 $h ( t ) = t$ 对任意 $t \in \mathbb { Q }$ 成立。

最后，在 (1) 中令 $y = x$ ，得到

$$
f (2 x) = 2 h (2 x ^ {2}) + f (0) = 4 x ^ {2} + \frac {1}{4}
$$

由于 $2 x$ 可以遍历 $\mathbb { Q }$ ，故

$$
f (x) = x ^ {2} + \frac {1}{4}
$$

直接代入可知该函数满足原方程。因此原方程的唯一解为 $f ( x ) = x ^ { 2 } + 1 / 4$ 

总结： 把原方程化为与基点无关的平移增量，通过比较平移的不同分解得到可加性或有理数齐次性，再恢复原函数。

## 1.2 换元与受限可加性

Korea Final Round 2020 P3 

求所有的函数 $f : \mathbb { Q } _ { > 0 } \to$ R 使得

$$
f (x) + f (y) + f (z) = 1
$$

对任意满足关系式 $x + y + z + 1 = 4 x y z$ 的正有理数 $x , y , z$ 成 $\underline { { \stackrel { \triangledown } { \cdot } \vec { \bigtriangledown } } }$ 。

解

答案为：对任意常数 $\lambda \in \mathbb { R }$ ，函数

$$
f (t) = \frac {\lambda}{1 + 2 t} + \frac {1 - \lambda}{3} \qquad (t \in \mathbb {Q} _ {> 0})
$$

先将题设中的三元约束标准化。通分可知，对正有理数 $x , y , z$ ，有

$$
x + y + z + 1 = 4 x y z \quad \Longleftrightarrow \quad \frac {1}{1 + 2 x} + \frac {1}{1 + 2 y} + \frac {1}{1 + 2 z} = 1\tag{1}
$$

映射 $x \mapsto 1 / ( 1 + 2 x )$ 是 $\mathbb { Q } _ { > 0 }$ 到 $\mathbb { Q } \cap ( 0 , 1 )$ 的双射，其逆映射为 $u \mapsto ( 1 - u ) / ( 2 u )$ 。定义 $g : \mathbb { Q } \cap ( 0 , 1 ) \to$ R 为

$$
g (u) = f \left(\frac {1 - u}{2 u}\right)
$$

由 (1)，原条件等价于

$$
g (u) + g (v) + g (w) = 1\tag{2}
$$

对任意满足 $u + v + w = 1$ 的正有理数 $u , v , w$ 成立。

定义 $h : \mathbb { Q } \cap ( - 1 / 3 , 2 / 3 ) \to$ R 为

$$
h (t) = g \left(t + \frac {1}{3}\right) - \frac {1}{3}
$$

那么对定义域内任意满足 $a + b + c = 0$ 的有理数 $a , b , c $ ，均有

$$
h (a) + h (b) + h (c) = 0\tag{3}
$$

在 (3) 中先后取 $( a , b , c ) \ : = \ : ( 0 , 0 , 0 )$ 与 $( t , - t , 0 )$ ，可得 $h ( 0 ) = 0$ ，且当 $| t | < 1 / 3$ 时有 $h ( - t ) = - h ( t )$ 。若正有理数 $a , b$ 满足 $0 < a , b < 1 / 3$ ，则把 $( - a , - b , a + b )$ 代入(3)，得到 $h ( a + b ) = h ( a ) + h ( b )$ 。进而，对任意正有理数 $a , b$ 满足 $a + b < 2 / 3$ ，由于$a / 2 , b / 2 , ( a + b ) / 2$ 均小于 1/3，有

$$
h (a + b) = 2 h \left(\frac {a + b}{2}\right) = 2 h \left(\frac {a}{2}\right) + 2 h \left(\frac {b}{2}\right) = h (a) + h (b)\tag{4}
$$

令 $\lambda = 3 h ( 1 / 3 )$ 。对任意正有理数 $r = p / q < 2 / 3$ ，反复应用 (4) 可得

$$
h \left(\frac {1}{3}\right) = q h \left(\frac {1}{3 q}\right), \quad h \left(\frac {p}{q}\right) = 3 p h \left(\frac {1}{3 q}\right) = \lambda \frac {p}{q}
$$

所以 $h ( r ) = \lambda r$ 对全部正有理数 $r < 2 / 3$ 成立；再由 $h ( - r ) = - h ( r )$ ，这一结论对整个定义域都成立。还原 $g$ 与 $f$ ，便得到

$$
g (u) = \frac {1}{3} + \lambda \left(u - \frac {1}{3}\right), \quad f (t) = \frac {\lambda}{1 + 2 t} + \frac {1 - \lambda}{3}
$$

由于 f 的值域为 R，参数 λ 不受其他限制。

最后，任取 $\lambda \in \mathbb { R }$ 并按上述公式定义 $f _ { \mathrm { ~ e ~ } }$ 。若正有理数 $x , y , z$ 满足题设约束，则由(1) 可得

$$
f (x) + f (y) + f (z) = \lambda \left(\frac {1}{1 + 2 x} + \frac {1}{1 + 2 y} + \frac {1}{1 + 2 z}\right) + 1 - \lambda = 1
$$

故上述函数全部满足要求，因而它们恰为所有解。

总结： 通过换元、参数覆盖或中心化显露可加关系，再利用辅助变量或分割增量扩大适用范围，结合定义域与正则条件确定函数。

## 1.3 近似可加性与线性结构

Baltic Way 2025 P3 

设函数 $f : \mathbb { Q } \to \mathbb { Q }$ 满足：对任意 $x , y \in \mathbb { Q }$ ，均有 $f ( x ) + f ( y ) \geqslant f ( x + y )$ 。证明：存在 $\alpha \in$ R，使得对所有 $x \in \mathbb { Q }$ ，均有 $f ( x ) \geqslant \alpha x$ 

解

取 $x = y = 0$ ，得 $f ( 0 ) \geqslant 0$ 。反复应用题设不等式可知，对任意正整数 n 和任意$x \in \mathbb { Q }$ ，均有

$$
n f (x) \geqslant f (n x)
$$

事实上，这一结论可直接对 n 作归纳得到。

任取有理数 $x < 0 < y$ 。因为 $- x / y$ 是正有理数，所以存在正整数 $m , n$ 使 $m x + n y =$ 0。由上面的结论及题设不等式，

$$
m f (x) + n f (y) \geqslant f (m x) + f (n y) \geqslant f (0) \geqslant 0
$$

将此式除以正数 $n y = - m x$ ，得到

$$
\frac {f (x)}{x} \leqslant \frac {f (y)}{y}
$$

令

$$
S = \left\{\frac {f (x)}{x}: x \in \mathbb {Q}, x <   0 \right\}, \quad T = \left\{\frac {f (y)}{y}: y \in \mathbb {Q}, y > 0 \right\}
$$

上面已经证明， $S$ 的每个元素都不大于 T 的每个元素。特别地， $S$ 非空且有上界，所以可令 $\alpha = \operatorname* { s u p } S \in \mathbb { R }$ ；同时， $T$ 中的每个元素都是 S 的上界，故

$$
{\frac {f (x)}{x}} \leqslant \alpha \leqslant {\frac {f (y)}{y}} \quad (x <   0 <   y)
$$

当 $x < 0$ 时，左侧不等式给出 $f ( x ) \geqslant \alpha x ;$ 当 $x > 0$ 时，右侧不等式给出同一结论；而$x = 0$ 时，结论就是已经证明的 $f ( 0 ) \geqslant 0$ 。因此所求实数 α 存在。

总结： 把单向或有界的可加误差沿整数倍放大并归一化，提取线性支撑、取整型结构或精确可加主部。

## 1.4 平移子群与陪集传播

IMOSL 2014 A4 

求所有的函数 f : Z → Z 使得对任意整数 m,n 均有

$$
f (f (m) + n) + f (m) = f (n) + f (3 m) + 2 0 1 4
$$

## 解

答案为 $f ( x ) = 2 x + 1 0 0 7$ ，直接代入可验证其满足题设。下面证明没有其他解。

称整数 t 为 f 的拟周期，如果 $f ( x + t ) - f ( x )$ 不依赖于整数 $x _ { \circ }$ 。若 $s , t$ 是拟周期，对应的增量分别为 A, B，则

$$
f (x + s + t) - f (x) = A + B, \qquad f (x - t) - f (x) = - B
$$

所以拟周期的任意整数线性组合仍是拟周期。

将原方程整理为

$$
f (n + f (m)) - f (n) = f (3 m) - f (m) + 2 0 1 4\tag{1}
$$

可知每个函数值 $f ( m )$ 都是拟周期。函数 f 不恒为零，否则与原方程矛盾。令 $d > 0$ 为全体函数值的最大公因数。这个最大公因数可由有限个函数值取得，故由 Bézout 等式，存在整数 $m _ { 1 } , \cdots , m _ { r }$ 及 $a _ { 1 } , \cdots , a _ { r }$ ，使

$$
d = a _ {1} f (m _ {1}) + \dots + a _ {r} f (m _ {r})
$$

因此 d 也是拟周期。由于 d 整除每个函数值，增量 $f ( x + d ) - f ( x )$ 也被 d 整除，故存在整数 q，使得

$$
f (x + k d) = f (x) + k q d \qquad (x, k \in \mathbb {Z})\tag{2}
$$

特别地，因 $d \mid f ( m )$ ，式 (1)、(2) 给出

$$
f (3 m) = (q + 1) f (m) - 2 0 1 4\tag{3}
$$

令 $c = f ( 0 )$ ，在式 (3) 中取 $m = 0$ ，得到 $q c = 2 0 1 4$ ，所以 $q \neq 0$ 

再将式 (3) 中的 m 换成 $m + d$ ，并用式 (2)，得到

$$
f (3 m) + 3 q d = (q + 1) \bigl (f (m) + q d \bigr) - 2 0 1 4
$$

与式 (3) 相减，得 $3 q d = ( q + 1 ) q d \cdot$ 。因为 $q d \neq 0$ ，所以 $q = 2$ ，进而 $c = 1 0 0 7$ 

令 $r ( x ) = f ( x ) - 2 x - 1 0 0 7$ 。由式 (2)、(3)，有

$$
r (x + d) = r (x), \qquad r (3 x) = 3 r (x)
$$

整数上的 d-周期函数只取有限多个值，故存在 $M \geqslant 0$ ，使 $| r ( x ) | \leqslant M$ 对一切整数 x 成立。固定任意整数 x，反复使用第二个关系，得到

$$
3 ^ {k} | r (x) | = | r (3 ^ {k} x) | \leqslant M \quad (k = 0, 1, 2, \dots)
$$

令 $k \to \infty$ ，可知 $r ( x ) = 0$ 。因此 $f ( x ) = 2 x + 1 0 0 7$ 对所有整数 x 成立。

总结： 利用平移量或特殊取值点的加法结构确定步长，沿其陪集传播函数值，再由附加关系确定或构造函数。

## 1.5 单调性与乘法关系

CTST 2003 P28 

求所有单调不减函数 $f : \mathbb { Z } _ { > 0 } \to$ R，满足对任意互质的正整数 $m , n$ ，都有

$$
f (m n) = f (m) f (n)
$$

## 解

零函数满足条件。以下设 f 非零。由 $f ( n ) = f ( 1 ) f ( n )$ 得 $f ( 1 ) = 1$ ，单调性又给出 $f ( n ) \geqslant 1$ 。令 $F ( n ) = \log f ( n )$ ，则 F 单调不减，且对互质的正整数 m, n，有$F ( m n ) = F ( m ) + F ( n )$ 。

固定整数 $m \geqslant 2 .$ 。由于 m 分别与 $m ^ { r } - 1 , m ^ { r } + 1$ 互质，对每个正整数 r，单调性及互质积性给出

$$
F (m ^ {r + 1} - 1) \geqslant F \bigl (m (m ^ {r} - 1) \bigr) = F (m) + F (m ^ {r} - 1)
$$

$$
F (m ^ {r + 1} + 1) \leqslant F \bigl (m (m ^ {r} + 1) \bigr) = F (m) + F (m ^ {r} + 1)
$$

反复应用，并将 $F ( m ^ { k } )$ 夹在两边，得到

$$
(k - 1) F (m) + F (m - 1) \leqslant F \left(m ^ {k}\right) \leqslant (k - 1) F (m) + F (m + 1)
$$

所以

$$
\lim _ {k \to \infty} \frac {F (m ^ {k})}{k} = F (m)
$$

取 $s = \left\lfloor k \log _ { 2 } m \right\rfloor$ ，则 $2 ^ { s } \leqslant m ^ { k } < 2 ^ { s + 1 }$ 。把上述估计用于底数 2，再用单调性，得到

$$
(s - 1) F (2) \leqslant F (2 ^ {s}) \leqslant F (m ^ {k}) \leqslant F (2 ^ {s + 1}) \leqslant s F (2) + F (3)
$$

除以 k，令 $k  \infty$ ，利用 $s / k  \log _ { 2 } m$ ，可得 $F ( m ) = F ( 2 ) \log _ { 2 } m$ 。故 $f ( m ) = m ^ { \alpha }$ 其中 $\alpha = \log _ { 2 } f ( 2 ) \geqslant 0$ 。结合 $f ( 1 ) = 1$ ，这一结论对所有正整数成立。

反过来，零函数以及所有 $f ( n ) = n ^ { \alpha } \left( \alpha \geqslant 0 \right)$ 均满足题设条件，故它们恰为全部解。

总结： 利用单调性比较适当的乘积或幂次，再借积性分解函数值，通过消元、离散夹逼或取根极限确定函数。

## 1.6 乘法关系与质数指数

Romania National 2017 Grade 10 P2 

若对任意正有理数 x, y 均有

$$
f (x y) = f (x) + f (y)
$$

则称映射 $f : \mathbb { Q } _ { + } \to \mathbb { Q }$ 具有性质 $P .$ 。

(a) 证明：不存在具有性质 P 的单射 f；(b) 是否存在具有性质 P 的满射 f？

解

(a) 令 $x = y = 1$ ，得到 $f ( 1 ) = 0$ 。对任意正有理数 x，由 $f ( x ) + f ( x ^ { - 1 } ) = f ( 1 )$ 得$f ( x ^ { - 1 } ) = - f ( x )$ ，再结合数学归纳法可知，对任意整数 n 都有

$$
f (x ^ {n}) = n f (x)
$$

假设 f 是单射。任取两个不同的质数 $p , q$ 。由于 $p , q \neq 1$ 且 $f ( 1 ) = 0$ ，有 $f ( p ) , f ( q ) \neq 0$ 0取非零整数 $a , b$ 与正整数 c，使得 $f ( p ) = a / c , f ( q ) = b / c _ { \mathrm { c } }$ 。于是

$$
f (p ^ {b}) = b f (p) = \frac {a b}{c} = a f (q) = f (q ^ {a})
$$
