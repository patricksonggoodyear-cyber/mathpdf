## IMO 1998 P2

某次比赛有 a 名参赛者和 b 名裁判，其中 a 为正整数， $b \geqslant 3$ 为奇数。每名裁判对每名参赛者的评定均为“通过”或“不通过”。假设任意两名不同的裁判对至多 k 名参赛者的评定相同。求证： ${ \frac { k } { a } } \geqslant { \frac { b - 1 } { 2 b } }$ 

解

记 N 为所有二元组 $( i , \{ p , q \} )$ 的个数，其中 i 表示一名参赛者， $\{ p , q \}$ 表示两名不同裁判组成的无序对，且这两名裁判对该参赛者的评定相同。按照裁判对计数，由题设得到

$$
N \leqslant k {\binom {b} {2}} = \frac {k b (b - 1)}{2}
$$

另一方面，设第 i 名参赛者被 $r _ { i }$ 名裁判评为“通过”，则其余 $b - r _ { i }$ 名裁判都评为“不通过”。因此，对这名参赛者评定相同的裁判对共有 ${ \binom { r _ { i } } { 2 } } + { \binom { b - r _ { i } } { 2 } }$ 对。按照参赛者计数，得到

$$
N = \sum_ {i = 1} ^ {a} \left[ \binom {r _ {i}} {2} + \binom {b - r _ {i}} {2} \right]
$$

因为 b 为奇数， $2 r _ { i } - b$ 是非零奇整数，所以 $( 2 r _ { i } - b ) ^ { 2 } \geqslant 1$ 。于是

$$
\binom {r _ {i}} {2} + \binom {b - r _ {i}} {2} = \frac {(2 r _ {i} - b) ^ {2} + b (b - 2)}{4} \geqslant \frac {(b - 1) ^ {2}}{4}
$$

对所有参赛者求和，并与前面的上界结合，得到

$$
\frac {a (b - 1) ^ {2}}{4} \leqslant N \leqslant \frac {k b (b - 1)}{2}
$$

由于 $a > 0$ 且 $b - 1 > 0$ ，约去相应的正因子，即得 ${ \frac { k } { a } } \geqslant { \frac { b - 1 } { 2 b } }$ 。

CMO 1993 P5 

10 个人到书店买书，已知 (1) 每人都买了三种书；(2) 任何两人所买的书中都至少有一种相同。问：购买人数最多的一种书最少有几人购买？说明理由。

解

设所有出现过的书共有若干种，第 j 种书有 $t _ { j }$ 人购买。由于每人买三种书，

$$
\sum_ {j} t _ {j} = 3 0
$$

另一方面，按共同购买的书来计数人对。每一对人至少被计数一次，所以

$$
\sum_ {j} \binom {t _ {j}} {2} \geqslant \binom {1 0} {2} = 4 5
$$

若每种书至多有 4 人购买，则对每个 $0 \leqslant t _ { j } \leqslant 4$ 都有

$$
\binom {t _ {j}} {2} \leqslant \frac {3 t _ {j}}{2}
$$

且等号仅在 $t _ { j } = 0$ 或 $t _ { j } = 4$ 时成立。因此 $\sum _ { j } { \binom { t _ { j } } { 2 } } \leqslant 4 5$ 。要与前一不等式相容，必须处处取等号，即每个正的 $t _ { j }$ 都等于 4，但这与 $\textstyle \sum _ { j } t _ { j } = 3 0$ 不是 4 的倍数矛盾。故至少有一种书被不少于 5 人购买。

下面说明 5 可以达到。用 1,2,··· ,7 表示七种书，让十个人所买的三种书依次为

$$
\begin{array}{l} \{1, 2, 3 \}, \quad \{1, 4, 5 \}, \quad \{1, 6, 7 \}, \quad \{2, 4, 6 \}, \quad \{2, 5, 7 \}, \\ \{3, 4, 7 \}, \quad \{3, 5, 6 \}, \quad \{1, 2, 3 \}, \quad \{2, 4, 6 \}, \quad \{3, 5, 6 \} \end{array}
$$

前七个三元组中任意两个都有一个共同元素，后三个是其中三个三元组的重复，故任意两人所买的书都至少有一种相同。七种书的购买人数依次为 4,5,5,4,4,5,3，最大值为 5。因此所求最小值为 5。

CTST 1994 P16 

设 $S = \{ 1 , 2 , 3 , 4 , 5 , 6 , 7 , 8 , 9 , 1 0 \}$ , $A _ { 1 } , A _ { 2 } , \cdots , A _ { k }$ 是 S 的子集，满足

(1) $\left| A _ { i } \right| = 5 \left( 1 \leqslant i \leqslant k \right)$ ； 

(2) $\vert A _ { i } \cap A _ { j } \vert \leqslant 2 \left( 1 \leqslant i < j \leqslant k \right)$ 

求这样一批子集个数 k 的最大值。

解

方法一

作 $1 0 \times k$ 的表格，其中第 i 行，第 j 列处的元素为

$$
a _ {i j} = \left\{ \begin{array}{l l} 1 & i \in A _ {j} \\ 0 & i \notin A _ {j} \end{array} \right. \quad i = 1, 2, \dots , 1 0, j = 1, 2, \dots , k
$$

于是表中第 i 行元素之和 $\begin{array} { r } { l _ { i } = \sum _ { j = 1 } ^ { k } a _ { i j } } \end{array}$ 表示 i 属于 $A _ { 1 } , A _ { 2 } , \cdots , A _ { k }$ 中 $l _ { i }$ 个集合，而第 $j$ 列元素之和 $\textstyle \sum _ { i = 1 } ^ { 1 0 } a _ { i j } = | A _ { j } |$ 表示集合 $A _ { j }$ 中元素个数，由已知条件 (1) 有 $\textstyle \sum _ { i = 1 } ^ { 1 0 } a _ { i j } = | A _ { j } | = 5$ ，所以

$$
\sum_ {i = 1} ^ {1 0} l _ {i} = \sum_ {i = 1} ^ {1 0} \sum_ {j = 1} ^ {k} a _ {i j} = \sum_ {j = 1} ^ {k} \sum_ {i = 1} ^ {1 0} a _ {i j} = \sum_ {j = 1} ^ {k} | A _ {j} | = 5 k\tag{3}
$$

若 $r \in A _ { i } \cap A _ { j }$ ，则将 $\{ A _ { i } , A _ { j } , r \}$ 组成三元组，这种三元组的个数记为 $S _ { \circ }$ 一方面因 r 属于 $A _ { 1 } , A _ { 2 } , \cdots , A _ { k }$ 中 $l _ { r }$ 个集合，可形成 $\binom { l _ { r } } { 2 }$ 个含 r 的三元组，所以 $\begin{array} { r } { S = \sum _ { r = 1 } ^ { 1 0 } \binom { l _ { r } } { 2 } } \end{array}$ 。另一方面，对任意 $A _ { i } , A _ { j } \ ( 1 \leqslant i < j \leqslant k )$ 有 $| A _ { i } \cap A _ { j } |$ 个元属于 $A _ { i } \cap A _ { j }$ ，可形成 $| A _ { i } \cap A _ { j } |$ 个含 $A _ { i } , A _ { j }$ 的三元组，所以 $\begin{array} { r } { S = \sum _ { 1 \leqslant i < j \leqslant k } | A _ { i } \cap A _ { j } | } \end{array}$ ，于是

$$
\sum_ {1 \leqslant i <   j \leqslant k} | A _ {i} \cap A _ {j} | = \sum_ {r = 1} ^ {1 0} {\binom {l _ {r}} {2}} = \frac {1}{2} (\sum_ {r = 1} ^ {1 0} l _ {r} ^ {2} - \sum_ {r = 1} ^ {1 0} l _ {r})
$$

利用 (3) 及已知条件 (2) 和 Cauchy 不等式得

$$
\begin{array}{l} k (k - 1) = 2 \binom {k} {2} \geqslant \sum_ {1 \leqslant i <   j \leqslant k} | A _ {i} \cap A _ {j} | \geqslant \frac {1}{2} \left[ \frac {1}{1 0} (\sum_ {i = 1} ^ {1 0} l _ {i}) ^ {2} - \sum_ {i = 1} ^ {1 0} l _ {i} \right] \\ = \frac {1}{2 0} [ (5 k) ^ {2} - 1 0 (5 k) ] = \frac {5}{4} k (k - 2) \end{array}
$$

所以 $k \leqslant 6$ o

其次，下列 6 个集合满足题设条件：

$$
\begin{array}{l l} A _ {1} = \{1, 2, 3, 4, 5 \} & A _ {2} = \{1, 2, 6, 7, 8 \} \quad A _ {3} = \{1, 3, 6, 9, 1 0 \} \\ A _ {4} = \{2, 4, 7, 9, 1 0 \} & A _ {5} = \{3, 5, 7, 8, 1 0 \} \quad A _ {6} = \{4, 5, 6, 8, 9 \} \end{array}
$$

综上可知，所求 k 的最大值为 6。

方法二

若 $k \geqslant 7$ ，则 $\textstyle \sum _ { i = 1 } ^ { k } | A _ { i } | = 5 k \geqslant 3 5$ ，故 S 中至少有一个元素 a 至少属于 $A _ { 1 } , A _ { 2 } , \cdots , A _ { k }$ 中 $\lceil \frac { 3 5 - 1 } { 1 0 } \rceil = 4$ 个不同集合。不妨设 $a \in A _ { i } \ ( i = 1 , 2 , 3 , 4 )$ ，于是对任意 $1 \leqslant i < j < t \leqslant 4$ ，$\left| A _ { i } \cap A _ { j } \cap A _ { t } \right| \geqslant \left| A _ { 1 } \cap A _ { 2 } \cap A _ { 3 } \cap A _ { 4 } \right| \geqslant 1$ ，由容斥原理得

$$
\begin{array}{l} 1 0 = | S | \geqslant \left| \bigcup_ {i = 1} ^ {4} A _ {i} \right| \\ = \sum_ {i = 1} ^ {4} \left| A _ {i} \right| - \sum_ {1 \leqslant i <   j \leqslant 4} \left| A _ {i} \cap A _ {j} \right| + \sum_ {1 \leqslant i <   j <   t \leqslant 4} \left| A _ {i} \cap A _ {j} \cap A _ {t} \right| - \left| A _ {1} \cap A _ {2} \cap A _ {3} \cap A _ {4} \right| \\ \geqslant 4 \times 5 - \binom {4} {2} \times 2 - \left[ \binom {4} {3} - 1 \right] \times 1 = 1 1 \end{array}
$$

矛盾！所以 $k \leqslant 6$ 。

其次，下列 6 个集合满足题设条件：

$$
A _ {1} = \{1, 2, 3, 4, 5 \} \quad A _ {2} = \{1, 2, 6, 7, 8 \} \quad A _ {3} = \{1, 3, 6, 9, 1 0 \}
$$

$$
A _ {4} = \{2, 4, 7, 9, 1 0 \} \quad A _ {5} = \{3, 5, 7, 8, 1 0 \} \quad A _ {6} = \{4, 5, 6, 8, 9 \}
$$

综上可知，所求 k 的最大值为 6。

CTST 2010 P6 

设 A 是有限集，且 $| A | \geqslant 2 , A _ { 1 } , A _ { 2 } , \cdot \cdot \cdot , A _ { n }$ 是 A 的子集且满足下述条件：

(1) $| A _ { 1 } | = | A _ { 2 } | = \cdot \cdot \cdot = | A _ { n } | = k , \ k > | A | / 2 ;$ 

(2) 对任意 $a , b \in A$ ，存在 3 个集合 $A _ { r } , A _ { s } , A _ { t } \ ( 1 \leqslant r < s < t \leqslant n )$ ，使得

$$
a, b \in A _ {r} \cap A _ {s} \cap A _ {t}
$$

(3) 对任意整数 $i , j , \ 1 \leqslant i < j \leqslant n$ ，有 $\left| A _ { i } \cap A _ { j } \right| \leqslant 3$ 

求：当 k 取到最大值时正整数 n 的所有可能值。

解

不妨设 $A = \{ 1 , 2 , \cdots , m \}$ ，由条件 (1) (2) 知 m ⩾ k ⩾ 2, n ⩾ 3。

假设 i 属于 $A _ { 1 } , A _ { 2 } , \cdots , A _ { n }$ 中 $r _ { i }$ 个集合 $( i = 1 , 2 , \cdots , m )$ 。如果 $i \in A _ { j }$ ，那么将 $( i , A _ { j } )$ 配成一对，并设这样的对子共有 X 个。于是对任意 i，可形成 $r _ { i }$ 个含 i 的对子，又 $i = 1 , 2 , \cdots , m$ 所以 $\textstyle X = \sum _ { i = 1 } ^ { m } r _ { i } .$ o

另一方面，对任意 $A _ { j }$ ，可形成 $| A _ { j } | = k$ 个含 $A _ { j }$ 的对子，又因为 $j = 1 , 2 , \cdots , n$ ，所以$\begin{array} { r } { X = \sum _ { j = 1 } ^ { n } | A _ { j } | = n k } \end{array}$ ，于是我们得到

$$
\sum_ {i = 1} ^ {m} r _ {i} = n k\tag{1}
$$

如果 $i \neq j$ 都属于 $A _ { t }$ ，那么将 $( i , j , A _ { t } )$ 组成一个第一类三元组 (前两个元不考虑顺序)，并设第一类三元组有 Y 个。于是由已知条件 (2) 知：对任意 $i \neq j$ ，至少可形成 3 个含 $i , j$ 的第一类三元组，而 $i , j$ 有 $\binom m 2$ 种不同的取法，故 $Y \geqslant 3 { \binom { m } { 2 } }$ 

另一方面由 $| A _ { t } | = k$ 知：对任意 $A _ { t }$ 可形成 $\binom { k } { 2 }$ 个含 $A _ { t }$ 的第一类三元组，而 $A _ { t }$ 有 $n$ 种不同取法，故 $Y = n { \binom { k } { 2 } }$ ，于是我们有 $n { \binom { k } { 2 } } \geqslant 3 { \binom { m } { 2 } }$ ，即

$$
n \geqslant \frac {3 m (m - 1)}{k (k - 1)}\tag{2}
$$

如果 t 是 $A _ { i }$ 和 $A _ { j }$ 的公共元，那么将 $( t , A _ { i } , A _ { j } )$ 组成一个第二类三元组 (后两个元不考虑顺序)，并设第二类三元组有 Z 个。因为 t 属于 $A _ { 1 } , A _ { 2 } , \cdots , A _ { n }$ 中 $r _ { t }$ 个集合，故对任意 t，可形成 $\binom { r _ { t } } { 2 }$ 个含 t 的第二类三元组，而 $t = 1 , 2 , \cdots , m$ ，所以 $\begin{array} { r } { Z = \sum _ { t = 1 } ^ { m } { \binom { r _ { t } } { 2 } } } \end{array}$ 。

另一方面，对任意 $A _ { i }$ 和 $A _ { j }$ ，可形成 $\left| A _ { i } \cap A _ { j } \right| \leqslant 3$ 个含 $A _ { i }$ 和 $A _ { j }$ 的第二类三元组，又1 $\leqslant i < j \leqslant n$ ，所以

$$
Z = \sum_ {1 \leqslant i <   j \leqslant n} | A _ {i} \cap A _ {j} | \leqslant 3 {\binom {n} {2}} = \frac {3}{2} n (n - 1)
$$

于是

$$
\frac {3}{2} n (n - 1) \geqslant \sum_ {t = 1} ^ {m} \binom {r _ {t}} {2} = \frac {1}{2} \left(\sum_ {t = 1} ^ {m} r _ {t} ^ {2} - \sum_ {t = 1} ^ {m} r _ {t}\right)
$$

由 Cauchy 不等式及 (1)，我们得到

$$
\begin{array}{l} \frac {3}{2} n (n - 1) \geqslant \frac {1}{2} \left[ \frac {1}{m} \left(\sum_ {t = 1} ^ {m} r _ {t}\right) ^ {2} - \sum_ {t = 1} ^ {m} r _ {t} \right] \\ \qquad = \frac {1}{2 m} \left(\sum_ {t = 1} ^ {m} r _ {t}\right) \left[ \left(\sum_ {t = 1} ^ {m} r _ {t}\right) - m \right] \\ \qquad = \frac {1}{2 m} (n k) (n k - m) \end{array}
$$

整理得

$$
(k ^ {2} - 3 m) n \leqslant (k - 3) m\tag{3}
$$

考虑以下两种情形：

(i) 若 $3 m \geqslant k ^ { 2 }$ ，则结合已知条件 $m \leqslant 2 k - 1$ ，解得

$$
3 - \sqrt {6} \leqslant k \leqslant 3 + \sqrt {6}
$$

即 $1 \leqslant k \leqslant 5$ 

(ii) 若 $3 m < k ^ { 2 }$ ，由 (3) 及 (2) 得

$$
\frac {3 m (m - 1)}{k (k - 1)} \leqslant n \leqslant \frac {(k - 3) m}{k ^ {2} - 3 m}\tag{4}
$$

去分母，整理得

$$
9 m ^ {2} - 3 (k ^ {2} + 3) m + k (k ^ {2} - k + 3) \geqslant 0
$$

即

$$
(3 m - k) [ 3 m - (k ^ {2} - k + 3) ] \geqslant 0
$$

由于 $k ^ { 2 } - k + 3 > k$ ，所以要么 $3 m \leqslant k$ ，但这与 $m \geqslant k > 0$ 矛盾；要么

$$
m \geqslant \frac {1}{3} (k ^ {2} - k + 3)
$$

又由已知条件 (1)，有 $m \leqslant 2 k - 1$ ，故

$$
2 k - 1 \geqslant m \geqslant \frac {1}{3} (k ^ {2} - k + 3)\tag{5}
$$

由此解出 $1 \leqslant k \leqslant 6$ 。

由 (i)，(ii)，我们得到 $1 \leqslant k \leqslant 6$ ，故所求 k 的最大值不大于 6，并且由不等式 (5) 知$k = 6$ 当且仅当 $m = 1 1$ ，再由 (4) 知 $k = 6$ 且 $m = 1 1$ 时，必有 $n = 1 1$ 。

其次，当 $k = 6 , m = 1 1 , n = 1 1$ 时，存在满足条件 (1)，(2)，(3) 的实例如下：

$$
A _ {t} = \{t, t + 1, t + 2, t + 6, t + 8, t + 9 \}, \quad t = 1, 2, \dots , 1 1
$$

且约定如果集合中的元素大于 11，那么表示该数减去 11，即

$$
\begin{array}{l l} A _ {1} = \{1, 2, 3, 7, 9, 1 0 \} & A _ {2} = \{2, 3, 4, 8, 1 0, 1 1 \} \quad A _ {3} = \{3, 4, 5, 9, 1 1, 1 \} \\ A _ {4} = \{4, 5, 6, 1 0, 1, 2 \} & A _ {5} = \{5, 6, 7, 1 1, 2, 3 \} \quad A _ {6} = \{6, 7, 8, 1, 3, 4 \} \\ A _ {7} = \{7, 8, 9, 2, 4, 5 \} & A _ {8} = \{8, 9, 1 0, 3, 5, 6 \} \quad A _ {9} = \{9, 1 0, 1 1, 4, 6, 7 \} \\ A _ {1 0} = \{1 0, 1 1, 1, 5, 7, 8 \} & A _ {1 1} = \{1 1, 1, 2, 6, 8, 9 \} \end{array}
$$

于是 $| A _ { i } | = k = 6 ~ i = 1 , 2 , \cdot \cdot \cdot , 1 1$ ，并且 $m = 2 k - 1 = 1 1$ 

下面直接验证两个计数条件。把元素视为模 11 的剩余类，并记 $S _ { 0 } = \{ 0 , 1 , 2 , 6 , 8 , 9 \}$ ，则$A _ { t } = t + S _ { 0 }$ 。在这 6 个剩余类之间，将无序点对的距离定义为两种有向差中较小的正整数。距离为 1,2,3,4,5 的无序点对分别为

1 : (0, 1), (1, 2), (8, 9) 2 : (0, 2), (0, 9), (6, 8) 3 : (0, 8), (1, 9), (6, 9) 4 : (1, 8), (2, 6), (2, 9) 5 : (0, 6), (1, 6), (2, 8) 

每个无序点对产生互为相反数的两个有向差，因此，对每个非零剩余类 d，恰有 3 个有序对$( u , v ) \in S _ { 0 } ^ { 2 }$ 满足 $v - u = d$ 。

任取不同的 $i , j \in A$ ，包含它们的集合 $A _ { t }$ 与满足 $u , v \in S _ { 0 } , \ v - u = j - i$ 的有序对一一对应，其中 $t = i - u = j - v .$ 。因此，恰有 3 个集合同时包含 $i , j$ 。每个元素也都恰好属于 6个集合，所以条件 (2) 在 $i = j$ 时同样成立。

另一方面，对不同的 s,t，集合 $A _ { s } \cap A _ { t }$ 中的每个元素对应于一个满足 $u - v = t - s$ 的有序对 $( u , v ) \in S _ { 0 } ^ { 2 }$ ，因此 $\left| A _ { s } \cap A _ { t } \right| = 3$ ，条件 (3) 也成立。

综上所述，k 的最大值为 6，这时 n 的唯一可能值为 11。

USAMO 2011 P6 

设 A 是 225 元集合， $A _ { 1 } , A _ { 2 } , \cdots , A _ { 1 1 }$ 是其 11 个 45 元子集，满足对任意 $1 \leqslant i < j \leqslant 1 1$ 均有 $\left| A _ { i } \cap A _ { j } \right| = 9$ 。求证： $\left| A _ { 1 } \cup A _ { 2 } \cup \ldots \cup A _ { 1 1 } \right| \geqslant 1 6 5$ ，并给出一个例子使等号成立。

解

记 $U = A _ { 1 } \cup A _ { 2 } \cup \dots \cup A _ { 1 1 } , \ n = | U |$ 。对每个 $x \in U$ ，记 $r _ { x }$ 为包含 x 的集合 $A _ { i }$ 的个数。对所有从属关系 $( x , A _ { i } )$ 计数，得到

$$
\sum_ {x \in U} r _ {x} = \sum_ {i = 1} ^ {1 1} | A _ {i} | = 1 1 \cdot 4 5 = 4 9 5
$$

再对所有三元组 $( x , \{ i , j \} )$ 计数，其中 $x \in A _ { i } \cap A _ { j }$ 且 $i < j$ ，得到

$$
\sum_ {x \in U} \binom {r _ {x}} {2} = \sum_ {1 \leqslant i <   j \leqslant 1 1} | A _ {i} \cap A _ {j} | = \binom {1 1} {2} \cdot 9 = 4 9 5
$$

因此

$$
\sum_ {x \in U} r _ {x} ^ {2} = \sum_ {x \in U} \left(2 \binom {r _ {x}} {2} + r _ {x}\right) = 2 \cdot 4 9 5 + 4 9 5 = 1 4 8 5
$$

由柯西不等式，

$$
4 9 5 ^ {2} = \left(\sum_ {x \in U} r _ {x}\right) ^ {2} \leqslant n \sum_ {x \in U} r _ {x} ^ {2} = 1 4 8 5 n
$$

故

$$
n \geqslant \frac {4 9 5 ^ {2}}{1 4 8 5} = 1 6 5
$$

下面构造等号成立的例子。记 $[ 1 1 ] = \{ 1 , 2 , \cdots , 1 1 \}$ ，并令

$$
\mathcal {T} = \{T \subseteq [ 1 1 ]: | T | = 3 \}
$$

则 $| T | = { \binom { 1 1 } { 3 } } = 1 6 5$ 。另取一个与 T 不交的 60 元集合 E，令 $A = \mathcal { T } \cup E$ ，于是 $| { \cal A } | = 2 2 5$ 。对每个 $1 \leqslant i \leqslant 1 1$ ，定义

$$
A _ {i} = \{T \in \mathcal {T}: i \in T \}
$$

固定 i 后，只需从其余 10 个数中再选两个，故

$$
\left| A _ {i} \right| = \binom {1 0} {2} = 4 5
$$

固定不同的 $i , j$ 后，只需从其余 9 个数中再选一个，故

$$
| A _ {i} \cap A _ {j} | = \binom{9}{1} = 9
$$

而每个三元子集至少含有一个 $i \in [ 1 1 ]$ ，所以

$$
A _ {1} \cup A _ {2} \cup \dots \cup A _ {1 1} = \mathcal {T}
$$

其大小恰为 165，等号成立。

All-Russian 1975 Grade 10 P4 

在 $m \times m$ 个小方格的正方形中选若干格子的中心，使任意四个选点都不能成为边平行于正方形边的矩形的四个顶点。分别求 $m = 7$ 和 $m = 1 3$ 时可选点数的最大值。

解

答案分别为 21,52。设各行选点数为 $x _ { 1 } , \cdots , x _ { m }$ ，总数为 $k _ { \mathfrak { c } }$ 。任意一对列至多同时在一行中被选中，否则产生一个禁止的矩形。因此

$$
\sum_ {i = 1} ^ {m} \binom{x _ {i}}{2} \leqslant \binom{m}{2}
$$

结合 $\sum x _ { i } ^ { 2 } \geqslant k ^ { 2 } / m$ ，得到 $k ^ { 2 } / m \leqslant m ( m - 1 ) + k$ ，所以

$$
k \leqslant \frac {m + m \sqrt {4 m - 3}}{2}
$$

分别代入 $m = 7 , 1 3$ ，得到 $k \leqslant 2 1 , 5 2$ o

统一给出两个取等构造。分别取 $p = 2 , 3$ ，则 $m = p ^ { 2 } + p + 1$ 。所有坐标与计算都模 $p _ { \mathfrak { c } }$ 。用非零三元向量的比例类分别编号行和列：若两个向量相差一个非零倍数，就视为同一类，并取首个非零坐标为 1 的代表。这样的类共有 $( p ^ { 3 } - 1 ) / ( p - 1 ) = m$ 个。在行 $a = ( a _ { 1 } , a _ { 2 } , a _ { 3 } )$ 与列 $\boldsymbol { x } = \left( x _ { 1 } , x _ { 2 } , x _ { 3 } \right)$ 的交点选点，当且仅当 $a _ { 1 } x _ { 1 } + a _ { 2 } x _ { 2 } + a _ { 3 } x _ { 3 } = 0$ 。

每行对应一个非零线性方程，有 $p ^ { 2 }$ 个解；去掉零解并按非零倍数合并，恰有 $( p ^ { 2 } - 1 ) / ( p \cdot$ $1 ) = p + 1$ 个列类。因此总点数为 $m ( p + 1 )$ ，分别为 21,52。两行的代表不成比例，两个对应方程线性独立，公共解形成一个一维空间，其非零解恰属于一个列类。因此任意两行只共用一个选中列，不会出现矩形，达到上述上界。
