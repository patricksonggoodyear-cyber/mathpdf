$$

$$

进一步证明：在所有满足上述条件的函数中，恰好只有两个函数是连续的。

解

在原方程中令 $x = y = t \neq 0$ ，得 $2 t f ( t ) = 2 t f ( t ) ^ { 2 }$ ，因此 $f ( t ) \in \{ 0 , 1 \}$ 0

若存在非零实数 a 使 $f ( a ) = 0$ ，则令 $x = a$ ，原方程化为 $a f ( y ) = 0$ ，对一切实数 y 成立，故 $f \equiv 0 .$ C

否则，对一切 $t \neq 0$ 均有 $f ( t ) = 1 { \mathrm { ~ } }$ 。记 $f ( 0 ) = c ,$ ，其中 c 为任意实数。当 $x , y$ 均非零时，原方程两边同为 $x + y ;$ 当恰有一个为零时，两边同为另一个变量与 c 的乘积；当两者均为零时，两边均为零。因此这些函数都满足原方程。全部解为

$$
f \equiv 0, \qquad {\text {或}} \qquad f (x) = {\left\{ \begin{array}{l l} {c,} & {x = 0,} \\ {1,} & {x \neq 0,} \end{array} \right.} \quad c \in \mathbb {R}

$$

对任意 $t \geqslant 0$ ，有 $g ( t ) = g ( \sqrt { t } ) ^ { 2 } \geqslant 0$ 。因此，当 $u \leqslant v$ 时， $g ( v ) - g ( u ) = g ( v - u ) \geqslant 0$ ，即g 单调不减。

记 $c = g ( 1 )$ ，由平方关系得 $c = c ^ { 2 }$ ，所以 $c = 0$ 或 $c = 1$ 。由加性知，对每个有理数 $q ,$ ，均有 $g ( q ) = c q$ 。对任意实数 x，取有理数列 $r _ { n } \leqslant x \leqslant s _ { n }$ ，使得 $r _ { n } , s _ { n }$ 均趋于 x，则单调性给出$c r _ { n } \leqslant g ( x ) \leqslant c s _ { n } \circ$ 。令 $n \to \infty$ ，得到 $g ( x ) = c x$ 。因此 $f ( x ) \equiv - 1$ 或 $f ( x ) = x - 1$ 。

最后验证：当 $f ( x ) \equiv - 1$ 时，原式两端均为 1；当 $f ( x ) = x - 1$ 时，最大值为 $x ^ { 2 } + y ^ { 2 } - 1$ 原式右端等于 $2 ( x - 1 ) ( y - 1 ) + x ^ { 2 } + y ^ { 2 } - 1 = ( x + y - 1 ) ^ { 2 }$ 。两者均满足 $f ( 0 ) \neq 0$ ，故均为所求的解。
