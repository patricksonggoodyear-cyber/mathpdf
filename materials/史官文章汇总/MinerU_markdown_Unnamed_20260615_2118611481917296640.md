用平行截线构造相似的辅助三角形，以相似比控制内切圆半径及其总量。

## IMO 1964 P3

设三角形 ABC 的三边长分别为 $a = B C , b = C A , c = A B$ ，内切圆为 $\omega _ { \mathsf { c } }$ 。分别作 $\omega$ 的与三边平行的另一条切线，每条切线都从 ABC 截出一个角部小三角形。在这三个小三角形中各作一个内切圆。求这四个内切圆的面积之和，并用 $a , b , c$ 表示。

解

设 $s = ( a + b + c ) / 2 , \Delta$ 为三角形 ABC 的面积， $r = \Delta / s$ 为其内切圆半径。以平行于 BC的那条切线为例，设它截出的 A 角小三角形的相似比为 $k _ { a \circ } \ A$ 到 BC 的高为 $h _ { a } = 2 \Delta / a$ ，而两条平行于 BC 的内切圆切线间的距离为 $2 r$ ，所以

$$
k _ {a} = \frac {h _ {a} - 2 r}{h _ {a}} = 1 - \frac {a}{s} = \frac {s - a}{s}
$$

同理，B,C 两角小三角形的相似比分别为 $k _ { b } = ( s - b ) / s \mathrm { ~ , ~ } k _ { c } = ( s - c ) / s \mathrm { ~ }$ 。由于 $a + b + c = 2 s$ 9有 $k _ { a } + k _ { b } + k _ { c } = 1 .$ 。三个小三角形的内切圆半径分别为 $k _ { a } r , k _ { b } r , k _ { c } r \gets$ 

记所求面积和为 S。利用相似比的上述表达式和 $a + b + c = 2 s$ ，直接展开可得

$$
1 + k _ {a} ^ {2} + k _ {b} ^ {2} + k _ {c} ^ {2} = \frac {a ^ {2} + b ^ {2} + c ^ {2}}{s ^ {2}}
$$

再由海伦公式 $\Delta ^ { 2 } = s ( s - a ) ( s - b ) ( s - c )$ ，得到

$$
\begin{array}{r l} & S = \pi r ^ {2} (1 + k _ {a} ^ {2} + k _ {b} ^ {2} + k _ {c} ^ {2}) \\ & \quad = \frac {\pi (a ^ {2} + b ^ {2} + c ^ {2}) (s - a) (s - b) (s - c)}{s ^ {3}} \\ & \quad = \frac {\pi (a ^ {2} + b ^ {2} + c ^ {2}) (b + c - a) (c + a - b) (a + b - c)}{(a + b + c) ^ {3}} \end{array}
$$

## IMOSL 2014 G2

在三角形 ABC 中，点 K,L,M 分别在线段 $B C , C A , A B$ 上，且 AK,BL,CM 共点。证明：三角形 ALM,BMK,CKL 中可选两个，使它们的内切圆半径之和不小于三角形 ABC 的内切圆半径。

## 解

记 r(T) 为三角形 T 的内切圆半径。令 $a = B K / K C , \ b = C L / L A , \ c = A M / M B$ 。由塞瓦定理，abc = 1。沿 $A , B , C$ 循环重命名后，可设 $a \geqslant 1 , \ b \leqslant 1$ ，于是 $b c \leqslant 1 , \ c a \geqslant 1$ ，即$A M / M B \leqslant L A / C L \cdot \ M B / A M \leqslant B K / K C$ o

过 M 作 BC 的平行线交 AC 于 X，作 AC 的平行线交 BC 于 $Y _ { \circ }$ 。由平行线分线段成比例，$A X / X C = A M / M B \leqslant A L / L C \mathrm { , } B Y / Y C = M B / A M \leqslant B K / K C$ ，故 $X \in A L , Y \in B K$ 。因此 $\triangle A M X \subseteq \triangle A L M , \triangle B M Y \subseteq \triangle B M K$ ，从而 $r ( A L M ) \geqslant r ( A M X ) . r ( B M K ) \geqslant r ( B M Y )$ 又 $\triangle A M X \sim \triangle A B C , \triangle B M Y \sim \triangle B A C$ ，相似比分别为 $A M / A B , ~ M B / A B$ ，所以

$$
r (A L M) + r (B M K) \geqslant r (A M X) + r (B M Y) = \frac {A M + M B}{A B} r (A B C) = r (A B C)
$$

这就找到了所需的两个三角形。

RMM 2016 P5 

圆 Ω 的半径为 R，凸六边形 $A _ { 1 } B _ { 1 } A _ { 2 } B _ { 2 } A _ { 3 } B _ { 3 }$ 内接于 Ω，且对角线 $A _ { 1 } B _ { 2 } , A _ { 2 } B _ { 3 } , A _ { 3 } B _ { 1 }$ 共点于 X。对 $i = { 1 , 2 , 3 }$ ，设圆 $\omega _ { i }$ 同时与线段 $X A _ { i } , X B _ { i }$ 及 Ω 上不含六边形其他顶点的弧 $A _ { i } B _ { i }$ 相切，其半径为 $r _ { i }$ 。

(a) 证明 $R \geqslant r _ { 1 } + r _ { 2 } + r _ { 3 }$ O

(b) 若 $R = r _ { 1 } + r _ { 2 } + r _ { 3 }$ ，证明三个圆 $\omega _ { i }$ 与上述三条对角线相切的六个切点共圆。

解

先证 (a)。作 Ω 的三条切线 $\ell _ { 1 } , \ell _ { 2 } , \ell _ { 3 }$ ，使它们分别平行于 $A _ { 2 } B _ { 3 } , A _ { 3 } B _ { 1 } , A _ { 1 } B _ { 2 }$ ，且 $\ell _ { i }$ 与 $\omega _ { i }$ 位于对应对角线的同侧。令 $C _ { 1 } = \ell _ { 2 } \cap \ell _ { 3 } \mathbf { \setminus } \ C _ { 2 } = \ell _ { 3 } \cap \ell _ { 1 } \mathbf { \setminus } \ C _ { 3 } = \ell _ { 1 } \cap \ell _ { 2 }$ 。三条切线围成三角形$C _ { 1 } C _ { 2 } C _ { 3 }$ ，其内切圆就是 Ω。记射线 $X A _ { i } , X B _ { i }$ 与 $\ell _ { i }$ 的交点分别为 $S _ { i } , T _ { i }$ ，并设 $\Delta _ { i } = \triangle X S _ { i } T _ { i }$ o由于对应边平行， $\Delta _ { i } \sim \triangle C _ { 1 } C _ { 2 } C _ { 3 }$ 。

记 $k _ { i }$ 为这两个三角形的相似比， $\rho _ { i }$ 为 $\Delta _ { i }$ 的内切圆半径。以 [PQR] 表示三角形 PQR 的面积。若 $\{ i , j , k \} = \{ 1 , 2 , 3 \}$ ，则由高之比得

$$
k _ {i} = \frac {[ X C _ {j} C _ {k} ]}{[ C _ {1} C _ {2} C _ {3} ]}, \quad \rho_ {i} = k _ {i} R
$$

点 X 在三角形 $C _ { 1 } C _ { 2 } C _ { 3 }$ 内，故 $k _ { 1 } + k _ { 2 } + k _ { 3 } = 1$ 。由于 $\omega _ { i }$ 位于射线 $X A _ { i } , X B _ { i }$ 所夹的角内且包含于 Ω，而 $\ell _ { i }$ 是 Ω 的外切线，故 $\omega _ { i }$ 位于 $\Delta _ { i }$ 内，因而 $r _ { i } \leqslant \rho _ { i }$ 。于是

$$
r _ {1} + r _ {2} + r _ {3} \leqslant \rho_ {1} + \rho_ {2} + \rho_ {3} = (k _ {1} + k _ {2} + k _ {3}) R = R
$$

再证 (b)。若等号成立，则每个 $r _ { i } = \rho _ { i }$ ，从而 $\omega _ { i }$ 是 $\Delta _ { i }$ 的内切圆。记 $M _ { i }$ 为 Ω 与 $\ell _ { i }$ 的切点。因为 $\omega _ { i }$ 在 Ω 内，且两圆均与 $\ell _ { i }$ 相切，所以它们在 $M _ { i }$ 相切。以 $M _ { i }$ 为中心、 $k _ { i }$ 为比的位似将 Ω 映为 $\omega _ { i }$ 。由于大、小三角形的对应边平行且共用切线 $\ell _ { i }$ ，该位似也将 $C _ { 1 } C _ { 2 } C _ { 3 }$ 映为$\Delta _ { i }$ ，特别将 $C _ { i }$ 映为 X，故 $C _ { i } , M _ { i } , X$ 共线。

设 $u _ { i }$ 为从 $C _ { i }$ 向 Ω 所作切线的切线长， $K _ { i } , L _ { i }$ 分别为 $\omega _ { i }$ 与 $X S _ { i } , X T _ { i }$ 的切点。上述位似给出 $X K _ { i } = X L _ { i } = k _ { i } u _ { i }$ 。对于互不相同的 $i , j , k$ ，切线长相等给出 $C _ { j } M _ { i } = u _ { j } , ~ M _ { i } C _ { k } = u _ { k }$ ；

再由 $C _ { i } , M _ { i } , X$ 共线及面积比可得

$$
\frac {k _ {j}}{k _ {k}} = \frac {[ X C _ {i} C _ {k} ]}{[ X C _ {i} C _ {j} ]} = \frac {M _ {i} C _ {k}}{C _ {j} M _ {i}} = \frac {u _ {k}}{u _ {j}}
$$

轮换 i，便有 $k _ { 1 } u _ { 1 } = k _ { 2 } u _ { 2 } = k _ { 3 } u _ { 3 }$ 。所以 $X K _ { i } = X L _ { i }$ 对所有 i 都取同一数值，六个切点同在以 X 为圆心的圆上。
