(b) 先证明充分性。设 N 为奇数，将颜色编号为 $0 , 1 , \cdots , N - 1$ ，并把正整数 n 染成其模 N 剩余类所对应的颜色。每种颜色显然出现无穷多次。若互不相同且奇偶性相同的正整数x,y 的颜色分别为 $r , s$ ，则 $m = ( x + y ) / 2$ 为正整数，且

$$

$$

因为 N 为奇数，2 在模 N 下可逆，所以 m 的剩余类为 $2 ^ { - 1 } ( r + s )$ ，只由 $r , s$ 决定。故这种染色满足题意。

下面证明必要性。固定任意一种颜色，将具有这种颜色的正整数依次记为

$$

任意相邻两项之差 $a _ { k + 1 } - a _ { k }$ 都是奇数；否则两项同奇偶，由 (a) 可知它们的算术平均值仍为这种颜色，却严格位于两项之间，与相邻性矛盾。

对任意 $k \geqslant 2 , a _ { k } { - } a _ { k - 1 }$ 与 $a _ { k + 1 } - a _ { k }$ 都是奇数，故 $a _ { k - 1 }$ 与 $a _ { k + 1 }$ 同奇偶。由 $( \mathrm { a } ) , ( a _ { k - 1 } + a _ { k + 1 } ) / 2$ 仍为这种颜色，并且 $\overrightarrow { j } ^ { \mathrm { I E } }$ 格位于 $a _ { k - 1 }$ 与 $a _ { k + 1 }$ 之间。这两个数之间唯一具有这种颜色的数是 a ， $a _ { k }$ 所以

$$

即所有相邻两项之差相等。因此，每个颜色类都恰为一个公差为奇数的等差数列。将第 $j$ 个颜 $\mathcal { \underline { { \mathrm { E } } } } _ { \mathrm { ~ } }$ 类写成

正整数无限序列 $a _ { 1 } , a _ { 2 } , \cdots$ 满足：对任意正整数 $n , m$ ，都有 $\displaystyle a _ { n + 2 m } \mid a _ { n } + a _ { n + m }$ 。证明该序列最终周期。

解

引理一：设 $d , m , n$ 为正整数且 $n > 2 m$ 。若 $d \mid a _ { n }$ ，则 $d \mid a _ { n - m }$ 当且仅当 $d \mid a _ { n - 2 m } .$ 

引理一证明：将题设用于正整数 $n - 2 m$ 与 m，可得 $a _ { n } \mid a _ { n - 2 m } + a _ { n - m }$ ，所以 $d \mid a _ { n - 2 m } +$ $a _ { n - m } .$ 。因此，d 整除 $a _ { n - m }$ 与 $a _ { n - 2 m }$ 中的一个时，也必整除另一个。

先证明数列有界。令 $M = \operatorname* { m a x } \{ a _ { 1 } , a _ { 2 } , \cdot \cdot \cdot , a _ { 6 } \}$ 。反设数列无界，则可取 $n > 1 4$ ，使 $k = a _ { n }$ 大于此前各项且 $k > 2 M$ 。对任意正整数 $s < n / 2$ ，题设给出

$$
k = a _ {n} \mid a _ {n - 2 s} + a _ {n - s}
$$

右边两项均小于 k，故 $0 < a _ { n - 2 s } + a _ { n - s } <$ 2k，从而 $a _ { n - 2 s } + a _ { n - s } = k$ 。依次取 $s = 1 , 2 , 4$ ，得到

$$
a _ {n} = a _ {n - 1} + a _ {n - 2} = a _ {n - 2} + a _ {n - 4} = a _ {n - 4} + a _ {n - 8}
$$

因此 $a _ { n - 1 } = a _ { n - 4 }$ 且 $a _ { n - 2 } = a _ { n - 8 } .$ 。由引理一反复向前传播，a 整除数列中指标依次相差 3 $a _ { n }$ 的各项，直至前三项中的某一项；同理， $a _ { n - 2 }$ 整除数列中指标依次相差 6 的各项，直至前六项中的某一项。又因 $a _ { n - 1 } + a _ { n - 2 } = k$ ，二者至少有一个不小于 $k / 2$ ，故前六项中必有一项不小于 $k / 2 > M$ ，矛盾。因此数列有界。

数列只有有限多个可能值。删去一个有限前缀并重新编号后，可以假设每个出现的值都出现无穷多次；所得尾序列仍满足题设条件。

对每个整除数列中某一项的正整数 $d ,$ ，定义

$$
I _ {d} = \left\{i \in \mathbb {Z} _ {> 0}: d \mid a _ {i} \right\}
$$

由于被 d 整除的某个数列值出现无穷多次，集合 $I _ { d }$ 是无限集。

引理二：每个集合 $I _ { d }$ 都是公差为奇数的无限等差数列。

引理二证明：将 $I _ { d }$ 中的指标依次写成 $i _ { 1 } < i _ { 2 } < i _ { 3 } < \cdots _ { \circ }$ 若相邻两项 $i _ { s } , i _ { s + 1 }$ 同奇偶，则取 $n = i _ { s + 1 } , \ m = ( i _ { s + 1 } - i _ { s } ) / 2$ ，由引理一可知 $( i _ { s } + i _ { s + 1 } ) / 2 \in I _ { d } \mathrm { ~ }$ 。这个指标严格位于 $i _ { s } , i _ { s + 1 }$ 之间，与二者在 $I _ { d }$ 中相邻矛盾。因此每个差 $i _ { s + 1 } - i _ { s }$ 都是奇数。

于是 $i _ { s }$ 与 $i _ { s + 2 }$ 同奇偶。对这两个指标再次使用引理一，可知 $( i _ { s } + i _ { s + 2 } ) / 2 \in I _ { d }$ 。这个指标严格位于 $i _ { s } , i _ { s + 2 }$ 之间，而二者之间的 $I _ { d }$ 元素只有 $i _ { s + 1 }$ ，故

$$
i _ {s + 1} = (i _ {s} + i _ {s + 2}) / 2
$$

所以 $i _ { s + 1 } - i _ { s } = i _ { s + 2 } - i _ { s + 1 }$ 。所有相邻差均相等且为奇数，引理二得证。

所有数列项组成有限集，故整除某个数列项的正整数也只有有限多个。将这些正整数构成的集合记为 $s$ 。对每个 $d \in S$ ，由引理二可写成

$$
I _ {d} = \left\{r _ {d} + t q _ {d}: t = 0, 1, 2, \dots \right\}
$$

其中 $q _ { d }$ 为正奇数。令 $R = \operatorname* { m a x } _ { d \in \mathcal { S } } r _ { d } .$ ，并令 D 为所有 $q _ { d }$ 的最小公倍数。于是对任意 $n \geqslant R$ 及任意 $d \in S$ ，都有

$$
d \mid a _ {n} \quad \Longleftrightarrow \quad n \in I _ {d} \quad \Longleftrightarrow \quad n + D \in I _ {d} \quad \Longleftrightarrow \quad d \mid a _ {n + D}
$$

分别取 $d = a _ { n }$ 与 $d = a _ { n + D }$ ，可得 $a _ { n } \mid a _ { n + D }$ 且 $a _ { n + D } \mid a _ { n }$ ，从而 $a _ { n + D } = a _ { n }$ 。因此原数列最终以 D 为周期。
