求证：至多只有一种办法用互不相交的对角线将凸多边形划分为锐角三角形。

## 解

假设所给定的为凸 n 边形。断言显然对 n = 3 成立。下设 $n \geqslant$ 4。

将用互不相交的对角线将凸多边形划分为三角形称为“三角形剖分”，将用互不相交的对角线将凸多边形划分为锐角三角形称为“锐角三角形剖分”。剖分出的三角形称为“边缘”的，如果它有两条边是原多边形的边。

我们需要如下断言：

(i) 在任何三角形剖分中，都至少能找到两个边缘三角形。

事实上，所有剖分出的三角形的内角之和等于凸 n 边形的内角之和，即 $( n - 2 ) \pi$ 。既然一个三角形的内角之和等于 π，所以所有剖分出的三角形的个数等于 $n - 2$ 。若其中有 $e$ 个边缘三角形，则每个边缘三角形有两条边是凸 n 边形的边，其余每个三角形至多有一条边是 $\ntrianglerighteq$ n 边形的边。数原多边形的边可得 $n \leqslant 2 e + ( n - 2 - e ) = n - 2 + e$ ，所以 $e \geqslant 2$ ，断言 (i) 得证。

(ii) 在任何凸 n 边形中，都至多有三个锐角。

假设对某个 $\sharp n$ 边形断言不成立，则在该凸 n 边形的外角中，至少有 4 个是钝角，它们的和大于 $4 \cdot 9 0 ^ { \circ } = 2 \pi$ 。然而，如所周知，凸 n 边形的所有外角之和等于 $2 \pi$ ，此为矛盾！

现在回到本题。

假设可以找到凸 n 边形的两个不同的锐角三角形剖分 $\triangle _ { 1 }$ 与 $\triangle _ { 2 }$ ，以 A 表示凸 n 边形的所有锐角的集合。

观察剖分 $\triangle _ { 1 }$ 的边缘三角形 $T _ { \mathrm { ~ c ~ } }$ 。它有一个角是凸 n 边形的角，由于 T 是锐角三角形，所以该角属于集合 A。由于根据断言 (i)，在剖分 $\triangle _ { 1 }$ 中可以找到两个边缘三角形，因此 A 中有两个角是剖分 $\triangle _ { 1 }$ 中的边缘三角形的角。对于 $\triangle _ { 2 }$ ，亦有同样的结论。

根据断言 (ii)，集合 A 中至多有 3 个角。因此，其中至少有 1 个角同时属于剖分 $\triangle _ { 1 }$ 中的边缘三角形 $T _ { 1 }$ 和剖分 $\triangle _ { 2 }$ 中的边缘三角形 $T _ { 2 }$ 。这意味着 $T _ { 1 }$ 与 $T _ { 2 }$ 重合，即 $\triangle _ { 1 }$ 与 $\triangle _ { 2 }$ 有公共的边缘三角形。删去该三角形，我们回到关于凸 n 1 边形的三角形剖分问题。继续这一删去边缘三角形的过程，即可最终得到 $\triangle _ { 1 }$ 与 $\triangle _ { 2 }$ 是由同样的三角形构成的集合。

## TOT 2001 Spring Junior A4

若干条除公共端点外互不相交的对角线将一个凸多边形剖分成三角形。在多边形的每个顶点旁，写下包含该顶点的小三角形个数。擦去所有对角线后，能否根据各顶点旁的数字恢复全部对角线？

## 解

可以。

把含有原多边形连续两条边的小三角形称为耳，这两条边的公共顶点称为耳尖。

先说明当边数大于 3 时，任意 $\ntrianglerighteq$ 多边形的三角剖分至少有两只耳。设剖分中有 t 个小三角形和 d 条对角线。每条对角线被两个小三角形共有，原多边形的每条边只属于一个小三角形，故 $3 t = n + 2 d ;$ ；另一方面，每增加一条互不相交的对角线，区域数增加 1，故 $t = d + 1$ o于是 $t = n - 2 , \ d = n - 3$ 。若共有 $e$ 只耳，则每只耳含有两条原多边形的边，其余每个小三角形至多含有一条原多边形的边。数原多边形的边可得 $n \leqslant 2 e + ( t - e ) = n - 2 + e$ ，所以$e \geqslant 2 { \mathrm { . } }$ 

设凸 n 边形的顶点依次为 $V _ { 1 } , V _ { 2 } , \cdots , V _ { n }$ ，顶点 $V _ { i }$ 旁的标号为 $c _ { i }$ ，下标按模 n 理解。注意到， $c _ { i } = 1$ 当且仅当 $V _ { i }$ 是一只耳的耳尖。事实上，如果 $c _ { i } = 1$ ，那么原多边形的两条边 $V _ { i - 1 } V _ { i }$ 与 $V _ { i } V _ { i + 1 }$ 必须属于同一个小三角形，这个三角形只能是 $V _ { i - 1 } V _ { i } V _ { i + 1 }$ ，所以 $V _ { i - 1 } V _ { i + 1 }$ 必为剖分中的对角线。反过来，如果 $V _ { i - 1 } V _ { i } V _ { i + 1 }$ 是一只耳，那么对角线 $V _ { i - 1 } V _ { i + 1 }$ 将 $V _ { i }$ 与其余部分隔开，故只有这一只小三角形包含 $V _ { i }$ ，于是 $c _ { i } = 1$ 。

下面对 n 归纳。当 $n = 3$ 时没有对角线，结论显然成立。设 $n \geqslant 4$ ，由耳的存在性，至少有一个顶点 $V _ { i }$ 满足 $c _ { i } = 1$ 。于是任何符合原标号的剖分都必须含有同一只耳 $V _ { i - 1 } V _ { i } V _ { i + 1 }$ ，对角线 $V _ { i - 1 } V _ { i + 1 }$ 也就被这些标号唯一确定。

删去顶点 $V _ { i }$ 以及这只耳，剩下一个凸 $( n - 1 )$ 边形。由于只删去了一个小三角形，顶点$V _ { i - 1 }$ 与 $V _ { i + 1 }$ 的新标号分别为 $c _ { i - 1 } - 1$ 与 $c _ { i + 1 } - 1$ ，其余顶点的标号不变。由归纳假设，这组新标号能够唯一确定剩余多边形的全部对角线。最后补回对角线 $V _ { i - 1 } V _ { i + 1 }$ ，便恢复了原剖分，且结果唯一。

因此，可以根据各顶点旁的数字恢复全部对角线。

## IMOSL 2015 G8

用若干条除公共端点外互不相交的对角线把凸多边形 Π 分成三角形，称为 Π 的一个三角剖分。如果一个三角剖分中的所有小三角形面积相等，就称其为泰式剖分。证明：Π 的任意两个不同泰式剖分，除某个四边形内的两个小三角形外完全相同。换言之，只需在这个四边形内翻转一次对角线，便可由其中一个剖分得到另一个。

## 解

记 [S] 为图形 $S$ 的面积。设凸多边形 Π 有 n 条边。一个三角剖分若有 t 个小三角形和 $d$ 条对角线，则 $t = d + 1$ 且 $3 t = n + 2 d$ ，所以 $t = n - 2$ 。因此 Π 的任一泰式剖分中的小三角形都有同一面积 $s = [ \Pi ] / ( n - 2 )$ 

若一个三角剖分中相邻的两个小三角形之并是平行四边形，就说该剖分含有这个平行四

边形。先证明两个引理。

引理一：同一个三角剖分至多含有一个平行四边形。

引理一证明：反设某个三角剖分含有两个平行四边形。若它们共有一个小三角形，可将第一个记为由 ABC 与 ACD 组成的平行四边形，将第二个记为由 ACD 与 CDE 组成的平行四边形。于是 $B C \parallel A D \parallel C E$ ，从而凸多边形的三个不同顶点 B,C,E 共线，矛盾。

下面设两个平行四边形不含公共小三角形。把第一个记为 $A B C D ,$ 。它的四条边将 Π 在其外部的部分隔成若干块，第二个平行四边形必位于其中一块；不妨这一块在边 AD 的外侧。可将第二个平行四边形的顶点依次记为 $X , Y , Z , T$ ，使 $A , B , C , D , X , Y , Z , T$ 按所得凸多边形的边界顺序排列。这里允许 $D = X$ 或 $T = A$ ，但仍至少有六个不同顶点。由于平行四边形的相邻内角互补，该凸多边形在 B,C 两点的外角之和为 $1 8 0 ^ { \circ }$ ，在 Y,Z 两点的外角之和也为$1 8 0 ^ { \circ }$ 。其余至少两个外角均为正，故全部外角之和大于 360◦，与凸多边形外角和等于 $3 6 0 ^ { \circ }$ 矛盾。

引理二：泰式剖分中的每个小三角形至少含有 Π 的一条边。

引理二证明：取泰式剖分中的一个小三角形 ABC，作非退化仿射变换，把它变成正三角形 $A ^ { \prime } B ^ { \prime } C ^ { \prime }$ 。仿射变换保持凸性、共线性和面积比，所以像剖分仍是像多边形的泰式剖分。

若正三角形的三条边都不是像多边形的边，则每条边的另一侧都有另一个小三角形。分别把以 $A ^ { \prime } B ^ { \prime }$ 与 $B ^ { \prime } C ^ { \prime }$ 为公共边的小三角形记为 $A ^ { \prime } B ^ { \prime } Z$ 与 $B ^ { \prime } C ^ { \prime } X$ ，把以 $C ^ { \prime } A ^ { \prime }$ 为公共边的小三角形记为 $C ^ { \prime } A ^ { \prime } Y$ ，则 $A ^ { \prime } , Z , B ^ { \prime } , X , C ^ { \prime } , Y$ 依次构成凸六边形。这个六边形在 $X , Y , Z \equiv$ 点的外角之和小于 $3 6 0 ^ { \circ }$ ，故其中至少一个小于 $1 2 0 ^ { \circ }$ ；不妨 Z 点的外角小于 $1 2 0 ^ { \circ }$ 。令 $\theta = \angle A ^ { \prime } Z B ^ { \prime } > 6 0 ^ { \circ }$ ，设$A ^ { \prime } B ^ { \prime } = a$ ，并记三角形 $A ^ { \prime } B ^ { \prime } Z$ 对底边 $A ^ { \prime } B ^ { \prime }$ 的高为 $h _ { \circ }$ 。对固定的底边和顶角，高在 $A ^ { \prime } Z = B ^ { \prime } Z$ 时最大，故

$$
h \leqslant (a / 2) \cot (\theta / 2) <   (a / 2) \cot 3 0 ^ {\circ} = \sqrt {3} a / 2
$$

所以 $[ A ^ { \prime } B ^ { \prime } Z ] < [ A ^ { \prime } B ^ { \prime } C ^ { \prime } ]$ ，与像剖分是泰式剖分矛盾。引理二得证。

把含有 的连续两条边的小三角形称为耳。每个三角剖分都有耳。当 $n = 3$ 时这显然成立；当 $n > 3$ 时，以小三角形为顶点、以公共对角线所对应的邻接关系为边所得的对偶图是连通图，并有 t 个顶点和 $d = t - 1$ 条边，故它是一棵至少有两片叶的树；其叶所对应的小三角形恰有两条边属于 Π。

$$
[ A B D ] = [ A B C ] + [ A C D ] - [ B C D ] = s
$$

于是对角线AC 与BD 都把四边形ABCD 的面积平分。设 $O = A C \cap B D$ 。由 $[ A B C ] = [ A C D ]$ 可知 $B , D$ 到 AC 的距离相等，而 $B , O , D$ 共线，故 $B O = D O$ ；同理由 $[ A B D ] = [ B C D ]$ 得$A O = C O$ 。所以两条对角线互相平分，ABCD 是平行四边形。
