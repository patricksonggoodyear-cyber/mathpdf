## Vietnam TST 2003 P1

设 $m , n , p , q$ 为正整数，且 $p \ < \ m , \ q \ < \ n _ { \mathfrak { c } }$ 。在平面直角坐标系中取点 $A ( 0 , 0 ) , \ B ( p , 0 )$ $C ( m , q ) , D ( m , n )$ 。考虑所有从 A 到 D 的路径 f 和从 B 到 C 的路径 g，其中每条路径只能沿坐标轴正方向行进，并且只能在整点处改变行进方向。设 S 为没有公共点的有序路径对$( f , g )$ 的数量。求证：

$$
S = \binom {m + n} {n} \binom {m + q - p} {q} - \binom {m + q} {q} \binom {m + n - p} {n}
$$

## 解

将路径中的每一条水平线段或竖直线段按整点分割成单位线段后，每条路径都可以唯一表示为由向右、向上两种单位步组成的格路径。

先不要求两条路径没有公共点。从 A 到 D 的路径含有 m 步向右和 n 步向上，共有 $\binom { m + n } { n }$ 条；从 B 到 C 的路径含有 $m - p$ 步向右和 q 步向上，共有 $\binom { m + q - p } { q }$ 条。因此所有有序路径对共有

$$
\binom {m + n} {n} \binom {m + q - p} {q}
$$

个。

下面计算有公共点的路径对数量。两条格路径只由格线上的单位线段组成，所以它们只要相交，交集中就必有整点。对于一个有公共点的路径对 $( f , g )$ ，取使 $x + y$ 最小的公共整点X，交换两条路径从 X 开始的尾段，便得到一条从 A 到 C 的路径和一条从 B 到 D 的路径。

反过来，任取一条从 A 到 C 的路径和一条从 B 到 D 的路径，它们必有公共点。事实上，用 $x + y = t$ 对两条路径同步参数化：当 $t = p$ 时，前一条路径上点的横坐标不大于后一条路径起点 B 的横坐标；当 $t = m + q$ 时，前一条路径终点 C 的横坐标不小于后一条路径上点的横坐标。由连续性，某一时刻两点的横坐标相等，而它们的纵横坐标之和也相等，故两点重合。取使 $x + y$ 最小的公共整点并交换尾段，就还原出一条从 A 到 D 的路径和一条从 B 到C 的路径。两次操作互为逆操作，因此这是一个双射。

从 A 到 C 的路径共有 $\binom { m + q } { q }$ 条，从 B 到 D 的路径共有 $\binom { m + n - p } { n }$ 条，所以有公共点的原路径对共有

$$
\binom {m + q} {q} \binom {m + n - p} {n}
$$

个。用所有路径对的数量减去有公共点的路径对数量，即得所证等式。

Nordic 2012 P4 

黑板上最初写有数 1。此后反复进行如下操作：每一步把黑板上的每一个数 a 分别替换为 $a - 1$ 和 $a + 1$ ；若出现 0，便立即将它擦去；若同一个数出现多次，则保留它的所有出现。问经过 n 步后，黑板上共有多少个数?

## 解

将同一个数的不同出现看作彼此不同。经过 n 步后，黑板上每个数的一次出现都唯一对应于一个序列 $x _ { 0 } , x _ { 1 } , \cdots , x _ { n }$ ，其中 $x _ { 0 } = 1$ ，所有 $x _ { i }$ 均为正整数，且 $x _ { i } - x _ { i - 1 } \in \{ - 1 , 1 \}$ 。因此，把 $x _ { i }$ 看作纵坐标，则所求数目 $\sigma _ { n }$ 等于从 $A = ( 0 , 1 )$ 出发，每步走 (1,1) 或 $( 1 , - 1 )$ ，始终不接触横轴，并在直线 $x = n$ 上结束的格路条数。

设一条长为 n 的格路含有 r 个上升步，则其终点为 $B _ { r } = ( n , 1 + 2 r - n )$ 。终点的纵坐标为正当且仅当 $r \geqslant \lceil n / 2 \rceil$ 。若暂不限制格路接触横轴，则从 A 到 $B _ { r }$ 的格路共有 <sup>n</sup> 条。

下面计算其中接触过横轴的格路数。对于一条从 A 到 $B _ { r }$ 且接触过横轴的格路，取它首次接触横轴的点 X，将从 A 到 X 的初始路段关于横轴反射，便得到一条从 $A ^ { \prime } = ( 0 , - 1 )$ 到$B _ { r }$ 的无约束格路。反过来，任意一条从 $A ^ { \prime }$ 到正纵坐标终点 $B _ { r }$ 的格路都必定接触横轴；将其到首次接触横轴处为止的初始路段关于横轴反射，就还原出一条从 A 到 $B _ { r }$ 且接触过横轴的格路。因此，这一反射构造是一个双射。

从 $A ^ { \prime }$ 到 $B _ { r }$ 的格路恰有 $r + 1$ 个上升步，故共有 $\scriptstyle { \binom { n } { r + 1 } }$ 条。约定 $\textstyle { \binom { n } { n + 1 } } = 0$ ，将所有可能的正纵坐标终点对应的格路数相加，并作裂项相消，得到

$$
\begin{array}{c} \sigma_ {n} = \sum_ {r = \lceil n / 2 \rceil} ^ {n} \left(\binom {n} {r} - \binom {n} {r + 1}\right) \\ = \binom {n} {\lceil n / 2 \rceil} = \binom {n} {\lfloor n / 2 \rfloor} \end{array}
$$

所以经过 n 步后，黑板上共有 $\scriptstyle { \binom { n } { \lfloor n / 2 \rfloor } }$ 个数。

考虑一个标准的 $8 \times 8$ 国际象棋棋盘，它由按通常方式染色的 64 个小正方形组成，其中32 个为黑色，32 个为白色。一条贯穿棋盘的锯齿形路径由 8 个白色小正方形组成，每行恰有一个，并且相邻两行中选取的两个白格恰在一个顶点处相接。问共有多少条这样的锯齿形路径？

## TOT 1996 Autumn Senior A5

一个圆形岛屿的边界上按顺序设有港口 1,2,3,4,5,6。岛上的道路构成有限平面道路网，道路的交叉、汇合或分岔处均视为路网顶点。每段道路均规定单行方向，并且沿道路离开任一港口或路网顶点后，都不能再回到该点。记 $f _ { i j }$ 为从港口 i 到港口 j 的不同有向路径的条数。证明：

$$
f _ {1 6} f _ {2 5} f _ {3 4} + f _ {1 5} f _ {2 4} f _ {3 6} + f _ {1 4} f _ {2 6} f _ {3 5} \geqslant f _ {1 6} f _ {2 4} f _ {3 5} + f _ {1 5} f _ {2 6} f _ {3 4} + f _ {1 4} f _ {2 5} f _ {3 6}
$$

解

道路网是有限有向无环图，固定其顶点的一个拓扑序，即每条有向道路都从序中较早的顶点指向较晚的顶点。考虑所有有序三元组 $( P _ { 1 } , P _ { 2 } , P _ { 3 } )$ ，其中 $P _ { i }$ 从港口 i 出发，三条路径的终点分别是港口 4,5,6 的某个排列。按终点排列的奇偶性将这些三元组分为奇类和偶类。题中不等式的左端是奇类的总数，右端是偶类的总数。

若三条路径中有两条经过同一个顶点，取拓扑序最早的这样的顶点 M。在经过 M 的路径中，选编号最小的两条，交换它们从 起的尾段。交换后的两条仍是有向路径：若有重复顶点，就会在有向无环图中形成有向回路。它们的终点互换，故终点排列的奇偶性改变。

这一操作是对合。事实上，交换的尾段中除 M 外的顶点都排在 M 之后，所以各路径在M 以前经过的顶点以及在 M 处的经过情况均不变。再次操作时仍选中同一个 M 和同两条路径，交换尾段便恢复原三元组。因此，有公共顶点的奇类与偶类三元组两两配对，计数时相互抵消。

余下三条路径两两没有公共顶点。设它们的终点依次为 $e _ { 1 } , e _ { 2 } , e _ { 3 } \circ$ 若某个 $i ~ < ~ j$ 满足$e _ { i } < e _ { j }$ ，则圆周上这两条路径的四个端点依次为 $i , j , e _ { i } , e _ { j }$ ，彼此交错；平面内连接交错端点的两条路径必相交，矛盾。故必有 $e _ { 1 } > e _ { 2 } > e _ { 3 }$ ，即终点依次为 6,5,4。这种三元组属于奇类。因此，原不等式的左端与右端之差，恰是三条两两无公共顶点的路径 $1  6 , 2  5 , 3  4$ 所组成的三元组的数量，必然非负。
