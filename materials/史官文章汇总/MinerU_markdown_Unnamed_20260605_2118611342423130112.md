IMO 1968 P5 

设 f 是定义在 R 上的实值函数，存在某个常数 $a > 0$ ，使得对一切实数 x 都有

$$
f (x + a) = \frac {1}{2} + \sqrt {f (x) - f (x) ^ {2}}
$$

求证：f 必为周期函数，并在 a = 1 的情形下给出一个非常数的此类函数 f 的具体例子。

## 解

由于根号对每个实数 x 都有定义，故 $0 \leqslant f ( x ) \leqslant 1$ 。再把原方程中的 x 换成 $x - a$ ，可得 $f ( x ) \geqslant 1 / 2$ 。令 $u ( x ) = f ( x ) - 1 / 2$ ，则 $0 \leqslant u ( x ) \leqslant 1 / 2$ ，原方程化为

$$
u (x + a) = \sqrt {1 / 4 - u (x) ^ {2}}
$$

由此对任意实数 x，都有

$$
u (x + 2 a) ^ {2} = 1 / 4 - u (x + a) ^ {2} = u (x) ^ {2}
$$

因为 $u ( x + 2 a )$ 与 u(x) 都非负，所以 $\boldsymbol { u } ( \boldsymbol { x } + 2 a ) = \boldsymbol { u } ( \boldsymbol { x } )$ ，即 $f ( x + 2 a ) = f ( x )$ 。因此 2a 是 f的一个周期。

当 a = 1 时，取 $f ( x ) = 1 / 2 + | \cos ( \pi x / 2 ) | / 2$ 。此时 $f ( x ) - f ( x ) ^ { 2 } = \sin ^ { 2 } ( \pi x / 2 ) / 4$ ，从而

$$
f (x + 1) = 1 / 2 + | \sin (\pi x / 2) | / 2 = 1 / 2 + \sqrt {f (x) - f (x) ^ {2}}
$$

又 f(0) = 1 而 $f ( 1 ) = 1 / 2$ ，故这是所求的非常值函数。

是否存在这样的定义在整个实轴上的非周期函数 f，使得对任何实数 x，都满足关系式$f ( x + 1 ) = f ( x + 1 ) f ( x ) + 1 ?$ 

原方程等价于 $f ( x + 1 ) ( 1 - f ( x ) ) = 1$ 。因此 $f ( x ) \neq 1 ;$ ；又因 $x + 1$ 遍历全体实数，可知$f ( x ) \neq 0$ 。于是对任意实数 x，都有

$$
f (x + 1) = \frac {1}{1 - f (x)}
$$

记 $t = f ( x )$ 。连续代入两次并利用 $t \neq 0 , 1$ ，得到

$$
f (x + 2) = \frac {t - 1}{t}, \quad f (x + 3) = \frac {1}{1 - (t - 1) / t} = t
$$

所以 $f ( x + 3 ) = f ( x )$ 对一切实数 x 成立，任何满足方程的函数都有周期 3。所求的非周期函数不存在。

TOT 1986 Spring Senior P4 

设函数 f : R R 对任意实数 x 都满足

$$
f (x + 1) f (x) + f (x + 1) + 1 = 0
$$

证明 f 不可能连续。

解

由原方程可知， $f ( x )$ 不能等于 1；又因为 $f ( x + 1 ) = - 1 / ( f ( x ) + 1 )$ ，且 $x + 1$ 遍历全体实数，f 也处处不取 0。固定实数 x，令 $t = f ( x )$ ，依次代入原方程，得到

$$
f (x + 1) = - \frac {1}{t + 1}, \qquad f (x + 2) = - \frac {t + 1}{t}, \qquad f (x + 3) = t
$$

若 $t > 0$ ，则 $f ( x + 1 ) < 0 ;$ ；若 $- 1 < t < 0$ ，则 $f ( x + 2 ) > 0$ ；若 $t < - 1$ ，则 $f ( x + 1 ) > 0$ 。在后两种情形下 $f ( x ) = t < 0$ 。因此在 $x , x + 1 , x + 2$ 这三个点中，f 总有正值和负值。若 f 连续，介值定理便保证它在 $[ x , x + 2 ]$ 内某处取 0，与前述结论矛盾。故 f 不可能连续。

Nordic 1996 P4 

这里有一个函数 $f : \mathbb { Z } _ { + } \to$ R 和一个正整数 a，它们满足

$$
f (a) = f (1 9 9 5), \quad f (a + 1) = f (1 9 9 6), \quad f (a + 2) = f (1 9 9 7)
$$

并且对任意正整数 n 均有

$$
f (n + a) = \frac {f (n) - 1}{f (n) + 1}
$$

(a) 求证：对任意正整数 n 均有 $f ( n + 4 a ) = f ( n )$ ；(b) 求 a 的最小可能值。

解

对实数 $t \neq - 1$ ，记 $T ( t ) = ( t - 1 ) / ( t + 1 )$ 。题设首先保证 $f ( n ) \neq - 1$ 。若 $f ( n ) = 0$ ，则$f ( n + a ) = - 1$ ；若 $f ( n ) = 1$ ，则 $f ( n + a ) = 0$ ，也会导致后续函数值为 1。故 f(n) 对所有正整数 n 均避开 $- 1 , 0 , 1 .$ 。直接计算得 $T ^ { 2 } ( t ) = - 1 / t$ ，从而 $T ^ { 4 } ( t ) = t$ 。由 $f ( n + a ) = T ( f ( n ) )$ 连续迭代四次，便有 $f ( n + 4 a ) = f ( n )$ ，完成 (a)。

下面求最小的 a。若 $a = 1$ ，由 (a) 知 4 是周期，而 $1 9 9 5 = 3 + 4 9 8 \cdot 4 { \mathrm { ~ o ~ } }$ 。条件 $f ( 1 ) = f ( 1 9 9 5 )$ 因而给出 $f ( 1 ) = f ( 3 ) = T ^ { 2 } ( f ( 1 ) ) = - 1 / f ( 1 )$ ，即 $f ( 1 ) ^ { 2 } = - 1$ ，矛盾。若 $a = 2$ ，由 (a) 知 8是周期。由于 $1 9 9 5 = 3 + 2 4 9 \cdot 8 \cdot 1 9 9 6 = 4 + 2 4 9 \cdot 8$ ，题设给出 $f ( 2 ) = f ( 3 ) = f ( 4 )$ ；另一方面 $f ( 4 ) = T ( f ( 2 ) )$ ，于是 $f ( 2 ) = T ( f ( 2 ) )$ ，同样推出 $f ( 2 ) ^ { 2 } = - 1$ ，矛盾。

取 $a = 3$ 时，先令 $f ( 1 ) = f ( 2 ) = f ( 3 ) = 2$ ，再对每个正整数n递归定义 $f ( n + 3 ) = T ( f ( n ) )$ 。因为 T 使 $2 , 1 / 3 , - 1 / 2 , - 3$ 依次循环，所得函数在正整数上处处有定义，且以 12 为周期。又$1 9 9 5 = 3 + 1 6 6 \cdot 1 2 , 1 9 9 6 = 4 + 1 6 6 \cdot 1 2 , 1 9 9 7 = 5 + 1 6 6 \cdot 1 2$ ，故题设的三个等式均成立。因此 a 的最小可能值为 3。

Kvant M606 

设函数 f : R R 对每个实数 x 都满足 $f ( x + 1 ) + f ( x - 1 ) = { \sqrt { 2 } } f ( x )$ 。证明 f 是周期函数。

解

将原方程中的 x 换成 $x + 1$ ，可得 $f ( x + 2 ) = { \sqrt { 2 } } f ( x + 1 ) - f ( x )$ 。再连续应用这一递推关系，得到

$$
f (x + 3) = f (x + 1) - \sqrt {2} f (x)
$$

因此

$$
f (x + 4) = \sqrt {2} f (x + 3) - f (x + 2) = - f (x)
$$

把 x 换成 $x + 4$ ，即得 $f ( x + 8 ) = - f ( x + 4 ) = f ( x )$ 。所以 8 是 f 的一个周期。
