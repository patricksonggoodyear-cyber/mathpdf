$$
f (f (x) + y) = f (f (y) + x)\tag{1}
$$

$$
\begin{array}{r l} f (f (x) f (y)) & = f (f (x) + y) + f (f (x) y) - f (y) \\ & = f (f (x) + y) + f (x + y) + f (x y) - f (x) - f (y) \end{array}

$$
\delta = f (f (x) + y) - f (x) - f (y)

\begin{array}{r l} f (z + f (f (x) + y)) & = f (f (z) + f (x) + y) \\ & = f (f (x) + f (z) + y) \\ & = f (x + f (f (z) + y)) \\ & = f (x + f (f (y) + z)) \\ & = f (f (x) + f (y) + z) \\ & = f (z + f (x) + f (y)) \end{array}

$$

$$

解

对任意 $t \in \mathbb { Q }$ ，在题设中取 $x = y = t$ ，可得 $f ( t + f ( t ) ) = t + f ( t )$ 。若 $f ( u ) = f ( v )$ 而$u \ne v$ ，则在题设中取 $x = u , y = v \colon$ ：第一种等式的左侧等于 $u + f ( u ) \neq v + f ( u )$ ，第二种等式的左侧等于 $v + f ( v ) \neq u + f ( v )$ ，均不可能成立。所以 f 是单射。

记 $x  y$ 表示 $f ( x + f ( y ) ) = f ( x ) + y$ 。题设保证对任意 $x , y ;$ ，至少有 $x  y$ 或 $y  x \bullet$ 由对角代入得到的等式还知 $x \to x _ { \circ }$ 记 $g ( t ) = f ( t ) + f ( - t )$ 。若 $x  y ;$ ，令 $A = x + f ( y )$ ，再考察 A 与 $- y { \mathrm { : } }$ 

若 $A \to - y$ ，则 $f ( A + f ( - y ) ) = f ( A ) - y = f ( x )$ 。由单射性， $A + f ( - y ) = x$ ，即 $g ( y ) = 0$ 。

若 $- y \to A$ ，则 $f ( - y + f ( A ) ) = f ( - y ) + A = x + g ( y )$ 。由 $x  y$ 知 $f ( A ) = f ( x ) + y$ 故左侧等于 $f ( f ( x ) )$ ，于是 $g ( y ) = f ( f ( x ) ) - x .$ 。

因此，只要 $x  y$ ，就有

$$
g (y) = 0 \qquad {\text {或}} \qquad g (y) = f (f (x)) - x
$$

特别地， $x  x$ ，所以当 $g ( x ) \neq 0$ 时， $g ( x ) = f ( f ( x ) ) - x \circ$ 若 $g ( x )$ 与 $g ( y )$ 均非零，题设给出 $x  y$ 或 $y  x .$ 。在前一种情形， $g ( y ) = f ( f ( x ) ) - x = g ( x )$ ；在后一种情形，交换 $x , y$ 可得相同结论。因此 g 的所有非零值都相等，其值域至多有两个元素。

再构造取到两个值的函数 $f ( x ) = 2 \lfloor x \rfloor - x \mathrm { { . } }$ 。写 $x = m + s , y = n + t$ ，其中 $m , n \in \mathbb { Z }$ 且$0 \leqslant s , t < 1$ ，并记 $k = m + n$ 。若 $s \geqslant t$ ，则 $x + f ( y ) = k + s - t$ ，从而 $f ( x + f ( y ) ) = k - s + t =$ $f ( x ) + y ;$ 若 $s < t$ ，则 $f ( x ) + y = k + t - s$ ，从而 $f ( f ( x ) + y ) = k - t + s = x + f ( y )$ 。故此函数满足题设，且

$$
g (x) = \left\{ \begin{array}{l l} 0, & x \in \mathbb {Z} \\ - 2, & x \notin \mathbb {Z} \end{array} \right.
$$

于是所求最小整数为 $c = 2$ 0
