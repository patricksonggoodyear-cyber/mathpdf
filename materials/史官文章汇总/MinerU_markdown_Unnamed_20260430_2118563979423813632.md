IMOSL 2022 C4 

设整数 $n > 3 \mathrm { . }$ 有 n 个小朋友围成一圈，起初把 n 枚硬币任意分给他们，允许有人没有硬币。一次操作中，持有至少两枚硬币的小朋友可以给左右相邻的小朋友各一枚硬币。求所有能够经过有限次操作，使每个小朋友最终恰有一枚硬币的初始分配。

解

将小朋友依次编号为 1,2,··· ,n，记第 i 人初始有 $a _ { i }$ 枚硬币，以下下标均按模 n 理解。答案是所有满足

$$
\sum_ {i = 1} ^ {n} i a _ {i} \equiv \frac {n (n + 1)}{2} \pmod {n}
$$

的初始分配。

先把操作的累计作用写成初末状态之间的方程。若第 i 人总共操作 $x _ { i }$ 次，则他共给出 $2 x _ { i }$ 枚硬币，并从两位邻居处分别得到 $x _ { i - 1 } , x _ { i + 1 }$ 枚硬币。因此，最终每人恰有一枚硬币就要求

$$
a _ {i} - 2 x _ {i} + x _ {i - 1} + x _ {i + 1} = 1, \qquad 1 \leqslant i \leqslant n
$$

令 $\begin{array} { r } { T = \sum _ { i = 1 } ^ { n } i ( a _ { i } - 1 ) } \end{array}$ 。将上述等式移项后加权求和，得到

$$
T = \sum_ {i = 1} ^ {n} i (2 x _ {i} - x _ {i - 1} - x _ {i + 1}) = n (x _ {n} - x _ {1})
$$

所以 $n \mid T$ ，这正是所述同余条件，必要性成立。

反过来，假设 $n \mid T$ 。为求出整数解 $x _ { i }$ ，令 $y _ { i } = x _ { i } - x _ { i - 1 }$ ，则所需方程化为 $y _ { i + 1 } - y _ { i } = 1 - a _ { i }$ o取 $y _ { 1 } = - T / n$ ，再依次用这个递推式定义 $y _ { 2 } , \cdots , y _ { n + 1 } $ 。由于 $\textstyle \sum a _ { i } = n$ ，有 $y _ { n + 1 } = y _ { 1 }$ ，而且

$$
\sum_ {i = 1} ^ {n} y _ {i} = n y _ {1} + \sum_ {j = 1} ^ {n} (n - j) (1 - a _ {j}) = n y _ {1} + T = 0
$$

令 $x _ { 0 } = 0$ ，并依次取 $x _ { i } = y _ { 1 } + \cdot \cdot \cdot + y _ { i }$ ，便有 $x _ { n } = x _ { 0 } = 0$ ，从而得到满足循环下标条件的整数解。给所有 $x _ { i }$ 同加一个足够大的整数，就得到非负整数解，且原方程不变。

还须证明这些代数条件确实保证目标状态可以合法到达。任意进行合法操作，设第 i 人目前已操作 $t _ { i }$ 次，剩余次数记为 $r _ { i } = x _ { i } - t _ { i }$ ，当前硬币数记为 $c _ { i }$ 。由初末状态方程，

$$
c _ {i} = a _ {i} - 2 t _ {i} + t _ {i - 1} + t _ {i + 1} = 1 + 2 r _ {i} - r _ {i - 1} - r _ {i + 1}
$$

初始时各 $r _ { i } \geqslant 0$ 。只要这个性质仍成立，若 $r _ { i } = 0$ ，便有 $c _ { i } \leqslant 1$ ，第 i 人不可能进行合法操作。因此，每次合法操作都发生在 $r _ { i } > 0$ 的位置，操作后所有余量仍非负，而 $\sum { r _ { i } }$ 减少 1。

所以过程至多进行 $\sum x _ { i }$ 次就必定停止，不必指定具体操作顺序。停止时每人至多有一枚硬币；又因为共有 n 人、n 枚硬币，只能是每人恰有一枚。充分性成立。

由于矩阵元素互不相同， $u _ { 1 } , \cdots , u _ { p }$ 两两不同， $v _ { 1 } , \cdots , v _ { p }$ 也两两不同，而且所有的和 $u _ { i } + v _ { j }$ 恰好各出现一次，组成 $0 , 1 , \cdots , p ^ { 2 } - 1$

$$

$$

## USAMO 2011 P2

## 解

$$

$$

因此 I 模 5 的余数不变。若最终只有 $A _ { j }$ 上的数为 2011，则 $I \equiv 2 0 1 1 j \equiv j { \pmod { 5 } }$ ，所以候选顶点唯一。

$$
