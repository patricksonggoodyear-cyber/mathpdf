## Iran TST 2014 P7

设 n 为正整数。一棵有 n 个顶点的树，其顶点初始分别标有 1,2,··· ,n，每个标号恰出现一次。按任意次序逐一选取树的全部边，每选取一条边，就交换其两个端点上的标号，每条边恰好选取一次。将初始标号为 i 的顶点上的最终标号记为 $\sigma ( i )$ 。证明：置换 σ 是一个长度为 n 的循环。

## 解

始终用初始标号给顶点命名。进行 k 次操作后，记顶点 i 上的标号为 $\sigma _ { k } ( i )$ ，并在集合$\{ 1 , 2 , \cdots , n \}$ 上画出箭头 $i  \sigma _ { k } ( i )$ 。由于所有标号各出现一次，每个点都有唯一前驱与唯一后继，因此这些箭头组成若干互不相交的有向回路；不动点也算一条长度为 1 的回路。

记 $F _ { k }$ 为保留原树全部顶点、只保留前 k 次操作所选边得到的森林。我们用归纳法证明：箭头图中各条回路的顶点集，恰好就是 $F _ { k }$ 各个连通分支的顶点集。

当 $k = 0$ 时， $\sigma _ { 0 } ( i ) = i $ ，每个点自成一条回路，而 $F _ { 0 }$ 的每个连通分支也只有一个点，结论成立。假设结论对 k 成立，下一次选取边 $a b .$ 。顶点 $a , b$ 必属于 $F _ { k }$ 的不同连通分支，否则$F _ { k }$ 中连接它们的路径与边 $a b$ 将在原树中形成圈。由归纳假设， $a , b$ 也位于箭头图的不同回路中。

交换顶点 $a , b$ 上的标号，恰好将箭头 $a  \sigma _ { k } ( a ) \setminus \ b  \sigma _ { k } ( b )$ 改为 $a  \sigma _ { k } ( b )$ $b \to \sigma _ { k } ( a )$ 其余箭头不变。删去原来的两条箭头后，原来的两条回路分别成为从 $\sigma _ { k } ( a )$ 到 a、从 $\sigma _ { k } ( b )$ 到b 的有向路径 (原回路只有一个点时，得到的路径可以没有边)。加入新的两条箭头，便把这两段路径接成一条回路。这恰好对应于加入边 $a b$ 后，森林中两个连通分支合并，其他分支及对应回路保持不变。因此归纳命题对 $k + 1$ 也成立。

全部 $n - 1$ 次操作完成后， $F _ { n - 1 }$ 就是原树，只有一个连通分支，所以最终置换 $\sigma = \sigma _ { n - 1 }$ 也只有一条回路，且包含全部 n 个元素，即为一个长度为 n 的循环。

Saint Petersburg MO 2006 Grade 10 P7 

整数 1,2,··· ,2006 各出现一次，被摆放在一个圆周上，满足如下性质：如果 $a + 1$ 是 b的左邻，则 $b + 1$ 是 a 的左邻，其中加法按模 2006 理解，即把 2006+1 看作 1。证明：存在一个数 x，它的左邻是 x+1。

## 解

以下数的加减均按模 2006 理解，并取 1,2,··· ,2006 为代表元。记 f(x) 为 x 的左邻，并令 $h ( x ) = f ( x ) - 1$ 。若 $h ( b ) = a$ ，则 $f ( b ) = a + 1$ ，由题设得到 $f ( a ) = b + 1$ ，即 $\boldsymbol { h } ( \boldsymbol { a } ) = \boldsymbol { b } _ { \circ }$ 所以 $h ( h ( x ) ) = x$ 。反设结论不成立，则 $h ( x ) \neq x$ ，从而这 2006 个数被 h 分成 1003 对不同的数；每对 {a, b} 都满足 $f ( a ) = b + 1 \setminus f ( b ) = a + 1$ o

沿着题设圆周的左邻方向依次读数，将这一循环次序改画成一个有向多边形，并把数标在边上，使编号为 x 的边之后紧接编号为 $f ( x )$ 的边。记编号为 x 的边的终点为 $V _ { x } \mathrm { . }$ 。对每一对 $\{ a , b \}$ ，把顶点 $V _ { a } , V _ { b }$ 黏合。这样得到一个有向多重图，其中共有 1003 个顶点，每个顶点都有两条入边和两条出边，允许出现环和重边。在与 $\{ a , b \}$ 对应的顶点处，入边编号为 a,b，出边编号为 $b + 1 , a + 1$ 。

在每个顶点指定两条入边与两条出边之间的一一配对，就为每条有向边规定了唯一后继，而且每条边也有唯一前驱。因此，全部边被分成若干条封闭回路。原多边形给出的配对在上述顶点处为 $a  b + 1 \lor \ b  a + 1$ ；采用这些原配对时，所有边恰好组成一条回路。

现在说明，交换某个顶点处两条入边的后继，会使回路总数恰好增加或减少 1。若这两条入边原属不同回路，在它们之后剪开并交换接续，就把两条回路合成一条；若原属同一回路，在这两处剪开后得到两段路径，交换接续就把它们各自闭合，成为两条回路。这里允许只有一条边的回路。因此，每交换一次，回路总数的奇偶性就改变一次。

依次在全部 1003 个顶点处交换后继。与 {a,b} 对应的配对就变为 $a  a + 1 , \ b  b + 1$ 所以最终每条编号为 x 的边之后都紧接编号为 x+1 的边，全部边仍恰好组成一条回路。然而，交换次数 1003 为奇数，回路总数的奇偶性应当改变，不可能从一条回路变为一条回路，矛盾。

故必存在一个数 x，它的左邻是 $x + 1$ 

## TOT 2006 Spring Senior A7

一只蚂蚁沿正十二面体的棱按一条封闭路线爬行；到达顶点后从不沿刚走过的棱原路折返，并且路线恰好经过每条棱两次。证明：至少存在一条棱，蚂蚁两次经过它时方向相同。(正十二面体有 12 个五边形面、30 条棱、20 个顶点，每个顶点与 3 条棱相接。)

## 解

反设每条棱的两次经过方向都相反。把每条棱看成方向相反的两条有向棱，则蚂蚁的路线恰好把全部 60 条有向棱各经过一次。

固定一个顶点。路线把三条到达该顶点的有向棱与三条从该顶点出发的有向棱一一配对。把关联的三条无向棱编号为 1,2,3，则“不原路折返”表示进入的棱与离开的棱不能同号。这样的配对只有 $1  2  3  1$ 和 $1  3  2  1$ 两种。相对于正十二面体表面的外侧方向，按照三条棱在顶点周围的环绕次序，这两种配对分别表示每次到达这个顶点都左转，以及每次到达这个顶点都右转。

对每个顶点指定左转或右转规则后，每条有向棱都有唯一后继，也有唯一前驱，所以全部 60 条有向棱被分成若干条封闭回路。不同回路可以经过同一顶点，但不会包含同一条有向棱。记回路总数为 $r _ { \mathrm { ~ c ~ } }$ 。

先说明一个后继交换事实。对于任意有限个对象，若每个对象都有唯一后继与唯一前驱，它们就分解成若干有向回路。交换两个不同对象的后继时，若二者原属不同回路，在它们之后剪开再交叉接续，就把两条回路合并；若二者原属同一回路，在两处剪开再交叉接续，就把一条回路拆成两条。因此，一次后继交换总使回路数改变 1，从而改变其奇偶性。

把一个顶点的左转规则改为右转规则，或反过来，相当于把到达该顶点的三条有向棱的三个后继循环交换。三个后继的一次循环交换可以分解为两次后继交换，所以这个改变不影响 r 的奇偶性。中间一次交换后的临时规则可能允许折返，但后继交换事实并不要求禁止折返，因而仍可用来计算回路数的奇偶性。

原路线包含全部 60 条有向棱，故原有规则给出 $r = 1$ 。现在逐个改变顶点的规则，使所有顶点都左转。此时从任意一条有向棱出发，始终沿其左侧五边形面的边界行进，所以得到的恰好是 12 个面的 12 条定向边界，即 $r = 1 2$ 。这与 r 的奇偶性始终不变矛盾。

因此，至少存在一条棱，蚂蚁两次经过它时方向相同。

## Japan Final Round 1998 P3

平面上互异的点 $P _ { 1 } , P _ { 2 } , \cdots , P _ { n }$ 依次连成有向闭折线 $P _ { 1 } P _ { 2 } \cdots P _ { n } P _ { 1 }$ 。允许闭折线自交，但线段不重叠，自交点均位于线段内部，且任意三条线段不经过同一点。沿指定方向行进，在每个顶点处把左转的转角记为正，右转的转角记为负，直行时转角为 0，转角的绝对值为 $1 8 0 ^ { \circ }$ 减去该顶点处两条线段的夹角。若所有有向转角之和为 $7 2 0 ^ { \circ }$ 的整数倍，证明：这条闭折线的自交点数为奇数。

## 解

记原闭折线的有向转角之和为 $T = 7 2 0 ^ { \circ } m$ ，其中 m 为整数。我们将逐次消去自交点，同时保持所有有向闭回路的总转角，并记录回路条数的变化。

在每个自交点 周围取一个足够小的圆盘，使这些圆盘两两不交，且每个圆盘内只有经过X 的两段相交直径，不含原顶点或其他交点。记两条原有通路为A → X → B 与 $C  X  D$ 其中 $A , B , C , D$ 均在圆盘边界上。删去盘内的两段直径，改接有向线段 $A  D$ 与 $C  B .$ 由于 $X A = X B = X C = X D$ ，两条新线段平行且不相交，故恰好消去交点 X，且不产生新的交点。

先说明改接保持总转角。若两条原有向线段的单位方向向量分别为 u,v，则两条新连接段的方向均为 $\mathbf { u } + \mathbf { v }$ 的方向，即原来两个方向之间较小夹角的平分方向。两条新通路的方向变化分别为 $\mathbf { u }  \mathbf { u } + \mathbf { v }  \mathbf { v }$ 与 $\mathbf { v }  \mathbf { u } + \mathbf { v }  \mathbf { u }$ ，所产生的四个有向转角逐对抵消。圆盘外的转角保持不变，因此全部有向闭回路的总转角仍为 T。

再说明改接对回路条数的影响。若两段原属不同回路，在这两处剪开并交换后续连接，就把两条回路合并；若原属同一回路，在两处剪开后得到两段有向路径，交换后续连接就把它们各自闭合成一条回路。因此，每次改接都使回路总数恰好增加或减少 1，从而改变其奇偶性。这个论证不要求尚未处理的其他交点已经消失。

设原折线共有 s 个自交点。依次完成所有改接后，得到若干条两两不交的有向简单闭折线。设其中逆时针绕行的有 $P$ 条，顺时针绕行的有 $Q$ 条。每条简单闭折线的总转角为 $3 6 0 ^ { \circ }$ 或 −360◦，故由总转角保持不变得到

$$
3 6 0 ^ {\circ} (P - Q) = T = 7 2 0 ^ {\circ} m
$$

所以 $P - Q = 2 m$ ，从而 $P + Q$ 为偶数。另一方面，起初只有一条闭回路，每次消去一个自交点都改变回路数的奇偶性，因此 $P + Q \equiv 1 + s { \pmod { 2 } }$ 。故 s 为奇数。

## IMOSL 2014 C9

纸上画有 n 个圆，任意两个圆交于两点，且没有三个圆经过同一点。一只蜗牛起初沿某个圆顺时针爬行；每当它到达与另一个圆的交点时，就转到另一个圆上，并把顺时针方向改为逆时针方向，或把逆时针方向改为顺时针方向。已知蜗牛的路径完整覆盖了所有圆。证明：n 是奇数。

## 解

在每个交点周围取一个足够小的圆盘，使这些圆盘两两不交，且每个圆盘中只有相交的两段圆弧。题设规则把圆盘边界上的四个端点两两配对；这两对端点可以在圆盘内用两条互不相交的光滑小弧连接。按此方式把全部交点分开，所得图形由若干条两两不交的简单闭曲线组成，蜗牛沿其中一条运动。由于它的路径覆盖全部原圆弧，这里实际上只有一条闭曲线。

先说明一次局部换接怎样改变闭曲线的条数。把一个小圆盘边界上的四个端点按环绕次序记为 1,2,3,4。圆盘内有两种不交叉的配对，即 $( 1 , 2 ) , ( 3 , 4 )$ 与 $( 1 , 4 ) , ( 2 , 3 )$ ；将一种改为另一种，称为一次换接。暂时删去圆盘内的两条连接弧，圆盘外的两条路径也把这四个端点两两配对。由平面上的不相交性，圆盘外不可能按 (1,3),(2,4) 配对，因此只有前述两种可能。若圆盘内外的配对相同，就组成两条闭曲线；若不同，就组成一条闭曲线。故每次换接恰好把两条闭曲线合并成一条，或把一条拆成两条，使闭曲线总数的奇偶性改变。

现在把全部交点各换接一次。交点共有 $\textstyle 2 { \binom { n } { 2 } } = n ( n - 1 )$ 个，是偶数，所以换接后闭曲线的条数仍为奇数。在每个交点，新的配对仍使路径转到另一个圆，但不再改变沿圆运动的顺、逆时针属性。因此，可以将每段保留下来的原圆弧都按逆时针方向定向，并沿连接弧延续这个方向，得到每条新闭曲线的一致定向。

设新闭曲线中绕其内部逆时针行进的有 P 条，顺时针行进的有 $Q$ 条。沿一条有向简单闭曲线行进一周时，切线方向的总转角为 $2 \pi$ 或 $- 2 \pi$ ，所以这些曲线的总转角之和为 $2 \pi ( P - Q )$ 

另一方面，将各小圆盘同时缩向对应交点，保持上述连接方式不变。所有原圆弧的转角总和趋于 $2 \pi n$ 。在一个交点处，设两圆的逆时针切线方向分别为 $\alpha , \beta ;$ ；两段连接弧分别把方向从 $\alpha$ 转为 $\beta .$ 、从 $\beta$ 转为 $\alpha$ ，其转角趋于互为相反数的两个角，故两者之和趋于 0。这里连接弧均取不额外绕转的小弧。缩小圆盘的过程中，各条简单闭曲线的总转角始终为 2π 或 −2π，

从而

$$
2 \pi (P - Q) = 2 \pi n
$$

因此 $n = P - Q \equiv P + Q { \pmod { 2 } }$ 。而 $P + Q$ 为奇数，故 n 为奇数。

## Saint Petersburg MO 2016 Grade 10 P6

一条 100 节闭折线内接于圆 (即每节线段的两个端点都在圆周上)，任意三节线段不经过同一点。它在每个顶点处的角均为钝角，且这些角的度数之和为 $7 2 0 ^ { \circ }$ 的整数倍。证明：这条闭折线的自交点数为奇数。

## 解

设顶点依次为 $A _ { 1 } , A _ { 2 } , \cdots , A _ { 1 0 0 }$ ，下标按模100理解，记 $\alpha _ { i } = \angle A _ { i - 1 } A _ { i } A _ { i + 1 }$ ，并设 $\textstyle \sum _ { i = 1 } ^ { 1 0 0 } \alpha _ { i } =$ $7 2 0 ^ { \circ } m$ ，其中 m 为整数。

先说明沿闭折线行进时，在所有顶点处的转向相同。因为 $\alpha _ { i } > 9 0 ^ { \circ }$ ，由圆周角定理，不含 $A _ { i }$ 的弧 $A _ { i - 1 } A _ { i + 1 }$ 大于半圆，所以含 $A _ { i }$ 的另一条弧小于半圆。因此，沿行进顺序从 $A _ { i - 1 }$ 到 $A _ { i }$ 、再到 $A _ { i + 1 }$ 的两条短弧具有相同方向。对所有 i 应用这一结论，便知相邻顶点之间的短弧全部同向。不妨选取使这些短弧均沿逆时针方向延续的行进方向，此时每个顶点都向左转，转角为 $1 8 0 ^ { \circ } - \alpha _ { i }$ 。于是总转角为

$$
T = 1 0 0 \cdot 1 8 0 ^ {\circ} - \sum_ {i = 1} ^ {1 0 0} \alpha_ {i} = 7 2 0 ^ {\circ} (2 5 - m)
$$

给闭折线按上述行进方向定向。在每个自交点 X 周围取一个足够小的圆盘，使这些圆盘两两不交，且每个圆盘内只有经过 X 的两段相交直径，不含原顶点或其他交点。记两条原有通路为 $A \to X \to B$ 与 $C  X  D$ ，其中 $A , B , C , D$ 均在圆盘边界上。删去盘内的两段直径，改接有向线段 $A  D$ 与 $C  B ,$ 。由于 $X A = X B = X C = X D$ ，两条新线段平行且不相交，故恰好消去交点 X，且不产生新的交点。

这个改接保持全部有向闭回路的总转角。事实上，若两条原有向线段的单位方向向量分别为 u,v，则两条新连接段的方向均为 $\mathbf { u } + \mathbf { v }$ 的方向，即原来两个方向之间较小夹角的平分方向。两条新通路的方向变化分别为 $\mathbf { u }  \mathbf { u } + \mathbf { v }  \mathbf { v }$ 与 $\mathbf { v }  \mathbf { u } + \mathbf { v }  \mathbf { u }$ ，所产生的四个有向转角逐对抵消；圆盘外的转角均不变。

另一方面，每次改接都使闭回路条数恰好增加或减少 1。若被改接的两段原属不同回路，在这两处剪开并交换后续连接，就把两条回路合并；若原属同一回路，在两处剪开后得到两段有向路径，交换后续连接就把它们各自闭合成一条回路。因此，每消去一个自交点，闭回路条数的奇偶性就改变一次。

设原折线有 s 个自交点。依次完成上述改接后，得到若干条两两不交的有向简单闭折线。设其中逆时针绕行的有 P 条，顺时针绕行的有 $Q$ 条。简单闭折线的总转角分别为 $3 6 0 ^ { \circ }$ 或$- 3 6 0 ^ { \circ }$ ，而改接保持总转角，故

$$
3 6 0 ^ {\circ} (P - Q) = T = 7 2 0 ^ {\circ} (2 5 - m)
$$

所以 $P { - } Q$ 为偶数，进而 $P { + } Q$ 也为偶数。起初只有一条闭回路，经过s次改接后有 $P { + } Q \equiv 1 { + } s$ (mod 2)，因此 s 为奇数。
