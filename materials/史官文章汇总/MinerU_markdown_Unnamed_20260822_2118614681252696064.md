## IMO 1971 P6

设 n 为正整数， $A = ( a _ { i j } ) _ { 1 \leqslant i , j \leqslant n }$ 是一个 $n \times n$ 方阵，其中每个元素都是非负整数。若$a _ { i j } = 0$ ，则第 i 行所有元素之和与第 $j$ 列所有元素之和的和不小于 $n$ 。证明：矩阵中全部元素之和不小于 $n ^ { 2 } / 2$ 。

## 解

记第 i 行所有元素之和为 $r _ { i }$ ，第 $j$ 列所有元素之和为 $c _ { j }$ ，并记矩阵中全部元素之和为 $S$ ，则

$$
S = \sum_ {i = 1} ^ {n} r _ {i} = \sum_ {j = 1} ^ {n} c _ {j}
$$

设x是 $r _ { 1 } , \cdots , r _ { n } , c _ { 1 } , \cdots , c _ { n }$ 中的最小值。必要时将矩阵转置，再重新编号各行，不妨设 $r _ { 1 } = x$ 若 $x \geqslant n / 2$ ，则每个行和都不小于 x，从而 $S \geqslant n x \geqslant n ^ { 2 } / 2$ 

以下设 $x < n / 2$ 。设第 1 行恰有 $y$ 个非零元素。由于矩阵中的元素都是非负整数，每个非零元素都不小于 1，故 $y \leqslant r _ { 1 } = x$ 。对于第 1 行中非零元素所在的 y 列，其列和由 x 的最小性均不小于 $x ;$ ； 对于其余 $n - y$ 列，若第 $j$ 列属于其中之一，则 $a _ { 1 j } = 0$ ，由题设有 $r _ { 1 } + c _ { j } \geqslant n$ 所以 $c _ { j } \geqslant n - x .$ 。因此

$$
S = \sum_ {j = 1} ^ {n} c _ {j} \geqslant x y + (n - y) (n - x) = \frac {n ^ {2}}{2} + \frac {(n - 2 x) (n - 2 y)}{2} > \frac {n ^ {2}}{2}
$$

最后一个不等式是因为 $y \leqslant x < n / 2$ 。这就证明了所需结论。

## All-Russian 1971 Grade 10 P6

棱长为 n 的立方体被分成 $n ^ { 3 }$ 个单位立方体。选出若干个小立方体，并过每个所选小立方体的中心作三条平行于原立方体棱的直线。最少选出多少个小立方体，才能使所作直线经过所有小立方体？

## 解

用有序三元组 $( x _ { 1 } , x _ { 2 } , x _ { 3 } )$ 表示小立方体的位置，并把所选小立方体看成三维棋盘上的车。过一辆车的三条车线覆盖它所在的格子以及与它仅有一个坐标不同的所有格子。记覆盖整个棋盘所需的最少车数为 $A _ { n }$ 。答案为

$$
A _ {n} = \left\lceil {\frac {n ^ {2}}{2}} \right\rceil = \left\{\begin{array}{l l}{{\frac {n ^ {2}}{2},}}&{{n \text {为偶数}}}\\{{\frac {n ^ {2} + 1}{2},}}&{{n \text {为奇数}}}\end{array}\right.
$$

当 $n = 1$ 时，结论显然成立。以下设 $n \geqslant 2$ ，先给出达到此数目的构造。令 $a = \lfloor n / 2 \rfloor$ $b = \lceil n / 2 \rceil$ ，并把坐标值分成 $U = \{ 1 , 2 , \cdots , a \}$ 与 $V = \{ a + 1 , a + 2 , \cdots , n \}$ 。在前两个坐标组成的 $n \times n$ 投影表中，只在两个对角方块 $U \times U$ 与 $V \times V$ 内放车。具体地，对 $1 \leqslant i , j \leqslant a$ 选取

$$
\left(i, j, 1 + \left(\left(i + j - 2\right) \bmod a\right)\right)
$$

对 $1 \leqslant r , s \leqslant b$ ，选取

$$
\left(a + r, a + s, a + 1 + \left((r + s - 2) \bmod b\right)\right)
$$

这两个方块内分别是以 U、V 为符号集的循环拉丁方，故每一行、每一列都恰好出现相应符号集中的全部元素。

若一个格子的前两个坐标同属 U 或同属 V，则与它有相同前两个坐标的直线上已经有车。若它的前两个坐标分属 $U , V$ ，则投影表中相应空格所在的行与列合起来恰好出现 $1 , 2 , \cdots , n ;$ 无论它的第三个坐标取何值，都有一辆车与它的第一、第三坐标相同或第二、第三坐标相同。因此所有格子都被覆盖。所用车数为

$$
a ^ {2} + b ^ {2} = \left\lceil \frac {n ^ {2}}{2} \right\rceil
$$

下面证明不能再少。设有 M 辆车覆盖整个三维棋盘。在与三个坐标面平行的全部 3n 个层中，取车数最少的一层 S，设其中有 m 辆车。不妨设 $S$ 平行于 $x _ { 1 } x _ { 2 }$ 坐标面。设这些车在 S内占据 $m _ { 1 }$ 条平行于 $x _ { 1 }$ 轴的行、 $m _ { 2 }$ 条平行于 $x _ { 2 }$ 轴的列，并设 $m _ { 1 } \geqslant m _ { 2 }$ ，显然 $m \geqslant m _ { 1 } , m _ { 2 } \circ$ 

层 S 中有 $( n - m _ { 1 } ) ( n - m _ { 2 } )$ 个格子既不在这些行上，也不在这些列上，因而只能由垂直于 $S$ 的车线覆盖。再考察全部 n 个平行于 $x _ { 1 } x _ { 3 }$ 坐标面的层：其中与 S 相交于未占行的$n - m _ { 1 }$ 个层合计至少含有 $( n - m _ { 1 } ) ( n - m _ { 2 } )$ 辆车；其余 $m _ { 1 }$ 个层各至少含有 m 辆车，这是因为 S 已是车数最少的坐标层。因此

$$
M \geqslant (n - m _ {1}) (n - m _ {2}) + m m _ {1} \geqslant (n - m _ {1}) ^ {2} + m _ {1} ^ {2}
$$

对整数 t，有

$$
(n - t) ^ {2} + t ^ {2} = 2 \left(t - \frac {n}{2}\right) ^ {2} + \frac {n ^ {2}}{2} \geqslant \left\lceil \frac {n ^ {2}}{2} \right\rceil
$$

故 $M \geqslant \lceil n ^ { 2 } / 2 \rceil$ 。结合上面的构造，所求最少数目就是 $\lceil n ^ { 2 } / 2 \rceil$ C

一个保险柜的密码锁由 3 个转轮组成，每个转轮都可以置于 8 个不同的位置。由于锁的机械装置有缺陷，只要 3 个转轮中任意 2 个处于正确位置，柜门就会打开。在不知道正确密码的情况下，至少必须试验多少组密码，才能保证打开保险柜？

## 解

把每个转轮的 8 个位置分别标为 $0 , 1 , \cdots , 7 .$ ，并把一次试验及正确密码都表示为三元组。一次试验能够打开保险柜，当且仅当它与正确密码至少有两个对应坐标相同。即使允许根据此前的结果选择下一次试验，在柜门尚未打开时得到的反馈始终只是“未打开”，所以最坏情形下所作的试验仍形成一个预先确定的序列。

先证明至少需要 32 次试验。设某个保证成功的试验序列共有 N 个三元组。对 $i , j \in$ $\{ 0 , 1 , \cdots , 7 \}$ ，令 $a _ { i j }$ 为前两个坐标分别为 $i , j$ 的三元组数，并令 $r _ { i }$ 和 $c _ { j }$ 分别为矩阵 $( a _ { i j } )$ 的第 i 行元素和与第 j 列元素和，于是 $\begin{array} { r } { N = \sum _ { i = 0 } ^ { 7 } r _ { i } = \sum _ { j = 0 } ^ { 7 } c _ { j } } \end{array}$ C

若 $a _ { i j } = 0$ ，则对每个 $k \in \{ 0 , 1 , \cdots , 7 \}$ ，正确密码 $( i , j , k )$ 都必须被某次试验打开。由于没有试验同时匹配它的前两个坐标，打开它的试验必须同时匹配第一、第三坐标，或者同时匹配第二、第三坐标。不同的 k 需要不同的三元组，而这两类三元组也不相交，否则交集中的三元组的前两个坐标就是 $i , j$ 。因此

$$
r _ {i} + c _ {j} \geqslant 8
$$

设所有 $r _ { i } , c _ { j }$ 中的最小值为 $m _ { \mathfrak { c } }$ 。若 $m \geqslant 4$ ，则 $\begin{array} { r } { N = \sum _ { i = 0 } ^ { 7 } r _ { i } \geqslant 8 m \geqslant 3 2 } \end{array}$ 。以下设 $m < 4 .$ 必要时交换前两个坐标的地位，不妨设 $r _ { 0 } = m$ 。设第 0 行中有 s 个正 $\widehat { \pi }$ 。因为这些正元都是正整数，所以 $s \leqslant m _ { \mathsf { c } }$ 。对于这些正元所在的 s 列，相应列和至少为 $m$ ；对于其余 $8 - s$ 列，由上面的不等式，相应列和至少为 $8 - m$ 。故

$$
N = \sum_ {j = 0} ^ {7} c _ {j} \geqslant m s + (8 - s) (8 - m) = 3 2 + 2 (4 - m) (4 - s) > 3 2
$$

从而任何保证成功的方案都至少需要 32 次试验。

下面构造一个恰好使用 32 次试验的方案。令 $A = \{ 0 , 1 , 2 , 3 \}$ ，并用 t 表示 t 除以 4 所得的余数。选取下列三元组：

$$
\mathcal {T} = \left\{\left(p, q, \overline {{p + q}}\right): p, q \in A \right\} \cup \left\{\left(4 + p, 4 + q, 4 + \overline {{p + q}}\right): p, q \in A \right\}
$$

两个集合各有 16 个三元组且互不相交，所以 $| \tau | = 3 2$ 。它们分别是在两个 $4 \times 4$ 对角方块上排成的循环拉丁方。

任取正确密码 $( x , y , z )$ 。若 $x , y$ 同属于 A，或者同属于 {4,5,6,7}，则 $\tau$ 中有一个三元组的前两个坐标恰为 $x , y$ ，相应试验能够打开保险柜。若 $x , y$ 分属这两个集合，则 $x , y$ 中恰有一个与 z 属于同一个集合。若 $x , z$ 属于同一个集合，在相应的循环拉丁方中固定第一坐标后，第三坐标会遍历该集合中的全部 4 个值，因而可以找到一个同时匹配第一、第三坐标的三元组；若 $y , z$ 属于同一个集合，同理固定第二坐标即可找到一个同时匹配第二、第三坐标的三元组。

所以这 32 次试验能够保证打开保险柜。结合下界，所求最小值为 32。

Japan Final Round 1999 P1 

在一个 $1 9 9 9 \times 1 9 9 9$ 方格表的某些格子中各放一枚棋子，每格至多放一枚。要求对每个没有棋子的格子，其所在行与所在列中的棋子总数至少为 1999。求所需棋子数的最小值。

## 解

答案为 $9 9 9 ^ { 2 } + 1 0 0 0 ^ { 2 } = 1 9 9 8 0 0 1$ 

设方格表中共有 N 枚棋子。在全部 1999 行与 1999 列中，选取棋子数最少的一条直线，设这条直线上有 k 枚棋子。不妨设它是一列，记为 $C _ { \circ }$ 。由 k 的选法，每一行和每一列都至少有 k 枚棋子。

列 C 中有 k 个格子放有棋子，与它们相交的 k 行各至少有 k 枚棋子。列 $C$ 中其余1999−k 个格子为空；对于其中任一空格，题设表明该格所在行与列 C 中的棋子总数至少为1999，而列 C 中有 k 枚棋子，所以该空格所在行至少有 1999−k 枚棋子。对全部 1999 行中的棋子数求和，得到

$$
N \geqslant k ^ {2} + (1 9 9 9 - k) ^ {2}
$$

由于 k 是整数，

$$
k ^ {2} + (1 9 9 9 - k) ^ {2} - (9 9 9 ^ {2} + 1 0 0 0 ^ {2}) = 2 (k - 9 9 9) (k - 1 0 0 0) \geqslant 0
$$

因此 $N \geqslant 9 9 9 ^ { 2 } + 1 0 0 0 ^ { 2 } = 1 9 9 8 0 0 1$ 

下面说明这个下界可以达到。将各行和各列分别编号为 1,2,··· ,1999，在且仅在 $i + j$ 为偶数的格子 $( i , j )$ 中放一枚棋子。奇数编号共有 1000 个，偶数编号共有 999 个，所以棋子总数为 $1 0 0 0 ^ { 2 } + 9 9 9 ^ { 2 } = 1 9 9 8 0 0 1$ 。任一空格 $( i , j )$ 都满足 i+j 为奇数，因而 $i , j$ 一奇一偶；该格所在的一条直线上有 1000 枚棋子，另一条直线上有 999 枚棋子，合计恰为 1999。故此构造满足题设条件，所求最小值为 1998001。
