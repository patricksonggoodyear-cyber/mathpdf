## IMOSL 1997 Q3

设 V 为有限个非零平面向量组成的集合。对非空子集 $A \subseteq V$ ，记 $\begin{array} { r } { L ( A ) = \left| \sum _ { v \in A } { v } \right| } \end{array}$ 。若$L ( A )$ 在 V 的所有非空子集中达到最大值，称 A 为最优子集。证明：若 $| V | = n \geqslant 1$ ，则 $V$ 的最优子集至多有 2n 个。

## 解

取任意最优子集 A，记 $\begin{array} { r } { \pmb { s } = \sum _ { \pmb { u } \in \pmb { A } } \pmb { u } \circ } \end{array}$ 。由于所有给定向量均非零， $| \boldsymbol s | > 0 .$ 对于 ${ \pmb u } \in A$ 删去它不可能使向量和更长，故 $| s - u | \leqslant | s |$ ；即使删去后得到空集，所得长度仍为零。对于$v \in V \setminus A$ ，加入它也不可能使向量和更长，故 $| s + v | \leqslant | s |$ 。将这两个不等式平方，得到

$$
\boldsymbol {s} \cdot \boldsymbol {u} \geqslant | \boldsymbol {u} | ^ {2} / 2 > 0 \quad (\boldsymbol {u} \in A), \quad \boldsymbol {s} \cdot \boldsymbol {v} \leqslant - | \boldsymbol {v} | ^ {2} / 2 <   0 \quad (\boldsymbol {v} \in V \setminus A)
$$

于是 A 恰由以 s 为正方向的开放半平面内的所有给定向量组成，分界线过原点且垂直于 s，其上没有给定向量。

让单位方向 $e$ 绕原点转动一周。对于每个给定向量 $w , e \cdot w$ 恰在两个方向上为零。因此至多有 $2 n$ 个临界方向，它们将方向圆周分成至多 $2 n$ 段开弧。在每段开弧内，满足 $e \cdot w > 0$ 的向量集合不变；每个最优子集都对应于其中一段开弧，故最优子集至多有 2n 个。

## Moscow MO 1963 Grade 10 P3

从正 25 边形的中心 O 向它的 25 个顶点分别作向量。应选取其中哪些向量，才能使所选向量之和的长度最大？

## 解

设每个向量的长度为 $R > 0$ ，在所有非空选取中取一个使向量和长度最大的选取，记其和为 $\scriptstyle { \pmb { s } } \circ$ 显然 $\mathbf { \boldsymbol { s } } \neq \mathbf { \boldsymbol { 0 } }$ 。若某个已选向量 u 满足 $\pmb { s } \cdot \pmb { u } \leqslant 0$ ，则删去它后有

$$
| \pmb {s} - \pmb {u} | ^ {2} - | \pmb {s} | ^ {2} = R ^ {2} - 2 \pmb {s} \cdot \pmb {u} > 0
$$

这与最优性矛盾。若某个未选向量 v 满足 $\mathbf { \nabla } _ { \pmb { s } } \cdot \pmb { v } \geqslant 0$ ，则加入它后有

$$
| \pmb {s} + \pmb {v} | ^ {2} - | \pmb {s} | ^ {2} = R ^ {2} + 2 \pmb {s} \cdot \pmb {v} > 0
$$

也与最优性矛盾。因此，过 O 作垂直于 s 的直线，所选向量恰好指向 s 所在一侧的全部顶点，且分界线上没有顶点。正 25 边形的顶点等角间隔，故这些顶点必是连续的 12 个或连续的 13 个。

由旋转对称性，任意连续 12 个向量的和等长。全部 25 个向量之和为零，而任意连续 13个向量的补集是连续 12 个，所以这两类选取的向量和也等长。既然最优选取必属于这两类，它们就全部达到最大值。答案为任意连续的 12 个向量，或任意连续的 13 个向量。

求证：平面上不存在由多于 $2 N \ ( N > 3 )$ 个两两不平行的向量构成的具有如下性质的有限集合：

(1) 对于该集合中的任何 N 个向量，都能从该集合中再找出 N−1 个向量，使得这 2N−1个向量的和等于 0；

(2) 对于该集合中的任何 N 个向量，都能从该集合中再找出 N 个向量，使得这 2N 个向量的和等于 0。

解

假设题中的断言不真。选取一条直线 ，使其不与我们的集合 中的任何一个向量垂直。于是 G 中至少有 N 个向量在直线 l 上的投影指向同一方向，设它们为 ${ \vec { e } } _ { 1 } , \cdots , { \vec { e } } _ { N } \circ$ 。在直线 l 上取定方向，使得这些向量的投影所指的方向为负。再在集合 G 中选取 N 个向量 ${ \vec { f } } _ { 1 } , \cdots , { \vec { f } } _ { N }$ ，使得它们的和在直线 l 上的投影的代数值 s 达到最大，由题中条件 (2) 知有 $s > 0$ 。若 ${ \vec { f } } _ { 1 } , \cdots , { \vec { f } } _ { N }$ 与原选出的 $\vec { e } _ { 1 } , \cdots , \vec { e } _ { N }$ 没有重合，则原选出的 N 个负投影向量已在其外；若有重合，由极大性可知未选向量的投影均为负。故总能在 ${ \vec { f } } _ { 1 } , \cdots , { \vec { f } } _ { N }$ 之外选取 N 个负投影向量，仍记为$\vec { e } _ { 1 } , \cdots , \vec { e } _ { N }$ 

由条件 (1)，我们可以找到 N −1 个向量 $\vec { a } _ { 1 } , \cdots , \vec { a } _ { N - 1 }$ ，使得

$$
\vec {f} _ {1} + \dots + \vec {f} _ {N} = - (\vec {a} _ {1} + \dots + \vec {a} _ {N - 1})
$$

显然，至少有某一个向量 $\vec { e _ { i } }$ 不出现在上式右端，不妨设其为 $\vec { e _ { 1 } }$ 。从而 $\vec { a } _ { 1 } + \cdot \cdot \cdot + \vec { a } _ { N - 1 } + \vec { e } _ { 1 }$ 的投影为负，并且其绝对值大于 s。再由条件 (2) 知，我们又可以找到 N 个向量，使得它们的和等于 − $\cdot \left( \vec { a } _ { 1 } + \cdot \cdot \cdot + \vec { a } _ { N - 1 } + \vec { e } _ { 1 } \right)$ ，从而该和的投影代数值大于 s，此与我们对 ${ \vec { f } } _ { 1 } , \cdots , { \vec { f } } _ { N }$ 的选取相矛盾。

平面上有向量 $\mathbf { } u _ { 1 } , \cdots , \mathbf { } u _ { n }$ ，每个向量的长度均不超过 1，且 $\textstyle \sum _ { i = 1 } ^ { n } { \pmb u } _ { i } = { \pmb 0 }$ 。证明：可以将它们重新排列为 $\mathbf { } { \boldsymbol { v } } _ { 1 } , \cdots , { \boldsymbol { v } } _ { n }$ ，使对每个 $1 \leqslant k \leqslant n$ ，都有 $\textstyle \left| \sum _ { i = 1 } ^ { k } v _ { i } \right| \leqslant { \sqrt { 5 } }$ 

## 解

先证一个一维事实：若有限个实数的绝对值均不超过 1，且总和为 0，则可以将其排序，使每个部分和都属于 [−1,1]。事实上，设当前部分和为 r；若 $r > 0$ ，则未取数之和为 $- r < 0$ 可选一个负数；若 $r < 0$ ，同理可选一个正数；若 $r = 0$ ，任取一个未取数。每一步加入的数的绝对值不超过 1，且当 $r \neq 0$ 时与 r 异号，因此新的部分和仍在 [−1,1]。

若所有向量均为零，命题显然成立。否则，在所有下标集合 $I \subseteq \{ 1 , \cdots , n \}$ 中取一个使向量和长度最大的，记 $\begin{array} { r } { \pmb { s } = \sum _ { i \in I } \pmb { u } _ { i } \neq \pmb { 0 } } \end{array}$ ，并令 $J = \{ 1 , \cdot \cdot \cdot , n \} \setminus I _ { \circ }$ 。取沿 s 方向的单位向量 e及与它垂直的单位向量 $f$ 。对于 $i \in I$ ，由极大性有 $\begin{array} { r } { | \pmb { s } - \pmb { u } _ { i } | \leqslant | \pmb { s } | } \end{array}$ ，平方得 $e \cdot u _ { i } \geqslant 0 ;$ ；对于$j \in J$ ，同理由 $| s + { \pmb u } _ { j } |$ ⩽ |s| 得 $e \cdot u _ { j } \leqslant 0$ 。故两组向量的 e 方向投影分别非负、非正。由于I 中向量的和是 s，而全部向量之和为零，两组向量的 $f$ 方向投影各自的总和均为零。

分别对 I、J 中向量的 f 方向投影应用上述一维事实，固定组内顺序，使每组任一前缀的f 方向投影和的绝对值不超过 1。现在将两组向量交错排列，始终保留各组内部的顺序。设已取向量的 e 方向投影和为 x：若 $x > 0$ ，取 J 组中的下一个向量；若 $x < 0$ ，取 I 组中的下一个向量；若 $x = 0$ ，从尚有向量的一组任取下一个。这个过程总能进行：当 $x > 0$ 时，未取向量的投影和为 $- x < 0$ ，所以 J 组必有未取向量； $x < 0$ 时同理。每个向量在 e 方向的投影绝对值不超过 1，且非零的 x 与下一项投影符号相反，故每步后仍有 $| x | \leqslant 1$ C

## CTST 2012 P18

在由 $2 0 1 2 \times 2 0 1 2$ 个单位方格组成的棋盘上，一些方格内各有一只甲虫，每格至多一只。某一时刻，所有甲虫飞离棋盘，随后又落回棋盘，落下时每格仍至多一只。每只甲虫的位移向量是从其起始方格的中心指向落入方格的中心的向量。求所有甲虫的位移向量之和的长度的最大值。

解

设 $m = 1 0 0 6$ ，以棋盘中心 O 为原点，平行于格线建立坐标系。记全部方格中心的集合为 S，甲虫起飞前和落下后的格心集合分别为 $X , Y \subseteq S$ ，则 $| X | = | Y |$ 。甲虫的位置对应给出双射 $f : X \to Y$ ，总位移向量为

$$
\boldsymbol {V} = \sum_ {x \in X} (f (x) - x) = \sum_ {y \in Y} y - \sum_ {x \in X} x
$$

因此 V 只由 $X , Y$ 决定，与甲虫如何对应无关。删去 $X \cap Y$ 中的点不改变 V，故在求最大值时可设 $X \cap Y = \emptyset$ 。

引理一：若 $| V |$ 取最大值，过 O 且垂直于 V 的直线 l 不经过任何格心，X,Y 分别由 l两侧的全部格心组成。

引理一证明：显然 $V \neq \mathbf { 0 }$ 。先证 $X \cup Y = S$ 。若尚有未选的两个不同格心 $p , q$ ，交换其标号可使 $( p - q ) \cdot V \geqslant 0$ 。把 p 加入 Y、q 加入 X 后，总位移向量变为 $V + p - q$ ，长度严格增大，矛盾。由于 |S| 和 $| X \cup Y | = 2 | X |$ 都是偶数，只要存在未选格心，就至少有两个，故$X , Y$ 互为补集。

再证 $Y = - X$ 。若不然，由 X,Y 等势且互补，可找到 $a , - a \in X$ 和 $b , - b \in Y$ 。适当选择 $a , b$ 的符号，使 $( a - b ) \cdot V \geqslant 0$ 。交换 a,b 所属的集合后，总位移向量变为 $\pmb { V } + 2 ( a - b )$ 长度严格增大，矛盾。

若 l 经过格心 a，不妨设 $a \in X$ ，则 $- a \in Y$ 。交换 $a , - a$ 所属的集合后，总位移向量变为 $V + 4 a$ 。由于 $a \perp V$ 且 $a \neq \mathbf { 0 }$ ，其长度严格增大，矛盾。最后，若 V 指向的一侧有 $a \in X$ 则 $- a \in Y$ ；交换这两点后总位移向量仍变为 $V + 4 a$ ，而 $a \cdot V > 0$ ，同样矛盾。因此 Y 恰由V 指向一侧的全部格心组成，X 由另一侧的全部格心组成。

引理二：对 $1 \leqslant k \leqslant m$ ，令 $S _ { k }$ 为满足 $\operatorname* { m a x } \{ | x | , | y | \} = k - 1 / 2$ 的格心 $( x , y ) \in S _ { \mathsf { 1 } }$ 。若过O 的直线 l 不经过 $S _ { k }$ ，将其两侧的 $S _ { k }$ 分别记为 $A _ { k } , B _ { k }$ ，并令 $\begin{array} { r } { V _ { k } = \sum _ { p \in A _ { k } } p - \sum _ { p \in B _ { k } } p } \end{array}$ ，则$| V _ { k } | \leqslant 6 k ^ { 2 } - 6 k + 2 ;$ ；当 l 水平或垂直时取等号，此时 $V _ { k }$ 垂直于 $l _ { \circ }$ 

引理二证明： $S _ { k }$ 位于边界坐标为 $\pm ( k - 1 / 2 )$ 的正方形上。由对称性，可设 l 的斜率非负且小于 1，并将 $A _ { k }$ 取为直线上方的点。令 $h = k - 1 / 2$ ，设 l 与右边界的交点位于从上往下数的第 t 个与第 $t + 1$ 个格心之间，其中 $1 \leqslant t \leqslant k \circ \ A _ { k }$ 包含上边界的 2k 个格心、右边界内部的 t − 1 个格心及左边界内部的 $2 k - t - 1$ 个格心。由于 $S _ { k }$ 中全部格心之和为零，$\begin{array} { r } { V _ { k } = 2 \sum _ { p \in A _ { k } } p \circ } \end{array}$ 逐边求和得到其水平、竖直分量分别为

$$
\left(\boldsymbol {V} _ {k}\right) _ {x} = - 2 (2 k - 1) (k - t), \quad \left(\boldsymbol {V} _ {k}\right) _ {y} = 2 \left(3 k ^ {2} - 3 k + 1 - (k - t) ^ {2}\right)
$$

令 $\boldsymbol { u } = ( \boldsymbol { k } - t ) ^ { 2 }$ ，则 $0 \leqslant u \leqslant ( k - 1 ) ^ { 2 }$ ，从而

$$
\frac {\left| \boldsymbol {V} _ {k} \right| ^ {2}}{4} = (3 k ^ {2} - 3 k + 1) ^ {2} + u (u - (2 k ^ {2} - 2 k + 1)) \leqslant (3 k ^ {2} - 3 k + 1) ^ {2}
$$

因为 $( k - 1 ) ^ { 2 } < 2 k ^ { 2 } - 2 k + 1$ ，等号仅在 $u = 0$ 时成立。此时 $t = k , ~ A _ { k }$ 恰为 $S _ { k }$ 的上半层，故$V _ { k }$ 竖直；特别地，取 l 水平时达到等号。由对称性，取 l 垂直时也达到等号。

回到原题，将引理一给出的起点、终点格心按 $S _ { 1 } , \cdots , S _ { m }$ 分层，则

$$
| \boldsymbol {V} | = \left| \sum_ {k = 1} ^ {m} \boldsymbol {V} _ {k} \right| \leqslant \sum_ {k = 1} ^ {m} | \boldsymbol {V} _ {k} | \leqslant \sum_ {k = 1} ^ {m} (6 k ^ {2} - 6 k + 2) = 2 m ^ {3}
$$
