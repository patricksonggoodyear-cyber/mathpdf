把函数方程化为固定步长的平移递推，利用有界性排除指数增长或线性漂移，从而限制递推系数或推出周期性。

IMO 1972 P5 

设函数 $f , g : \mathbb { R } \to$ R，满足对任意实数 $x , y$ 均有

$$
f (x + y) + f (x - y) = 2 f (x) g (y)
$$

求证：若 $f ( x )$ 不恒等于零，且对任意实数 x 有 $| f ( x ) | \leqslant 1$ ，则对任意实数 y 均有 $| g ( y ) | \leqslant 1$ 

解

取 $x _ { 0 }$ 使 $f ( x _ { 0 } ) \neq 0$ 。固定任意实数 y，记 $c = g ( y )$ ，并对每个整数 n 令 $u _ { n } = f ( x _ { 0 } + n y )$ 由题设， $\left| u _ { n } \right| \leqslant 1$ ，且

$$
u _ {n + 1} - 2 c u _ {n} + u _ {n - 1} = 0
$$

假设 $| c | > 1$ 。特征方程 $r ^ { 2 } - 2 c r + 1 = 0$ 有两个不同的非零实根 $r _ { 1 } , r _ { 2 }$ ，其乘积为 1。将它们适当标号，可使 $\left| \boldsymbol { r } _ { 1 } \right| > 1 > \left| \boldsymbol { r } _ { 2 } \right|$ 。两列 $\left( r _ { 1 } ^ { n } \right) , \left( r _ { 2 } ^ { n } \right)$ 均满足递推式，且在 $n = 0 , 1$ 处的初值线性无关，故存在实数 A,B 使

$$
u _ {n} = A r _ {1} ^ {n} + B r _ {2} ^ {n} \qquad (n \in \mathbb {Z})
$$

数列 $\left( u _ { n } \right)$ 在 $n  + \infty$ 时有界，迫使 $A = 0 { \mathrm { ; } }$ ；在 $n \to - \infty$ 时有界，又迫使 $B = 0 .$ 。于是 $u _ { 0 } = 0$ 与 $u _ { 0 } = f ( x _ { 0 } ) \neq 0$ 矛盾。故 $| g ( y ) | = | c | \leqslant 1$ 。由于 y 任意，结论成立。

IMOSL 1996 A7 

设函数 f : R R 满足对一切 $x \in$ R，都有 $| f ( x ) | \leqslant 1$ 。同时，对一切 $x \in$ R，都有

$$
f \left(x + \frac {1 3}{4 2}\right) + f (x) = f \left(x + \frac {1}{6}\right) + f \left(x + \frac {1}{7}\right)
$$

求证： $f$ 为周期函数，即存在 $c \neq 0$ 使得 $f ( x + c ) = f ( x )$ 对任意实数 x 都成立。

解

任取实数 x，对每个整数 n 令 $a _ { n } = f ( x + n / 4 2 )$ 。由题设，数列 $( a _ { n } ) _ { n \in \mathbb { Z } }$ 有界，且

$$
a _ {n + 1 3} + a _ {n} = a _ {n + 7} + a _ {n + 6}
$$

令 $d _ { n } = a _ { n + 7 } - a _ { n }$ ，则上式等价于 $d _ { n + 6 } = d _ { n }$ ，即数列 $( d _ { n } )$ 以 6 为周期。

由于 7 与 6 互质， $n + 7 j \ ( j = 0 , 1 , \cdot \cdot \cdot , 5 )$ 模 6 遍历全部剩余类。因此

$$
a _ {n + 4 2} - a _ {n} = \sum_ {j = 0} ^ {5} d _ {n + 7 j} = \sum_ {r = 0} ^ {5} d _ {r} =: C
$$

其中 C 与 n 无关。于是对每个非负整数 k 都有 $a _ { 4 2 k } = a _ { 0 } + k C$ 。数列 $\left( a _ { n } \right)$ 有界，故 $C = 0$ 从而 $f ( x + 1 ) = a _ { 4 2 } = a _ { 0 } = f ( x )$ 。由于 x 任意，1 是 f 的一个周期。

Nordic 2001 P2 

设函数 f : R R 是有界的，并且对任意实数 x 满足

$$
f \left(x + \frac {1}{3}\right) + f \left(x + \frac {1}{2}\right) = f (x) + f \left(x + \frac {5}{6}\right)
$$

求证：f 是周期函数。

解

任取实数 x，对每个整数 n 令 $a _ { n } = f ( x + n / 6 )$ 。由题设，数列 $( a _ { n } ) _ { n \in \mathbb { Z } }$ 有界，且

$$
a _ {n + 2} + a _ {n + 3} = a _ {n} + a _ {n + 5}
$$

令 $d _ { n } = a _ { n + 3 } - a _ { n }$ ，则上式等价于 $d _ { n + 2 } = d _ { n }$ ，即数列 $( d _ { n } )$ 以 2 为周期。因此

$$
a _ {n + 6} - a _ {n} = d _ {n} + d _ {n + 3} = d _ {n} + d _ {n + 1} = d _ {0} + d _ {1} =: C
$$

其中 C 与 n 无关。于是对每个非负整数 k 都有 $a _ { 6 k } = a _ { 0 } + k C \scriptscriptstyle \mathrm { ~ . ~ }$ 。数列 $\left( a _ { n } \right)$ 有界，故 $C = 0$ 从而 $f ( x + 1 ) = a _ { 6 } = a _ { 0 } = f ( x )$ 。由于 x 任意，1 是 f 的一个周期。
