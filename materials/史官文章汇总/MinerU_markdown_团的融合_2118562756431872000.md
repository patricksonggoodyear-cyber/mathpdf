图中有 2n 1 个顶点。现知去掉其中任何一个顶点（连同由它连出的所有边）之后，剩下的图中都有一个具有 n 个顶点的完全子图。证明：原来的图中有一个具有 n+1 个顶点的完全子图。

## 解

将原来的图称为图 G ．自图 G 中选取一个具有 n 个顶点的完全子图，将该子图的顶点的集合记为 A ，将其余顶点的集合记为 B 。再将图 G 的所有具有 n 个顶点的完全子图编号为 1 至 N 。将第 k 号子图的顶点集合与 A 的交集记为 $A _ { k }$ ，将其与 B 的交集记为 $B _ { k }$ 。我们来考察集合

$$
A _ {k} ^ {\prime} = A _ {1} \cap A _ {2} \cap \dots \cap A _ {k}, \quad B _ {k} ^ {\prime} = B _ {1} \cup B _ {2} \cup \dots \cup B _ {k}, \quad k = 1, 2, \dots , N
$$

并逐个计算 $| A _ { k } ^ { \prime } \cup B _ { k } ^ { \prime } |$ ，其中 X 表示集合 X 中的元素个数。一开始显然有 $\left| A _ { 1 } ^ { \prime } \cup B _ { 1 } ^ { \prime } \right| = n$ ，最终则有 $A _ { N } ^ { \prime } = \varnothing$ ，这是因为根据题意，对于图 G 中的任何一个顶点，都能找到一个形如 $A _ { i } ^ { \prime } \cup B _ { i } ^ { \prime }$ 的子图，使得该顶点不属于这个子图．从而

$$
\left| A _ {N} ^ {\prime} \cup B _ {N} ^ {\prime} \right| = \left| B _ {N} ^ {\prime} \right| \leqslant \left| B \right| = n - 1
$$

于是 $\vert A _ { N } ^ { \prime } \cup B _ { N } ^ { \prime } \vert < \vert A _ { 1 } ^ { \prime } \cup B _ { 1 } ^ { \prime } \vert$ 。这就表明，存在某个 k ，使得 $| A _ { k + 1 } ^ { \prime } \cup B _ { k + 1 } ^ { \prime } | < | A _ { k } ^ { \prime } \cup B _ { k } ^ { \prime } |$ 。我们来证明，对于这个 k，集合

$$
C = A _ {k} ^ {\prime} \cup A _ {k + 1} \cup (B _ {k} ^ {\prime} \cap B _ {k + 1})
$$

中含有不多于 $n + 1$ 个顶点，并且形成完全子图。我们指出

$$
\left| A _ {k} ^ {\prime} \cup A _ {k + 1} \right| = \left| A _ {k} ^ {\prime} \right| + \left| A _ {k + 1} \right| - \left| A _ {k + 1} ^ {\prime} \right|
$$

这是因为 $A _ { k } ^ { \prime } \cap A _ { k + 1 } = A _ { k + 1 } ^ { \prime }$ 。同时也有

$$
\left| B _ {k} ^ {\prime} \cap B _ {k + 1} \right| = \left| B _ {k} ^ {\prime} \right| + \left| B _ {k + 1} \right| - \left| B _ {k + 1} ^ {\prime} \right|
$$

这是因为 $B _ { k + 1 } ^ { \prime } = B _ { k } ^ { \prime } \cup B _ { k + 1 }$ 。将上述二式相加，并注意到 $| A _ { k + 1 } | + | B _ { k + 1 } | = n$ ，即得

$$
| C | = | A _ {k} ^ {\prime} \cup A _ {k + 1} | + | B _ {k} ^ {\prime} \cap B _ {k + 1} | = n + | A _ {k} ^ {\prime} \cup B _ {k} ^ {\prime} | - | A _ {k + 1} ^ {\prime} \cup B _ {k + 1} ^ {\prime} | > n
$$

亦即 $| C | \geqslant n + 1$ 。下面再证 C 中的任何两个顶点均有边相连。注意到 C 的子集 $A _ { k } ^ { \prime } \cup A _ { k + 1 }$ 和 $A _ { k + 1 } \cup ( B _ { k } ^ { \prime } \cap B _ { k + 1 } )$ 分别包含在完全子图 A 和 $A _ { k + 1 } \cup B _ { k + 1 }$ <sub>1</sub> 之中，而任何顶点 $a \in A _ { k } ^ { \prime }$ 都与任一顶点 $b \in B _ { k } ^ { \prime } \cap B _ { k + 1 } \subset B _ { k } ^ { \prime }$ 相连，这是因为 a 至少属于某一个 $A _ { i }$ ，其中 $i \leqslant k ; ~ b$ 则属于相应的 $B _ { i }$ ，而 $A _ { i } \cup B _ { i }$ 是完全图。

给定自然数 $n \geqslant 2 .$ 称一个人群是 n-紧的，若对人群中的任何一人，都能在其余人中找到 n 个两两相识的人。

求最大的 N，使得每个 N 人的 n-紧人群中都必有 n+1 个两两相识的人。

## 解

将人视为顶点、相识视为边，得简单图 G。于是 G 是 n-紧的，当且仅当对每个顶点 $v ,$ ，$G - v$ 中都含有一个 n 团。所求即最大的 N，使得每个 N 阶 n-紧图都含 (n + 1) 团。

我们将证明答案为 $N = 2 n - 1$ ，先证明一个引理。

引理：设简单图 G 不含 (n + 1) 团，且 $| V ( G ) | \leqslant 2 n - 1$ 。若 G 含有 n 团，则 G 的全体n 团有一个公共顶点。

引理的证明：设 $T _ { 1 } , T _ { 2 } , \cdots , T _ { m }$ 是 G 的全部 n 团。记 $l _ { j } = \left| \bigcup _ { i = 1 } ^ { j } T _ { i } \right|$ ，则 $l _ { j } \leqslant 2 n - 1$ 。对j 用归纳法证明更强的结论

$$
\left| \bigcap_ {i = 1} ^ {j} T _ {i} \right| \geqslant 2 n - l _ {j}
$$

当 $j = 1$ 时， $| T _ { 1 } | = n \geqslant 2 n - l _ { 1 } = n$ ，结论成立。

假设结论对 j 1 成立 $( j > 1 )$ 。令 $\begin{array} { r } { A = \bigcup _ { i = 1 } ^ { j - 1 } T _ { i } , C = \bigcap _ { i = 1 } ^ { j - 1 } T _ { i } } \end{array}$ ，则 $| A | = l _ { j - 1 }$ ，且由归纳假设 $| C | \geqslant 2 n - l _ { j - 1 } > 0$ ，C 中每个顶点都与 A 中每个顶点相邻——这是因为 C 落在每个$T _ { i }$ 中，而 A 中每个顶点属于某个 $T _ { i }$ ，同属一团则相邻。于是 $( A \cap T _ { j } ) \cup C$ 构成一个团；由于G 不含 (n + 1) 团，故 $| ( A \cap T _ { j } ) \cup C | \leqslant n .$ 。另一方面，

$$
\left| A \cap T _ {j} \right| = n - \left| T _ {j} \setminus A \right| = n - \left(l _ {j} - l _ {j - 1}\right)
$$

且因 $C \subseteq A$ 而有 $C \setminus ( A \cap T _ { j } ) = C \setminus T _ { j }$ ，所以

$$
n \geqslant | (A \cap T _ {j}) \cup C | = | A \cap T _ {j} | + | C \setminus T _ {j} | = n - (l _ {j} - l _ {j - 1}) + | C \setminus T _ {j} |
$$

即 $| C \setminus T _ { j } | \leqslant l _ { j } - l _ { j - 1 }$ 。从而

$$
\left| \bigcap_ {i = 1} ^ {j} T _ {i} \right| = | C \cap T _ {j} | = | C | - | C \setminus T _ {j} | \geqslant (2 n - l _ {j - 1}) - (l _ {j} - l _ {j - 1}) = 2 n - l _ {j}
$$

归纳完成。特别地，取 $j = m$ 得

$$
\left| \bigcap_ {i = 1} ^ {m} T _ {i} \right| \geqslant 2 n - l _ {m} \geqslant 2 n - (2 n - 1) = 1
$$

即全体 n 团有一个公共顶点。引理获证。

回到原题。先证明每个 2n 1 阶 n-紧图 G 都含 (n+1) 团。反设 G 不含 (n+1) 团，则G 的最大团大小不超过 n；又因 G 是 n-紧的，G 含有 n 团，故 G 的最大团恰为 n 团。由引理，G 的全体 n 团有一个公共顶点 $v _ { \circ }$ 。但由 n-紧性，G v 中含有 n 团，即存在一个不含 v的 n 团，这与”v 属于每个 $n$ 团” 矛盾。故 G 必含 (n+1) 团，从而 $N \geqslant 2 n - 1$ 0

再证明 $N \leqslant 2 n - 1$ ，即存在 2n 阶的 n-紧图不含 (n+1) 团。取 $G _ { 0 }$ 为两个不相交的 n 团（共 $2 n$ 个顶点，两团之间没有边）。任取顶点 v，则 v 所在团以外的另一团是一个不含 v 的 n团，故 $G _ { 0 }$ 是 $n -$ 紧的；而 $G _ { 0 }$ 的每个连通分支都是 n 团，故 $G _ { 0 }$ 不含 (n + 1) 团。这表明 $2 n$ 人的 n-紧人群未必含有 n+1 个两两相识的人，于是 $N \leqslant 2 n - 1$ o

综上所述，所求 N 的最大值为 $2 n - 1$ o

## CTST 2012 P7

在简单图中，两两相邻的 t 个顶点称为一个 t 团，与其余每个顶点都相邻的顶点称为中心点。给定整数 $n , k$ ，其中 $n \geqslant 3 , n / 2 < k < n$ 。设 G 是一个有 n 个顶点的简单图，G 中不存在 (k +1) 团，但在 G 中任意添上一条边后就存在 (k +1)。

求 G 的中心点个数的最小可能值。

## 解

我们先证明下面的引理：

引理：设 F 是一个简单图，共有 n 个顶点，若 F 中不存在 (k+1) 团，但存在 k 团，并且 $n / 2 < k < n$ 。设 $T _ { 1 } , \cdots , T _ { m }$ 是 F 的所有 k 团，则有

$$
\left| \bigcap_ {i = 1} ^ {m} T _ {i} \right| \geqslant 2 k - n
$$

引理的证明：记 $| \cup _ { i = 1 } ^ { m } T _ { i } | = l _ { m }$ ，注意到 $l _ { m } \leqslant n$ ，只需证明 $\begin{array} { r } { \left| \bigcap _ { i = 1 } ^ { m } T _ { i } \right| \geqslant 2 k - l _ { m } } \end{array}$ 。下面对m 用归纳法证明上式。

当 $m = 1$ 时，结论是平凡的。假设结论对 m 1 成立， $m > 1$ 。令

$$
A = \bigcup_ {i = 1} ^ {m - 1} T _ {i}, \quad B = \bigcup_ {i = 1} ^ {m} T _ {i}, \quad C = \bigcap_ {i = 1} ^ {m - 1} T _ {i}, \quad D = \bigcap_ {i = 1} ^ {m} T _ {i}
$$

则 $| A | = l _ { m - 1 } , | B | = l _ { m }$ ，由归纳假设知

$$
| C | \geqslant 2 k - l _ {m - 1} > 0
$$

因为 C 中的每个顶点都与 A 中的每个顶点相邻，因此 $( A \cap T _ { m } ) \cup C$ 组成一个团，因为F 中不存在 (k +1) 团，故

$$
\left| \left(A \cap T _ {m}\right) \cup C \right| \leqslant k
$$

由此得

$$
| A \cap T _ {m} | = | T _ {m} | - | T _ {m} \backslash A | = k - | (T _ {m} \cup A) \backslash A | = k - | B \backslash A | = k - (l _ {m} - l _ {m - 1})
$$

从而

$$
\begin{array}{c} k \geqslant | (A \cap T _ {m}) \cup C | = | A \cap T _ {m} | + | C \backslash (A \cap T - m) | = k - (l _ {m} - l _ {m - 1}) + | C \backslash T _ {m} | \\ \implies | C \backslash T _ {m} | \leqslant l _ {m} - l _ {m - 1} \end{array}
$$

于是

$$
| D | = | T _ {m} \cap C | = | C | - | C \backslash T _ {m} | \geqslant 2 k - l _ {m - 1} - (l _ {m} - l _ {m - 1}) = 2 k - l _ {m}
$$

引理获证。

回到原题，由条件知 G 中必存在 k 团。设 $T _ { 1 } , \cdots , T _ { m }$ 是 G 的所有 k 团，则 $\cap _ { i = 1 } ^ { m } A _ { i }$ 包含了 G 的所有点。用反证法证明上述事实，假设顶点 v 不属于每个 $A _ { i }$ ，则 v 必与 $A _ { i }$ 中某个顶点 u 不相邻，否则 v 和 $A _ { i }$ 就构成一个 (k+1) 团，与 G 的假设矛盾！现连结 $v , u ,$ ，由假设知此时存在一个 (k+1) 团，必包含 v 和 u，设为 $v , u , v _ { 1 } , \cdots , v _ { k - 1 }$ ，则在 $G$ 中 $v , v _ { 1 } , \cdots , v _ { k - 1 }$ 构成一个 k 团，即 v 属于某个 k 团中，矛盾！

由引理有 $\begin{array} { r } { \left| \bigcap _ { i = 1 } ^ { m } A _ { i } \right| \geqslant 2 k - n } \end{array}$ ，其中的顶点都是中心点，故 G 中至少有 $2 k - n$ 

最后指出存在一个图 G，满足题述条件，且恰有 $2 k - n$ 个中心点：

设 G 的顶点为

$$
A _ {1}, A _ {2}, \dots , A _ {2 k - n}, \qquad B _ {1}, B _ {2}, \dots , B _ {n - k}, \qquad C _ {1}, C _ {2}, \dots , C _ {n - k}
$$

综上所述，G 的中心点的最小可能值等于 2k $- \ n$ 共 n 个顶点， $B _ { i }$ 与 $C _ { i }$ 不相邻，其余顶点间都相邻。则显然只有 $A _ { 1 } , A _ { 2 } , \cdots , A _ { 2 k - n }$ 这 2k n个中心点。该图中不含 (k + 1) 团，因为任取 $( k + 1 )$ 个顶点，都会包含一对 $B _ { i } , C _ { i }$ 。但是任意添上一条边 $B _ { i } C _ { i }$ ，则有 (k + 1) 团。
