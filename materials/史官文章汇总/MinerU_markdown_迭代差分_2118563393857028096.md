求证：不存在函数 $f : \mathbb { N } \to \mathbb { N }$ ，使得对任意非负整数 n 均有

$$
f (f (n)) = n + 1 9 8 7
$$

解

我们将证明： $f ^ { p } ( x ) = x + k$ 存在满足要求的函数 $f : \mathbb { Z } _ { + } \to \mathbb { Z } _ { + }$ ，其必要条件是 $p \mid k$ 首先显然 $f$ 是单射，同时显然 $f ^ { p } : \mathbb { Z } _ { + } \to \{ k + 1 , k + 2 , \cdot \cdot \cdot \}$ 是满射。

考察每次迭代的函数值域

$$
f (\mathbb {Z} _ {+}) \supseteq f ^ {2} (\mathbb {Z} _ {+}) \supseteq f ^ {3} (\mathbb {Z} _ {+}) \supseteq \dots \supseteq f ^ {p} (\mathbb {Z} _ {+})
$$

以及它们的差分集

$$
D _ {1} = \mathbb {Z} _ {+} \setminus f (\mathbb {Z} _ {+}), \qquad D _ {2} = f (\mathbb {Z} _ {+}) \setminus f ^ {2} (\mathbb {Z} _ {+}), \qquad \dots , \qquad D _ {p} = f ^ {p - 1} (\mathbb {Z} _ {+}) \setminus f ^ {p} (\mathbb {Z} _ {+})
$$

则有

$$
D _ {1} \cup D _ {2} \cup \dots \cup D _ {p} = \mathbb {Z} _ {+} \setminus f ^ {p} (\mathbb {Z} _ {+}) = \{1, 2, \dots , k \}
$$

同时上述差分集两两不交，即 $D _ { 1 } , D _ { 2 } , \cdots , D _ { p }$ 是对 $\{ 1 , 2 , \cdots , k \}$ 的一个拆分。

取 $x _ { 1 } \in D _ { s }$ ，则 $y _ { 1 } = f ( x _ { 1 } ) \in f ^ { s } ( \mathbb { Z } _ { + } )$ 。如果 $y _ { 1 } = f ^ { s + 1 } ( m )$ ，则有 $f ( x _ { 1 } ) = f ^ { s + 1 } ( m )$ ，又因为 $f$ 为单射，所以 $x _ { 1 } = f ^ { s } ( m )$ ，这与 $x _ { 1 } \in D _ { s }$ 矛盾！所以 $y _ { 1 } \in D _ { s + 1 }$ ，进而 $| D _ { s } | \leqslant | D _ { s + 1 } | .$ o取 $y _ { 2 } \in D _ { s + 1 }$ ，设 $y _ { 2 } = f ^ { s } ( n ) = f [ f ^ { s - 1 } ( n ) ]$ ，记 $x _ { 2 } = f ^ { s - 1 } ( n ) \in f ^ { s - 1 } ( \mathbb { Z } _ { + } )$ 。如果 $f ^ { s } ( l ) = x _ { 2 }$ 9则会推出 $f ^ { s + 1 } ( l ) = f ( x _ { 2 } ) = y _ { 2 }$ ，这与 $y _ { 2 } \in D _ { s + 1 }$ 矛盾！所以 $x _ { 2 } \in D _ { s }$ ，进而 $| D _ { s } | \geqslant | D _ { s + 1 } | .$ 

综合两方面，我们可以得到 $| D _ { 1 } | = | D _ { 2 } | = \cdot \cdot \cdot = | D _ { p } | = \frac { k } { p }$ ，说明 $p \mid k$ 

回到原题，因为 $2 \nmid 1 9 8 7$ ，所以不存在符合要求的函数。

$$
f (f (f (n))) = f (n + 1) + 1
$$

解

共有两个函数满足条件 $f ( n ) = n + 1$ 和

$$
f (n) = \left\{ \begin{array}{l l} n + 1, & n \equiv 0 \pmod {4} \text {或} n \equiv 2 \pmod {4} \\ n + 5, & n \equiv 1 \pmod {4} \\ n - 3, & n \equiv 3 \pmod {4} \end{array} \right.
$$

为叙述简便，记 $h _ { k } ( x )$ 为函数 h 的第 k 次迭代，即 $h _ { 0 } ( x ) = x , h _ { k } ( x ) = h ( h _ { k - 1 } ( x ) )$ C由题设有

$$
f ^ {4} (n) = f \left(f ^ {3} (n)\right) = f \left(f (n + 1) + 1\right)
$$

且

$$
f ^ {4} (n + 1) = f ^ {3} (f (n + 1)) = f (f (n + 1) + 1) + 1
$$

故

$$
f ^ {4} (n) + 1 = f ^ {4} (n + 1)
$$

成立。

记 $R _ { i }$ 为 $f ^ { i }$ 的值域，显然 $R _ { 0 } = \mathbb { Z } _ { \geq 0 }$ ，且

$$
R _ {0} \supseteq R _ {1} \supseteq R _ {2} \supseteq R _ {3} \supseteq \dots
$$

若 $a \in R _ { 4 }$ ，则由上式可得 $a + 1 \in R _ { 4 }$ ，故 $\mathbb { Z } _ { \geq 0 } \backslash R _ { 4 }$ 是有限集，因此 $R _ { 1 }$ 无界。

若存在 $m \neq n$ 使 $f ( m ) = f ( n )$ ，则由题设递推可得 $f ( m + k ) = f ( n + k )$ 对所有 $k \geqslant 0$ 都成立，故 f 从某点后周期，从而 $R _ { 1 }$ 有界，矛盾！因此 $f$ 必为单射。

定义 $S _ { i } = R _ { i - 1 } \backslash R _ { i }$ 。对 $i \leqslant$ 4 每个 $S _ { i }$ 有限，且单射性给出 $| S _ { 1 } | = | S _ { 2 } | = | S _ { 3 } | = \cdot \cdot \cdot = k \cdot$ 又 $\mathrm { 0 } \in S _ { 1 } \cup S _ { 2 } \cup S _ { 3 }$ ，故 k $\geqslant 1$

$$
\{0, a + 1, f (0) + 1 \}
$$

其中 a 是某个满足 $S _ { 1 } = \{ a \}$ 的整数。经过分类讨论可得两种可能：若 $a = 0$ ，则 $f ( 0 ) = 1$ 且 $f ( 1 ) = 2$ ，进而递推得 $f ( n ) = n + 1$ ；若 $f ^ { 2 } ( a ) = 0$ ，则最终得到 $a = 2$ ，并推出函数满足给出的模 4 分类形式。因此两解皆得证。
