是否存在一个能被 1998 整除且各位数字之和小于 27 的正整数？

解

答案：不存在。

用 $S ( n )$ 表示非负整数 n 的十进制数字和。对任意非负整数 $x , y ;$ ，十进制加法中每发生一次进位，数字和就减少 9，因此

$$
S (x + y) \leqslant S (x) + S (y)
$$

因为 1998 = 2·999，所以 1998 的每个正整数倍都是 $9 9 9 = 1 0 ^ { 3 } - 1$ 的正整数倍。下面对N 按数值大小作归纳，证明每个 999 的正整数倍 N 都满足 $S ( N ) \geqslant 2 7$ 。当 $N = 9 9 9$ 时，结论显然成立。

设 $N > 9 9 9$ 。将 N 除以 1000，写成

$$
N = 1 0 0 0 q + r, \qquad q \geqslant 1, \quad 0 \leqslant r <   1 0 0 0
$$

由于 1000 ≡ 1 (mod 999)，有

$$
q + r \equiv N \equiv 0 \pmod {9 9 9}
$$

而且

$$
N - (q + r) = 9 9 9 q > 0
$$

所以 $q + r$ 是比 N 小的 999 的正整数倍。由归纳假设， $S ( q + r ) \geqslant 2 7$ 。在 $N = 1 0 0 0 q + r$ 中，高位的 q 与低三位的 r 没有重叠，故

$$
S (N) = S (q) + S (r) \geqslant S (q + r) \geqslant 2 7
$$

因此，能被 1998 整除的正整数不可能具有小于 27 的数字和。

设正整数 $a , b , c , n$ 满足 $a b c = 1 0 ^ { n } - 1$ 。若 $S ( x )$ 表示 x 的十进制各位数字之和，证明：

$$
S (a) + S (b ^ {2}) + S (c ^ {4}) \geqslant \sqrt [ 3 ]{2 4 3 n}
$$

解

先证明三个关于十进制数字和的引理。

引理一：对任意非负整数 $x , y$ ，均有

$$
S (x + y) \leqslant S (x) + S (y)
$$

引理一证明：按十进制逐位计算 $x + y$ 。每发生一次进位，就把当前位的 10 个单位换成下一位的 1 个单位，数字和减少 9；若没有进位，数字和保持不变。因此相加后的数字和不超过两个加数的数字和之和。

引理二：对任意非负整数 $x , y$ ，均有

$$
S (x y) \leqslant S (x) S (y)
$$

引理二证明：将 x 写成十进制形式

$$
x = x _ {k} 1 0 ^ {k} + x _ {k - 1} 1 0 ^ {k - 1} + \dots + x _ {0}
$$

其中 $0 \leqslant x _ { i } \leqslant 9$ 。反复使用引理一，并注意乘以 $1 0 ^ { i }$ 不改变数字和，可得

$$
S (x y) = S \left(\sum_ {i = 0} ^ {k} x _ {i} y 1 0 ^ {i}\right) \leqslant \sum_ {i = 0} ^ {k} S \left(x _ {i} y 1 0 ^ {i}\right) = \sum_ {i = 0} ^ {k} S \left(x _ {i} y\right)
$$

把 $x _ { i } y$ 看成 $x _ { i }$ 个 $y$ 的和，再次使用引理一，得到 $S ( x _ { i } y )$ ⩽ $x _ { i } S ( y )$ 。所以

$$
S (x y) \leqslant \sum_ {i = 0} ^ {k} x _ {i} S (y) = S (x) S (y)
$$

引理三：对任意正整数 m，每个 $1 0 ^ { m } - 1$ 的正整数倍的数字和都不小于 $9 m$ 

引理三证明：对这样的正整数倍 N 按数值大小作归纳。当 $N = 1 0 ^ { m } - 1$ 时，其十进制表示由 $m$ 个数字 9 组成，所以 $S ( N ) = 9 m$ o

以下设 $N > 1 0 ^ { m } - 1$ 。将 N 除以 $1 0 ^ { m }$ ，写成

$$
N = 1 0 ^ {m} q + r, \qquad 0 \leqslant r <   1 0 ^ {m}
$$

由于 $1 0 ^ { m } \equiv 1 { \pmod { 1 0 ^ { m } - 1 } }$ ，有

$$
q + r \equiv N \equiv 0 \pmod {1 0 ^ {m} - 1}
$$

而且 $q \geqslant 1$ ，并且

$$
N - (q + r) = (1 0 ^ {m} - 1) q > 0
$$

所以 $q + r$ 是 $1 0 ^ { m } - 1$ 的一个比 N 小的正整数倍。由归纳假设， $S ( q + r ) \geqslant 9 m .$ 。在 $N = 1 0 ^ { m } q + r$ 中，将 r 的十进制表示在左侧补零至恰有 m 位，可以看出高位的 q 与低位的 r 没有重叠，故

$$
S (N) = S (q) + S (r)
$$

再由引理一， $S ( N ) = S ( q ) + S ( r ) \geqslant S ( q + r ) \geqslant 9 m$ 。归纳完成。

回到原题。因为

$$
a b ^ {2} c ^ {4} = (a b c) b c ^ {3} = (1 0 ^ {n} - 1) b c ^ {3}
$$

所以 $a b ^ { 2 } c ^ { 4 }$ 是 $1 0 ^ { n } - 1$ 的正整数倍。由引理三，

$$
S (a b ^ {2} c ^ {4}) \geqslant 9 n
$$

另一方面，反复使用引理二可得

$$
S (a b ^ {2} c ^ {4}) \leqslant S (a) S (b ^ {2}) S (c ^ {4})
$$

于是 $S ( a ) S ( b ^ { 2 } ) S ( c ^ { 4 } ) \geqslant 9 n$ 。三个数字和都是正数，故由均值不等式

$$
S (a) + S (b ^ {2}) + S (c ^ {4}) \geqslant 3 \sqrt [ 3 ]{S (a) S (b ^ {2}) S (c ^ {4})} \geqslant 3 \sqrt [ 3 ]{9 n} = \sqrt [ 3 ]{2 4 3 n}
$$

结论成立。

对正整数 m，记 $s ( m )$ 为 m 的十进制数字和。对整数 n ⩾ 2，令 $f ( n )$ 为满足下述条件的最小正整数 k：存在一个含有 n 个正整数的集合 A，使得对 A 的每个非空子集 X，都有$s \left( \sum _ { x \in X } x \right) = k$ 。证明存在常数 $0 < C _ { 1 } < C _ { 2 }$ ，使得

$$
C _ {1} \log_ {1 0} n \leqslant f (n) \leqslant C _ {2} \log_ {1 0} n
$$

解

约定 $s ( 0 ) = 0$ 。先证明两个引理。

引理一：任意给定的 m 个整数中，必能选出至少一个整数，使所选整数之和能被 $m$ 整除。

引理一证明：将这 m 个整数依次记为 $a _ { 1 } , a _ { 2 } , \cdots , a _ { m }$ ，考察 m 个部分和

$$
a _ {1}, \quad a _ {1} + a _ {2}, \quad \dots , \quad a _ {1} + a _ {2} + \dots + a _ {m}
$$

如果其中一个部分和能被 m 整除，结论成立；否则，这 m 个部分和模 m 的余数都属于$1 , 2 , \cdots , m - 1$ ，故其中两个余数相同。将相应的两个部分和相减，便得到若干个连续的 $a _ { i }$ ，其和能被 m 整除。

引理二：对任意正整数 q，每个 $1 0 ^ { q } - 1$ 的正整数倍的数字和都不小于 $9 q$ 。

引理二证明：对任意非负整数 u,v，十进制加法中每发生一次进位，数字和就减少 9，因此 $s ( u + v ) \leqslant s ( u ) + s ( v )$ 。设 M 是 $1 0 ^ { q } - 1$ 的正整数倍，将 M 按每 q 位一组写成

$$
M = a _ {0} + a _ {1} \cdot 1 0 ^ {q} + \dots + a _ {r} \cdot 1 0 ^ {r q}, \quad 0 \leqslant a _ {i} <   1 0 ^ {q}, \quad a _ {r} > 0
$$

若 $r = 0$ ，则 $M < 1 0 ^ { q }$ ，从而 $M = 1 0 ^ { q } - 1$ ，结论成立。若 $r \geqslant 1$ ，令 $M ^ { \prime } = a _ { 0 } + a _ { 1 } + \cdot \cdot \cdot + a _ { r } \circ$ 因为 $1 0 ^ { q } \equiv 1 { \pmod { 1 0 ^ { q } - 1 } }$ ，所以 $M ^ { \prime }$ 仍是 $1 0 ^ { q } - 1$ 的正整数倍，而且

$$
M - M ^ {\prime} = \sum_ {i = 1} ^ {r} a _ {i} (1 0 ^ {i q} - 1) > 0
$$

分块不改变数字和，再由数字和的次可加性可得

$$
s (M ^ {\prime}) \leqslant \sum_ {i = 0} ^ {r} s (a _ {i}) = s (M)
$$

因此可以反复进行上述操作，使所得正整数严格减小，而数字和不增加。最终得到一个小于$1 0 ^ { q }$ 的正整数倍，它只能是 $1 0 ^ { q } - 1$ ，故 $s ( M ) \geqslant 9 q$ 。

上界：令 $p$ 为满足 $1 0 ^ { p } \geqslant n ( n + 1 ) / 2$ 的最小正整数，并构造集合

$$
A = \left\{1 0 ^ {p} - 1, 2 (1 0 ^ {p} - 1), \dots , n (1 0 ^ {p} - 1) \right\}
$$

任取非空指标集 $I \subseteq \{ 1 , 2 , \cdots , n \}$ ，令 $t = \textstyle \sum _ { i \in I } i$ ，则 $1 \leqslant t \leqslant n ( n + 1 ) / 2 \leqslant 1 0 ^ { p }$ ，而对应的子集和为

$$
t \left(1 0 ^ {p} - 1\right) = (t - 1) 1 0 ^ {p} + \left(1 0 ^ {p} - 1 - (t - 1)\right)
$$

把 $t - 1$ 写成恰有 p 位的十进制数 (允许前导零)。若其各位数字依次为 $b _ { 1 } , b _ { 2 } , \cdots , b _ { p }$ ，则$1 0 ^ { p } - 1 - ( t - 1 )$ 的相应各位数字依次为 $9 - b _ { 1 } , 9 - b _ { 2 } , \cdot \cdot \cdot , 9 - b _ { p } ,$ 。上式右端的两项分别位于高位块和低 p 位块，不会发生进位，所以

$$
s \left(t \left(1 0 ^ {p} - 1\right)\right) = \sum_ {i = 1} ^ {p} \left(b _ {i} + \left(9 - b _ {i}\right)\right) = 9 p
$$

因此集合 A 的每个非空子集的元素和的数字和都等于 9p，从而 $f ( n ) \leqslant 9 p$ 。由 p 的最小性，有 $1 0 ^ { p - 1 } < n ( n + 1 ) / 2$ ，故 $p < \log _ { 1 0 } { ( 5 n ( n + 1 ) ) }$ 。对 $n \geqslant 2$ ，容易验证 $5 ( n + 1 ) < n ^ { 4 }$ ，于是

$$
f (n) \leqslant 9 p <   4 5 \log_ {1 0} n
$$

下界：取一个实现 $f ( n )$ 的集合 B，并记 $K = f ( n )$ 。任取 B 中两个不同的元素 $x , y$ 。由于每个非负整数均与其数字和模 9 同余，由题设可得

$$
x \equiv K, \qquad y \equiv K, \qquad x + y \equiv K \pmod {9}
$$

另一方面， $x + y \equiv 2 K { \pmod { 9 } }$ ，所以 $K \equiv 0 { \pmod { 9 } }$ 。由于 $K > 0$ ，故 $K \geqslant 9$ 

令 $q = \lfloor \log _ { 1 0 } ( n + 1 ) \rfloor$ ，则 $1 0 ^ { q } - 1 \leqslant n < 1 0 ^ { q + 1 } - 1$ 。当 $q \geqslant 1$ 时，从 B 中任取 $1 0 ^ { q } - 1$ 个元素。由引理一，其中存在一个非空子集，其元素和 M 能被 $1 0 ^ { q } - 1$ 整除。再由引理二及集合 B 的性质，有 $K = s ( M ) \geqslant 9 q$ 。当 $q = 0$ 时， $K \geqslant 9 q$ 也显然成立。因此

$$
K \geqslant \max \{9, 9 q \} \geqslant \frac {9 (q + 1)}{2}
$$

又因为 $n < 1 0 ^ { q + 1 }$ ，所以 $q + 1 > \log _ { 1 0 } n$ ，从而

$$
f (n) = K > \frac {9}{2} \log_ {1 0} n
$$

综上，取 $C _ { 1 } = 9 / 2$ 与 $C _ { 2 } = 4 5$ 即可。
