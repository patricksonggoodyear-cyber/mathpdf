设 $x _ { 1 } , x _ { 2 } , \cdots , x _ { n }$ 为实数，其算术平均值为 a。证明：

$$
\sum_ {k = 1} ^ {n} (x _ {k} - a) ^ {2} \leqslant \frac {1}{2} \left(\sum_ {k = 1} ^ {n} | x _ {k} - a |\right) ^ {2}
$$

解

令 $y _ { k } = x _ { k } - a \ ( k = 1 , 2 , \cdot \cdot \cdot , n )$ ，则 $\sum _ { k = 1 } ^ { n } y _ { k } = 0$ ，记 $P = \{ k : y _ { k } > 0 \} , N = \{ k : y _ { k } < 0 \}$ 并令 $s = \sum _ { k \in P } y _ { k } = - \sum _ { k \in N } y _ { k }$ ，于是 $\sum _ { k = 1 } ^ { n } \left| y _ { k } \right| = 2 s$ 。对于任意有限个非负实数，其平方和不超过和的平方。因此，分别对正偏差和负偏差的绝对值应用这一事实，得到

$$
\sum_ {k = 1} ^ {n} y _ {k} ^ {2} = \sum_ {k \in P} y _ {k} ^ {2} + \sum_ {k \in N} (- y _ {k}) ^ {2} \leqslant \left(\sum_ {k \in P} y _ {k}\right) ^ {2} + \left(\sum_ {k \in N} (- y _ {k})\right) ^ {2} = 2 s ^ {2}
$$

代回 $y _ { k } = x _ { k } - a$ ，即得所证不等式。

$$
\frac {a _ {1} ^ {2} + a _ {2} ^ {2} + \cdots + a _ {n} ^ {2}}{n} \geqslant \left(\frac {a _ {1} + a _ {2} + \cdots + a _ {n}}{n}\right) ^ {2} + C _ {n} \cdot (a _ {1} - a _ {n}) ^ {2}\tag{1}
$$

解

记

$$
V = \frac {a _ {1} ^ {2} + a _ {2} ^ {2} + \cdots + a _ {n} ^ {2}}{n} - \left(\frac {a _ {1} + a _ {2} + \cdots + a _ {n}}{n}\right) ^ {2} = \frac {1}{n ^ {2}} \sum_ {i <   j} (a _ {i} - a _ {j}) ^ {2}
$$

由于 V 与 $( a _ { 1 } - a _ { n } ) ^ { 2 }$ 在所有变量整体平移时均保持不变，将每个变量减去它们的平均值后，可设 $a _ { 1 } + a _ { 2 } + \cdots + a _ { n } = 0$ 。

当 $n = 2$ 时， $V = ( a _ { 1 } - a _ { 2 } ) ^ { 2 } / 4$ ，故 $C _ { 2 } = 1 / 4 = 1 / ( 2 n )$ 。以下设 $n \geqslant 3$ 。固定 $a _ { 1 } , a _ { n }$ 与所有变量之和，由 Cauchy 不等式可知，当且仅当中间的 $n - 2$ 个变量相等时，它们的平方和最小。因此只需令

$$
a _ {2} = a _ {3} = \dots = a _ {n - 1} = A = - \frac {a _ {1} + a _ {n}}{n - 2}
$$

令 $x = a _ { 1 } , y = a _ { n }$ 以及 $\lambda = n C _ { n }$ 。把上式代入 (1) 并乘以 $n - 2$ ，得到

$$
(n - 2) (x ^ {2} + y ^ {2}) + (x + y) ^ {2} \geqslant (n - 2) \lambda (x - y) ^ {2}\tag{2}
$$

令 $y = - x \neq 0$ ，由 (2) 得 $\lambda \leqslant 1 / 2$ 。另一方面，当 $\lambda = 1 / 2$ 时，(2) 左边减去右边等于

$$

$$

故 $\lambda = 1 / 2$ 可行。

$$

$$

其锐性可由正数构型 $a _ { 1 } = t + 1 , a _ { n } = t - 1$ 以及 $a _ { i } = t ~ ( 2 \leqslant i \leqslant n - 1 )$ 得到，其中 $t > 1$ ；中间条件在 $n = 2$ 时为空，此时仍取等。

$$
\frac {1}{(x - y) ^ {2}} + \frac {1}{(y - z) ^ {2}} + \frac {1}{(z - x) ^ {2}} \geqslant \frac {4}{x y + y z + z x}\tag{1}
$$

并确定等号何时成立？

解

不妨设 $x = \operatorname* { m i n } \{ x , y , z \}$ 。将 $( x , y , z )$ 平移为 $( 0 , y - x , z - x )$ 后，式 (1) 的左边保持不变，而

$$
x y + y z + z x - (y - x) (z - x) = x (2 y + 2 z - x) \geqslant 0
$$

故右边不减，只需证明平移后的更强情形。重新记变量后，可设 $x = 0$ ，此时

$$
\begin{array}{r l} & {\frac {1}{y ^ {2}} + \frac {1}{z ^ {2}} + \frac {1}{(y - z) ^ {2}} \geqslant \frac {4}{y z} \Longleftrightarrow (y ^ {2} + z ^ {2}) (y - z) ^ {2} + y ^ {2} z ^ {2} \geqslant 4 y z (y - z) ^ {2}} \\ & {\qquad \Longleftrightarrow y ^ {4} - 6 y ^ {3} z + 1 1 y ^ {2} z ^ {2} - 6 y z ^ {3} + z ^ {4} = (y ^ {2} - 3 y z + z ^ {2}) ^ {2} \geqslant 0} \end{array}

若原不等式取等，则上述平移也必须不使右边严格增大，因而 $x = 0$ 。又

$$
y ^ {2} - 3 y z + z ^ {2} = 0 \quad \Longleftrightarrow \quad y = \frac {3 \pm \sqrt {5}}{2} z
$$

故取等条件为 $x = 0 , y = { \frac { 3 \pm { \sqrt { 5 } } } { 2 } } z$ 及其所有排列。

设正实数 $a , b , c$ 互不相同，求证：

$$
\frac {a b + b c + c a}{(a + b) (b + c) (c + a)} <   \frac {1}{7} \left(\frac {1}{| a - b |} + \frac {1}{| b - c |} + \frac {1}{| c - a |}\right)
$$

解

不妨 $a > b > c > 0$ ，并令

$$
f (a, b, c) = \frac {1}{| a - b |} + \frac {1}{| b - c |} + \frac {1}{| c - a |} - \frac {7 (a b + b c + c a)}{(a + b) (b + c) (c + a)}
$$

我们先证明：对任意 $x \in [ 0 , c ]$ ，均有 $f ( a , b , c ) \geqslant f ( a - x , b - x , c - x )$ 。事实上，这等价于

$$
\begin{array}{l l} & \frac {a b + b c + c a}{(a + b) (b + c) (c + a)} \leqslant \frac {(a - x) (b - x) + (b - x) (c - x) + (c - x) (a - x)}{(a + b - 2 x) (b + c - 2 x) (c + a - 2 x)} \\ \Longleftrightarrow & 3 x + \frac {(a - x) (b - x) (c - x)}{(a - x) (b - x) + (b - x) (c - x) + (c - x) (a - x)} \geqslant \frac {a b c}{a b + b c + c a} \end{array}
$$

设函数

$$
g (x) = 3 x + \frac {(a - x) (b - x) (c - x)}{(a - x) (b - x) + (b - x) (c - x) + (c - x) (a - x)}
$$

则 $g ( 0 ) = { \frac { a b c } { a b + b c + c a } } \circ$ 当 $0 \leqslant x < c$ 时，求导得到

$$
g ^ {\prime} (x) = 3 - \frac {(a - x) ^ {- 2} + (b - x) ^ {- 2} + (c - x) ^ {- 2}}{[ (a - x) ^ {- 1} + (b - x) ^ {- 1} + (c - x) ^ {- 1} ] ^ {2}} > 0
$$

上式分式的分母平方展开后还含有正的交叉项，故该分式小于 1。再由连续性可知 $g ( x ) \geqslant g ( 0 )$ 对所有 $x \in [ 0 , c ]$ 成立，从而只需考虑 $c = 0 .$ 。记 $\lambda = b / a \in ( 0 , 1 )$ ，则

$$
f (a, b, 0) \geqslant 0 \iff \frac {1}{a - b} + \frac {1}{b} + \frac {1}{a} \geqslant \frac {7}{a + b} \iff \frac {1 - \lambda^ {3} + 2 \lambda}{\lambda - \lambda^ {2}} \geqslant 7
$$

而事实上

$$
\frac {1 - \lambda^ {3} + 2 \lambda}{\lambda - \lambda^ {2}} = \frac {2}{1 - \lambda} + 1 + \lambda + \frac {1}{\lambda} = \frac {2}{1 - \lambda} + 8 (1 - \lambda) + 9 \lambda + \frac {1}{\lambda} - 7 \geqslant 8 + 6 - 7 = 7
$$

这里两次 AM-GM 不等式分别要求 $\lambda = 1 / 2$ 与 $\lambda = 1 / 3$ 才能取等，二者不相容，故上式实际上严格大于 7，原不等式成立。

设 n 是正整数， $x _ { 1 } , x _ { 2 } , \cdots , x _ { n }$ 是实数，求证：

$$
\sum_ {i = 1} ^ {n} \sum_ {j = 1} ^ {n} \sqrt {\left| x _ {i} - x _ {j} \right|} \leqslant \sum_ {i = 1} ^ {n} \sum_ {j = 1} ^ {n} \sqrt {\left| x _ {i} + x _ {j} \right|}
$$

解

对 n 作强归纳； $n = 1$ 时命题显然，空集对应的 $n = 0$ 情形也视为显然成立。假设所有小于 n 的情形均已成立，下面证明 n 的情形。

不等式左边在所有 $x _ { i }$ 整体平移时保持不变。若已经存在 i,j 使 $x _ { i } + x _ { j } = 0$ ，则令 $\lambda _ { 0 } = 0$ 否则，令 A 为所有正数 $x _ { i } + x _ { j }$ 中的最小值，若不存在正数则令 $A = 0 { \mathrm { ; } }$ ；令 B 为所有负数$x _ { i } + x _ { j }$ 中的最大值，若不存在负数则令 $B = 0$ 。于是 $B \leqslant 0 \leqslant A$ ，且没有 $x _ { i } + x _ { j }$ 严格落在区间 $( B , A )$ 内。

对 $\lambda \in [ B , A ]$ ，设

$$
f (\lambda) = \sum_ {i = 1} ^ {n} \sum_ {j = 1} ^ {n} \sqrt {\left| x _ {i} + x _ {j} - \lambda \right|}
$$

对每个 $i , j$ ，相应的被开方数在整个区间内保持同号，故其对应项或者形如 $\sqrt { x _ { i } + x _ { j } - \lambda }$ ，或者形如 $\sqrt { \lambda - x _ { i } - x _ { j } }$ ，都是 λ 的凹函数。因此 $f$ 在 $[ B , A ]$ 上为凹函数，最小值在端点取得。若所有 $x _ { i } + x _ { j }$ 同号，则 $f$ 沿着通向唯一非零端点的方向单调递减。因此，在初始时没有零和数对的情况下，总能选取 $\lambda _ { 0 } \in \{ A , B \}$ ，使 $f ( \lambda _ { 0 } ) \leqslant f ( 0 )$ ，且某个 $x _ { i } + x _ { j } = \lambda _ { 0 }$ 。

无论哪种情况，将每个 $x _ { i }$ 替换为 $x _ { i } - \lambda _ { 0 } / 2$ 后，不等式左边保持不变，右边不增，并且存在 $i , j$ 使 $x _ { i } + x _ { j } = 0$ 。以下仍用 $x _ { i }$ 表示平移后的数。

若 $i = j$ ，则 $x _ { i } = 0$ 。不等式两边所有含下标 i 的项逐项相等，删去 $x _ { i }$ 后由 $n - 1$ 的归纳假设即可。

若 $i \neq j$ ，则 $x _ { j } = - x _ { i }$ ，且对每个 k 均有

$$
\sqrt {| x _ {i} - x _ {k} |} = \sqrt {| x _ {j} + x _ {k} |}, \quad \sqrt {| x _ {j} - x _ {k} |} = \sqrt {| x _ {i} + x _ {k} |}
$$

因此两边所有含下标 i 或 j 的项总和相等，删去 $x _ { i } , x _ { j }$ 后由 $n - 2$ 的归纳假设即可。归纳完成。

给定整数 $n \geqslant 2$ 。求最小的实数 λ，使得对任意实数 $a _ { 1 } , a _ { 2 } , \cdots , a _ { n }$ 及 $b ,$ ，均有

$$

解

令

答案为： $\frac { n - 1 + { \sqrt { n - 1 } } } { \sqrt { n } }$ ，记 $C = \frac { n - 1 + \sqrt { n - 1 } } { \sqrt { n } }$ C

$$
p = \frac {1}{n} \sum_ {i = 1} ^ {n} a _ {i}, \quad x _ {i} = a _ {i} - p, \quad \beta = b - p
$$

则 $\textstyle \sum _ { i = 1 } ^ { n } x _ { i } = 0$ ，且

$$
\sum_ {i = 1} ^ {n} \sqrt {\left| a _ {i} - b \right|} = \sum_ {i = 1} ^ {n} \sqrt {\left| x _ {i} - \beta \right|}
$$

由 $\sqrt { | u + v | } \leqslant \sqrt { | u | } + \sqrt { | v | }$ ，有

$$
\sum_ {i = 1} ^ {n} \sqrt {\left| a _ {i} \right|} \leqslant \sum_ {i = 1} ^ {n} \sqrt {\left| x _ {i} \right|} + n \sqrt {| p |} = \sum_ {i = 1} ^ {n} \sqrt {\left| x _ {i} \right|} + \sqrt {n \left| \sum_ {i = 1} ^ {n} a _ {i} \right|}
$$

所以只需证明

$$
\sum_ {i = 1} ^ {n} \sqrt {| x _ {i} |} \leqslant C \sum_ {i = 1} ^ {n} \sqrt {| x _ {i} - \beta |}
$$

由 $\textstyle \sum _ { i = 1 } ^ { n } x _ { i } = 0$ ，对于每个 i 均有

$$

$$

故反复应用 $\sqrt { | u + v | } \leqslant \sqrt { | u | } + \sqrt { | v | }$ ，得到

$$
\sqrt {| x _ {i} |} \leqslant \sqrt {\frac {n - 1}{n}} \sqrt {| x _ {i} - \beta |} + \frac {1}{\sqrt {n}} \sum_ {j \neq i} \sqrt {| x _ {j} - \beta |}

$$
