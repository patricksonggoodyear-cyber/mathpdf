## TOT 1980 P1

圆周上有若干个红点和蓝点。允许在任意两个相邻点之间插入一个红点，并把这两个相邻点的颜色同时改变；也允许删去任意一个红点，并把它原来的两个邻点的颜色同时改变。最初圆周上只有两个点，且均为红色；操作过程中不允许点数少于 2。证明：不能经过有限次操作使圆周上只剩两个蓝点。

## 解

每次操作都翻转两个原有点，而插入或删去的点均为红点，所以蓝点数改变 0 或 $\pm 2$ ，其奇偶性不变。初始时没有蓝点，故每个可达状态中的蓝点数都是偶数。

考虑任意一个从初态可达的状态。若其中有 $2 k > 0$ 个蓝点，任选一个绕圆周的方向，并从某个蓝点开始，依次把这些蓝点记为 $B _ { 1 } , B _ { 2 } , \cdots , B _ { 2 k }$ 。设从 $B _ { i }$ 沿所选方向走到下一个蓝点之间共有 $m _ { i }$ 个红点，其中下标按模 2k 理解。令

$$
S = m _ {1} - m _ {2} + m _ {3} - \dots + m _ {2 k - 1} - m _ {2 k}
$$

若把起始蓝点移到下一个蓝点，各红段长度循环移动一位， $S$ 变为 −S；若改变绕行方向，各红段长度的次序反转，所得 S 仍为原来的 S 或 −S。因此，虽然 S 本身可能因起点或方向的选择而改变符号，但 $S ^ { 2 }$ 模 3 的余数与这些选择无关。

若状态中没有蓝点，则直接令 S 等于红点数。对所有从初态可达的状态定义

$$
J \equiv S ^ {2} \pmod {3}
$$

下面证明 J 在每次操作中保持不变。

只需检查插入操作，因为删除一个红点并改变其两个原邻点的颜色，恰好是相应插入操作的逆过程。以下用 R,B 分别表示红点和蓝点。按照所选绕行方向依次写出新插入点的两个邻点在操作前的颜色，四种局部变化为

$$
\mathrm{RR} \longrightarrow \mathrm{BRB}, \qquad \mathrm{RB} \longrightarrow \mathrm{BRR}, \qquad \mathrm{BR} \longrightarrow \mathrm{RRB}, \qquad \mathrm{BB} \longrightarrow \mathrm{RRR}
$$

先设操作前后都有蓝点。此时总能选取一个未被操作改变的蓝点作为共同起点：在 RR情形中，原有蓝点均未改变；在 RB 或 BR 情形中，原有蓝点数为正偶数，故除被翻转的蓝点外尚有蓝点；在 BB 情形中，操作后剩余的蓝点均未改变。用同一绕行方向计算两个状态的 S，使操作区域以外各红段的符号相同。表中的 $a , c \geqslant 0$ 分别表示沿所选方向位于这两个相邻点之前、之后，且处于同一有关红段中未写出的红点数， $\varepsilon \in \{ 1 , - 1 \}$ 表示最左相关红段的符号。四种情况下，相关红段对 的贡献如下：

所以在这些情况下都有 $S ^ { \prime } \equiv S { \pmod { 3 } }$ ，从而 J 不变。

若插入前没有蓝点，设有 r 个红点；插入后两段红点数为 $r - 2 , 1$ ，可取 $S ^ { \prime } = r - 3$ ，而$S = r$ 。若插入后没有蓝点，则插入前恰有两个相邻蓝点；设其余有 个红点，可取插入前$S = r$ ，而插入后 $S ^ { \prime } = r + 3$ 。两种边界情形也都有 $S ^ { \prime } \equiv S { \pmod { 3 } }$ 

综上，每次插入都保持 J 不变；删除操作是插入操作的逆过程，所以也保持 J 不变。

初始状态只有两个红点，故 $S = 2$ ，从而 $J \equiv 1 { \pmod { 3 } }$ 。若最终只剩两个蓝点，则两个红段的长度都为 0，故 $S = 0$ ，从而 $J \equiv 0 { \pmod { 3 } }$ 。初态与目标状态的 J 不同，因此目标状态不可能达到。

## Moscow MO 1993 Grade 8 P3

直线上有两枚棋子，红色棋子在左，蓝色棋子在右。允许进行以下两种操作中的任意一种：在直线上的任意位置连续插入两枚同色棋子，或删去任意两枚相邻的同色棋子。能否经过有限次操作，使直线上恰好留下两枚棋子，红色棋子在右，蓝色棋子在左？

## 解

答案是否定的。

将红色棋子记为 1，蓝色棋子记为 0，并按从左到右的顺序组成一个 0-1 数列。记 I 为这个数列的逆序数，即左边是红色棋子、右边是蓝色棋子的棋子对数。

若插入或删去两枚相邻的红色棋子，设这两枚棋子右侧有 枚蓝色棋子，则 的改变量为 ±2b。若插入或删去两枚相邻的蓝色棋子，设这两枚棋子左侧有 r 枚红色棋子，则 I 的改变量为 $\pm 2 r$ 。因此，每次操作都使 I 改变一个偶数，故 I 的奇偶性始终不变。

初始状态中棋子的顺序为红、蓝，所以 $I = 1$ ，是奇数；目标状态中棋子的顺序为蓝、红，所以 $I = 0$ ，是偶数。两者的奇偶性不同，故目标状态不可能经过有限次允许的操作得到。

对任意数列可进行如下操作：每次选取数列中相邻三项，记为 $a , b , c ,$ ，替换为 $b , c , a ;$ ，其他项保持不变。试确定所有的整数 $n \geqslant 3$ ，使得数列 $1 , 2 , \cdots , n$ 可经有限次操作变成 $n , n - 1 , \cdots , 1$ o

解

设数列 $x = ( x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { m } )$ 是 $1 , 2 , \cdots , m$ 的一个排列，并以 I(x) 表示它的逆序数，即

$$
I (x) = \left| \{(i, j): 1 \leqslant i <   j \leqslant m, x _ {i} > x _ {j} \} \right|
$$

一次操作把相邻三项 $( a , b , c )$ 变为 $( b , c , a )$ ，这相当于对这三项施行一个 3-循环，也就是连续进行两次对换，故排列的奇偶性不变，即逆序数的奇偶性不变。

初始数列 $1 , 2 , \cdots , n$ 的逆序数为 0，而目标数列 $n , n - 1 , \cdots , 1$ 的逆序数为 $n ( n - 1 ) / 2$ o因此，若目标能够实现，则 $n ( n - 1 ) / 2$ 必须为偶数，也就是

$$
n \equiv 0, 1 \pmod {4}
$$

下面证明这一条件也充分。事实上，对任意 $m \ \geqslant \ 3 .$ ，每个 $1 , 2 , \cdots , m$ 的偶排列都可以经过有限次操作变成 $1 , 2 , \cdots , m$ 。对此关于 m 作归纳。当 $m = 3$ 时，三个偶排列恰为(1, 2, 3), (2, 3, 1), (3, 1, 2)，结论显然成立。

设 $m \geqslant 4$ ，并假设结论对 $m - 1$ 成立。任取 $1 , 2 , \cdots , m$ 的一个偶排列。若 m 尚不在末位，并且其右侧至少还有两项，就对从 m 所在位置开始的相邻三项进行一次操作，使 m 向右移动两位；重复此过程，直到 m 到达末位或倒数第二位。若 m 到达倒数第二位，则对数列末尾三项连续进行两次操作，便可将 m 移至末位。此时前 $m - 1$ 项仍构成偶排列：因为全部操作都保持排列的奇偶性，而位于末位的最大数 m 不产生逆序。由归纳假设，只在前 $m - 1$ 项中进行操作即可将它们变为 $1 , 2 , \cdots , m - 1$ ，从而整个排列变为 $1 , 2 , \cdots , m$ 

又因一次操作连续进行三次便回到原状，所以该操作可逆。于是 1,2,··· ,n 可以变成任意偶排列。当 $n \equiv 0 , 1 { \pmod { 4 } }$ 时，倒序排列 $n , n - 1 , \cdots , 1$ 正是偶排列，故必可实现。

综上，所求整数恰为满足 $n \equiv 0 , 1$ (mod 4) 的所有 $n \geqslant 3$ o

## IMOSL 2017 C2

称含有 n 个字母 a、n 个字母 b、n 个字母 c 的长度 3n 字符串为“变色龙”。一次交换是交换两个相邻字母。证明：对任意变色龙 X，存在变色龙 Y，使从 X 变到 Y 至少需要 $3 n ^ { 2 } / 2$ 次交换。

解答：令

$$
P = a ^ {n} b ^ {n} c ^ {n}, \quad Q = c ^ {n} b ^ {n} a ^ {n}
$$

对任意字符串 $Z ,$ ，记 $F ( Z )$ 为其中次序为 $( a , b ) , ( a , c ) , ( b , c )$ 的位置对总数。交换两个不同的相邻字母恰使 $F$ 改变 1，而

$$
F (P) = 3 n ^ {2}, \quad F (Q) = 0
$$

对任意两个变色龙 $U , V$ ，记 $d ( U , V )$ 为把 U 变为 V 所需的最少交换次数。因此，把 P 变为$Q$ 至少需要 $3 n ^ { 2 }$ 次交换，即 $d ( P , Q ) \geqslant 3 n ^ { 2 }$ 。由距离的三角不等式，

$$
d (X, P) + d (X, Q) \geqslant d (P, Q) \geqslant 3 n ^ {2}
$$

故 $P , Q$ 中至少一个与 X 的距离不小于 $3 n ^ { 2 } / 2$ ，取它为 Y。

IMOSL 2005 C5 

一排有 n 枚双面标记，初始都白面朝上。每一步可选一枚非端点且白面朝上的标记，将它移走，并翻转它左、右两侧最近的标记。证明：最终能够只剩两枚标记，当且仅当 3 ∤ n−1。

## 解

方法一

记当前黑面朝上的标记数为 B。每次操作移走一枚白色标记并翻转两枚标记，所以 B 的改变量必为偶数。初始时 $B = 0$ ，故若最后只剩两枚标记，它们必定同色。

先证明一个更强的结论：若从 n 枚全为白色的标记出发能够只剩两枚标记，则 $n \equiv 0$ 或2 (mod 3)；并且在 $n \equiv 0 { \pmod { 3 } }$ 时，最后两枚标记均为黑色，在 $n \equiv 2 { \pmod { 3 } }$ 时，最后两枚标记均为白色。

当 $n = 2$ 时，不作操作，最后两枚标记均为白色；当 $n = 3$ 时，移走中间的白色标记并翻转两端，最后两枚标记均为黑色。因此结论在 $n = 2 , 3$ 时成立。

设 $n \geqslant$ 4，并假定结论对少于 n 枚标记的情形成立。考虑一个最终只剩两枚标记的操作过程。原来最左、最右的标记始终不能被移走，分别记为 $L , R e$ 。设最后被移走的是原来从左到右第 k 枚标记 X，其中 $2 \leqslant k \leqslant n - 1$ 。在最后一步之前只剩 $L , X , R$ ，且此时 X 为白色。

把 X 想象成两个初始均为白色的副本 $X _ { \ell } , X _ { r }$ 。从原操作过程中抽出所有移走 X 左侧标记的操作，保持它们原来的相对次序，并将它们作用在原来的前 k 枚标记上，以 $X _ { \ell }$ 为右端点。由于 X 直到最后一步才被移走，右侧的操作不会改变任何严格位于 X 左侧的标记，也不会改变这些标记之间的最近邻关系；删去右侧对 X 的翻转也不影响左侧操作的合法性，因为合法性只要求被移走的标记为白色，并不限制两个邻点的颜色。因此，抽出的操作构成一个合法的子过程，最后只剩 $L , X _ { \ell }$ 。同理，所有移走 X 右侧标记的操作构成一个从原来后 $n - k + 1$ 枚标记出发、最后只剩 $X _ { r } , R$ 的合法子过程。

以 0,1 分别表示白色和黑色。实际的 X 所经历的每一次翻转，恰好来自上述两个子过程之一，所以在最后一步之前，X 的颜色数值等于 $X _ { \ell }$ 与 $X _ { r }$ 的颜色数值之和模 2。此时 X 为白色，故两个副本同色。

由归纳假设，两个子过程的初始标记数 k 与 $n - k + 1$ 都同余于 0 或 2 (mod 3)；初始标记数同余于 0 时两个端点为黑色，同余于 2 时两个端点为白色。由于 $X _ { \ell } , X _ { r }$ 同色，这两个初始标记数的模 3 余数必相同。若它们都同余于 0，则 $n + 1 = k + ( n - k + 1 ) \equiv 0 { \pmod { 3 } }$ ，所以 $n \equiv 2 { \pmod { 3 } }$ ；此时最后一步之前 L,R 均为黑色，翻转后均为白色。若它们都同余于 2，则 $n + 1 \equiv 1 { \pmod { 3 } }$ ，所以 $n \equiv 0 { \pmod { 3 } }$ ；此时最后一步之前 $L , R$ 均为白色，翻转后均为黑色。强化结论的归纳证明完成，特别地，若能够只剩两枚标记，则 $3 \nmid n - 1$ o

再证明充分性。当 $n \ = \ 2$ 时不必操作；当 $n \ : = \ : 3$ 时，移走中间的白色标记即可。设$n \geqslant 5$ ，并在全为白色的局面中把从左端起的前五枚标记依次记为 $A _ { 1 } , A _ { 2 } , A _ { 3 } , A _ { 4 } , A _ { 5 }$ 。依次移走 $A _ { 2 } , A _ { 4 } , A _ { 3 }$ ：第一步后 $A _ { 1 } , A _ { 3 }$ 变为黑色；第二步移走仍为白色的 $A _ { 4 }$ ，使 $A _ { 3 }$ 变回白色、 $A _ { 5 }$ 变为黑色；第三步移走 $A _ { 3 }$ ，使 $A _ { 1 } , A _ { 5 }$ 都变回白色。三步均合法，局部变化为

$$
\mathrm{WWWWW} \longrightarrow \mathrm{BBWW} \longrightarrow \mathrm{BWB} \longrightarrow \mathrm{WW}
$$

其余标记不受影响，所以这三步把 n 枚全为白色的标记化为 n − 3 枚全为白色的标记。若$n \equiv 0$ 或 2 (mod 3)，反复进行这一缩减，最终到达 $n = 3$ 或 $n = 2$ 的基本情形，从而能够只剩两枚标记。综上，所求条件恰为 $3 \nmid n - 1$ 0

## 方法二

先证明必要性。记当前黑面朝上的标记数为 B。一次操作移走的是白色标记；设被翻转的两枚标记中原有 t 枚黑色标记，其中 $t \in \{ 0 , 1 , 2 \}$ ，则操作后黑色标记数的改变量为 2−2t，是偶数。因此，B 的奇偶性不变。初始时 $B = 0$ ，所以若最后只剩两枚标记，这两枚标记必同色。

对当前每一枚白色标记 X，记 b(X) 为它左侧的黑色标记数，并给 X 赋权 $( - 1 ) ^ { b ( X ) }$ 。令所有白色标记的权之和为

$$
S = \sum_ {X \text {为白色}} (- 1) ^ {b (X)}
$$

下面证明 S 模 3 的余数在每次操作中不变。

设一次操作移走白色标记 C，其左、右两侧最近的标记分别为 $L , R _ { \circ }$ 记 L 左侧有 q 枚黑色标记，并令 $\varepsilon = ( - 1 ) ^ { q }$ 。用 W,B 分别表示白色和黑色。按照 L,R 的颜色分类，操作前后$L , C , R$ 对 S 的贡献及其改变量如下：

位于 L 左侧的白色标记的权显然不变。对位于 R 右侧的每一枚白色标记，两次翻转使其左侧黑色标记数的改变量分别为 2,0,0,−2，具体取决于上表四种情形；这个改变量总是偶数，所以其权也不变。因此，每次操作都使 S 改变 3 的倍数，故 S 模 3 的余数不变。

初始时所有标记均为白色，所以 $S = n$ 。若终局的两枚标记均为黑色，则 $S = 0$ ；若它们均为白色，则 $S = 2$ 。因此必须有

$$
n \equiv 0 \quad {\text {或}} \quad n \equiv 2 \pmod {3}
$$

这等价于 $3 \nmid n - 1$ 0

再证明充分性。设 $n \equiv 0$ 或 2 (mod 3)。当 $n = 2$ 时，不作操作便已经只剩两枚标记；当$n = 3$ 时，移走中间的白色标记并翻转两端的标记，便只剩两枚黑色标记。

下面设 $n \geqslant 5$ 。在当前全为白色的标记中，从左端起固定记前五枚为 $A _ { 1 } , A _ { 2 } , A _ { 3 } , A _ { 4 } , A _ { 5 }$ 依次移走 $A _ { 2 } , A _ { 4 } , A _ { 3 }$ 。移走 $A _ { 2 }$ 后， $A _ { 1 } , A _ { 3 }$ 变为黑色；此时 $A _ { 4 }$ 仍为白色，且其两侧最近的标记为 $A _ { 3 } , A _ { 5 }$ ，所以第二步合法。移走 $A _ { 4 }$ 后， $A _ { 3 }$ 重新变为白色， $A _ { 5 }$ 变为黑色；此时 $A _ { 3 }$ 两侧最近的标记为 $A _ { 1 } , A _ { 5 }$ ，所以第三步也合法。移走 $A _ { 3 }$ 并翻转 $A _ { 1 } , A _ { 5 }$ 后，这两枚标记又都变为白色。三步的局部变化可以写成

$$
\mathrm{WWWWW} \longrightarrow \mathrm{BBWW} \longrightarrow \mathrm{BWB} \longrightarrow \mathrm{WW}
$$

其余标记始终不受影响。因此，三步操作把由 n 枚白色标记组成的局面化为由 $n - 3$ 枚白色标记组成的同型局面。

由于 n−3 仍同余于 0 或 2 (mod 3)，反复使用上述三步缩减，最终归结到 $n = 2$ 或 $n = 3$ 的情形，从而能够只剩两枚标记。综上，最终能够只剩两枚标记，当且仅当 $3 \nmid n - 1$ 。

## USAMO 1994 P2

一个 99 边形的各边初始依次染成红、蓝、红、蓝、···、红、蓝、黄三色。现在进行一系列染色修改，每次只改变一条边的颜色，并始终要求任意两条相邻边的颜色不同。问：能否经过有限次修改，使各边依次染成红、蓝、红、蓝、红、蓝、···、红、黄、蓝？

解

答案是否定的。

方法一

规定三种颜色的大小关系为红 < 蓝 < 黄，并沿题面列举颜色的绕行方向依次把 99 条边的颜色记为 $c _ { 1 } , c _ { 2 } , \cdots , c _ { 9 9 }$ ，约定 $c _ { 1 0 0 } = c _ { 1 }$ 。若 $c _ { i } > c _ { i + 1 }$ ，则称有向相邻边对 $( c _ { i } , c _ { i + 1 } )$ 为一个环形相邻逆序对。令

$$
D = \left| \left\{i \in \{1, 2, \dots , 9 9 \}: c _ {i} > c _ {i + 1} \right\} \right|
$$

考虑一次实际改变第 i 条边颜 $\mathcal { \boxplus }$ 的合法操作，下标均按模 99 理解。若第 i 条边的两个邻色不同，则由于总共只有三种颜色，而 $c _ { i }$ 必须与两个邻色都不同， $c _ { i }$ 已经是唯一合法的颜色，不能再被改变。因此，任何实际可行的改色操作中，两个邻色必相同，设均为 $d _ { \mathfrak { c } }$ 

设改色前第 i 条边的颜色为 $x ,$ ，改色后为 $y$ 。在所有环形相邻边对中，只有 $( d , x ) , ( x , d )$ 被替换为 $( d , y ) , ( y , d )$ 。因为 $d \neq x ,$ ，前两个有向对中恰有一个是逆序对；同理，因为 $d \neq y$ 后两个有向对中也恰有一个是逆序对。因此，每次合法操作都保持 D 不变。这一论证也包含第 1 条边和第 99 条边附近的情形，因为相邻边对 $\left( { { c _ { 9 9 } } , { c _ { 1 } } } \right)$ 已经计入 $D$ 

初始染色为 (红,蓝)<sup>49</sup>,黄。其中有 48 个从蓝到红的相邻逆序对，并且首尾相接处的黄到红也是一个逆序对，故 $D _ { \dot { \mathcal { H } } } = 4 9$ 。目标染色为 (红,蓝)<sup>48</sup>,红,黄,蓝，其中有 48 个从蓝到红的相邻逆序对，此外黄到蓝以及首尾相接处的蓝到红各贡献一个逆序对，故 $D _ { \sharp } \sharp \sharp = 5 0$ 。两者不同，与 D 的不变性矛盾，所以目标染色不可能得到。

## 方法二

取题面列举各边颜色时所用的绕行方向，并规定颜色的循环方向为红 → 蓝 → 黄 → 红。对两种不同的颜色 X,Y，若 X → Y 顺着这个循环方向，则令 $\varepsilon ( X , Y ) = 1$ ；若逆着这个循环方向，则令 $\varepsilon ( X , Y ) = - 1$ 。依次记各边的颜色为 $c _ { 1 } , c _ { 2 } , \cdots , c _ { 9 9 }$ ，其中下标按模 99 计算，并定义有向相邻转移和

$$
I = \sum_ {i = 1} ^ {9 9} \varepsilon (c _ {i}, c _ {i + 1})
$$

考虑一次实际改变第 i 条边颜色的合法操作。若它的两条相邻边颜色不同，则由于合法染色中 c 与这两种颜色均不同，而总共只有三种颜色，所以 c 已经是唯一能够与两个邻色都 $c _ { i }$ $c _ { i }$ 不同的颜色，不可能再把它改成另一种合法颜色。因此，任何实际可行的改色操作中，第 i 条边的两个邻色必相同，设均为 $d _ { \mathfrak { c } }$ 。

改色前，和式中受影响的两项之和为

$$
\varepsilon (d, c _ {i}) + \varepsilon (c _ {i}, d) = 0
$$

改色后，设第 i 条边的新颜色为 $c _ { i } ^ { \prime }$ ，相应两项之和仍为

$$
\varepsilon (d, c _ {i} ^ {\prime}) + \varepsilon (c _ {i} ^ {\prime}, d) = 0
$$

故每次合法操作都保持 I 不变。

初始染色中，沿所定方向共有 49 次红 → 蓝、48 次蓝 → 红、1 次蓝 → 黄和 1 次黄 →红；目标染色中共有 48 次红 → 蓝、49 次蓝 → 红、1 次红 → 黄和 1 次黄 → 蓝。因此

$$
I _ {\text {初}} = 4 9 - 4 8 + 1 + 1 = 3, \qquad I _ {\text {目标}} = 4 8 - 4 9 - 1 - 1 = - 3
$$

初始状态与目标状态的有向相邻转移和不同，而这一整数在每次合法操作下保持不变，所以目标染色不可能得到。特别地，也可以把这个障碍写成模不变量：I 模 4 的余数保持不变，而初态和目标态分别同余于 3,1 (mod 4)。
