构造向量来建立不等式。

Russian Federal 1995 Grade 11 P5 

设实数角 $\alpha , \beta , \gamma$ 满足 $\sin \alpha + \sin \beta + \sin \gamma \geqslant 2$ 。证明 $\cos \alpha + \cos \beta + \cos \gamma \leqslant { \sqrt { 5 } }$ 0

## 解

记 $S = \sin \alpha + \sin \beta + \sin \gamma , \ C = \cos \alpha + \cos \beta + \cos \gamma$ ，并取平面向量 $\pmb { u } = ( \sin \alpha , \cos \alpha )$ $\pmb { v } = ( \sin \beta , \cos \beta ) , \ \pmb { w } = ( \sin \gamma , \cos \gamma )$ 。以 表示欧氏范数，这三个向量的范数都为 1，故由范数的三角不等式，

$$
\sqrt {S ^ {2} + C ^ {2}} = \| \boldsymbol {u} + \boldsymbol {v} + \boldsymbol {w} \| \leqslant \| \boldsymbol {u} \| + \| \boldsymbol {v} \| + \| \boldsymbol {w} \| = 3
$$

题设给出 $S \geqslant 2$ ，于是 $C ^ { 2 } \leqslant 9 - S ^ { 2 } \leqslant 5$ ，从而 $C \leqslant { \sqrt { 5 } }$ 。

Romania TST 2007 P23 

设实数 $a _ { 1 } , \cdots , a _ { n } , b _ { 1 } , \cdots , b _ { n }$ 满足 $\begin{array} { r } { \sum a _ { k } ^ { 2 } = \sum b _ { k } ^ { 2 } = 1 , \ \sum a _ { k } b _ { k } = 0 , } \end{array}$ 。证明

$$
\left(\sum_ {k = 1} ^ {n} a _ {k}\right) ^ {2} + \left(\sum_ {k = 1} ^ {n} b _ {k}\right) ^ {2} \leqslant n
$$

解

设 a,b 为题中两个单位正交向量， $c = ( 1 , \cdot \cdot \cdot , 1 ) , \ A = c \cdot a , B = c \cdot b .$ 。则 $c - A a - B b$ 与a,b 都正交，故 $n = \| c \| ^ { 2 } = A ^ { 2 } + B ^ { 2 } + \| c - A a - B b \| ^ { 2 } \geqslant A ^ { 2 } + B ^ { 2 }$ o

设实数 $x _ { 1 } , x _ { 2 } , \cdots , x _ { 1 9 8 1 }$ 和 $y _ { 1 } , y _ { 2 } , \cdots , y _ { 1 9 8 1 }$ 满足 $\textstyle \sum _ { j = 1 } ^ { 1 9 8 1 } x _ { j } = \sum _ { j = 1 } ^ { 1 9 8 1 } y _ { j } = 0$ 。证明

$$
\sqrt {\sum_ {j = 1} ^ {1 9 8 1} \left(x _ {j} ^ {2} + y _ {j} ^ {2}\right)} \leqslant \frac {1}{\sqrt {2}} \sum_ {j = 1} ^ {1 9 8 1} \sqrt {x _ {j} ^ {2} + y _ {j} ^ {2}}
$$

解

令平面向量 $\pmb { u } _ { j } = ( x _ { j } , y _ { j } )$ ，以    表示欧氏范数，并记 $\begin{array} { r } { l _ { j } = \| \boldsymbol { * } _ { j } \| , ~ L = \sum _ { j = 1 } ^ { 1 9 8 1 } l _ { j } } \end{array}$ 。由题设，$\textstyle \sum _ { j = 1 } ^ { 1 9 8 1 } u _ { j } = { \mathbf { 0 } }$ ，故对每个 j，由范数的三角不等式，

$$
l _ {j} = \left\| \sum_ {i \neq j} \boldsymbol {u} _ {i} \right\| \leqslant \sum_ {i \neq j} l _ {i} = L - l _ {j}
$$

因此 $l _ { j } \leqslant L / 2$ 。于是

$$
\sum_ {j = 1} ^ {1 9 8 1} \left(x _ {j} ^ {2} + y _ {j} ^ {2}\right) = \sum_ {j = 1} ^ {1 9 8 1} l _ {j} ^ {2} \leqslant \frac {L}{2} \sum_ {j = 1} ^ {1 9 8 1} l _ {j} = \frac {L ^ {2}}{2}
$$

两边开平方即得所需不等式；这个证明也包括 $L = 0$ 的情形。

IMOSL 1997 Q19 

设 n 为正整数。设实数 $a _ { 1 } , a _ { 2 } , \cdots , a _ { n } , a _ { n + 1 }$ 满足 $a _ { 1 } \geqslant a _ { 2 } \geqslant \dots \geqslant a _ { n } \geqslant a _ { n + 1 } = 0$ 。证明

$$
\sqrt {\sum_ {k = 1} ^ {n} a _ {k}} \leqslant \sum_ {k = 1} ^ {n} \sqrt {k} \left(\sqrt {a _ {k}} - \sqrt {a _ {k + 1}}\right)
$$

解

各个 $a _ { k }$ 均非负。令 $x _ { k } = { \sqrt { a _ { k } } } - { \sqrt { a _ { k + 1 } } } \geqslant 0 \ ( 1 \leqslant k \leqslant n )$ ，则 $\textstyle { \sqrt { a _ { j } } } = \sum _ { k = j } ^ { n } x _ { k }$ 。在 R<sup>n</sup> 中记 $\| \cdot \| _ { 2 }$ 为欧氏范数，并令 $e ^ { ( k ) }$ 的前 k 个坐标为 1，其余坐标为 0。于是 $\| e ^ { ( k ) } \| _ { 2 } = { \sqrt { k } }$ ，且

$$
\left(\sqrt {a _ {1}}, \sqrt {a _ {2}}, \dots , \sqrt {a _ {n}}\right) = \sum_ {k = 1} ^ {n} x _ {k} e ^ {(k)}
$$

对这个向量和应用欧氏范数的三角不等式，即 Minkowski 不等式，得到

$$
\sqrt {\sum_ {k = 1} ^ {n} a _ {k}} = \left\| \sum_ {k = 1} ^ {n} x _ {k} e ^ {(k)} \right\| _ {2} \leqslant \sum_ {k = 1} ^ {n} x _ {k} \| e ^ {(k)} \| _ {2} = \sum_ {k = 1} ^ {n} \sqrt {k} (\sqrt {a _ {k}} - \sqrt {a _ {k + 1}})
$$

所求不等式得证。

设 n 为正整数，实数 $x _ { 1 } \geqslant x _ { 2 } \geqslant \dots \geqslant x _ { n } \geqslant 0$ 满足

$$
\sum_ {j = 1} ^ {n} \frac {x _ {j}}{\sqrt {j}} = 1
$$

证明 $x _ { 1 } ^ { 2 } + x _ { 2 } ^ { 2 } + \cdot \cdot \cdot + x _ { n } ^ { 2 } \leqslant 1$ 0

解

令 $x _ { n + 1 } = 0$ ，并记 $\delta _ { k } = x _ { k } - x _ { k + 1 } \geqslant 0$ 。在 R<sup>n</sup> 中，令向量 ${ \pmb v } _ { k }$ 的前 k 个坐标为 1，其余坐标为 0，以 表示欧氏范数。则 $\lVert \pmb { v } _ { k } \rVert = { \sqrt { k } }$ ，且 $\begin{array} { r } { { \pmb x } = ( x _ { 1 } , x _ { 2 } , \cdots , x _ { n } ) = \sum _ { k = 1 } ^ { n } \delta _ { k } { \pmb v } _ { k } } \end{array}$ ，因为其第 j 个坐标为 $\textstyle \sum _ { k = j } ^ { n } \delta _ { k } = x _ { j }$ o

对每个 k，由 $j \leqslant k$ 时 $1 / \sqrt { j } \geq 1 / \sqrt { k }$ ，得 $\textstyle \sum _ { j = 1 } ^ { k } ( 1 / { \sqrt { j } } ) \geq { \sqrt { k } }$ 。由范数的三角不等式，再交换有限求和的次序，得到

$$
\| \boldsymbol {x} \| \leqslant \sum_ {k = 1} ^ {n} \delta_ {k} \| \boldsymbol {v} _ {k} \| = \sum_ {k = 1} ^ {n} \delta_ {k} \sqrt {k}
$$

$$
\leqslant \sum_ {k = 1} ^ {n} \delta_ {k} \sum_ {j = 1} ^ {k} \frac {1}{\sqrt {j}} = \sum_ {j = 1} ^ {n} \frac {1}{\sqrt {j}} \sum_ {k = j} ^ {n} \delta_ {k} = \sum_ {j = 1} ^ {n} \frac {x _ {j}}{\sqrt {j}} = 1
$$

两边平方，即得 $x _ { 1 } ^ { 2 } + x _ { 2 } ^ { 2 } + \cdot \cdot \cdot + x _ { n } ^ { 2 } = \| { \pmb x } \| ^ { 2 } \leqslant 1$ 。

设 n 为正整数， $a _ { i } \geqslant 0 , \ x _ { i } \in \mathbb { R }$ ，其中 $i = 1 , 2 , \cdots , n .$ 。证明：

$$
\left[ \left(1 - \sum_ {i = 1} ^ {n} a _ {i} \cos x _ {i}\right) ^ {2} + \left(1 - \sum_ {i = 1} ^ {n} a _ {i} \sin x _ {i}\right) ^ {2} \right] ^ {2} \geqslant 4 \left(1 - \sum_ {i = 1} ^ {n} a _ {i}\right) ^ {3}
$$

解

记 $\textstyle r = \sum _ { i = 1 } ^ { n } a _ { i }$ 。若 $r \geqslant 1$ ，右端非正，结论显然成立。以下设 $0 \leqslant r < 1$ ，用 $\| \cdot \|$ 表示二维向量的欧氏范数。令 $u = ( 1 , 1 ) \cdot v _ { i } = ( a _ { i } \cos x _ { i } , a _ { i } \sin x _ { i } )$ ，则 $\| u \| = \sqrt { 2 } , \ \| v _ { i } \| = a _ { i }$ 。由范数的逆三角不等式，

$$
\left\| u - \sum_ {i = 1} ^ {n} v _ {i} \right\| \geqslant \| u \| - \left\| \sum_ {i = 1} ^ {n} v _ {i} \right\| \geqslant \sqrt {2} - \sum_ {i = 1} ^ {n} \| v _ {i} \| = \sqrt {2} - r > 0
$$

原式左端为 $\begin{array} { r } { \left\| u - \sum _ { i = 1 } ^ { n } v _ { i } \right\| ^ { 4 } } \end{array}$ ，因此只需证明 $( \sqrt 2 - r ) ^ { 4 } \geqslant 4 ( 1 - r ) ^ { 3 }$ C

设 $f ( r ) = r ^ { 3 } - 4 ( \sqrt { 2 } - 1 ) r ^ { 2 } + 1 2 - 8 \sqrt { 2 }$ ，直接展开得

$$
(\sqrt {2} - r) ^ {4} - 4 (1 - r) ^ {3} = r f (r)
$$

因 $3 < 8 ( \sqrt { 2 } - 1 )$ ，在 [0, 1] 上有 $f ^ { \prime } ( r ) = r [ 3 r - 8 ( \sqrt { 2 } - 1 ) ] \leqslant 0 .$ 。所以 $f ( r ) \geqslant f ( 1 ) = 1 7 - 1 2 { \sqrt { 2 } } =$ $( { \sqrt { 2 } } - 1 ) ^ { 4 } > 0$ ，从而 $r f ( r ) \geqslant 0$ ，原不等式成立。
