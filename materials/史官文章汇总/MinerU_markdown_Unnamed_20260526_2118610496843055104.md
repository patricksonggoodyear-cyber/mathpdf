(a) 令 $x = y = 1$ ，得到 $f ( 1 ) = 0$ 。对任意正有理数 x，由 $f ( x ) + f ( x ^ { - 1 } ) = f ( 1 )$ 得$f ( x ^ { - 1 } ) = - f ( x )$ ，再结合数学归纳法可知，对任意整数 n 都有

$$

$$

$$
f (p ^ {b}) = b f (p) = \frac {a b}{c} = a f (q) = f (q ^ {a})
$$

由单射性应有 $p ^ { b } = q ^ { a }$ ，但这与正有理数质因数分解的唯一性矛盾。因此，不存在具有性质 P的单射。

(b) 存在。对任意正有理数 x，由质因数分解的唯一性可写成

$$
x = \prod_ {p \mathrm{为质数}} p ^ {\nu_ {p} (x)}
$$

其中各指数均为整数，且只有有限多个指数非零。定义

$$

$$

上式实际为有限和，故 $f ( x ) \in \mathbb { Q }$ 。又因为 $\nu _ { p } ( x y ) = \nu _ { p } ( x ) + \nu _ { p } ( y )$ ，所以

$$
f (x y) = \sum_ {p \text {为质数}} \frac {\nu_ {p} (x) + \nu_ {p} (y)}{p !} = f (x) + f (y)
$$

$$

因此 f 为满射。
