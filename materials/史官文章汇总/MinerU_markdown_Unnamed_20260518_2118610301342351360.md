求所有的函数 $f : \mathbb { R } _ { + } \to \mathbb { R } _ { + }$ 满足对任意正实数 x,y 均有

$$
f (x f (y)) = y f (x)
$$

并且函数 f 在正无穷处的极限为 0。

解

记题设等式为 $P ( x , y )$ ，并令 $c = f ( 1 ) > 0$ 。由 $P ( 1 , 1 )$ 得 $f ( c ) = c ,$ ，由 $P ( 1 , c )$ 得 $f ( f ( c ) ) =$ $c ^ { 2 } 。$ 。另一方面， $f ( c ) = c$ 给出 $f ( f ( c ) ) = f ( c ) = c ,$ ，所以 $c ^ { 2 } = c _ { \circ }$ 由 $c > 0$ 可知 $c = 1$ ，即$f ( 1 ) = 1$ o

设 $a > 0$ 是 f 的一个不动点，即 $f ( a ) = a$ 。由 $P ( x , a )$ 得 $f ( a x ) = a f ( x )$ 。若 $a > 1$ ，从$f ( 1 ) = 1$ 出发反复应用这个等式，便有 $f ( a ^ { n } ) = a ^ { n }$ 对所有正整数 n 成立；但 $a ^ { n } \to + \infty$ ，这与 f 在正无穷处的极限为 0 矛盾。若 $0 \textless a \textless 1$ ，在 $f ( a x ) = a f ( x )$ 中取 $x = 1 / a$ ，得到$f ( 1 / a ) = 1 / a$ ，于是 $1 / a > 1$ 也是不动点，同样矛盾。因此 f 的唯一不动点是 1。

最后，由 $P ( x , x )$ 可得 $f ( x f ( x ) ) = x f ( x )$ ，所以 $x f ( x )$ 是 f 的不动点。由不动点的唯一性， $x f ( x ) = 1$ ，故 $f ( x ) = 1 / x .$ 。反之，直接代入可知 $f ( x ) = 1 / x$ 满足题设函数方程，且在正无穷处的极限为 0，因此它是唯一解。

IMO 1994 P5 

求所有的函数 $f : ( - 1 , + \infty ) \to ( - 1 , + \infty )$ ，满足对任意 $x , y > - 1$ 均有

$$
f (x + f (y) + x f (y)) = y + f (x) + y f (x)
$$

同时 $f ( x ) / x$ 在区间 (−1, 0) 和区间 $( 0 , + \infty )$ 上分别严格递增。

解

答案为

$$
f (x) = - \frac {x}{x + 1}
$$

先研究 f 的不动点。把原方程记为 $P ( x , y )$ 。令 $y = x$ ，由 $P ( x , x )$ 得

$$
f (x + f (x) + x f (x)) = x + f (x) + x f (x)
$$

因此，对每个 $x > - 1$ ，数 $x + f ( x ) + x f ( x )$ 都是 f 的不动点。

下面证明 f 的不动点只能是 0。设 $t > - 1$ 且 $f ( t ) = t _ { \mathsf { c } }$ 。再次使用 $P ( t , t )$ 可知 $t ^ { 2 } + 2 t$ 也是不动点。若 $t > 0$ ，则 $t ^ { 2 } + 2 t > t > 0$ ，而

$$
{\frac {f (t)}{t}} = 1 = {\frac {f (t ^ {2} + 2 t)}{t ^ {2} + 2 t}}
$$

这与 $f ( x ) / x$ 在 (0, +∞) 上严格递增矛盾。若 $- 1 < t < 0$ ，则

$$
- 1 <   t ^ {2} + 2 t <   t <   0
$$

同样由两个不动点处的函数值之比均为 1，与 $f ( x ) / x$ 在 (−1,0) 上严格递增矛盾。因此 $t = 0$ 。

于是前面构造出的不动点必为 0，即对任意 $x > - 1$ 都有

$$
x + f (x) + x f (x) = 0
$$

解得 $f ( x ) = - x / ( x + 1 )$ 

最后验证所得函数。它满足 $f ( x ) + 1 = 1 / ( x + 1 ) > 0$ ，故确实把 $( - 1 , + \infty )$ 映入自身。并且

$$
1 + x + f (y) + x f (y) = \frac {x + 1}{y + 1} > 0
$$

故原方程左端的自变量仍在定义域内。又有

$$
f (x + f (y) + x f (y)) = \frac {y - x}{x + 1} = y + f (x) + y f (x)
$$

并且 $f ( x ) / x = - 1 / ( x + 1 )$ 在 (−1, 0) 和 $( 0 , + \infty )$ 上均严格递增。因此该函数满足全部条件。

IMO 1996 P3 

设 $\mathbb { Z } _ { \geqslant 0 }$ 为非负整数集。求所有函数 $f : \mathbb { Z } _ { \geq 0 } \to \mathbb { Z } _ { \geq 0 }$ ，使得对任意 $m , n \in \mathbb { Z } _ { \geq 0 }$ 均有

$$
f (m + f (n)) = f (f (m)) + f (n)
$$

解

全部解如下：

(1) 零函数 $f ( n ) = 0$ 

(2) 任取正整数 k 和非负整数 $a _ { 1 } , a _ { 2 } , \cdots , a _ { k - 1 }$ ，并令 $a _ { 0 } = 0$ 。将任意非负整数 n 唯一写成 $n = q k + r$ ，其中 $q \in \mathbb { Z } _ { \geqslant 0 }$ 且 $0 \leqslant r < k$ ，定义

$$
f (n) = (q + a _ {r}) k
$$

下证这些就是全部解。记题设等式为 $P ( m , n )$ 。由 $P ( 0 , 0 )$ 得

$$
f (f (0)) = f (f (0)) + f (0)
$$

故 $f ( 0 ) = 0$ 。再由 $P ( 0 , n )$ 得 $f ( f ( n ) ) = f ( n )$ 。因此原方程可以改写为

$$
f (m + f (n)) = f (m) + f (n)
$$

特别地，每个函数值 f(n) 都是 f 的不动点。

若 f 没有正不动点，则每个 f(n) 只能等于 0，故得到解 (1)。以下设 f 有正不动点，并令 k 为最小的正不动点。由 $f ( k ) = k$ 及上式归纳可得，对任意 $q \in \mathbb { Z } _ { \geqslant 0 }$ 均有 $f ( q k ) = q k$ 0

任取不动点 x，作带余除法 $x = q k + r$ ，其中 $q \in \mathbb { Z } _ { \geqslant 0 }$ 且 $0 \leqslant r < k$ 。于是

$$
q k + r = f (x) = f (r + f (q k)) = f (r) + f (q k) = f (r) + q k
$$

从而 $f ( r ) = r$ 。若 $r > 0$ ，则 r 是小于 k 的正不动点，与 k 的选取矛盾，故 $r = 0$ 。所以 f 的不动点恰为 k 的非负整数倍。

对任意 $n = q k + r$ ，有

$$
f (n) = f (r + f (q k)) = f (r) + q k
$$

而 $f ( r )$ 本身是不动点，故存在非负整数 $a _ { r }$ 使得 $f ( r ) = a _ { r } k$ 。又因 $f ( 0 ) = 0$ ，有 $a _ { 0 } = 0$ 。因此

$$
f (q k + r) = (q + a _ {r}) k
$$

这正是 (2) 中的函数。

最后验证。解 (1) 显然满足原方程。对于 (2)，设 $m = q k + r , n = t k + s$ ，其中 $q , t \in \mathbb { Z } _ { \geq 0 }$ 且 $0 \leqslant r , s < k$ ，则

$$
f (m) = (q + a _ {r}) k, \quad f (n) = (t + a _ {s}) k
$$

因此 $f ( f ( m ) ) = f ( m )$ ，并且

$$
f (m + f (n)) = (q + t + a _ {r} + a _ {s}) k = f (f (m)) + f (n)
$$

故上述函数全部满足题设。

求所有的函数 f : R → R，使得对任意实数 $x , y$ ，均有

$$
f (x + f (x + y)) + f (x y) = x + f (x + y) + y f (x)
$$

解

记原方程的等式为 $P ( x , y )$ ，考虑 $P ( x , 1 )$ 

$$
f (x + f (x + 1)) = x + f (x + 1)\tag{1}
$$

说明 $B = \{ x + f ( x + 1 ) \mid x \in \mathbb { R } \} \neq \emptyset$ 中的元素全是 f 的不动点。

考虑 $P ( 0 , y )$ ，其中 $y \in B$ 

$$
[ y - 1 ] f (0) = 0
$$

若 $f ( 0 ) \neq 0$ ，则推出 $B = \{ 1 \}$ ，即 $f ( x ) = 2 - x$ ，经检验这是原方程的解。

若 $f ( 0 ) = 0 { \mathrm { { c } } }$ 。考虑 $P ( x , 0 )$ ：

$$
f (x + f (x)) = x + f (x)\tag{2}
$$

考虑 $P ( 1 , y )$ 

$$
f (1 + f (1 + y)) + f (y) = 1 + f (1 + y) + y f (1)
$$

下面我们证明 $f ( 1 ) = 1$ 。利用 $f ( 0 ) = 0$ ，赋值 $P ( - 1 , 1 )$ 得到 $f ( - 1 ) = - 1$ ，再赋值 $P ( 1 , - 1 )$ 得到 $f ( 1 ) = 1$ 。由此上式变为

$$
f (1 + f (1 + y)) + f (y) = 1 + f (1 + y) + y\tag{3}
$$

记 F 是 f 全部不动点所构成的集合，则式子 (3) 表明，如果 $y _ { 0 } \in F$ 且 $y _ { 0 } + 1 \in F$ ，那么$y _ { 0 } + 2 \in F _ { \mathrm { { \ell } } }$ 。在式子 (1) 中把 x 换成 x−1，可知 $x - 1 + f ( x ) \in F ;$ ；式子 (2) 又给出 $x + f ( x ) \in F$ 。应用上述传播性质，得到 $x + 1 + f ( x ) \in F _ { \mathrm { ~ c ~ } }$ 。再把 x 换成 $x - 1$ ，可知

$$
x + f (x - 1) \in F\tag{4}
$$

结合式子 (4) 考虑 $P ( x , - 1 )$ 

$$
f (x + f (x - 1)) + f (- x) = x + f (x - 1) - f (x) \implies f (x) + f (- x) = 0
$$

即 f 是奇函数。考虑 $P ( - x , - y )$ 并与原式对比

$$
\begin{array}{c} f (x + f (x + y)) + f (x y) = x + f (x + y) + y f (x) \\ - f (x + f (x + y)) + f (x y) = - x - f (x + y) + y f (x) \end{array}
$$

得到 $f ( x y ) = y f ( x )$ ，所以 $f ( x ) = x f ( 1 ) = x .$ o

求所有的函数 $f : \mathbb { R } _ { + } \to \mathbb { R } _ { + }$ ，使得对任意正实数 $x , y$ ，均有

$$
f (x + f (x) + f (y)) = 2 f (x) + y\tag{1}
$$

解

唯一的解是 $f ( x ) = x$ 。

记原命题为 $P ( x , y )$ 。由 $P ( x , x )$ 得

$$
f (x + 2 f (x)) = x + 2 f (x)
$$

$t = x + 2 f ( x )$ ，则 $f ( t ) = t .$ 。在 $P ( x , y )$ 中以刚得到的不动点 t 代替 y，可得

$$
f (2 x + 3 f (x)) = x + 4 f (x)
$$

再令 $u = 2 x + 3 f ( x )$ ，并把这个新产生的嵌套自变量代回 $P ( x , y )$ ，由上式得到

$$
\begin{array}{r l} f (2 x + 5 f (x)) & = f (x + f (x) + f (u)) \\ & = 2 f (x) + u = 2 x + 5 f (x) \end{array}
$$

另一方面，把最初得到的不动点 t 作为第一个变量，由 $P ( t , x )$ 得

$$
f (2 x + 5 f (x)) = f (t + f (t) + f (x)) = 2 f (t) + x = 3 x + 4 f (x)
$$

比较关于同一函数值 $f ( 2 x + 5 f ( x ) )$ 的两种计算结果，得到 $f ( x ) = x _ { \circ }$ 直接代入可知它确为解。

称函数 $f : \mathbb { Q } \to \mathbb { Q }$ 是神奇的，如果对任意有理数 $x , y ;$ ，均有等式

$$
f (x + f (y)) = f (x) + y \quad {\text {与}} \quad f (f (x) + y) = x + f (y)
$$

至少有一个成立。

求证：存在整数 c，使得对任意神奇函数 f，至多存在 c 个两两不同的有理数可以表示为$f ( r ) + f ( - r )$ 的形式，其中 r 是有理数。并求出满足要求的最小整数 $c _ { \circ }$ 

解

对任意 $t \in \mathbb { Q }$ ，在题设中取 $x = y = t$ ，两种等式此时相同，故

$$
f (t + f (t)) = t + f (t)
$$

称满足 $f ( a ) = a$ 的数 a 为不动点。上式说明 $t + f ( t )$ 总是不动点。若 $a , b$ 都是不动点，在题设中取 $x = a , y = b$ ，两种等式也都成为 $f ( a + b ) = a + b ;$ ，故不动点之和仍是不动点。

令 $a = f ( 0 )$ ，则 a 与 2a 都是不动点。在题设中取 $x = a , y = 0$ ，可得 $f ( 2 a ) = a$ 或$f ( a ) = 2 a ;$ ；结合 $f ( a ) = a \cdot \ f ( 2 a ) = 2 a$ ，得 $a = 0$ ，即 $f ( 0 ) = 0$ 。若 $f ( t ) = 0$ ，则 $t = t + f ( t )$ 是不动点，从而 $t = f ( t ) = 0 ,$ 。所以 0 是 f 的唯一零点。

再在题设中取 $x = - f ( t ) , y = t .$ 。第一种等式直接给出 $f ( - f ( t ) ) + t = 0$ ；第二种等式给出 $f ( f ( - f ( t ) ) + t ) = 0$ ，由零点唯一性也得到同一结论。因此

$$
f (- f (t)) = - t \quad (t \in \mathbb {Q})
$$

这说明 f 为单射；又对任意 t 都有 $t = f ( - f ( - t ) )$ ，故 f 也满射。

现证明不动点具有平移性质。若 a 是不动点，在题设中取 $x = a - f ( y )$ ，则 $x + f ( y ) =$ a，而另一侧为 $f ( a - f ( y ) ) + y$ 。第一种等式给出 $a = f ( a - f ( y ) ) + y ;$ 第二种等式给出$f ( f ( a - f ( y ) ) + y ) = a = f ( a )$ ，由单射性仍有 $a = f ( a - f ( y ) ) + y ,$ 。于是

$$
f (a - f (y)) = a - y
$$

将 $y = - f ( x )$ 代入，并利用 $f ( - f ( x ) ) = - x$ ，得到

$$
f (a + x) = a + f (x) \quad (a \text {为不动点,} x \in \mathbb {Q})
$$

由于 $y + f ( y )  x + f ( x )$ 都是不动点，分别对题设两种等式使用上述平移性质，可将题设改写为：对任意 $x , y \in \mathbb { Q }$ ，下列两式至少有一个成立：

$$
f (x - y) = f (x) - f (y) \qquad {\text {或}} \qquad f (y - x) = f (y) - f (x)
$$

把其中的 x 换成 $x + y$ ，便得到

$$
f (x + y) = f (x) + f (y) \qquad {\text {或}} \qquad f (x + y) = f (y) - f (- x)
$$

记 $g ( x ) = f ( x ) + f ( - x )$ ，则 $g ( - x ) = g ( x )$ 。若 $f ( x + y ) \neq f ( x ) + f ( y )$ ，将后一析取关系分别用于 $( x , y )$ 与 $( y , x )$ ，得到

$$
f (x + y) = f (y) - f (- x) = f (x) - f (- y)
$$

所以 $g ( x ) = g ( y )$ 。反过来说，若 $g ( x ) \neq g ( y )$ ，则 f 在 $( x , y )$ 与 $( - x , - y )$ 上都满足加法式，进而 $g ( x + y ) = g ( x ) + g ( y )$ 。于是对所有 $x , y \in \mathbb { Q }$ 都有

$$
g (x) = g (y) \qquad {\text {或}} \qquad g (x + y) = g (x) + g (y)
$$

假设 g 有两个不同的非零值，取 $u , v$ 使 $\alpha = g ( u ) \neq 0 , \ \beta = g ( v ) \neq 0$ 且 $\alpha \neq \beta _ { \sf c }$ 。上式给出$g ( u + v ) = \alpha + \beta$ 。因为 $\beta \neq 0$ ，有 $g ( u + v ) \neq \alpha = g ( - u )$ ；再次把上式用于 $u + v$ 与 $- u ,$ ，得到

$$
\beta = g (v) = g (u + v) + g (- u) = \beta + 2 \alpha
$$

矛盾。所以 g 的所有非零值都相同，其值域至多有两个元素。

最后说明两个值能够取到。对有理数 x 定义 $f ( x ) = 2 \lfloor x \rfloor - x .$ 。写 $x = m + s , y = n + t$ 其中 $m , n \in \mathbb { Z }$ 且 $0 \leqslant s , t < 1$ ，并记 $k = m + n$ 。此时

$$
f (x) + y = k + t - s, \qquad x + f (y) = k + s - t
$$

$$
