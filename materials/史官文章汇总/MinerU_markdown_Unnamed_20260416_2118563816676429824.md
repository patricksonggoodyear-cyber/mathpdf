Saint Petersburg MO 2019 Grade 9 P5 

如果把一个正数替换为 2 的某个非负整数次幂 (诸如 1,2,4,8,···)，使得它增大，但不超过原数的 3 倍，称为对该数的“改善”。给定 $2 ^ { 1 0 0 }$ 个正数，其和为 $2 ^ { 1 0 0 }$ 。证明：可以擦去其中一些数，并“改善”剩下的每个数，使所得数的和仍然为 $2 ^ { 1 0 0 }$ 。

## 解

令 $M = 2 ^ { 1 0 0 }$ 。先证明一个引理。

引理：若若干不超过 M 的 2 的非负整数次幂的总和至少为 M，则其中一部分的和恰为M。

引理证明：若已有一项为 M，结论显然。否则，反复把两个相同的数合并为其两倍，并记录每个合并项来自哪些原项。每次合并保持总和不变并减少项数。若出现 M，它对应的原项即为所求；若始终未出现 M，最终各项是彼此不同且小于 M 的 2 的幂，总和至多为$1 + 2 + \cdot \cdot \cdot + 2 ^ { 9 9 } = M - 1$ ，矛盾。

删去所有小于 1/3 的数。原数共有 M 个，删去项的总和小于 $M / 3$ ，故剩余项之和大于$2 M / 3$ 。若某个剩余数 $x > M / 3$ ，由原数皆为正知 $x < M$ ，直接把它改善为 M，并删去其余数即可。

以下设每个剩余数 $x \in [ 1 / 3 , M / 3 ]$ 。取不超过 3x 的最大的 2 的非负整数次幂 y。由$y \leqslant 3 x < 2 y$ ，有 $y > 3 x / 2 > x \qquad $ ，且 $y \leqslant M$ ，所以这是合法改善。所有改善值的总和大于$( 3 / 2 ) ( 2 M / 3 ) = M \mathfrak { c }$ 。应用引理，从中选出和为 M 的一部分，保留对应原数并删去其余原数，就得到要求的结果。

CTST 2019 P22 

对非空有限数集 X，记 $S ( X )$ 为 X 中所有元素之和。设整数 $n \geqslant 2 .$ ，求证：存在集合$\{ 1 , 2 , 3 , \cdots , 2 ^ { n } \}$ 的n元子集T，满足对T 的任意两个不同的非空子集A,B，均有 $S ( A ) \nmid S ( B )$ 

## 解

取 $T = \{ 2 ^ { n } - 2 ^ { i } : 0 \leqslant i < n \}$ ，其元素互不相同且都属于 $\{ 1 , 2 , \cdots , 2 ^ { n } \}$ ，故 $T$ 是题述范围内的 n 元集合。

反设存在不同的非空子集 $A , B \subseteq T$ ，以及正整数 k，使 $S ( B ) = k S ( A )$ 。设 A,B 对应的指数集合分别为 $I , J \subseteq \{ 0 , 1 , \cdots , n - 1 \}$ ，即 $A = \{ 2 ^ { n } - 2 ^ { i } : i \in I \} \setminus B = \{ 2 ^ { n } - 2 ^ { j } : j \in J \}$ 。令$\begin{array} { r } { p = | I | \cdot \ q = | J | \cdot \ P = \sum _ { i \in I } 2 ^ { i } \cdot \ Q = \sum _ { j \in J } 2 ^ { j } } \end{array}$ ，则 $0 < P , Q < 2 ^ { n }$ ，且 $( k p - q ) 2 ^ { n } = k P - Q \circ$ 若 $k = 1$ ，右边的绝对值小于 $2 ^ { n }$ ，故 $p = q , \ P = Q$ ；由二进制表示的唯一性可得 $I = J$ ，进而 $A = B$ ，矛盾。因此 $k \geqslant$ 2。

将上述等式改写为

$$
q 2 ^ {n} + k \sum_ {i \in I} 2 ^ {i} = k p 2 ^ {n} + \sum_ {j \in J} 2 ^ {j}
$$

在黑板上写下左边的各项，即 $q$ 个 $2 ^ { n }$ ，以及每个 $2 ^ { i } \ ( i \in I )$ 各 k 个，最初共有 $q + k p$ 项。只要存在两个相同且小于 $2 ^ { n }$ 的二的幂 $2 ^ { s }$ ，就将它们合并为一个 $2 ^ { s + 1 }$ 。每次操作保持数值总和不变，并使项数减少 1。由于 $k \geqslant$ 2 且 I 非空，至少能操作一次；项数不断减少，故有限次操作后，所有小于 $2 ^ { n }$ 的幂均不重复。

最终形式为若干个 $2 ^ { n }$ ，以及互不相同且小于 $2 ^ { n }$ 的二的幂。这些小幂的总和至多为 $1 +$ $2 + \cdot \cdot \cdot + 2 ^ { n - 1 } = 2 ^ { n } - 1$ ，严格小于 $2 ^ { n }$ 。由除以 $2 ^ { n }$ 的商、余数的唯一性，上述等式强制最终恰有 $k p$ 个 $2 ^ { n }$ ，且小幂之和恰为 $Q { \mathrm { : } }$ ；再由二进制表示的唯一性，小幂必须是 $2 ^ { j } \ ( j \in J )$ 各一个。因此最终项数仍为 $k p + q$ ，与至少一次合并使项数严格减少矛盾。所构造的 T 满足要求。

## IMO 2014 P5

对于每个正整数 n，开普敦银行发行面值为 $1 / n$ 的硬币。给定这样一些硬币 (不一定面值不同) 的有限集合，总价值至多为 $9 9 + 1 / 2$ ，求证：可以将这个集合分成 100 个或更少的组，使得每组的总价值至多为 1。

## 解

证明一般结论：对任意正整数 N，总价值不超过 $N - 1 / 2$ 的有限批硬币，都能分成至多N 组，使每组总价值不超过 1。

先反复进行两种合并：把两枚面值为 $1 / ( 2 t )$ 的硬币合并成一枚面值为 $1 / t$ 的硬币；把 $q$ 枚面值为 $1 / q$ 的硬币合并成一枚面值为 1 的硬币，其中 $q > 1$ 为奇数。每次合并都保持总价值不变，并严格减少硬币枚数，故有限步后停止。此时每个偶数分母至多对应一枚硬币，每个奇数分母 $q > 1$ 至多对应 $q - 1$ 枚硬币。把面值为 的硬币各自成组并移去，每移去一枚就把$N$ 减少 1。余下硬币的总价值仍不超过 $N - 1 / 2$ ，且 $N \geqslant 1$ ；继续用 N 表示余下需要的组数。

预先设置 N 个组 $B _ { 1 } , B _ { 3 } , \cdot \cdot \cdot , B _ { 2 N - 1 } { \circ }$ 把分母不超过 2N 的硬币按分母的最大奇数约数分组：若面值为 $1 / ( q 2 ^ { s } )$ ，其中 $q$ 为奇数、 $s \geqslant 0$ ，就放入 $B _ { q }$ 。这里 $q \leqslant 2 N - 1$ ，所以每枚这样的硬币都有对应的组。对固定的 $q ,$ ，面值为 $1 / q$ 的硬币至多有 $q - 1$ 枚 (当 $q = 1$ 时已经全部移去)，而每个面值 $1 / ( q 2 ^ { s } ) , ~ s \geqslant 1$ 至多有一枚。由于只涉及有限多个尺度， $B _ { q }$ 的总价值 $W _ { q }$ 

满足

$$
W _ {q} <   \frac {q - 1}{q} + \frac {1}{q} \sum_ {s = 1} ^ {\infty} 2 ^ {- s} = 1
$$

所以这些大面值硬币已经放入各组，并且每组总价值都小于 1。

余下每枚硬币的分母大于 2N，面值小于 $1 / ( 2 N )$ 。逐枚把它们放入各组：在任意一步，各组中已有硬币的总价值不超过 $N - 1 / 2$ ，所以至少有一组的当前总价值不超过 $1 - 1 / ( 2 N )$ 。该组的空余额度至少为 $1 / ( 2 N )$ ，足以容纳下一枚硬币。因此所有余下硬币都能放完。

最后把此前的合并逐次拆回原硬币，每组总价值不变，再加上移去的单独成组的面值为1 的硬币，组数不超过最初的 N。取最初的 $N = 1 0 0$ ，即得题设结论。

## CTST 2005 P20

给定整数 $n \geqslant 2 { \mathrm { . } }$ 。求最大的 λ，使得若有 n 个袋子，每一个袋子中都是一些质量为 2 的整数次幂克的小球，且各个袋子中的小球的总质量都相等，则必有某一质量的小球的总个数至少为 λ(同一个袋子中可以有相等质量的小球)。

## 解

答案为 $\lambda = \lfloor n / 2 \rfloor + 1$ 。

先证明下界。将所有小球的质量同时除以最重小球的质量，不妨设最重小球的质量为 1。设每个袋子中小球的总质量为 G，则 $G \geqslant 1$ 。由于小球总数有限，可取非负整数 $K$ ，使所有小球的质量都属于 $\{ 1 , 1 / 2 , \cdots , 1 / 2 ^ { K } \}$ 。若每一种质量的小球总数都不超过 $\lfloor n / 2 \rfloor$ ，则

$$
n \leqslant n G \leqslant \lfloor n / 2 \rfloor \sum_ {r = 0} ^ {K} 2 ^ {- r} = \lfloor n / 2 \rfloor (2 - 2 ^ {- K}) <   2 \lfloor n / 2 \rfloor \leqslant n
$$

矛盾。因此必有某一种质量的小球的总个数至少为 $\lfloor n / 2 \rfloor + 1$ 

再证明这个下界可以达到。令 $m = \lfloor n / 2 \rfloor + 1$ 。由于 $2 n / ( n + 1 ) < 2$ ，可取充分大的正整数 k，使得

$$
2 - 2 ^ {- k} \geqslant \frac {2 n}{n + 1}
$$

由于 $m \geqslant ( n + 1 ) / 2$ ，有

$$
m \sum_ {r = 0} ^ {k} 2 ^ {- r} = m (2 - 2 ^ {- k}) \geqslant n
$$

准备每种质量 $1 , 1 / 2 , \cdots , 1 / 2 ^ { k }$ 的小球各 m 个，按质量从大到小排列。每一组都从尚未取走的首项开始取球，取到总质量为 1 时结束。只要剩余小球的总质量不小于 1，这样的一组就一定能够取出：当下一球的质量为 $w = 2 ^ { - r }$ 时，本组已取各球的质量都不小于 $w$ ，且是 $w$ 的整数倍，所以当前部分和与目标 1 都是 $w$ 的整数倍；尚未达到 1 时，所缺质量至少为 $w$ ，加入下一球不会越过 1。又因小球总数有限、剩余总质量不小于 1，截取必能恰好达到 1。每取完一组，剩余总质量减少 ，故由全部小球的总质量至少为 ，这一过程至少可以进行 次。

把所得的前 n 组分别放入 n 个袋子，则每袋的总质量均为 1，而每一种质量的小球总数都不超过 $m _ { \mathfrak { c } }$ 。由于 $m \leqslant n$ ，最前面的 $m$ 个单位质量小球分别构成前 $m$ 组，均被保留，所以最大同重球数恰为 $m .$ 。结合下界，所求最大值为 $\lfloor n / 2 \rfloor + 1$ 。

## APMO 2016 P2

若一个正整数能表示为 $2 ^ { a _ { 1 } } + 2 ^ { a _ { 2 } } + \cdot \cdot \cdot + 2 ^ { a _ { 1 0 0 } }$ ，其中 $a _ { 1 } , a _ { 2 } , \cdots , a _ { 1 0 0 }$ 是非负整数 (允许相同)，则称此数为“好的”。求最小的正整数 n，使得任意 n 的倍数均不是好的。

## 解

答案为 $n = 2 ^ { 1 0 1 } - 1$ ，记 $M = 2 ^ { 1 0 1 } - 1$ o

先证明每个满足 $1 \leqslant k < M$ 的整数 k 都有好的倍数。因为 $k < M$ ，它的二进制表示只可能使用第 0 至第 100 位，且不可能这 101 位全为 1，所以可写成 $k = 2 ^ { a _ { 1 } } + \cdot \cdot \cdot + 2 ^ { a _ { r } }$ ，其中$1 \leqslant r \leqslant 1 0 0$ ，各 $a _ { i }$ 为非负整数。

若 $r = 1 0 0$ ，则k 本身就是好的。若 $r < 1 0 0$ ，令 $s = 1 0 0 { - } r > 0$ ，利用 $2 ^ { s } = 1 + 1 + 2 + \cdot \cdot \cdot + 2 ^ { s - 1 }$ 得到

$$
2 ^ {s} k = \sum_ {i = 1} ^ {r - 1} 2 ^ {a _ {i} + s} + 2 ^ {a _ {r}} + \sum_ {j = 0} ^ {s - 1} 2 ^ {a _ {r} + j}
$$

右端共有 $( r - 1 ) + 1 + s = 1 0 0$ 项，所以 $2 ^ { s } k$ 是好的。

下面证明 M 的任何正整数倍都不能表示为至多 100 个 2 的非负整数次幂之和。反设存在这样的倍数，并取其中最小的一个，记为 $c M$ 。反复将两个相同的 2 的幂合并为一个下一尺度的幂，每次合并都保持总和不变并减少一项，故有限次后每个尺度至多剩一项。于是

$$
c M = 2 ^ {a _ {1}} + 2 ^ {a _ {2}} + \dots + 2 ^ {a _ {r}}, \quad 1 \leqslant r \leqslant 1 0 0, \quad 0 \leqslant a _ {1} <   a _ {2} <   \dots <   a _ {r}
$$

若 $a _ { r } \geqslant 1 0 1$ ，则 $2 ^ { a _ { r } } - 2 ^ { a _ { r } - 1 0 1 } = 2 ^ { a _ { r } - 1 0 1 } M$ ，所以

$$
2 ^ {a _ {1}} + \dots + 2 ^ {a _ {r - 1}} + 2 ^ {a _ {r} - 1 0 1} = c M - 2 ^ {a _ {r} - 1 0 1} M
$$

左侧是正数，且仍是至多 100 个非负整数次幂之和。因此右侧是一个比 cM 小的正整数倍，与最小性矛盾。

故所有指数都在 0,1,··· ,100 中。由于这些指数互不相同且至多有 100 个，至少缺少一个尺度，几何级数给出

$$
M \leqslant c M <   2 ^ {0} + 2 ^ {1} + \dots + 2 ^ {1 0 0} = 2 ^ {1 0 1} - 1 = M
$$

矛盾。因此 M 没有好的正整数倍，结合对所有更小正整数的构造，所求最小值为 $2 ^ { 1 0 1 } - 1$ 

## IMOSL 2013 C8

A、B 在实数轴上进行游戏。A 有 4 单位黑墨水；每轮 A 选正整数 m 并交出 $1 / 2 ^ { m }$ 单位，B 选整数 k，把区间 $[ k / 2 ^ { m } , ( k + 1 ) / 2 ^ { m } ]$ 涂黑。A 希望在有限轮后用完墨水而 [0,1] 尚未全黑。问 A 是否有必胜策略。

解

A 没有必胜策略。下面给出 B 的策略，并证明只要 [0,1] 尚未全黑，已经使用的墨水总量就小于 3。

记 x 为从 0 向右已经连续涂黑的最大端点，初始令 $x = 0$ 。只需考虑 $x < 1$ 的情形。A本轮交出 $h = 2 ^ { - m }$ 单位墨水时，令 $a = h \vert x / h \vert$ ，并记 $I _ { 0 } = [ a , a + h ] \times I _ { 1 } = [ a + h , a + 2 h ]$ 。于是 $a \leq x < a + h$ 。若 $I _ { 1 }$ 的左端点为 1，B 涂黑 $I _ { 0 }$ ，使 $[ 0 , 1 ]$ 全黑；否则 $I _ { 0 } , I _ { 1 }$ 均在 [0, 1] 中，此时若 $I _ { 1 }$ 尚未全黑，B 就涂黑 $I _ { 1 }$ ，若 $I _ { 1 }$ 已经全黑，B 就涂黑 $I _ { 0 }$ 。

把每次涂黑的整个区间与该次使用的墨水对应，即使区间重叠，也按历次操作分别计数。每个已经涂过的区间，要么完全包含于连续黑段 $[ 0 , x ]$ ，要么其左端点严格大于 $x ;$ ；否则它会使连续黑段延伸到更右处。对后一类区间，称其为待并入区间。证明在 $x < 1$ 时始终保持两个不变量：已经并入 [0,x] 的历次操作所耗墨水总量至多为 $3 x { \mathrm { ; } }$ ；对每种长度 $2 ^ { - j }$ ，至多有一个待并入区间。

初始时两个不变量显然成立。设当前不变量成立。如果 B 涂黑 $I _ { 1 }$ ，则 $I _ { 0 }$ 内尚有未黑的点，连续黑段不会增长，故第一个不变量不变。若此前已有一个长度为 h 的待并入区间，它被涂黑时必是当时前沿右侧的 $I _ { 1 }$ 。只要它还未并入连续黑段，前沿就仍在它左边的同一个长度为 $h$ 的网格区间内，所以它恰是当前的 $I _ { 1 }$ 。这会使当前 $I _ { 1 }$ 已经全黑，与本轮选择矛盾。因此第二个不变量也保持成立。

如果 B 涂黑 $I _ { 0 }$ ，并且本轮之后 [0,1] 仍未全黑，设连续黑段增长了 $\alpha$ 。由于 $I _ { 1 }$ 原已全黑，本轮之后连续黑段至少延伸到 $a + 2 h$ ，所以 $\alpha > h$ 。本轮新并入的所有旧区间都包含于$[ x , x + \alpha ]$ ，长度均不超过 $\alpha$ ；由第二个不变量，它们的长度互不相同，且都是 2 的负整数次幂。若其中最大长度为 $L ,$ ，这些旧区间所耗墨水总量严格小于 $L + L / 2 + L / 4 + \cdot \cdot \cdot = 2 L \leq 2 \alpha$ 若没有这样的旧区间，该估计同样成立。再加上本轮的 $h$ 单位墨水，新并入部分所耗墨水总量小于 $3 \alpha$ ，故并入 $[ 0 , x + \alpha ]$ 的墨水总量仍至多为 $3 ( x + \alpha )$ 。本轮没有新增待并入区间，第二个不变量也保持成立。

最后，在任意一个 [0,1] 尚未全黑的时刻，每个待并入区间都在 $[ x , 1 ]$ 中，故其长度不超过 $1 - x$ 。这些区间的长度互不相同且为二进尺度，所以其所耗墨水总量至多为 $2 ( 1 - x )$ 。结合第一个不变量，已使用墨水的总量至多为

$$
3 x + 2 (1 - x) = 2 + x <   3
$$

因此 A 不可能在 [0,1] 尚未全黑时用完 4 单位墨水，B 的策略保证 A 不能获胜。
