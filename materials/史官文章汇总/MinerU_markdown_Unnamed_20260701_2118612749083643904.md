设 $k , \ell$ 是非负整数， $r , s$ 是正整数。记 S 为所有满足

$$

是无限集，其中约定 $\operatorname* { g c d } ( 0 , 0 ) = 0$

对任意 $( a , b ) \in S$ ，设 $d = \operatorname* { g c d } ( a , b )$ 。由 $d \mid a , \ d \mid b$ 以及 $a \mid b ^ { 2 } + k b + 1$ 可知 $d \mid 1$ ，所以$\operatorname* { g c d } ( a , b ) = 1$ 。此外，a 和 b 都整除 $a ^ { 2 } + b ^ { 2 } + \ell a + k b + 1$ ，故存在正整数 M，使得

$$

$$

对每个正整数 M，右端都不为 0；否则分别对等式
