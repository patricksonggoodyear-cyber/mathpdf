求证：存在无限多个合数 n，使得数 $3 ^ { n - 1 } - 2 ^ { n - 1 }$ 可被 n 整除。

解

设 t 为正整数，令

$$
n = 3 ^ {2 ^ {t}} - 2 ^ {2 ^ {t}}
$$

当 $t \geqslant 2$ 时，

$$
n = \left(3 ^ {2 ^ {t - 1}} - 2 ^ {2 ^ {t - 1}}\right) \left(3 ^ {2 ^ {t - 1}} + 2 ^ {2 ^ {t - 1}}\right)
$$

且两个因子均大于 1，所以 n 为合数。下面证明：对任何正整数 t，都有

$$
n \mid 3 ^ {n - 1} - 2 ^ {n - 1}\tag{1}
$$

若正整数 $r \mid s .$ ，则 $x ^ { r } - y ^ { r } \mid x ^ { s } - y ^ { s }$ 。因此，为证 (1)，只需证明 $2 ^ { t } \mid n - 1$ 。又因为 $2 ^ { t } \mid 2 ^ { 2 ^ { t } }$ ，这等价于证明 $2 ^ { t } \mid 3 ^ { 2 ^ { t } } - 1$ 

下面用归纳法证明：对一切正整数 t ，都有 $2 ^ { t + 2 } \mid 3 ^ { 2 ^ { t } } - 1 \circ t = 1$ 时结论显然。假设 $t = k$ 时结论成立，则当 $t = k + 1$ 时，有

$$
3 ^ {2 ^ {k + 1}} - 1 = (3 ^ {2 ^ {k}} + 1) (3 ^ {2 ^ {k}} - 1)
$$

其中 $3 ^ { 2 ^ { k } } - 1$ 可被 $2 ^ { k + 2 }$ 整除， $3 ^ { 2 ^ { k } } + 1$ 是偶数，所以 $2 ^ { k + 3 } \mid 3 ^ { 2 ^ { k + 1 } } - 1$ 0

因此 (1) 对每个正整数 t 都成立。又因为 $3 ^ { 2 ^ { t } } - 2 ^ { 2 ^ { t } }$ 随 $t \ \overrightharpoon { \mathrm { ‰ ~ } }$ 格递增，所以取 $t = 2 , 3 , \cdots$ 即得到无限多个满足题意的合数 n。

是否存在一个正整数 N，使得 N 恰有 2000 个不同的质因数，并且 $N \mid 2 ^ { N } + 1 ?$ 这里允许 N 被某个质数的高次幂整除。

解

答案是肯定的。关键是建立一个可以反复使用的迭代步骤：从一个满足整除条件的数出发，构造出恰好多一个不同质因数、并且仍满足同一整除条件的新数。

迭代步骤：设奇数 n 恰有 k 个不同的质因数，并且 $n \mid 2 ^ { n } + 1$ ，则存在一个恰有 $k + 1$ 个不同质因数的奇数 N，使得 $N \mid 2 ^ { N } + 1$ C

证明：写成 $n = p _ { 1 } ^ { a _ { 1 } } p _ { 2 } ^ { a _ { 2 } } \cdot \cdot \cdot p _ { k } ^ { a _ { k } }$ 并记 $b _ { i } = \nu _ { p _ { i } } ( 2 ^ { n } + 1 )$ ，其中 $\nu _ { p } ( m )$ 表示质数 $p$ 在 $m$ 的质因数分解中的指数。由 $n \mid 2 ^ { n } + 1$ 可知 $b _ { i }$ ⩾ $a _ { i }$ 0

固定质因数 $p _ { 1 }$ 。对正整数 t，令

$$
M _ {t} = 2 ^ {n p _ {1} ^ {t}} + 1
$$

对奇数指数使用升幂公式 $\nu _ { p } ( x ^ { r } + 1 ) = \nu _ { p } ( x + 1 ) + \nu _ { p } ( r )$ ，可得

$$
\nu_ {p _ {i}} (M _ {t}) = \left\{ \begin{array}{l l} b _ {1} + t, & i = 1 \\ b _ {i}, & 2 \leqslant i \leqslant k \end{array} \right.
$$

因此 $M _ { t }$ 中只由原有质数 $p _ { 1 } , p _ { 2 } , \cdots , p _ { k }$ 构成的部分恰为

$$
p _ {1} ^ {b _ {1} + t} p _ {2} ^ {b _ {2}} \cdot \cdot \cdot p _ {k} ^ {b _ {k}} = C p _ {1} ^ {t}
$$

其中常数 $C = p _ { 1 } ^ { b _ { 1 } } p _ { 2 } ^ { b _ { 2 } } \cdot \cdot \cdot p _ { k } ^ { b _ { k } }$ 与 t 无关。另一方面， $M _ { t } = 2 ^ { n p _ { 1 } ^ { t } } + 1$ 的增长远快于 $C p _ { 1 } ^ { t }$ ，所以当 t充分大时， $M _ { t }$ 必有一个不属于 $p _ { 1 } , p _ { 2 } , \cdots , p _ { k }$ 的质因数，记为 $q .$ 。

上面的估值还表明 $n p _ { 1 } ^ { t } \mid M _ { t }$ 。由于 $q \ | \ M _ { t }$ 且 $q$ 不整除 $n p _ { 1 } ^ { t }$ ，令 $N = n p _ { 1 } ^ { t } q$ ，便有 $N \mid M _ { t }$ 而 N 的不同质因数恰为 $p _ { 1 } , p _ { 2 } , \cdots , p _ { k } , q$ 。最后， $q$ 是奇数，故幂和的因式分解给出

$$
M _ {t} = 2 ^ {n p _ {1} ^ {t}} + 1 \mid 2 ^ {n p _ {1} ^ {t} q} + 1 = 2 ^ {N} + 1
$$

于是 $N \mid 2 ^ { N } + 1$ ，迭代步骤得证。

现在从 $n _ { 1 } = 3$ 开始。它恰有一个不同的质因数，并且 $3 \mid 2 ^ { 3 } + 1$ 。每次对 $n _ { k }$ 使用上述迭代步骤，取所得的 N 为 $n _ { k + 1 }$ ，便递推得到奇数列 $n _ { 1 } , n _ { 2 } , \cdots$ ，其中 $n _ { k }$ 恰有 k 个不同的质因数，并且 $n _ { k } \mid 2 ^ { n _ { k } } + 1$ ，取 $k = 2 0 0 0$ ，数 $n _ { 2 0 0 0 }$ 即为所求。
