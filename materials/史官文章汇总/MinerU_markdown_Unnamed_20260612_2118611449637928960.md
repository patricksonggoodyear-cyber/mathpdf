## Brazil National 2016 P2

求最小正整数 n，使得平面上任意 n 个整点中，都存在两个点，使这两个点间距离的平方为 2016 的倍数。

解

将整点 $( x , y )$ 记作高斯整数 $z = x + y i$ ，并记 $N ( z ) = z \bar { z } = x ^ { 2 } + y ^ { 2 }$ 。两个整点所对应的高斯整数之差的范数，正是两点间距离的平方。高斯整数环 $\mathbb { Z } [ i ]$ 是唯一分解整环；有理质数$3 , 7 \equiv 3 { \pmod { 4 } }$ 在其中仍为质数，而

$$
2 = - i (1 + i) ^ {2}
$$

对于 $q \in \{ 3 , 7 \}$ ，若 $q \mid N ( z ) = z { \bar { z } }$ ，则高斯质数 $q$ 整除 z 或 z¯；对后一种情形取共轭，也得到$q \mid z _ { \circ }$ 。因此

$$
3 ^ {2} \mid N (z) \Longleftrightarrow 3 \mid z, \quad 7 \mid N (z) \Longleftrightarrow 7 \mid z
$$

另一方面，共轭不改变因子 1+i 的指数，所以

$$
\nu_ {1 + i} (N (z)) = 2 \nu_ {1 + i} (z)
$$

由 $2 0 1 6 = 2 ^ { 5 } \cdot 3 ^ { 2 }$ · 7 以及 $( 1 + i ) ^ { 5 } = - 4 ( 1 + i )$ ，可得

$$
2 0 1 6 \mid N (z) \Longleftrightarrow 2 1 (1 + i) ^ {5} \mid z \Longleftrightarrow 8 4 (1 + i) \mid z
$$

记 $\Delta = 8 4 ( 1 + i )$ 。乘以 $\Delta$ 将格 $\mathbb { Z } [ i ]$ 映为子格 $\Delta \mathbb { Z } [ i ]$ ，该子格的指数等于

$$
N (\Delta) = 8 4 ^ {2} N (1 + i) = 2 \cdot 8 4 ^ {2} = 1 4 1 1 2
$$

所以模 $\Delta$ 恰有 14112 个高斯整数剩余类。任取 14113 个整点，它们对应的高斯整数中必有两个模 $\Delta$ 同余。两者之差被 $\Delta$ 整除，根据上面的等价关系，这两个点间距离的平方被 2016 整除。

最后说明 14112 个点还不足以保证结论。考虑点集

$$
\mathcal {S} = \{(x, y) \in \mathbb {Z} ^ {2}: 0 \leqslant x \leqslant 8 3, 0 \leqslant y \leqslant 1 6 7 \}
$$

它含有 $8 4 \cdot 1 6 8 = 1 4 1 1 2$ 个点。若其中两点之差被 $\Delta$ 整除，则存在整数 $r , s$ ，使得

$$
(x _ {1} - x _ {2}) + (y _ {1} - y _ {2}) i = 8 4 (1 + i) (r + s i) = 8 4 (r - s) + 8 4 (r + s) i
$$

由于 $| x _ { 1 } - x _ { 2 } | \leqslant 8 3$ ，必有 $r - s = 0$ 。于是 $y _ { 1 } - y _ { 2 } = 1 6 8 r$ ；再由 $\left| y _ { 1 } - y _ { 2 } \right| \leqslant 1 6 7$ 得 $r = 0$ ，从而两点相同。因此 S 中任意两个不同点的距离平方都不是 2016 的倍数。

故所求最小值为 14113。
