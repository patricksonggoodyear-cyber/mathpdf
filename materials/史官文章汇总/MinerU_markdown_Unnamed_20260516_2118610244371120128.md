• A 每次行动时，选择若干枚在 B 上一步中没有被移动、且分别位于不同盒子中的硬币，并把每枚选中的硬币移到与其所在盒子相邻的一个盒子中。

解

答案为 4022。

把盒子数一般化为 $n \geqslant { 7 } ;$ ，下面证明所需硬币数恰为 $2 n - 2$ C

先证上界。称每个盒子中均有一枚或两枚硬币、且恰有两个盒子只有一枚硬币的分布为正规分布。A 起初把 $2 n - 2$ 枚硬币摆成正规分布，并把只有一枚硬币的两个盒子染成白色，其余盒子染成红色。

考虑 B 的一次行动。通常情况下，对每个红色盒子 X，A 把其中未被 B 移动的另一枚硬币移向 B 从 移出硬币的相反方向。这样，两人的行动合起来使每个红色盒子分别向左右邻盒各送出一枚硬币。每个盒子中原有的硬币均已移出，而每个盒子至多从两个邻盒各收到一枚，因此行动结束后每个盒子中至多有两枚硬币。每个拥有红色邻盒的盒子都会收到硬币；唯一可能没有红色邻盒的是夹在两个白色盒子之间的红色盒子 R。如果 B 移动两个白色盒子中的硬币时至少有一枚移向 R，则 R 也非空。由于硬币总数仍为 $2 n - 2$ ，所得分布仍为正规分布。

剩下的例外情形是：某个红色盒子 R 的两个邻盒均为白色，而且 B 把这两个白色盒子中的硬币都移向远离 R 的方向。此时 A 不移动 R 中剩下的硬币，只对其他红色盒子采用上述相反方向的移动。盒子 R 中恰好留有一枚硬币；又因 $n \geqslant 7$ ，其余每个盒子都有一个不同于R 的红色邻盒，故都会收到硬币。除 R 外，每个盒子中原有的硬币均已移出，并且每个邻盒至多向它送来一枚硬币，所以这些盒子仍至多含有两枚。结合硬币总数仍为 $2 n - 2$ ，所得分布再次是正规分布。归纳可知， $2 n - 2$ 枚硬币足以使 A 永远达到目标。

设整数 $n > 3 \mathrm { . }$ 有 n 个小朋友围成一圈，起初把 n 枚硬币任意分给他们，允许有人没有硬币。一次操作中，持有至少两枚硬币的小朋友可以给左右相邻的小朋友各一枚硬币。求所有能够经过有限次操作，使每个小朋友最终恰有一枚硬币的初始分配。

解

设第 i 个小朋友当前有 $c _ { i }$ 枚硬币。答案是所有满足

$$
\sum_ {i = 1} ^ {n} i c _ {i} \equiv \frac {n (n + 1)}{2} \pmod {n}
$$

的初始分配。

一次操作使某个 $c _ { i }$ 减少 2，并使 $c _ { i - 1 } , c _ { i + 1 }$ 各增加 1，其中下标按模 n 理解。因此 $\textstyle \sum _ { i = 1 } ^ { n } i c _ { i }$ 模 $n$ 不变，故上述同余式是必要条件。下面证明它也是充分条件。

先固定 n 号小朋友，并且暂时不让他操作；只要某个 $i < n$ 满足 $c _ { i } \geqslant 2$ ，就让他操作。这个过程必在有限步后停止。事实上，考虑

$$
\Phi = \sum_ {j = 1} ^ {n} j ^ {2} c _ {j}
$$

当 $2 \leqslant i < n$ 的小朋友操作时，Φ 增加 $( i - 1 ) ^ { 2 } + ( i + 1 ) ^ { 2 } - 2 i ^ { 2 } = 2$ ；当 $i = 1$ 的小朋友操作时，Φ 增加 $n ^ { 2 } + 2$ 。因此 Φ 每步严格增加，而总硬币数为 n，所以 $\Phi \leqslant n ^ { 3 }$ 。过程停止时，前$n - 1$ 个小朋友各有 0 或 1 枚硬币，因而状态形如

$$
(z _ {1}, \dots , z _ {n - 1}, M), \qquad z _ {i} \in \{0, 1 \}
$$

称这样的状态为不规则度为 M 的半均匀状态。

以下用 1<sup>r</sup> 表示由 r 个连续的 1 组成的区段，其中允许 $r = 0$ 。

引理：若某个连续区段的状态为 $( a , 1 ^ { k } , b , 1 ^ { k } , c )$ ，其中 $b \geqslant 2$ ，则经过有限次操作，可以把它变成 $( a + 1 , 1 ^ { k } , b - 2 , 1 ^ { k } , c + 1 )$ 。称这一过程为一次长传递。

引理证明：对 k 归纳。当 $k = 0$ 时，这正是一次原操作。当 $k = 1$ 时，依次让持有 b 枚硬币的小朋友、他的两个邻居、再让原来持有 b 枚硬币的小朋友操作即可。

设 $k \geqslant 2 .$ 。先让持有 b 枚硬币的小朋友操作，再让他的两个邻居操作，得到

$$
(a, 1 ^ {k - 2}, 2, 0, b, 0, 2, 1 ^ {k - 2}, c)
$$

接着让两侧持有 2 枚硬币的小朋友依次向外操作，直至这两个 2 分别传到区段的两端，得到

$$
(a + 1, 0, 1 ^ {k - 1}, b, 1 ^ {k - 1}, 0, c + 1)
$$

再对中间的 $( 0 , 1 ^ { k - 1 } , b , 1 ^ { k - 1 } , 0 )$ 使用归纳假设，便得到 $( a + 1 , 1 ^ { k } , b - 2 , 1 ^ { k } , c + 1 )$ 0

下面证明，从任意半均匀状态都能到达不规则度至多为 2 的半均匀状态。若当前不规则度 $M \geqslant 3$ ，则其余 $n - 1$ 个位置中恰有 $M - 1 \geqslant 2$ 个位置为 0。沿圆周两个方向分别取离 M最近的零点，则两零点之间经过 M 的圆弧形如

$$
(0, 1 ^ {a}, M, 1 ^ {b}, 0)
$$

若 $a = b$ ，以 M 为中心作一次长传递，便得到不规则度为 $M - 2$ 的半均匀状态。

以下设 $a > b$ ，另一种情形完全对称。以 M 为中心作一次长传递，使右端的 0 和左侧距M 相同距离的一个 1 各得到一枚硬币。令

$$
\alpha = a - b - 1, \beta = b
$$

只写出此后需要操作的区段，所得状态形如

$$
(0, 1 ^ {\alpha}, 2, 1 ^ {\beta}, M - 2, \dots)
$$

其中未写出的各项均为 0 或 1，并且暂时不让它们操作。

若 $\alpha < \beta$ ，就以这个 2 为中心作一次长传递，一端取其左侧的 0，另一端取其右侧相同距离处的一个 1。把已经变成 1 且以后不再操作的左端区段略去后，仍得到同一形式，但 $\beta$ 变为

$$
\beta^ {\prime} = \beta - \alpha - 1 <   \beta
$$

反复进行此操作，有限步后必有 $\alpha \geqslant \beta$ 

若此时 $\alpha = \beta$ ，则以 2 为中心作长传递，其两端恰为左侧的 0 和右侧的 $M - 2$ 。操作后这两处分别变为 1 和 $M - 1$ ，而原来的 2 变为 0，于是得到不规则度为 M−1 的半均匀状态。

若此时 $\alpha > \beta$ ，则以 2 为中心作长传递，一端取右侧的 M −2，另一端取左侧相同距离处的一个 1，从而得到形如

$$
(0, 1 ^ {\alpha - \beta - 1}, 2, 1 ^ {\beta}, 0, 1 ^ {\beta}, M - 1, \dots)
$$

的状态。现在只考虑两个零点之间的区段

$$
(0, 1 ^ {x}, 2, 1 ^ {y}, 0)
$$

每次从中间的 2 向离它较近的零点作长传递，并在另一侧取与该零点等距的位置。若另一端是 1，则长传递后仍得到同一类型的区段，但两个零点之间的距离严格缩短；若另一端也是 0，则两个端点都变为 1，原来的 2 变为 0，于是得到不规则度为 $M - 1$ 的半均匀状态。由于两个零点之间的距离不能无限下降，后一种情形必在有限步后发生。

因此，只要 $M \geqslant 3$ ，就能到达不规则度严格小于 M 的半均匀状态。反复使用上述过程，最终可到达不规则度 $M \leqslant 2$ 的半均匀状态。

若 M = 1，由硬币总数为 n 可知每个小朋友都恰有一枚硬币。若 $M = 2$ ，则恰有一个小朋友没有硬币，其余小朋友除持有 2 枚硬币者外都恰有一枚。重新编号，使持有 2 枚硬币者为 n 号，并设没有硬币者为 k 号，其中 $1 \leqslant k < n$ 。此时

$$
\sum_ {i = 1} ^ {n} i c _ {i} = \frac {n (n + 1)}{2} + n - k \equiv \frac {n (n + 1)}{2} - k \pmod {n}
$$

而题设同余条件及其不变性要求右端同余于 $n ( n + 1 ) / 2$ ，故 $k \equiv 0 { \pmod { n } }$ ，这与 $1 \leqslant k < n$ 矛盾。因此 $M = 2$ 不可能，最终必能到达每人恰有一枚硬币的状态。

## IMOSL 2001 C7

设 n 为正整数。起初把 n 枚石子堆成一列，其右侧各列均为空。一次操作可以选择一列，要求该列的石子数至少比紧邻右列多 2，然后把所选列最上面的一枚石子移到紧邻右列的顶端，空列的石子数视为 0。只要还能操作，就继续任意选择合法操作；无法继续时的状态称为终态。证明：无论每一步怎样选择，过程都在有限步后终止，且终态唯一，并用 n 确定终态中各列的石子数。

解

把各列从左到右编号为 1,2,···，记当前第 i 列有 $p _ { i }$ 枚石子。一次在第 k 列进行的操作把 $( p _ { k } , p _ { k + 1 } )$ 变为 $( p _ { k } - 1 , p _ { k + 1 } + 1 )$ ，合法条件是 $p _ { k } - p _ { k + 1 }$ ⩾ 2。

首先，所有可达状态都满足 $p _ { 1 } \geqslant p _ { 2 } \geqslant \cdot \cdot \cdot \geqslant 0 .$ 。事实上，操作后第 k 列仍不低于第 $k + 1$ 列，而第 k−1 列与第 k 列之间、第 $k + 1$ 列与第 $k + 2$ 列之间的高度差只会增加。初始状态满足这一性质，故它始终成立。特别地，非空列始终从第 1 列开始连续排列。

再考虑非负整数 $\begin{array} { r } { \Phi = \sum _ { i \geq 1 } p _ { i } ^ { 2 } } \end{array}$ 。每次操作使它减少

$$
p _ {k} ^ {2} + p _ {k + 1} ^ {2} - (p _ {k} - 1) ^ {2} - (p _ {k + 1} + 1) ^ {2} = 2 (p _ {k} - p _ {k + 1} - 1) \geqslant 2
$$

因此任何合法操作序列都在有限步后终止。

下面用缺陷区段刻画终态。令 $d _ { i } = p _ { i } - p _ { i + 1 }$ ⩾ 0。若在第 k 列操作，则 $d _ { k }$ 减少 2， $d _ { k + 1 }$ 增加 1；当 $k > 1$ 时， $d _ { k - 1 }$ 也增加 1，其他差分不变。

称一段差分 $d _ { i } , d _ { i + 1 } , \dotsb , d _ { j }$ 为缺陷区段，如果

$$
i <   j, \qquad d _ {i} = d _ {j} = 0, \qquad d _ {i + 1} = \dots = d _ {j - 1} = 1, \qquad p _ {j + 1} > 0
$$

其中允许 $j = i + 1$ ，此时内部没有差分。条件 $p _ { j + 1 } > 0$ 保证整个区段对应的石堆均非空，排除了右侧无穷多个空列形成的零差分。

证明任何可达状态中都不存在缺陷区段。反设存在，在所有可达状态的缺陷区段中选取$j - i$ 最小者，再选取一个尽早出现这种最短区段的状态。初始时只有一列非空，因此所选状态必由某次操作产生。记操作前的列高为 $a _ { i }$ ，差分为 $e _ { i } = a _ { i } - a _ { i + 1 }$ ，操作后的列高和差分仍记为 $p _ { i } , d _ { i }$ ，并设最后一步在第 k 列操作。

由于操作前所有差分均非负，而操作后的两个端点差分 $d _ { i } , d _ { j }$ 都为 0，最后一步不可能使它们增加。因此 k 不可能等于 $i - 1 , i + 1 , j - 1 , j + 1$ 中的任何正整数。下面分情况回溯。

• 若 $k = i$ ，则必有 $j \geqslant i + 2$ 。操作前 $e _ { i + 1 } = 0$ ，而 $e _ { j } = 0$ ，二者之间的差分仍全为 1，且$a _ { j + 1 } = p _ { j + 1 } > 0$ 。于是 $e _ { i + 1 } , \cdot \cdot \cdot , e _ { j }$ 是更短的缺陷区段，矛盾。

• 若 $k = j$ ，则必有 $j \geqslant i + 2$ 。操作前 $e _ { i } = e _ { j - 1 } = 0$ ，二者之间的差分仍全为 1，且$a _ { j } = p _ { j } + 1 > 0$ 。于是 $e _ { i } , \cdots , e _ { j - 1 }$ 是更短的缺陷区段，矛盾。

• 若 $i < k < j$ ，由上述排除条件可知 $i + 2 \leqslant k \leqslant j - 2$ 。操作前 $e _ { i } = e _ { k - 1 } = 0$ ，二者之间的差分仍全为 1，且 $a _ { k } = p _ { k } + 1 > 0$ 。于是 $e _ { i } , \cdots , e _ { k - 1 }$ 是更短的缺陷区段，矛盾。

• 若 $k \notin [ i , j ]$ ，则该区段内的差分均未改变；又因 $k \neq j + 1$ ，右端非空条件也未改变。因此同一个最短缺陷区段在操作前已经存在，与所选状态出现得最早矛盾。

所有情形均不可能，故缺陷区段始终不存在。

设终态共有 c 列非空。因为已不能操作，所以 $d _ { i } \in \{ 0 , 1 \}$ ；又因 $p _ { c } > 0 \setminus p _ { c + 1 } = 0$ ，必有$p _ { c } = d _ { c } = 1$ 。若 $d _ { 1 } , \cdots , d _ { c - 1 }$ 中出现两个或更多个 0，取相邻两次出现的 0，它们之间的差分全为 1，便构成缺陷区段，矛盾。因此，终态从左向右每次恰下降 1，至多只有一处相邻两列等高。

若没有相邻等高列，令 $r = 0 :$ ；否则令唯一满足 $d _ { r } = 0$ 的位置为 r，其中 $1 \leqslant r \leqslant c - 1$ C由 $p _ { c } = 1$ 逐列向左还原，得到

$$
p _ {i} = \left\{ \begin{array}{l l} c - i, & 1 \leqslant i \leqslant r \\ c - i + 1, & r <   i \leqslant c \\ 0, & i > c \end{array} \right. \quad n = \sum_ {i = 1} ^ {c} p _ {i} = \frac {c (c + 1)}{2} - r
$$

其中 c 由 $c ( c - 1 ) / 2 < n \leqslant c ( c + 1 ) / 2$ 唯一确定，再取 $r = c ( c + 1 ) / 2 - n$ 。故终态完全由 n决定，与操作顺序无关。
