范数不等式的使用技巧。

IMOSL 2010 A2 

实数 $a , b , c , d$ 满足 $a + b + c + d = 6$ 及 $a ^ { 2 } + b ^ { 2 } + c ^ { 2 } + d ^ { 2 } = 1 2$ 。证明

$$
3 6 \leqslant 4 (a ^ {3} + b ^ {3} + c ^ {3} + d ^ {3}) - (a ^ {4} + b ^ {4} + c ^ {4} + d ^ {4}) \leqslant 4 8
$$

解

令 $x = a - 1 , y = b - 1 , z = c - 1 , t = d - 1$ ，则 $x + y + z + t = 2 , \ x ^ { 2 } + y ^ { 2 } + z ^ { 2 } + t ^ { 2 } = 4$ o展开可得

$$
4 \left(a ^ {3} + b ^ {3} + c ^ {3} + d ^ {3}\right) - \left(a ^ {4} + b ^ {4} + c ^ {4} + d ^ {4}\right) = 5 2 - \left(x ^ {4} + y ^ {4} + z ^ {4} + t ^ {4}\right)
$$

记 $\boldsymbol { u } = ( x , y , z , t )$ 。对于四维实向量，二次范数与四次范数满足 $\| u \| _ { 4 } \leqslant \| u \| _ { 2 } \leqslant { \sqrt { 2 } } \| u \| _ { 2 }$ ，其中$\| u \| _ { p } = ( | x | ^ { p } + | y | ^ { p } + | z | ^ { p } + | t | ^ { p } ) ^ { 1 / p }$ 。事实上，展开平方以及柯西不等式分别给出

$$
x ^ {4} + y ^ {4} + z ^ {4} + t ^ {4} \leqslant (x ^ {2} + y ^ {2} + z ^ {2} + t ^ {2}) ^ {2} \leqslant 4 (x ^ {4} + y ^ {4} + z ^ {4} + t ^ {4})
$$

因此 $4 \leqslant x ^ { 4 } + y ^ { 4 } + z ^ { 4 } + t ^ { 4 } \leqslant 1 6$ ，代入上式即得结论。下界在 $( a , b , c , d ) = ( 3 , 1 , 1 , 1 )$ 时取到，上界在 $( a , b , c , d ) = ( 0 , 2 , 2 , 2 )$ 时取到。

CTST 2012 P11 

设 $m , n$ 是给定的大于 1 的整数， $r , s$ 是给定的正实数，且 $r \ < s$ 。对不全为 0 的非负实数 $a _ { i j } \ ( 1 \leqslant i \leqslant m , 1 \leqslant j \leqslant n )$ ，求

$$
f = \frac {\left[ \sum_ {j = 1} ^ {n} \left(\sum_ {i = 1} ^ {m} a _ {i j} ^ {s}\right) ^ {r / s} \right] ^ {1 / r}}{\left[ \sum_ {i = 1} ^ {m} \left(\sum_ {j = 1} ^ {n} a _ {i j} ^ {r}\right) ^ {s / r} \right] ^ {1 / s}}
$$

的最大值。

解

最大值为 $( \operatorname* { m i n } \{ m , n \} ) ^ { 1 / r - 1 / s }$ 。

先说明所用的范数比较：若 $p > 1 , \ t _ { 1 } , \cdot \cdot \cdot , t _ { N }$ 是非负实数，则

$$
\left(\sum_ {i = 1} ^ {N} t _ {i} ^ {p}\right) ^ {1 / p} \leqslant \sum_ {i = 1} ^ {N} t _ {i} \leqslant N ^ {1 - 1 / p} \left(\sum_ {i = 1} ^ {N} t _ {i} ^ {p}\right) ^ {1 / p}
$$

记 $\textstyle T = \sum _ { i = 1 } ^ { N } t _ { i }$ 。当 $T > 0$ 时，由 $0 \leqslant t _ { i } / T \leqslant 1$ 得 $\textstyle \sum _ { i = 1 } ^ { N } ( t _ { i } / T ) ^ { p } \leqslant 1$ ，这就证明了左边的不等式； $T = 0$ 时显然成立。右边的不等式由 $t ^ { p }$ 在非负实数上的凸性得到

$$
\left(\frac {1}{N} \sum_ {i = 1} ^ {N} t _ {i}\right) ^ {p} \leqslant \frac {1}{N} \sum_ {i = 1} ^ {N} t _ {i} ^ {p}
$$

后整理即得。

令 $b _ { i j } = a _ { i j } ^ { r } \mathrm { , } p = s / r > 1$ ，并记

$$
U = \sum_ {j = 1} ^ {n} \left(\sum_ {i = 1} ^ {m} b _ {i j} ^ {p}\right) ^ {1 / p}, \quad V = \left[ \sum_ {i = 1} ^ {m} \left(\sum_ {j = 1} ^ {n} b _ {i j}\right) ^ {p} \right] ^ {1 / p}
$$

因为原数组不全为零，所以 $U , V > 0$ ，且 $f ^ { r } = U / V$ 。对每一列使用范数比较的左边，再对 $m$ 个行和使用右边，得到

$$
U \leqslant \sum_ {i = 1} ^ {m} \sum_ {j = 1} ^ {n} b _ {i j} \leqslant m ^ {1 - 1 / p} V
$$

另一方面，先对 n 个列范数使用右边的不等式，再对每一行使用左边的不等式，得到

$$
U \leqslant n ^ {1 - 1 / p} \left(\sum_ {j = 1} ^ {n} \sum_ {i = 1} ^ {m} b _ {i j} ^ {p}\right) ^ {1 / p}, \quad V ^ {p} = \sum_ {i = 1} ^ {m} \left(\sum_ {j = 1} ^ {n} b _ {i j}\right) ^ {p} \geqslant \sum_ {i = 1} ^ {m} \sum_ {j = 1} ^ {n} b _ {i j} ^ {p}
$$

所以 $U \leqslant n ^ { 1 - 1 / p } V$ 。合并两个上界可得

$$
f \leqslant (\min \{m, n \}) ^ {(1 - 1 / p) / r} = (\min \{m, n \}) ^ {1 / r - 1 / s}
$$

记 $k = \operatorname* { m i n } \{ m , n \}$ ，取 $a _ { 1 1 } = a _ { 2 2 } = \cdot \cdot \cdot = a _ { k k } = 1$ ，其余 $a _ { i j } = 0$ 。此时分子为 $k ^ { 1 / r }$ ，分母为 $k ^ { 1 / s }$ ，恰好取到上述上界。

CGMO 2021 P1 

设 n 是正整数， $x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { n + 1 } , p , q$ 是正实数， $p < q$ ，且 $x _ { n + 1 } ^ { p } > x _ { 1 } ^ { p } + x _ { 2 } ^ { p } + \cdot \cdot \cdot + x _ { n } ^ { p }$ 。证明

$$
\left(x _ {n + 1} ^ {p} - \sum_ {i = 1} ^ {n} x _ {i} ^ {p}\right) ^ {1 / p} <   \left(x _ {n + 1} ^ {q} - \sum_ {i = 1} ^ {n} x _ {i} ^ {q}\right) ^ {1 / q}
$$

解

先说明正指数幂和的比较：若 $0 < p < q , \ N \geqslant 2$ ，且 $t _ { 1 } , \cdots , t _ { N }$ 都是正实数，则

$$
\left(\sum_ {i = 1} ^ {N} t _ {i} ^ {p}\right) ^ {1 / p} > \left(\sum_ {i = 1} ^ {N} t _ {i} ^ {q}\right) ^ {1 / q}
$$

事实上，令 $\begin{array} { r } { S = ( \sum _ { i = 1 } ^ { N } t _ { i } ^ { p } ) ^ { 1 / p } } \end{array}$ ，则每个 $t _ { i } / S \in ( 0 , 1 )$ ，且 $\textstyle \sum _ { i = 1 } ^ { N } ( t _ { i } / S ) ^ { p } = 1$ 。因为 $q > p$ ，所以$\textstyle \sum _ { i = 1 } ^ { N } ( t _ { i } / S ) ^ { q } < 1$ ，从而得到上述比较。这个结论对任意正指数 $p < q$ 都成立。

令 $\begin{array} { r } { a = ( x _ { n + 1 } ^ { p } - \sum _ { i = 1 } ^ { n } x _ { i } ^ { p } ) ^ { 1 / p } > 0 } \end{array}$ 。对 $n + 1$ 个正实数 $x _ { 1 } , \cdots , x _ { n } , a$ 使用幂和比较，得到

$$
x _ {n + 1} = \left(\sum_ {i = 1} ^ {n} x _ {i} ^ {p} + a ^ {p}\right) ^ {1 / p} > \left(\sum_ {i = 1} ^ {n} x _ {i} ^ {q} + a ^ {q}\right) ^ {1 / q}
$$

因此 $\begin{array} { r } { x _ { n + 1 } ^ { q } - \sum _ { i = 1 } ^ { n } x _ { i } ^ { q } > a ^ { q } > 0 } \end{array}$ ，右端根式有意义，再取 q 次方根即得所证不等式。

IMOSL 2024 A3 

判断下列命题是否成立：对任意正实数序列 $\left( a _ { n } \right)$ ，至少存在一个正整数 n，使得

$$
\frac {3 ^ {a _ {1}} + 3 ^ {a _ {2}} + \cdots + 3 ^ {a _ {n}}}{(2 ^ {a _ {1}} + 2 ^ {a _ {2}} + \cdots + 2 ^ {a _ {n}}) ^ {2}} <   \frac {1}{2 0 2 4}
$$

解

命题成立。令 $p = \log _ { 2 } 3$ ，则 $1 < p < 2$ 。记 $\begin{array} { r } { b _ { i } = 2 ^ { a _ { i } } > 1 , \ S _ { n } = \sum _ { i = 1 } ^ { n } b _ { i } > n } \end{array}$ ，于是 $3 ^ { a _ { i } } = b _ { i } ^ { p }$ 

对非负向量，一次范数不小于 p 次范数。这里可以直接归一化证明：因为 $0 < b _ { i } / S _ { n }$ ⩽ 1及 $p > 1$ ，所以

$$
\sum_ {i = 1} ^ {n} \left(\frac {b _ {i}}{S _ {n}}\right) ^ {p} \leqslant \sum_ {i = 1} ^ {n} \frac {b _ {i}}{S _ {n}} = 1
$$

也就是 $\textstyle \sum _ { i = 1 } ^ { n } b _ { i } ^ { p } \leqslant S _ { n } ^ { p }$ 。从而

$$
\frac {3 ^ {a _ {1}} + 3 ^ {a _ {2}} + \cdots + 3 ^ {a _ {n}}}{(2 ^ {a _ {1}} + 2 ^ {a _ {2}} + \cdots + 2 ^ {a _ {n}}) ^ {2}} = \frac {\sum_ {i = 1} ^ {n} b _ {i} ^ {p}}{S _ {n} ^ {2}} \leqslant S _ {n} ^ {p - 2} <   n ^ {p - 2}
$$

其中最后一步用了 $S _ { n } > n$ 及 $p - 2 < 0$ 。取正整数 $n > 2 0 2 4 ^ { 1 / ( 2 - p ) }$ ，便有 $n ^ { p - 2 } < 1 / 2 0 2 4$ ，故命题成立。

CGMO 2025 P3 

是否存在大于 1 的整数 $x , y , z , k ,$ ，满足下述条件： $x , y , z$ 均恰有 k 个大于 1 的正约数，且存在 x 的这些约数的排列 $a _ { 1 } , a _ { 2 } , \cdots , a _ { k }$ 及 y 的这些约数的排列 $b _ { 1 } , b _ { 2 } , \cdots , b _ { k }$ ，使得 $a _ { 1 } +$ $b _ { 1 } , a _ { 2 } + b _ { 2 } , \cdot \cdot \cdot , a _ { k } + b _ { k }$ 恰为 z 的全部大于 1 的正约数？

解

不存在。反设有这样的整数，并记 $c _ { i } = a _ { i } + b _ { i }$ 。一个有 $k + 1$ 个正约数的整数 m，其全部约数的乘积为 $m ^ { ( k + 1 ) / 2 }$ ：将约数在乘积中按 $d \mapsto m / d$ 置换，两个相同乘积相乘恰为 $m ^ { k + 1 }$ 去掉约数 1 不改变乘积。因此

$$
\prod_ {i = 1} ^ {k} a _ {i} = x ^ {(k + 1) / 2}, \qquad \prod_ {i = 1} ^ {k} b _ {i} = y ^ {(k + 1) / 2}, \qquad \prod_ {i = 1} ^ {k} c _ {i} = z ^ {(k + 1) / 2}
$$

令 $\alpha = ( k + 1 ) / ( 2 k )$ ，由 $k > 1$ 知 $0 < \alpha < 1$ 。分别对正数 $a _ { i } / c _ { i } \setminus b _ { i } / c _ { i }$ 应用平均值不等式，得到

$$
\left(\frac {x}{z}\right) ^ {\alpha} \leqslant \frac {1}{k} \sum_ {i = 1} ^ {k} \frac {a _ {i}}{c _ {i}}, \quad \left(\frac {y}{z}\right) ^ {\alpha} \leqslant \frac {1}{k} \sum_ {i = 1} ^ {k} \frac {b _ {i}}{c _ {i}}
$$

相加并使用 $a _ { i } + b _ { i } = c _ { i }$ ，得到 $x ^ { \alpha } + y ^ { \alpha } \leqslant z ^ { \alpha } ,$ 。

另一方面， $x / ( x + y ) \cdot y / ( x + y )$ 都在 (0, 1) 内，其 α 次方严格大于本身，故 $x ^ { \alpha } + y ^ { \alpha } > ( x + y ) ^ { \alpha }$ 。而 z 本身是某个 $c _ { i } = a _ { i } + b _ { i }$ ，且 $a _ { i } \leqslant x \setminus b _ { i } \leqslant y$ ，所以 $z \leqslant x + y ,$ 。于是

$$
x ^ {\alpha} + y ^ {\alpha} > (x + y) ^ {\alpha} \geqslant z ^ {\alpha}
$$

与 $x ^ { \alpha } + y ^ { \alpha } \leqslant z ^ { \alpha }$ 矛盾。
