## USAMO 2026 P2

安妮在黑板上从左到右写着一列正整数，其中每个数都是 2 的幂。每次操作，她可以擦去两个相邻数，并用一个严格大于这两个数的 2 的幂替换它们。这样数列的长度减少 1，她不断操作，直到只剩一个数。如果最后剩下的数小于初始所有数之和的 4 倍，就称安妮获胜。无论初始数列如何，安妮是否总能获胜？

## 解

答案是肯定的。相邻合并始终对应初始数列的连续区间，我们对这些区间建立递归上界。对一列 2 的幂 $x _ { 1 } , x _ { 2 } , \cdots , x _ { r }$ ，定义

$$
B (x _ {1}, x _ {2}, \dots , x _ {r}) = \left\{ \begin{array}{l l} x _ {1}, & r = 1 \\ 2 x _ {1} + 4 \sum_ {i = 2} ^ {r - 1} x _ {i} + 2 x _ {r}, & r \geqslant 2 \end{array} \right.
$$

约定空和为 0。我们证明这列数能经合法操作合并成一个不超过 B 的数。

对数列长度 r 归纳。当 r = 1 时无需操作。当 r = 2 时，用 $2 \operatorname* { m a x } \{ x _ { 1 } , x _ { 2 } \}$ 替换这两个数即可；它是严格大于二者的 2 的幂，并且 $2 \operatorname* { m a x } \{ x _ { 1 } , x _ { 2 } \} \leqslant 2 x _ { 1 } + 2 x _ { 2 } = B ( x _ { 1 } , x _ { 2 } )$ 。

以下设 $r \geqslant 3$ ，并记

$$
S = B \left(x _ {1}, x _ {2}, \dots , x _ {r}\right) = 2 x _ {1} + 4 \sum_ {i = 2} ^ {r - 1} x _ {i} + 2 x _ {r}
$$

对 $1 \leqslant k \leqslant r - 1$ ，令 $L _ { k } = B ( x _ { 1 } , x _ { 2 } , \cdots , x _ { k } ) , R _ { k } = B ( x _ { k + 1 } , x _ { k + 2 } , \cdots , x _ { r } )$ 。数列 $L _ { 1 } , L _ { 2 } , \cdots , L _ { r - }$ 1严格递增，因为 $L _ { 2 } - L _ { 1 } = x _ { 1 } + 2 x _ { 2 } > 0$ ，而当 $2 \leqslant k \leqslant r - 2$ 时， $L _ { k + 1 } - L _ { k } = 2 x _ { k } + 2 x _ { k + 1 } > 0$ o又有 $L _ { 1 } = x _ { 1 } < S / 2$ ，故可以取满足 $L _ { k } \leqslant S / 2$ 的最大下标 k。

若 $k < r - 1$ ，则 $L _ { k + 1 } > S / 2 ;$ ；直接展开定义可得 $L _ { k + 1 } + R _ { k } = S$ ，所以 $R _ { k } < S / 2$ 。若$k = r - 1$ ，则 $R _ { k } = x _ { r } < S / 2$ 。因此总能找到一个切分位置 k，使

$$
L _ {k} \leqslant \frac {S}{2}, \quad R _ {k} \leqslant \frac {S}{2}
$$

由归纳假设，只在前 k 项中操作，可以把它们合并成一个 2 的幂 $p \leqslant L _ { k } \leqslant S / 2$ ；只在后 $r \mathrm { ~ - ~ } k$ 项中操作，可以把它们合并成一个 2 的幂 $q \leqslant R _ { k } \leqslant S / 2$ 。此时 $p , q$ 相邻。令

$M = \operatorname* { m a x } \{ p , q \}$ ，再用 2M 替换它们。因为 $p , q$ 都是 2 的幂，所以 2M 仍是 2 的幂且严格大于二者；又因 $M \leqslant S / 2$ ，所以 $2 M \leqslant S _ { \circ }$ 归纳完成。

若原数列为 $a _ { 1 } , a _ { 2 } , \cdots , a _ { n }$ 且 $n \geqslant 2$ ，则最后剩下的数不超过

$$
B (a _ {1}, a _ {2}, \dots , a _ {n}) = 4 \sum_ {i = 1} ^ {n} a _ {i} - 2 a _ {1} - 2 a _ {n} <   4 \sum_ {i = 1} ^ {n} a _ {i}
$$

当 $n = 1$ 时，最后的数就是 $a _ { 1 } < 4 a _ { 1 }$ 。因此无论初始数列如何，安妮总能获胜。

设 $c > 2$ ，非负实数列 $a ( 1 ) , a ( 2 ) , \cdots$ 满足

$$
a (m + n) \leqslant 2 a (m) + 2 a (n) \quad (m, n \geqslant 1)
$$

且

$$
a (2 ^ {k}) \leqslant \frac {1}{(k + 1) ^ {c}} \quad (k \geqslant 0)
$$

解

先把二元相加的顺序编码成一棵有根二叉树，其中每个非叶结点恰有两个子结点。根的深度为 0，将正整数 $n _ { 1 } , \cdots , n _ { t }$ 放在叶子上，每个非叶结点的标数为两个子结点标数之和。若第 i 片叶子的深度为 $d _ { i }$ ，从根开始逐层使用题设不等式，就得到

$$
a \left(\sum_ {i = 1} ^ {t} n _ {i}\right) \leqslant \sum_ {i = 1} ^ {t} 2 ^ {d _ {i}} a (n _ {i})
$$

因此，合并顺序的作用就是决定各项的叶深，以及相应的放大系数 $2 ^ { d _ { i } }$ 。

先说明一个叶深构造事实：若非负整数 $s _ { 1 } , \cdots , s _ { t }$ 满足 $\textstyle \sum _ { i = 1 } ^ { t } 2 ^ { - s _ { i } } \leqslant 1$ ，则存在一棵上述二叉树，恰有编号为 $1 , \cdots , t$ 的 t 片叶子，且第 i 片叶子的深度 $d _ { i } \leqslant s _ { i } \circ$ 

为证此结论，不妨把叶子连同其编号重排，使 $s _ { 1 } \leqslant \cdots \leqslant s _ { t } .$ 。在一棵各层均完整、深度为$s _ { t }$ 的二叉树中，依次选择深度为 $s _ { i }$ 的结点，要求它不在此前已选结点的下方，也不与此前结点重合。选第 i 个结点时，此前所选结点在深度 $s _ { i }$ 这一层占据的后代结点总数为

$$
\sum_ {j <   i} 2 ^ {s _ {i} - s _ {j}} \leqslant 2 ^ {s _ {i}} - 1
$$

这里的不等式由 $\textstyle \sum _ { j \leqslant i } 2 ^ { - s _ { j } } \leqslant 1$ 得到。因此该层的 $2 ^ { s _ { i } }$ 个结点中总有未被占据的结点可选。所得结点两两没有祖孙关系。

保留根到这些结点的全部路径，再压缩所有只有一个子结点的结点；如果根只有一个子结点，就将这个子结点提升为新根。所得树恰有这 t 片叶子，每个非叶结点恰有两个子结点，而且压缩只会减小叶深。这就证明了所需的构造事实；当 $t = 1$ 时，所得树可以只有一个深度为 0 的结点。

结合 $a ( n _ { i } ) \geqslant 0$ ，只要 $\textstyle \sum _ { i } 2 ^ { - s _ { i } } \leqslant 1$ ，就有

$$
a \left(\sum_ {i = 1} ^ {t} n _ {i}\right) \leqslant \sum_ {i = 1} ^ {t} 2 ^ {d _ {i}} a (n _ {i}) \leqslant \sum_ {i = 1} ^ {t} 2 ^ {s _ {i}} a (n _ {i})
$$

令 $q = c / 2 > 1$ ，并记 $\begin{array} { r } { H = \sum _ { r = 1 } ^ { \infty } r ^ { - q } } \end{array}$ 。将正整数按区间 $[ 2 ^ { j } , 2 ^ { j + 1 } )$ 分组，可得

$$
1 <   H \leqslant \sum_ {j = 0} ^ {\infty} 2 ^ {j (1 - q)} <   \infty
$$

故 H 是一个只依赖于 c 的有限常数。

任取正整数 n，写出二进制展开 $\textstyle n = \sum _ { i = 1 } ^ { t } 2 ^ { u _ { i } }$ ，其中 $0 \leqslant u _ { 1 } < \cdots < u _ { t } .$ 。根据各项已知上界的大小，选择叶深上界

$$
s _ {i} = \lceil \log_ {2} H + q \log_ {2} (u _ {i} + 1) \rceil
$$

因为 $H > 1$ ，这些 $s _ { i }$ 都是正整数，并且

$$
\sum_ {i = 1} ^ {t} 2 ^ {- s _ {i}} \leqslant \frac {1}{H} \sum_ {i = 1} ^ {t} \frac {1}{(u _ {i} + 1) ^ {q}} \leqslant 1
$$

所以它们满足叶深构造所需的容量条件。另一方面，由向上取整的定义， $2 ^ { s _ { i } } < 2 H ( u _ { i } + 1 ) ^ { q }$ 于是利用题设在 2 的幂处给出的上界，得到

$$
a (n) \leqslant \sum_ {i = 1} ^ {t} 2 ^ {s _ {i}} a (2 ^ {u _ {i}}) \leqslant \sum_ {i = 1} ^ {t} \frac {2 ^ {s _ {i}}}{(u _ {i} + 1) ^ {2 q}} <   2 H \sum_ {i = 1} ^ {t} \frac {1}{(u _ {i} + 1) ^ {q}} \leqslant 2 H ^ {2}
$$

上界与 n 无关，因此数列有界。

答案为 $\frac { 1 0 5 3 } { 2 2 1 }$ C

设从 n 个 1 开始，经过 $n - 1$ 次操作后所得末数的最小值为 $m _ { n }$ 。最后一次操作所用的两个数分别由互不相交的 r 个和 $n - r$ 个初始数字产生，故

$$
m _ {1} = 1, \qquad m _ {n} = \frac {1}{4} \min _ {1 \leqslant r <   n} \left(m _ {r} + m _ {n - r}\right)
$$

下面用二叉树求解这个递推。把每个初始的 1 看成一片叶子；每次把两个数 $a , b$ 替换为$( a + b ) / 4$ ，就在表示这两个数的两棵树上方添加一个父节点。全部操作结束后便得到一棵有 $n$ 片叶子的满二叉树。反过来，任意这样的满二叉树都可以通过从下到上依次合并来实现。

\sum_ {i = 1} ^ {n} 2 ^ {- d _ {i}} = 1

求最小的正整数 n，使得可以适当地进行有限次操作，让所有 n 张红色卡片上的实数之和大于 100。

解

先证明，在全部卡片按数值从小到大的排列中，只对相邻的红、蓝卡片取平均，就能使最终红数之和达到最大。这里的相邻是指数值排序中的相邻，不是给卡片预先固定位置。

对任意状态 $T ,$ ，将卡片按数值从小到大排列，数值相等时蓝卡片排在红卡片之前。只要色串中还有相邻的 $R B$ ，就把这两张卡片上的数取平均，并把它们的次序写成 BR。两数相等以后交换位置不改变状态，而平均数位于原来两数之间，所以整个排列仍按数值从小到大。每一步恰使色串中“红在蓝前”的卡片对数减少 1，故至多进行 $n ^ { 2 }$ 步就得到色串 $B ^ { n } R ^ { n }$ 。为讨论数值相等时的边界，也允许两个相等数作不改变数值的平均；真正执行时删去这些零变化步骤即可。

这样的过程所得最终红数之和与相邻操作的先后次序无关。事实上，色串中两个不同的相邻 RB 必定不相交，对它们的操作可以交换，且交换后状态完全相同。对“红在蓝前”的卡片对数归纳：若两个过程的第一步不同，就先把这两个可交换的步骤都做完，再对剩余过程应用归纳假设。记这个共同的最终红数之和为 $F ( T )$ 。由于每次平均都不减少红数之和， $F ( T )$ 不小于状态 T 中当前的红数之和。

固定卡片的排序及其色串，设各位置上的数为 $z _ { 1 } \leqslant \cdots \leqslant z _ { 2 n }$ 。每一步取平均都是线性运算，故存在只依赖于色串的系数 $w _ { 1 } , \cdots , w _ { 2 n }$ ，使

$$
F (T) = \sum_ {k = 1} ^ {2 n} w _ {k} z _ {k}
$$

把递归中的平均运算展开为二叉树时，深度为 $d$ 的叶子对相应根值的权重为 $2 ^ { - d }$ ；这里的系数就是各最终红数中对应叶权的总和。

关键是这些系数满足

$$
0 \leqslant w _ {1} \leqslant w _ {2} \leqslant \dots \leqslant w _ {2 n} \leqslant 1
$$

为证此结论，从终止色串 $B ^ { n } R ^ { n }$ 倒推：其红数之和对各位置的系数依次为 n 个 0 和 n 个1。倒推一次相邻平均时，若这两个位置当前的系数为 $u , v$ ，则操作前两个位置的系数都变为$( u + v ) / 2$ ，其余系数不变。把非递减序列中的两个相邻数替换为它们的平均数，仍得到非递减序列。逐步倒推即可得到上述结论。

当卡片的数值次序改变时，F 仍然连续。两个同色数相等时，交换它们不改变状态；两个异色数相等时，可以先作一次零变化的平均，把 RB 写成 BR，由操作次序无关性可知两侧的线性表达式在这个边界上相同。因此 F 是连续的分段线性函数。

现在考虑原题中任意一次操作，所选红数为 x、蓝数为 y，其中 $x \ < \ y$ 。让这两个数沿$x + t , y - t$ 连续变化，其中 $0 \leqslant t \leqslant ( y - x ) / 2$ ，其余数保持不变。卡片的排序只在有限多个参数值处改变。在排序不变的每一段中，所选红数不大于所选蓝数，故其位置对应的系数满足$w _ { R } \leqslant w _ { B }$ ，于是 F 关于 t 的斜率为 $w _ { R } - w _ { B } \leqslant 0$ 。结合边界处的连续性，原题的每一次操作都不会使 F 增大。

设初始状态为 $T _ { 0 }$ 。经过任意有限次操作到达 T 后，红数之和不超过 $F ( T ) \leqslant F ( T _ { 0 } )$ ；而从$T _ { 0 }$ 开始的相邻平均过程恰能达到 $F ( T _ { 0 } )$ 。因此它确实给出了原题的最大值。下面计算这个值。

把所有卡片按所写的数从小到大排列。把初始红卡片从右到左编号为 $R _ { 1 } , R _ { 2 } , \cdots , R _ { n }$ ，蓝卡片从左到右编号为 $B _ { 1 } , B _ { 2 } , \cdots , B _ { n }$ ；数值相等时，约定蓝卡片排在红卡片之前，同色红卡片按 $R _ { n } , R _ { n - 1 } , \cdot \cdot \cdot , R _ { 1 }$ 的固定次序排列，同色蓝卡片按 $B _ { 1 } , B _ { 2 } , \cdots , B _ { n }$ 的固定次序排列。若端点处有多张同值同色卡片，就选取与另一种颜色相邻的那一张，故一次相邻平均操作只把色串中的一个 RB 变成 $B R$ ，同色卡片的相对次序始终不变。初始色串为 $R ^ { n } B ^ { n }$ ；相邻平均过程结束时不能再有红数小于蓝数，故终止色串为 $B ^ { n } R ^ { n }$ 。因此每一对红、蓝卡片恰好交叉一次。事件 $( i , j )$ 表示 $R _ { j }$ 与 $B _ { i }$ 操作，则它必须晚于 $( i - 1 , j )$ 与 $( i , j - 1 )$ (相应事件存在时)。任意两个不受这些先后关系约束的事件使用四张不同卡片，故可以交换而不改变结果；任意两个满足这些先后关系的操作序列都可通过反复交换相邻的不可比事件互相转化。于是所有完整的邻项平均过程都等价于如下标准顺序：先让 $B _ { 1 }$ 依次与 $R _ { 1 } , R _ { 2 } , \cdots , R _ { n }$ 操作，再让 $B _ { 2 }$ 依次与它们操作，依此进行到 $B _ { n }$ 

设 $B _ { i }$ 与 $R _ { j }$ 操作后两张卡片上的公共数为 $h ( i , j )$ ，并约定 $h ( 0 , j ) = 0 , \ h ( i , 0 ) = 1$ 。在这一步之前，蓝数为 $h ( i , j - 1 )$ )，红数为 $h ( i - 1 , j )$ ，所以

$$
h (i, j) = \frac {h (i , j - 1) + h (i - 1 , j)}{2}
$$

由帕斯卡恒等式归纳可得

$$
h (i, j) = \frac {\sum_ {k = 0} ^ {i - 1} \binom {i + j - 1} {k}}{2 ^ {i + j - 1}}
$$

而且

$$
h (i, j - 1) - h (i - 1, j) = \frac {1}{2 ^ {i + j - 2}} \binom {i + j - 2} {i - 1} > 0
$$

故标准顺序中的每一步确实满足红数严格小于蓝数。最终第 j 张红卡片上的数为 $h ( n , j )$ ，记最大红数之和为 $S _ { n }$ 。由上式可知 $h ( n , n ) = 1 / 2$ ，并且

$$
h (n, j) - h (n, j + 1) = \frac {1}{2 ^ {n + j}} \binom {n + j - 1} {n - 1}
$$

分部求和得到

$$
\begin{array}{l} S _ {n} = \sum_ {j = 1} ^ {n} h (n, j) = \frac {n}{2} + \sum_ {j = 1} ^ {n - 1} j \big (h (n, j) - h (n, j + 1) \big) \\ = \frac {n}{2} + \frac {n}{2 ^ {2 n - 1}} \sum_ {j = 1} ^ {n - 1} \binom {n + j - 1} {n} 2 ^ {n - 1 - j} \end{array}
$$

考虑长度为 $2 n - 1$ 且至少含有 $n + 1$ 个 1 的 0-1 串。由 0、1 互换的对称性，至少含有 n 个 1的串有 $2 ^ { 2 n - 2 }$ 个，去掉恰含 n 个 1 的串后，再按第 $n + 1$ 个 1 出现在第 $n + j$ 位分类，便有

$$
\sum_ {j = 1} ^ {n - 1} \binom {n + j - 1} {n} 2 ^ {n - 1 - j} = 2 ^ {2 n - 2} - \binom {2 n - 1} {n}
$$

因此

$$
S _ {n} = n - n \frac {\binom {2 n} {n}}{2 ^ {2 n}}
$$

令 $a _ { n } = { \binom { 2 n } { n } } / 2 ^ { 2 n }$ 。由 $a _ { n + 1 } = a _ { n } ( 2 n + 1 ) / ( 2 n + 2 )$ 可得

$$
S _ {n + 1} - S _ {n} = 1 - \frac {a _ {n}}{2} > 0
$$

所以只需比较 $n = 1 0 5$ 与 $n = 1 0 6$ 。记

$$
Q _ {n} = \frac {1 \cdot 3 \cdot 5 \cdots (2 n - 1)}{2 \cdot 4 \cdot 6 \cdots (2 n - 2)} = 2 n a _ {n}
$$

由 $( 2 k - 1 ) ^ { 2 } > ( 2 k - 2 ) ( 2 k )$ ，有

$$
Q _ {1 0 5} ^ {2} > \frac {(2 \cdot 4) (4 \cdot 6) \cdots (2 0 8 \cdot 2 1 0)}{2 ^ {2} \cdot 4 ^ {2} \cdots 2 0 8 ^ {2}} = 1 0 5 > 1 0 0
$$

故 $1 0 5 a _ { 1 0 5 } = Q _ { 1 0 5 } / 2 > 5$ ，从而 $S _ { 1 0 5 } < 1 0 0$ 。

另一方面，

$$
Q _ {1 0 6} = \frac {3 5}{1 2 8} \cdot \frac {9 \cdot 1 1 \cdot 1 3 \cdots 2 1 1}{1 0 \cdot 1 2 \cdot 1 4 \cdots 2 1 0}
$$

由 $( 2 k ) ^ { 2 } > ( 2 k - 1 ) ( 2 k + 1 )$ ，有

$$
\left(\frac {9 \cdot 1 1 \cdot 1 3 \cdots 2 1 1}{1 0 \cdot 1 2 \cdot 1 4 \cdots 2 1 0}\right) ^ {2} <   9 \cdot 2 1 1 = 1 8 9 9
$$

又因 $1 2 2 5 \cdot 1 8 9 9 < 1 5 3 6 ^ { 2 }$ ，故

$$
Q _ {1 0 6} <   \frac {3 5 \sqrt {1 8 9 9}}{1 2 8} <   1 2
$$

于是 $1 0 6 a _ { 1 0 6 } = Q _ { 1 0 6 } / 2 < 6$ ，从而 $S _ { 1 0 6 } > 1 0 0$ 。结合 $S _ { n }$ 的严格递增性，所求最小正整数为 106。
