设 M 是含有 n 个元素的集合。求所有函数 $f : 2 ^ { M }  \{ 0 , 1 , \cdots , n \}$ ，使每个非空集合$A \subseteq M$ 都有 $f ( A ) > 0$ ，且对任意 $A , B \subseteq M$ ，均有

$$
f (A \cup B) = f (A \cap B) + f (A \triangle B)
$$

其中 $A \triangle B = ( A \cup B ) \setminus ( A \cap B )$ 

解

唯一的函数是 $f ( A ) = \left| A \right|$ 。取 $A = B$ ，得到 $f ( \varnothing ) = 0$ 。任取 $W \subseteq M$ 及 $a \in M \setminus W$ ，在题设等式中取 $A = W \cup \{ a \} , \ B = W$ ，得到

$$
f (W \cup \{a \}) - f (W) = f (\{a \})
$$

添加元素的增量与背景集合无关，逐个累加得 $\begin{array} { r } { f ( A ) = \sum _ { a \in A } f ( \{ a \} ) } \end{array}$ 。各单点值都是正整数，而 $f ( M ) \leqslant n$ ，所以全部单点值均为 1。当 $n = 0$ 时也只有 $f ( \varnothing ) = 0$ 。反之， $f ( A ) = | A |$ 由并、交与对称差的基数关系立即满足条件。

$$
f (A) f (B) = f (A \cup B) f (A \cap B)
$$

## 解

答案为 $3 ^ { n } + 1 .$ 。所有子集均为红色时，条件成立，这给出一种染色。以下设至少存在一个蓝色子集，并取元素个数最少的蓝色子集 X。

任取蓝色子集 $B _ { \circ }$ 。因为 $f ( X ) f ( B ) > 0$ ，题设等式给出 $f ( X \cap B ) > 0$ ，所以 $X \cap B$ 包含某个蓝色子集 $C _ { \circ }$ 。 由 X 的极小性， $| C | \geqslant | X | ;$ ；又因 $C \subseteq X \cap B \subseteq X$ ，故 $C = X$ ，从而$X \subseteq B$ 。因此所有蓝色子集都包含 X，且 $f ( X ) = 1$ 

令 $R = S \setminus X$ ，对 $U \subseteq R$ 定义 $g ( U ) = f ( X \cup U ) > 0$ ，则 $g ( \emptyset ) = 1$ 。若 $i \in R \backslash U$ ，将$X \cup U$ 与 $X \cup \{ i \}$ 代入题设等式，得到

$$
g (U \cup \{i \}) = g (U) g (\{i \})
$$

因此添加元素 i 的乘法比值与背景集合无关；等价地， $\log _ { 2 } g$ 的单元素增量恒定。 $X \cup \{ i \}$ 中可能为蓝色的子集只有 X 与 $X \cup \{ i \}$ ，所以 $g ( \{ i \} ) \in \{ 1 , 2 \}$ 。令 $L = \left\{ i \in R : g ( \{ i \} ) = 2 \right\}$ ，沿逐个添加元素的链累积，得到

$$
g (U) = \prod_ {i \in U} g (\{i \}) = 2 ^ {| U \cap L |}
$$

下面对 $| U |$ 归纳，证明 $X \cup U$ 为蓝色当且仅当 $U \subseteq L \circ \ U = \emptyset$ 时成立。若 $U \subseteq L$ ，由归纳假设， $X \cup U$ 的蓝色真子集共有 $2 ^ { | U | } - 1$ 个，而 $g ( U ) = 2 ^ { | U | }$ ，所以它本身为蓝色。若 $U \not \subseteq L$ 其蓝色真子集恰对应于 $V \subseteq U \cap L$ ，共有 $2 ^ { | U \cap L | } = g ( U )$ 个，所以它本身为红色。因此蓝色子集恰为区间 $X \subseteq T \subseteq X \cup L$ C
