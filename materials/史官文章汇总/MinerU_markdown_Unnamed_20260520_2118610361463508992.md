## 解

(a) 如果 $x _ { 0 }$ 是函数 f 的不动点，那么 $( x _ { 0 } , x _ { 0 } )$ 在图像上。将该点绕原点顺时针旋转 $9 0 ^ { \circ }$ ，得到的 $( x _ { 0 } , - x _ { 0 } )$ 也在图像上，故

$$
x _ {0} = f (x _ {0}) = - x _ {0}
$$

所以 $x _ { 0 } = 0$ o

设 $f ( 0 ) = a$ ，图像旋转 $9 0 ^ { \circ }$ 之后是自己，则再旋转 $9 0 ^ { \circ }$ 之后还是自己，故而 $( 0 , - a )$ 也在图像上，得到 $a = 0$ 。所以 $f ( x ) = x$ 恰有一解，即是 $x = 0$ 的时候。

(b) 满足要求的图像绕原点旋转 $1 8 0 ^ { \circ }$ 后也保持不变，因此相应的函数是奇函数。我们先在非负实数上定义函数，再将它作奇延拓。

设区间

$$
A = \bigcup_ {k \in \mathbb {Z}} [ 4 ^ {k}, 2 \cdot 4 ^ {k}), \quad B = \bigcup_ {k \in \mathbb {Z}} [ 2 \cdot 4 ^ {k - 1}, 4 ^ {k})
$$

那么 A,B 是对正实数集的划分。设函数

$$
f (x) = \left\{ \begin{array}{l} 0, \quad x = 0 \\ - x / 2, \quad x \in A \\ 2 x, \quad x \in B \end{array} \right.
$$

再对 $x < 0$ 定义 $f ( x ) = - f ( - x )$ 0

若 $x \in A$ ，则 $x / 2 \in B$ ，所以

$$
f (f (x)) = f (- x / 2) = - f (x / 2) = - x
$$

若 $x \in B$ ，则 $2 x \in A$ ，所以

$$
f (f (x)) = f (2 x) = - x
$$

在 $x = 0$ 时该等式也成立；再由 f 的奇性可知，它对所有负数 x 也成立。因此对图像上的任意一点 $( x , f ( x ) )$ ，将其绕原点顺时针旋转 $9 0 ^ { \circ }$ 后得到

$$
(f (x), - x) = (f (x), f (f (x)))
$$

这仍是图像上的点。由于该旋转的四次方是恒等变换，图像在旋转后恰好变为自身，故 f 是满足要求的一个例子。

求证：存在函数 f,g : R → R 使得 $f \circ g$ 在 R 上单调递减，而 $g \circ f$ 在 R 上单调递增。

$$

$$
f (2 n) = f (f (f (n))) = 2 f (n)
$$

$$
f (4 k - 1) = f (f (4 k - 3)) = 2 (4 k - 3)
