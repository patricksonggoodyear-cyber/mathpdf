IMOSL 1969 Q8 

求所有定义在 R 上的函数 f，使得对一切实数 $x , y$ 都满足以下方程：

$$
x f (y) + y f (x) = (x + y) f (x) f (y)
$$

进一步证明：在所有满足上述条件的函数中，恰好只有两个函数是连续的。

解

在原方程中令 $x = y = t \neq 0$ ，得 $2 t f ( t ) = 2 t f ( t ) ^ { 2 }$ ，因此 $f ( t ) \in \{ 0 , 1 \}$ 。

若存在非零实数 a 使 $f ( a ) = 0$ ，则令 $x = a$ ，原方程化为 $a f ( y ) = 0$ ，对一切实数 y 成立，故 $f \equiv 0$ 

否则，对一切 $t \neq 0$ 均有 $f ( t ) = 1$ 。记 $f ( 0 ) = c ,$ ，其中 c 为任意实数。当 $x , y$ 均非零时，原方程两边同为 $x + y { \mathrm { } } ;$ ；当恰有一个为零时，两边同为另一个变量与 c 的乘积；当两者均为零时，两边均为零。因此这些函数都满足原方程。全部解为

$$
f \equiv 0, \qquad {\text {或}} \qquad f (x) = {\left\{ \begin{array}{l l} {c,} & {x = 0,} \\ {1,} & {x \neq 0,} \end{array} \right.} \quad c \in \mathbb {R}
$$

其中零函数连续；第二类函数在非零点处连续，在 0 处连续当且仅当 $c = 1$ 。故恰好有两个连续解，即 $f \equiv 0$ 和 $f \equiv 1$ 。

IMOSL 2001 A4 

求所有函数 f : R → R，使其对任意实数 x,y 满足

$$
f (x y) [ f (x) - f (y) ] = (x - y) f (x) f (y)
$$

解

在原式中令 y = 1，得到

$$
f (x) [ f (x) - f (1) x ] = 0
$$

所以 $f ( x ) \in \{ 0 , f ( 1 ) x \}$ ，特别地 $f ( 0 ) = 0 \mathrm { { } }$ 。若 $f ( 1 ) = 0$ ，则 $f \equiv 0$ 。以下设 $k = f ( 1 ) \neq 0$ ，并记

$$
G = \{x \in \mathbb {R}: f (x) \neq 0 \}
$$

由于 $f ( 0 ) = 0$ ，有 $G \subseteq \mathbb { R } ^ { \times }$ ，且 $1 \in G _ { \mathsf { c } }$ 。若 $t \not \in G$ 而 $x \in G$ ，将 $y = t$ 代入原式，得 $f ( x t ) f ( x ) = 0$ 故 $x t \not \in G _ { \mathfrak { c } }$ 。于是对任意 $a , b \in G$ ，必有 $a / b \in G \colon$ ：否则取 $t = a / b , \ x = b$ 就会推出 $a \not \in G { \mathfrak { c } }$ 。因G 非空且对商封闭，G 是 $\mathbb { R } ^ { \times }$ 的乘法子群。

故除零函数外，所有可能的解为

$$
f (x) = \left\{ \begin{array}{l l} k x, & x \in G, \\ 0, & x \notin G, \end{array} \right. \quad k \in \mathbb {R} \setminus \{0 \}, \quad G \leqslant \mathbb {R} ^ {\times}
$$

反过来，任取上述 $k , G _ { \circ }$ 。若 $x , y \in G$ ，则 $x y \in G$ ，原式两边都等于 $k ^ { 2 } x y ( x - y )$ ；若恰有一个不在 G，则其与另一个元素的乘积也不在 G，原式两边均为零；若 $x , y \notin G$ ，原式两边也均为零。零函数显然同样满足原式，因此以上即为全部解。

Russian Federal 2018 Grade 11 P7 

函数 f 定义在整个实数轴上，对一切实数 $x , y$ 满足条件

$$
f (x) + f (y) = 2 f \left(\frac {x + y}{2}\right) f \left(\frac {x - y}{2}\right)
$$

试问：f(x) 是否一定是偶函数？

解

令 $x = y = 0$ ，得 $f ( 0 ) = f ( 0 ) ^ { 2 }$ ，因此 $f ( 0 ) = 0$ 或 $f ( 0 ) = 1$ 

若 $f ( 0 ) = 0$ ，令 $y = x$ ，得 $2 f ( x ) = 2 f ( x ) f ( 0 ) = 0$ ，故 $f \equiv 0$ ，是偶函数。

若 $f ( 0 ) = 1$ ，令 $y = - x ,$ ，得 $f ( x ) + f ( - x ) = 2 f ( 0 ) f ( x ) = 2 f ( x )$ ，所以对一切实数 x 都有 $f ( - x ) = f ( x )$ 。综上，f 一定是偶函数。

Polish 3rd Round 2011 P4 

求所有定义在实数集且取值为实数的函数 $f , g$ ，使得对任意实数 $x , y$ 有

$$
f (x) f (y) = g (x) g (y) + g (x) + g (y)
$$

解

令 $h ( t ) = g ( t ) + 1$ ，则给定等式等价于

$$
f (x) f (y) + 1 = h (x) h (y) \qquad {\text {对任意}} x, y
$$

把 $x = y$ 代入得

$$
f (x) ^ {2} + 1 = h (x) ^ {2} \qquad {\text {对任意}} x.
$$

把原等式两边平方并利用上式，可得到

$$
2 f (x) f (y) = f (x) ^ {2} + f (y) ^ {2},
$$

从而 $( f ( x ) - f ( y ) ) ^ { 2 } = 0$ ，即 $f ( x ) = f ( y )$ 对任意 $x , y$ 成立，说明 f 为常函数。由此 h 也为常函数（若 h 非零且非常数可通过令 y 为某常数推出矛盾），所以 g 也是常函数。

令 $f ( x ) \equiv C \setminus g ( x ) \equiv D$ （常数），代入得

$$
C ^ {2} + 1 = (D + 1) ^ {2}.
$$

因此所有满足该关系的常数对 (C,D) 对应的常函数是一切解。

答案：所有形如 $f \equiv C , g \equiv D$ 的常函数，其中常数 $C , D$ 满足 $C ^ { 2 } + 1 = ( D + 1 ) ^ { 2 }$ C
