$$

$$

解

$$
g (x + 2 f (y)) = g (x) \quad (x, y \in \mathbb {R})
$$

记 $g$ 的平移不变量集合为

$$
T = \{t \in \mathbb {R}: g (x + t) = g (x) \text {对一切} x \in \mathbb {R} \text {成立} \}
$$

于是 $2 f ( y ) \in T$ 对所有实数 y 成立。若 $a , b \in T$ ，则 $g ( x + a - b ) = g ( x - b ) = g ( x )$ ，故$a - b \in T$ 

若 $f \equiv 0$ ，则直接满足原方程。以下设 f 不恒为零，选取 $y _ { 0 }$ 使 $p = 2 f ( y _ { 0 } ) \neq 0$ ，则 $p \in T .$ 0由 $g ( y + p ) = g ( y )$ 可得 $f ( y + p ) - f ( y ) = 2 p y + p ^ { 2 }$ 。另一方面， $2 f ( y + p )$ 与 $2 f ( y )$ 均属于 T，所以

$$
4 p y + 2 p ^ {2} = 2 f (y + p) - 2 f (y) \in T \qquad (y \in \mathbb {R})
$$

由于 $p \neq 0$ ，当 y 遍历实数时， $4 p y + 2 p ^ { 2 }$ 也遍历实数。因此 $T = \mathbb { R }$ ，从而对任意实数 $x$ 都有$g ( x ) = g ( 0 )$ 。记 $c = g ( 0 )$ ，便得到 $f ( x ) = x ^ { 2 } + c _ { \mathsf { S } }$ 

最后， $f \equiv 0$ 显然满足原方程；对于任意实数 c，若 $f ( x ) = x ^ { 2 } + c$ ，则

$$
f (x + f (y)) - f (x - f (y)) = (x + f (y)) ^ {2} - (x - f (y)) ^ {2} = 4 x f (y)
$$

故它也满足原方程。综上，全部解为 $f ( x ) \equiv 0$ ，或 $f ( x ) = x ^ { 2 } + c .$ ，其中 c 为任意实数。

$$
f (x + f (y)) - f (x) = (x + f (y)) ^ {4} - x ^ {4}
$$

解

全部解为 $f ( x ) \equiv 0$ ，以及 $f ( x ) = x ^ { 4 } + C$ ，其中 C 为任意实数。

令 $g ( x ) = f ( x ) - x ^ { 4 }$ ，原方程化为

$$
g (x + f (y)) = g (x) \qquad (x, y \in \mathbb {R})
$$

定义 g 的平移不变量集合

$$
H = \{h \in \mathbb {R}: g (x + h) = g (x) \text {对一切} x \in \mathbb {R} \text {成立} \}
$$

显然 $0 \in H$ 。若 $u , v \in H$ ，则对任意实数 x，都有 $g ( x + u - v ) = g ( x - v ) = g ( x )$ ，故 $u - v \in H$ o由原方程可知，对任意实数 y，都有 $f ( y ) \in H$ 。

$$
f (y + a) - f (y) = (y + a) ^ {4} - y ^ {4}
$$

另一方面， $f ( y + a ) , f ( y ) \in H$ ，而 H 对取差封闭，因此对任意实数 y，都有 $( y + a ) ^ { 4 } - y ^ { 4 } \in H$ 注意到

$$
(y + a) ^ {4} - y ^ {4} = 4 a y ^ {3} + 6 a ^ {2} y ^ {2} + 4 a ^ {3} y + a ^ {4}
$$

$$
f (x + f (y)) - f (x) = (x + f (y)) ^ {4} + C - (x ^ {4} + C) = (x + f (y)) ^ {4} - x ^ {4}

$$
f (x - f (y)) = f (x + y ^ {n}) + f (f (y) + y ^ {n})
$$

令 $x = f ( y )$ ，则

$$
f (f (y) + y ^ {n}) = \frac {1}{2} f (0)
$$

令 $z = x - f ( y )$ ，则

$$
x + y ^ {n} = z + f (y) + y ^ {n}
$$

于是有

$$
f (z) = f (z + f (y) + y ^ {n}) + \frac {1}{2} f (0)\tag{1}
$$

令 $S = \{ f ( y ) + y ^ { n } | y \in \mathbb { R } \}$ 。下面分两种情形讨论：

情形一，S 中仅含一个元素，于是存在常数 a 使得 $f ( y ) \equiv a - y ^ { n }$ 对任意 y 成立。代入(1) 式即得

$$
a - z ^ {n} = - (z + a) ^ {n} + a + \frac {1}{2} a
$$

对所有实数 z 成立，故 $a = 0$ 。易验证 $f ( x ) = - x ^ { n }$ 满足要求。

情形二，S 含有多于一个元素。由 (1) 式知对任意 $s \in S$ ，都有

$$
f (z) = f (z + s) + \frac {1}{2} f (0)
$$

于是对 $s _ { 1 } , s _ { 2 } \in S$ 成立，进而 $f ( z + s _ { 1 } ) = f ( z + s _ { 2 } )$ ，即 f 是以 $s _ { 1 } - s _ { 2 }$ 为周期的周期函数。由于 S 至少含有两个元素，故存在 $\lambda > 0$ ，使得 f 以 λ 为周期。于是

$$
[ f (y + \lambda) + (y + \lambda) ^ {n} ] - [ f (y) + y ^ {n} ] = (y + \lambda) ^ {n} - y ^ {n}
$$

也是 f 的周期。这是关于 y 的 $n - 1$ 次多项式，首项系数 $n \lambda > 0$ ，可以取到充分大的所有实数，即充分大的实数均为 f 的周期，于是所有实数均为 f 的周期，这样 f 是常数函数。由(1) 式即知 $f ( 0 ) = 0$ ，易验证 $f ( x ) \equiv 0$ 满足要求。

综上所述，所有满足要求的函数为 $f ( x ) = - x ^ { n }$ 和 $f ( x ) \equiv 0$ C

(i) $f ( x ) = x \circ$ 

(ii) $f ( x ) \equiv 0$ 

(iii) 任取集合 $X \subseteq ( - \infty , - 2 / 3 )$ ，定义

$$

一、和积换元，明确参数的可达范围。令 $z = x + y , t = x y$ 。实数 $x , y$ 是方程 $u ^ { 2 } - z u + t = 0$ 的两根，因此给定实数 $z , t$ 后，这样的 $x , y$ 存在当且仅当 $z ^ { 2 } \geqslant 4 t$ 。设 $g ( t ) = 2 ( f ( t ) - t )$ ，利用 $x ^ { 2 } + y ^ { 2 } = z ^ { 2 } - 2 t$ ，原方程等价于

$$
f \big (z ^ {2} + g (t) \big) = f (z) ^ {2} \qquad (z ^ {2} \geqslant 4 t)\tag{1}
$$

$$
f (z ^ {2} + c) = f (z) ^ {2} \qquad (z \in \mathbb {R})\tag{2}
