设 P 是一个凸多边形。求证：在 P 内存在一个凸六边形，其面积至少是 P 的面积的 $3 / 4$ 

## 解

以下以 [R] 表示图形 R 的面积。在 P 内取一个面积最大的三角形 ABC，记 $[ A B C ] = S ,$ 。过 A,B,C 分别作 BC,CA,AB 的平行线，它们围成三角形 $A _ { 1 } B _ { 1 } C _ { 1 }$ ，其中 $A \in B _ { 1 } C _ { 1 } , B \in$ $C _ { 1 } A _ { 1 } , C \in A _ { 1 } B _ { 1 }$ 。

多边形 P 完全包含在 $\triangle A _ { 1 } B _ { 1 } C _ { 1 }$ 内。事实上，如果 P 中有一点 X 位于直线 $B _ { 1 } C _ { 1 }$ 的异于 BC 一侧，那么 X 到直线 BC 的距离大于 A 到直线 BC 的距离，于是 $[ X B C ] > [ A B C ]$ 与 ABC 的最大性矛盾。对另外两边作同样讨论即可得到上述结论。

在直线 BC 的异于 A 一侧作 P 的一条平行于 BC 的支撑线 $\ell _ { a }$ ；类似地作支撑线 $\ell _ { b } \parallel C A$ 与 $\ell _ { c } \parallel A B$ ，它们分别位于直线 CA 的异于 B 一侧和直线 AB 的异于 C 一侧。三条支撑线与 $\triangle A _ { 1 } B _ { 1 } C _ { 1 }$ 的三边共同围成一个包含 P 的凸六边形 H。记三条支撑线在 H 上截得的边分别为 $U _ { a } V _ { a } , U _ { b } V _ { b } , U _ { c } V _ { c }$ ，并取

$$
A _ {0} \in P \cap U _ {a} V _ {a}, \qquad B _ {0} \in P \cap U _ {b} V _ {b}, \qquad C _ {0} \in P \cap U _ {c} V _ {c}
$$

这六点在 P 的边界上依次排列为 $A , C _ { 0 } , B , A _ { 0 } , C , B _ { 0 }$ ，因而由 P 的凸性，它们构成的凸六边形 $Q = A C _ { 0 } B A _ { 0 } C B _ { 0 }$ 包含在 P 内。

$$
x = [ A _ {0} B C ], \qquad y = [ B _ {0} C A ], \qquad z = [ C _ {0} A B ], \qquad t = x + y + z
$$

六边形 Q 由 ABC 及其三边外侧的三个三角形组成，因此

$$
[ Q ] = S + t
$$

下面估计外六边形 H 的面积。由于 A,B,C 分别是 $B _ { 1 } C _ { 1 } , C _ { 1 } A _ { 1 } , A _ { 1 } B _ { 1 }$ 的中点，所以$[ A _ { 1 } B C ] = S$ 。线段 $U _ { a } V _ { a }$ 平行于 BC，而它与 BC 之间以 BC 为底的三角形面积为 x，故由相似三角形可得

$$
[ A _ {1} U _ {a} V _ {a} ] = \frac {(S - x) ^ {2}}{S}
$$

从而 BC 与 $U _ { a } V _ { a }$ 之间的四边形面积为 $2 x - x ^ { 2 } / S$ 。同理，另外两个相应四边形的面积分别为$2 y - y ^ { 2 } / S$ 与 $2 z - z ^ { 2 } / S$ 。于是由 $P \subseteq H$ 及柯西不等式可得

$$
[ P ] \leqslant [ H ] = S + 2 t - \frac {x ^ {2} + y ^ {2} + z ^ {2}}{S} \leqslant S + 2 t - \frac {t ^ {2}}{3 S}
$$

最后，由上式与 $[ Q ] = S + t$ ，有

$$
\begin{array}{r} 4 [ Q ] - 3 [ P ] \geqslant 4 (S + t) - 3 \left(S + 2 t - \frac {t ^ {2}}{3 S}\right) \\ = S - 2 t + \frac {t ^ {2}}{S} = \frac {(S - t) ^ {2}}{S} \geqslant 0 \end{array}
$$

因此 $[ Q ] \geqslant 3 [ P ] / 4$ ，而 Q 是包含在 P 内的凸六边形，命题得证。

设 P 是关于点 O 对称的凸多边形。求证：存在覆盖 P 的平行四边形 R，使得

$$
\frac {| R |}{| P |} \leqslant \sqrt {2}
$$

其中 $| R | , | P |$ 分别表示 R,P 的面积。

解

在 P 中取点 A,B，使 $\triangle O A B$ 的面积最大，并记 $A ^ { \prime } , B ^ { \prime }$ 分别为 A,B 关于点 O 的对称点。过点 A 作直线 $a \parallel O B$ ，过点 B 作直线 $b \parallel O A$ ，再记 $a ^ { \prime } , b ^ { \prime }$ 分别为 a,b 关于点 O 的对称直线。设这四条直线围成平行四边形 $R _ { 1 }$ 

我们先证明 $P \subseteq R _ { 1 }$ 。否则，存在点 $Z \in P$ ，使得 $a , b , a ^ { \prime } , b ^ { \prime }$ 中至少有一条直线将 O 与 Z分开。若该直线为 a，则由于 $a \parallel O B$ ，点 Z 到直线 OB 的距离大于点 A 到直线 OB 的距离，从而 $[ O Z B ] > [ O A B ]$ ，与 $\triangle O A B$ 的选取矛盾。对于直线 b 情形相同；对于直线 $a ^ { \prime } , b ^ { \prime }$ ，利用P 关于点 O 对称即可化归到前两种情形。因此 $P \subseteq R _ { 1 }$ 

点 $A , B , A ^ { \prime } , B ^ { \prime }$ 分别是 $R _ { 1 }$ 四条边的中点。记以这四点为顶点的平行四边形为 $R _ { 2 }$ 。由 $P$ 的凸性知 $R _ { 2 } \subseteq P$ ，并且 $| R _ { 1 } | = 2 | R _ { 2 } |$ 。

仿射变换保持 $\ntrianglerighteq$ 性、中心对称性、包含关系以及面积之比。作一个仿射变换，将 $R _ { 1 }$ 化为正方形。不妨设

$$
O = (0, 0), \quad A = (1, 0), \quad B = (0, 1), \quad A ^ {\prime} = (- 1, 0), \quad B ^ {\prime} = (0, - 1)
$$

此时 $R _ { 1 } = [ - 1 , 1 ] ^ { 2 }$ ，而 $R _ { 2 }$ 是以上述四点为顶点、面积为 2 的正方形。记

$$
\alpha = \max _ {(u, v) \in P} (u + v), \quad \beta = \max _ {(u, v) \in P} (v - u)
$$

由 P 关于原点对称以及 $R _ { 2 } \subseteq P \subseteq R _ { 1 }$ ，有 $1 \leqslant \alpha , \beta \leqslant 2$ 。于是平行四边形

$$
R _ {3} = \{(u, v): | u + v | \leqslant \alpha , | v - u | \leqslant \beta \}
$$

覆盖 P，且它的边分别平行于 $R _ { 2 }$ 的边。比较 $R _ { 3 }$ 与 $R _ { 2 }$ 在这两个方向上的宽度，得到 $| R _ { 3 } | =$ $\alpha \beta | R _ { 2 } |$ 

在 P 中取点 $U = ( u _ { 1 } , v _ { 1 } )$ 和 $V = ( u _ { 2 } , v _ { 2 } )$ ，使得 $u _ { 1 } + v _ { 1 } = \alpha , v _ { 2 } - u _ { 2 } = \beta$ 。由于 $P \subseteq [ - 1 , 1 ] ^ { 2 }$ 且 $\alpha , \beta \geqslant 1$ ，点 U 位于由射线 OA,OB 所夹的区域内，点 V 位于由射线 $O B , O A ^ { \prime }$ 所夹的区域内。由凸性，四边形 OAUB 和 OBVA′ 都包含在 P 中，其面积分别为

$$
[ O A U B ] = [ O A B ] + [ A B U ] = \frac {1}{2} + \frac {\alpha - 1}{2} = \frac {\alpha}{2}
$$

而 $[ O B V A ^ { \prime } ] = \beta / 2$ 。再考虑它们关于点 O 的对称图形，这四个四边形的内部互不相交且都包含在 P 中。因此

$$
| P | \geqslant \alpha + \beta = \frac {\alpha + \beta}{2} | R _ {2} |
$$

利用算术平均数不小于几何平均数，结合以上各式可得

$$
\left| R _ {1} \right| \left| R _ {3} \right| = 2 \alpha \beta \left| R _ {2} \right| ^ {2} \leqslant 2 \left(\frac {\alpha + \beta}{2} \left| R _ {2} \right|\right) ^ {2} \leqslant 2 | P | ^ {2}
$$

故 $| R _ { 1 } |$ 与 $| R _ { 3 } |$ 中至少有一个不超过 ${ \sqrt { 2 } } | P |$ 。由于 $R _ { 1 }$ 和 $R _ { 3 }$ 都覆盖 P，取其中面积较小者作为 R，即得结论。

求最小的正实数 α，使得对任意面积为 1 的凸多边形 P，都存在平面上一点 M，使得$P \cup Q$ 的凸包面积不超过 α，其中 Q 是 P 关于点 M 的中心对称图形。

## 解

答案是 α = 2。以下用 [F] 表示图形 F 的面积，凸多边形均包含其内部与边界。

先证明 $\alpha = 2$ 满足要求。我们将构造一个包含 P、面积不超过 2 的平行四边形 R。取 R的中心为 M，则 P 关于 M 的中心对称图形 Q 也包含在 R 内，由 R 的凸性可知 $P \cup Q$ 的凸包同样包含在 R 内。

如果 P 是三角形，取一边中点为中心作中心对称，原三角形与其对称图形恰好拼成面积为 2 的平行四边形。以下设 P 至少有四个顶点；若边上有冗余的共线顶点，先将它们略去。在以 P 的四个顶点为顶点的所有四边形中，取面积最大的一个，按边界顺序记为 ABCD。

分别过 A,C 作平行于 BD 的直线 $\ell _ { A } , \ell _ { C }$ 。断言 P 位于这两条平行线之间。否则，不妨有顶点 X 越过 $\ell _ { A }$ ，位于不含 C 的一侧，则 X 到 BD 的距离大于 A 到 BD 的距离。由于所取各点都是 P 的顶点， $X , B , C , D$ 构成凸四边形，且 $X , C$ 位于 BD 的两侧，于是

$$
[ X B C D ] = [ X B D ] + [ C B D ] > [ A B D ] + [ C B D ] = [ A B C D ]
$$

这与 ABCD 面积最大矛盾。越过 $\ell _ { C }$ 的情形同理。

同样，分别过 $B , D$ 作平行于 AC 的直线 $\ell _ { B } , \ell _ { D }$ ，则 P 也位于这两条平行线之间。因此，这两条带状区域的交集是一个包含 P 的平行四边形 R。设 AC 与 BD 所成的一个夹角为 θ，则 R 的两条邻边长分别为 AC,BD，从而

$$
[ R ] = A C \cdot B D \sin \theta = 2 [ A B C D ] \leqslant 2 [ P ] = 2
$$

这就证明 ${ \textsf { T } } \alpha = 2$ 满足要求。

再证明 α 不能小于 2。取面积为 1 的三角形 ABC 作为 P。对平面上任意一点 M，记$B , C$ 关于 M 的对称点分别为 $A ^ { \prime } , B ^ { \prime } , C ^ { \prime }$ ，并记这六点的凸包为 K。

令 $x , y , z$ 分别为点 M 到直线 $B C , C A , A B$ 的有向距离与对应顶点 $A , B , C$ 到该直线的距离之比，各自以对应顶点所在的一侧为正。由有向面积相加，有 $x + y + z = 1$ ；这里允许$x , y , z$ 为负，因此没有预先限制 M 的位置。

若其中一个数不小于 $1 / 2$ ，不妨设 $x \geqslant 1 / 2$ ，则 K 包含以 BC 和 $B ^ { \prime } C ^ { \prime }$ 为对边的平行四边形。设 A 到 BC 的距离为 h，则这两条对边之间的距离为 2xh，所以

$$
[ K ] \geqslant B C \cdot 2 x h = 4 x [ A B C ] = 4 x \geqslant 2
$$

以下设 $x , y , z$ 均小于 $1 / 2 .$ 。由 $x + y + z = 1$ 可知三者均为正，故 M 位于三角形 ABC 内部。此时 A′ 位于 BC 的外侧，而 A,M,A′ 共线且 M 是 AA′ 的中点，故 A′ 位于角 BAC 内；三角形 BCA′ 的面积为 $1 - 2 x$ 。类似地，三角形 $C A B ^ { \prime } , A B C ^ { \prime }$ 的面积分别为 $1 - 2 y , 1 - 2 z$ 这三个三角形分别位于三角形 $A B C$ 的三条边外侧，且各自不越过另外两边，所以它们与三角形 $A B C$ 的内部两两不交，并且全部包含在 K 中。因此

$$
[ K ] \geqslant 1 + (1 - 2 x) + (1 - 2 y) + (1 - 2 z) = 2
$$

综上，对这个面积为 1 的三角形，无论如何选择 M，所得凸包的面积都不小于 2，故所求最小值为 2。

平面上给定一点O 和n个向量 $\mathbf { \Phi } _ { { \pmb { a } } _ { 1 } , { \pmb { a } } _ { 2 } , \dots { \ b { a } } _ { n } } , $ ，它们的和为零。每一种排列 ${ \pmb a } _ { i _ { 1 } } , { \pmb a } _ { i _ { 2 } } , \cdots , { \pmb a } _ { i _ { r } }$ 都确定一列点 $A _ { 0 } , A _ { 1 } , \ldots , A _ { n }$ ，其中 $A _ { 0 } = A _ { n } = O$ ，且

$$
\overrightarrow {A _ {k - 1} A _ {k}} = \pmb {a} _ {i _ {k}} \qquad (k = 1, 2, \dots , n)
$$

求证：存在一种排列，使得点 $A _ { 1 } , A _ { 2 } , \cdots , A _ { n - }$ 全部位于某个以 O 为顶点的 $6 0 ^ { \circ }$ 角的内部或边界上。

解

零向量可以插入排列中的任意位置，故只需考虑非零向量。如果所有非零向量共线，先依次排列同向于某条射线的向量，再排列反向向量，即可使所有点位于该射线上。以下设这些向量不全共线。

按照方向角的顺序排列这些向量，并将它们首尾相接，得到一个以 $A _ { 0 }$ 为起点的凸多边形。由于向量之和为零，这个多边形是闭合的。以下只考虑它的顶点，并从中选取一个面积最大的三角形 $A B C$ 。

分别过 $A , B , C$ 作直线，使其平行于 $B C , C A , A B .$ 。这三条直线围成一个三角形 $A ^ { \prime } B ^ { \prime } C ^ { \prime }$ 原凸多边形完全包含在 $A ^ { \prime } B ^ { \prime } C ^ { \prime }$ 内；否则，若有顶点越过其中一条边，则用该顶点替换 A,B,C中与这条边对应的顶点，便会得到一个面积大于 $A B C$ 的三角形，矛盾。

在原多边形的边界上，A,B,C 将边界分成三段。由上述包含关系，从 A 到 B 且不经过C 的一段折线位于三角形 $A C ^ { \prime \prime } B$ 内，其中 C′ 是过 A 的平行于 BC 的直线与过 B 的平行于CA 的直线的交点。点 $C ^ { \prime }$ 关于线段 AB 的中点的中心对称点恰为 C。因此，将这段折线关于AB 的中点作中心对称，再反向行走，便得到一段从 A 到 B、完全位于三角形 ABC 内的折线；它所使用的向量正是原来这一段中的向量，只是次序相反。

对从 B 到 C 以及从 C 到 A 的两段折线作同样处理，再将所得三段折线依次连接，就得到一条完全位于三角形 ABC 内的闭合折线。它的各条有向边恰好是给定的 n 个向量，每个向量使用一次，因而给出了这些向量的一种排列。

三角形 ABC 至少有一个内角不大于 $6 0 ^ { \circ }$ 。将上述闭合折线循环改换起点，使这个角的顶点成为起点，再整体平移，使该顶点与 O 重合。此时折线的各条有向边仍依次给出原向量的一种排列，而所有顶点都位于这个以 O 为顶点、大小不超过 $6 0 ^ { \circ }$ 的角内。必要时将该角扩大至 60◦，即得所求。

求证：可以在中心对称的凸多边形内放入一个面积不小于该多边形面积一半的菱形。

## 解

设 O 为对称中心，A 为距离 O 最远的一个顶点，B 为 A 关于 O 的对称点。过 A,O,B分别作直线 AB 的垂线 $\ell _ { A } , \ell _ { O } , \ell _ { B } \mathrm { ~ }$ 。由于任意点在 AB 方向上的投影长度都不超过它到 O 的距离，而后者不超过 OA，所以 $\ell _ { A }$ 与 $\ell _ { B }$ 之间的带状区域包含整个多边形。

设 $\ell _ { O }$ 与多边形边界的两个交点为 C,D。由中心对称性，C,D 关于 O 对称。过 C 作多边形的一条支撑线 $\ell _ { 1 }$ ，并令 $\ell _ { 2 }$ 为 $\ell _ { 1 }$ 关于 O 的对称直线；于是 $\ell _ { 2 }$ 经过 D，且整个多边形也夹在 $\ell _ { 1 } , \ell _ { 2 }$ 之间。

四条直线 $\ell _ { A } , \ell _ { B } , \ell _ { 1 } , \ell _ { 2 }$ 围成一个包含原多边形的平行四边形 UVWT。线段 AB 与 CD 在O 处互相垂直且彼此平分，所以四边形 ACBD 是菱形。又因 $\ell _ { A } , \ell _ { B }$ 之间的距离为 AB，而$\ell _ { 1 } , \ell _ { 2 }$ 在任一条平行于 CD 的直线上截得的线段长度均为 CD，故

$$
[ U V W T ] = A B \cdot C D, \quad [ A C B D ] = \frac {1}{2} A B \cdot C D = \frac {1}{2} [ U V W T ]
$$

由于原多边形包含在 UVWT 内，故 $[ A C B D ] = [ U V W T ] / 2$ 不小于原多边形面积的一半。另一方面，A,C,B,D 都在原多边形的边界上，由凸性知菱形 ACBD 包含在原多边形内，命题得证。

Moscow MO 2008 Grade 11 P7 

对于下列三个条件，分别判断是否对任意多面体都能找到 4 个顶点，使得以它们为顶点的四面体在任意平面上的正交投影面积与原多面体在该平面上的正交投影面积之比满足相应条件：

(a) 大于 1/4；

(b) 不小于 1/9；

(c) 不小于 1/7。

## 解

答案：（a）不能；（b）可以；（c）可以。

（a）正八面体 ABCDEF 即为反例。正八面体的对称变换在所有由 4 个不共面顶点组成的集合上传递，故不失一般性，可设所选顶点为 A,B,C,F。设正方形 BCDE 的中心为 O。四面体 ABCF 在平面 BCD 上的正交投影为 $\triangle { O B C }$ ，而正八面体在该平面上的正交投影为正方形 BCDE，两者的面积比恰为 1/4，不满足严格大于 $1 / 4$ 的要求。

（b）在任一多面体 Λ 上选取四个顶点 A,B,C,D，使得它们所形成的四面体具有最大可能的体积；若这样的四面体不止一个，则任取其中之一。以 α 表示经过顶点 A 的平行于 BCD的平面。如果在 Λ 上存在这样的顶点 F，它与顶点 B,C,D 不在平面 α 的同侧，则四面体FBCD 的体积大于四面体 ABCD，此与对顶点 A,B,C,D 的选取相矛盾。这就表明，在平面 α 把空间所分成的两个部分中，多面体 Λ 只与其中的一个部分有公共点。经过类似的讨论可知，对于经过顶点 B 的平行于 ACD 的平面 $\beta _ { i }$ ，对于经过顶点 C 的平行于 ABD 的平面 γ和对于经过顶点 D 的平行于 ABC 的平面 δ，都有相应的结论。这就证明了，多面体 Λ 整个位于由平面 $\alpha , \beta , \gamma$ 和 δ 所围成的四面体 $A ^ { \prime } B ^ { \prime } C ^ { \prime } D ^ { \prime }$ 之中。

在四面体 ABCD 中，连接一个顶点与其对面重心的线段称为中线。四条中线交于同一点G，且 G 将每条中线按 3 : 1 分割，其中靠近顶点的一段占 3 份。考虑以 G 为中心、系数为−3 的位似变换。它把四面体 ABCD 的四个面所在的平面分别变为 $\alpha , \beta , \gamma , \delta$ ，因此把 ABCD变为外接四面体 $A ^ { \prime } B ^ { \prime } C ^ { \prime } D ^ { \prime }$ 

所以四面体 ABCD 与 $A ^ { \prime } B ^ { \prime } C ^ { \prime } D ^ { \prime }$ 位似，位似系数为 −1/3；同时 A,B,C,D 分别是外接四面体四个侧面的重心。正交投影保持位似关系，故在任意平面 Π 上，两四面体的投影面积之比为 $1 / 9$ 。又因 $\Lambda \subseteq A ^ { \prime } B ^ { \prime } C ^ { \prime } D ^ { \prime }$ ，所以 Λ 在 Π 上的投影面积不超过 ABCD 在 Π 上的投影面积的 9 倍，故（b）成立。

（c）继续使用（b）中的构型。分别作平面 $\alpha , \beta , \gamma , \delta$ 关于平面 $B C D , A C D , A B D , A B C$ 的对称平面 $\alpha ^ { \prime } , \beta ^ { \prime } , \gamma ^ { \prime } , \delta ^ { \prime } \circ$ 与（b）中的最大体积论证相同，Λ 位于上述每一对对称平面之间。因此，Λ 包含在由 $\alpha , \beta , \gamma , \delta , \alpha ^ { \prime } , \beta ^ { \prime } , \gamma ^ { \prime } , \delta ^ { \prime }$ 围成的多面体 Ω 内。

由于 $A , B , C , D$ 分别是外接四面体四个侧面的重心，平面 $B C D , A C D , A B D , A B C$ 在相应棱上给出的分点比均为 2 : 1；反射后的平面 $\alpha ^ { \prime } , \beta ^ { \prime } , \gamma ^ { \prime } , \delta ^ { \prime }$ 则给出相反的 1 : 2 分点比。因此Ω 是从外接四面体 A′B′C′D′ 的四个顶角各截去一个小四面体后得到的截角四面体。

对 ABCD 的任一侧面 F，Ω 有两个侧面与 F 平行：一个是与 F 全等的三角形，另一个是六边形。后者所在的外接四面体侧面与 $F$ 的相似比为 3，面积为 F 的 9 倍；它的三个角各被截去一个与 F 全等的三角形，故该六边形的面积为 F 的 6 倍。因此，这一对平行侧面的面积之和为 F 面积的 7 倍。

对任意凸多面体，其在平面 上的正交投影面积等于所有侧面在 上的正交投影面积之和的一半。将 Ω 的侧面按上述四对平行方向分组，并注意平行图形投影时具有相同的面积缩放因子，可知 Ω 在 Π 上的投影面积恰为 ABCD 在 Π 上的投影面积的 7 倍。由于 $\Lambda \subseteq \Omega$ Λ 在 Π 上的投影面积不超过 ABCD 投影面积的 7 倍，故（c）成立。
