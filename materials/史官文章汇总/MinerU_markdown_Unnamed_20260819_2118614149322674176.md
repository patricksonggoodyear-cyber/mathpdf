集合 $\{ 1 0 ^ { m } : m \in \mathbb { Z } \}$ 在正实数中是离散的，所以当 h 充分大时必有 $m _ { h } = t _ { \mathfrak { c } }$ 。于是多项式$P ^ { \prime } ( x ) - 1 0 ^ { t } Q ^ { \prime } ( x )$ 有无穷多个根，只能恒为零。因此 $P ( x ) - 1 0 ^ { t } Q ( x )$ 为常值多项式。
