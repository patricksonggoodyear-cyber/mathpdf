## Turkey 2nd Round 2017 P1

一次婚礼有 25 道菜，从 2017 名居民中邀请一些人参加。每个人至少喜欢一道菜，每道菜也至少有人喜欢。如果受邀者中每道菜都至少有一人喜欢，称受邀者集合为合适名单。称一个居民集合为美食团，如果它与每个合适名单都有公共成员。证明：若一个美食团的每个真子集都不是美食团，则存在一道菜被这个美食团中的所有人喜欢。

## 解

记喜欢第 i 道菜的居民集合为 $F _ { i }$ ，其中 $1 \leqslant i \leqslant 2 5$ 。一个名单合适，当且仅当它与每个$F _ { i }$ 都相交。因此每个 $F _ { i }$ 都与全部合适名单相交，本身就是美食团。

设 X 为题设中的美食团。若 X 不包含任何一个完整的 $F _ { i }$ ，则每个 $F _ { i } \setminus$ X 都非空，可分别取 $x _ { i } \in F _ { i } \setminus X$ 。名单 $L = \{ x _ { 1 } , \cdot \cdot \cdot , x _ { 2 5 } \}$ 与每个 $F _ { i }$ 相交，所以是合适名单；但 $L \cap X = \emptyset$ 与 X 是美食团矛盾。
