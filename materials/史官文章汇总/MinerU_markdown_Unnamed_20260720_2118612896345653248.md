All-Russian 2019 Grade 11 P1 

在平面上的每个点 X 处都标有一个实数 f(X)。已知只要点 M 是 $\triangle A B C$ 的重心，就有$f ( M ) = f ( A ) + f ( B ) + f ( C )$ 。求证：对于平面上的任意点 X，都有 $f ( X ) = 0$ 。

## 解

任取平面上一点 M。选取一个以 M 为重心的非退化三角形 $\triangle A B C$ ，再分别令 D,E,F为 $\triangle B C M , \triangle C A M , \triangle A B M$ 的重心。由重心的向量表示，

$$
\overrightarrow {M D} = - \frac {1}{3} \overrightarrow {M A}, \qquad \overrightarrow {M E} = - \frac {1}{3} \overrightarrow {M B}, \qquad \overrightarrow {M F} = - \frac {1}{3} \overrightarrow {M C}
$$

因此， $D , E , F$ 分别是 A,B,C 在以 M 为中心、位似比为 1/3 的位似下的像，故 M 也是$\triangle D E F$ 的重心。

依次对 $\triangle D E F , \triangle B C M , \triangle C A M , \triangle A B M$ 应用题设条件，并利用 M 是 $\triangle A B C$ 的重心，得到

$$
\begin{array}{r l} & f (M) = f (D) + f (E) + f (F) \\ & \quad = [ f (B) + f (C) + f (M) ] + [ f (C) + f (A) + f (M) ] + [ f (A) + f (B) + f (M) ] \\ & \quad = 2 [ f (A) + f (B) + f (C) ] + 3 f (M) \\ & \quad = 5 f (M) \end{array}
$$

于是 $f ( M ) = 0$ 。由于点 M 是任意的，故对于平面上的任意点 X，都有 $f ( X ) = 0$ 

## Putnam 2009 A1

设 f 是定义在平面上的实值函数，且对平面上的任意正方形 ABCD，均有 $f ( A ) + f ( B ) +$ $f ( C ) + f ( D ) = 0$ 。是否由此必然可知，对平面上的任意一点 P，都有 $f ( P ) = 0 ?$ 

答案是肯定的。任取平面上一点 P，作一个以 P 为中心的正方形 $A B C D$ 。设 $E , F , G , H$ 依次为 $A B , B C , C D , D A$ 的中点，于是 $E F G H$ 、AEPH、BFPE、CGPF、DHPG 均为正方形。将题设条件分别用于这六个正方形，得到

$$
\begin{array}{r l} & f (A) + f (B) + f (C) + f (D) = 0 \\ & f (E) + f (F) + f (G) + f (H) = 0 \\ & f (A) + f (E) + f (P) + f (H) = 0 \\ & f (B) + f (F) + f (P) + f (E) = 0 \\ & f (C) + f (G) + f (P) + f (F) = 0 \\ & f (D) + f (H) + f (P) + f (G) = 0 \end{array}
$$

将最后四个等式相加，再减去第一个等式和第二个等式的两倍，得到 $4 f ( P ) = 0$ ，即 $f ( P ) = 0$ 0由于 P 是任意点，所以 f 在整个平面上恒等于零。

Romania TST 1996 P1 

设 $n > 2$ 为整数，函数 $f : \mathbb { R } ^ { 2 } $ R 满足：对任意正 n 边形 $A _ { 1 } A _ { 2 } \dotsm A _ { n }$ ，都有

$$
f (A _ {1}) + f (A _ {2}) + \dots + f (A _ {n}) = 0
$$

证明 f 是零函数。

解

将平面视为复平面 C，令 $\zeta = e ^ { 2 \pi \mathrm { i } / n }$ 。固定任意 $z \in \mathbb { C }$ 。对每个 $k = 1 , 2 , \cdots , n$ ，点

$$
z - \zeta^ {k} + \zeta , z - \zeta^ {k} + \zeta^ {2}, \dots , z - \zeta^ {k} + \zeta^ {n}
$$

是一个正 n 边形的顶点，故

$$
\sum_ {j = 1} ^ {n} f (z - \zeta^ {k} + \zeta^ {j}) = 0
$$

将这 n 个等式相加。在二重求和中，对每个 k 令 $j \equiv k + m { \pmod { n } }$ ，则

$$
0 = \sum_ {k = 1} ^ {n} \sum_ {j = 1} ^ {n} f (z - \zeta^ {k} + \zeta^ {j}) = \sum_ {m = 1} ^ {n} \sum_ {k = 1} ^ {n} f (z - (1 - \zeta^ {m}) \zeta^ {k})
$$

当 $1 \leqslant m \leqslant n - 1$ 时， $1 - \zeta ^ { m } \neq 0$ ，所以点 $z - ( 1 - \zeta ^ { m } ) \zeta ^ { k } \ ( k = 1 , 2 , \cdots , n )$ 构成一个以 z 为中心的正 n 边形，相应的内层和等于 0。当 $m = n$ 时， $\zeta ^ { n } = 1$ ，相应的内层和为 $n f ( z )$ 。因此上式给出 $n f ( z ) = 0$ ，从而 $f ( z ) = 0$ 。由于 z 是任意点，故 f 是零函数。

在平面上的每个点 X 处都标有一个实数 f(X)。已知对于任意非退化三角形 $\triangle A B C$ ，若I 是其内心，则

$$
f (I) = \frac {f (A) + f (B) + f (C)}{3}
$$

证明平面上所有点处所标的数都相等。

解

先证明一个辅助结论。设 ABCD 是一个两底不等的等腰梯形，其中 $A B \parallel C D$ ，则

$$
f (A) + f (C) = f (B) + f (D)
$$

事实上，设两腰所在直线 AD,BC 交于点 X，该等腰梯形的对称轴为 ℓ。关于直线 ℓ 的反射把 $\triangle X A C$ 变为 $\triangle X B D$ 。设 I 是 $\triangle X A C$ 的内心。由于 ℓ 平分 $\angle A X C$ ，所以 $I \in \ell$ ，从而点I 在上述反射下保持不动，故 I 也是 $\triangle X B D$ 的内心。由题设，

$$
\frac {f (X) + f (A) + f (C)}{3} = f (I) = \frac {f (X) + f (B) + f (D)}{3}
$$

消去公共项，便得到所证的辅助结论。

任取平面上两个不同的点 $A _ { 1 } , A _ { 2 }$ ，以 $A _ { 1 } A _ { 2 }$ 为边作正五边形 $A _ { 1 } A _ { 2 } A _ { 3 } A _ { 4 } A _ { 5 }$ ，并记 $a _ { i } =$ $f ( A _ { i } )$ 。正五边形的每条边均平行于与它不相交的那条对角线，因此 $A _ { 1 } A _ { 3 } A _ { 4 } A _ { 5 }$ 与 $A _ { 3 } A _ { 4 } A _ { 5 } A _ { 2 }$ 都是两底不等的等腰梯形。对它们分别应用上述辅助结论，得到

$$
a _ {1} + a _ {4} = a _ {3} + a _ {5}, \qquad a _ {3} + a _ {5} = a _ {4} + a _ {2}
$$

所以 $a _ { 1 } = a _ { 2 }$ ，即 $f ( A _ { 1 } ) = f ( A _ { 2 } )$ 。由于 $A _ { 1 } , A _ { 2 }$ 是任意两个不同的平面点，故平面上所有点处所标的数都相等。
