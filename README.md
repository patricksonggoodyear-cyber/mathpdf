# mathpdf

**用途只有一个：上传材料，然后把原文链接交给 AI。**

## 上传

打开 [materials/](https://github.com/patricksonggoodyear-cyber/mathpdf/tree/main/materials)，点击 **Add file → Upload files**，可以一次拖入多份文件，然后提交。

不需要改文件名、不需要分类、不需要按板块拆分、不需要添加 YAML 或 Markdown 模板。PDF、Markdown、图片及其他附件都可以直接上传。

## 给 AI

- [AI 阅读说明与材料索引入口](https://github.com/patricksonggoodyear-cyber/mathpdf/blob/main/llms.txt)
- [网页材料列表](https://patricksonggoodyear-cyber.github.io/mathpdf/)
- 每个文件的「AI 原文」使用 GitHub Raw 地址，直接读取源文件。

## 注意

这是公开仓库。上传的文件和原文链接对所有人公开。AI 是否能直接解析某种文件格式，取决于使用的模型；无法解析时，直接把文件上传到对话中。
